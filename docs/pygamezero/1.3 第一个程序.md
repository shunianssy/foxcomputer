# 1.3 第一个程序

让我们创建第一个 Pygame Zero 程序，体验游戏开发的乐趣。

## 创建项目

### 1. 创建项目目录

```bash
# Windows PowerShell
mkdir hello_pygamezero
cd hello_pygamezero

# Linux/macOS
mkdir hello_pygamezero && cd hello_pygamezero
```

### 2. 创建主程序文件

创建文件 `main.py`：

```python
# 导入 Pygame Zero
import pgzrun

# 设置窗口大小
WIDTH = 800
HEIGHT = 600

# 设置窗口标题
TITLE = "我的第一个 Pygame Zero 游戏"

# 绘制函数 - 每秒调用 60 次
def draw():
 # 填充背景为白色
 screen.fill((255, 255, 255))
 
 # 绘制文字
 screen.draw.text("Hello, Pygame Zero!", (300, 280), fontsize=40)
 screen.draw.text("按任意键退出", (350, 350), fontsize=20)

```

### 3. 运行程序

```bash
pgzrun main.py
```

你应该看到一个白色窗口，显示 "Hello, Pygame Zero!" 文字。

## 程序解析

### 导入语句

```python
import pgzrun
```

这行代码导入了 Pygame Zero 库，它是所有 Pygame Zero 程序的起点。

### 窗口设置

```python
WIDTH = 800 # 窗口宽度（像素）
HEIGHT = 600 # 窗口高度（像素）
TITLE = "我的第一个 Pygame Zero 游戏" # 窗口标题
```

这些全局变量定义了游戏窗口的属性。

### 绘制函数

```python
def draw():
 screen.fill((255, 255, 255))
 screen.draw.text("Hello, Pygame Zero!", (300, 280), fontsize=40)
```

`draw()` 函数是 Pygame Zero 的核心函数之一：

- 每秒调用 60 次
- 负责绘制所有游戏元素
- 必须清空屏幕（`screen.fill()`）

### 启动游戏

```python
pgzrun.go()
```

这行代码启动游戏循环，开始运行游戏。

## 增强版本

让我们添加更多功能：

```python
import pgzrun

WIDTH = 800
HEIGHT = 600
TITLE = "增强版 Pygame Zero 程序"

# 定义颜色
WHITE = (255, 255, 255)
RED = (255, 0, 0)
GREEN = (0, 255, 0)
BLUE = (0, 0, 255)

# 圆形的位置和大小
circle_x = 400
circle_y = 300
circle_radius = 50

def draw():
 # 填充背景
 screen.fill(WHITE)
 
 # 绘制圆形
 screen.draw.circle((circle_x, circle_y), circle_radius, RED)
 
 # 绘制矩形
 screen.draw.rect(Rect(100, 100, 100, 100), GREEN)
 
 # 绘制线条
 screen.draw.line((600, 100), (700, 200), BLUE, 5)
 
 # 绘制文字
 screen.draw.text("按方向键移动圆形", (300, 500), fontsize=20)

def update():
 # 全局变量声明
 global circle_x, circle_y
 
 # 键盘控制
 if keyboard.left:
 circle_x -= 5
 if keyboard.right:
 circle_x += 5
 if keyboard.up:
 circle_y -= 5
 if keyboard.down:
 circle_y += 5
 
 # 边界检测
 if circle_x < circle_radius:
 circle_x = circle_radius
 if circle_x > WIDTH - circle_radius:
 circle_x = WIDTH - circle_radius
 if circle_y < circle_radius:
 circle_y = circle_radius
 if circle_y > HEIGHT - circle_radius:
 circle_y = HEIGHT - circle_radius

pgzrun.go()
```

## 新增功能解析

### update() 函数

```python
def update():
 global circle_x, circle_y
 if keyboard.left:
 circle_x -= 5
```

`update()` 函数处理游戏逻辑：

- 每秒调用 60 次
- 处理输入、移动、碰撞等
- 不负责绘制画面

### 键盘输入

```python
if keyboard.left:
 circle_x -= 5
```

`keyboard` 对象提供键盘输入检测：

- `keyboard.left`: 左箭头键
- `keyboard.right`: 右箭头键
- `keyboard.up`: 上箭头键
- `keyboard.down`: 下箭头键
- `keyboard.a`: A 键
- `keyboard.space`: 空格键

### 全局变量

```python
global circle_x, circle_y
```

在函数中修改全局变量需要使用 `global` 关键字。

## 完整游戏示例

让我们创建一个简单的小游戏：

```python
import pgzrun
import random

WIDTH = 800
HEIGHT = 600
TITLE = "接球游戏"

# 玩家（挡板）
paddle_x = 350
paddle_y = 550
paddle_width = 100
paddle_height = 20

# 球
ball_x = 400
ball_y = 300
ball_radius = 15
ball_speed_x = 5
ball_speed_y = 5

# 分数
score = 0

def draw():
 # 背景
 screen.fill((0, 0, 0))
 
 # 绘制挡板
 screen.draw.rect(Rect(paddle_x, paddle_y, paddle_width, paddle_height), (0, 255, 0))
 
 # 绘制球
 screen.draw.circle((ball_x, ball_y), ball_radius, (255, 0, 0))
 
 # 显示分数
 screen.draw.text(f"分数: {score}", (10, 10), fontsize=30, color=(255, 255, 255))

def update():
 global ball_x, ball_y, ball_speed_x, ball_speed_y, score
 
 # 移动球
 ball_x += ball_speed_x
 ball_y += ball_speed_y
 
 # 墙壁碰撞
 if ball_x <= ball_radius or ball_x >= WIDTH - ball_radius:
 ball_speed_x *= -1
 if ball_y <= ball_radius:
 ball_speed_y *= -1
 
 # 挡板碰撞
 if (paddle_x <= ball_x <= paddle_x + paddle_width and
 paddle_y <= ball_y + ball_radius <= paddle_y + paddle_height):
 ball_speed_y *= -1
 score += 1
 
 # 游戏结束
 if ball_y > HEIGHT:
 ball_x = 400
 ball_y = 300
 ball_speed_x = 5
 ball_speed_y = 5
 score = 0
 
 # 挡板移动
 if keyboard.left and paddle_x > 0:
 paddle_x -= 8
 if keyboard.right and paddle_x < WIDTH - paddle_width:
 paddle_x += 8

pgzrun.go()
```

## 运行游戏

```bash
pgzrun main.py
```

使用左右方向键控制挡板，接住下落的球。
