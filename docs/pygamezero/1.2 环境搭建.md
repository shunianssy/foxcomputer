# 1.2 环境搭建

在开始使用 Pygame Zero 之前，需要先安装 Python 和 Pygame Zero 库。

## 系统要求

### 最低要求

- **操作系统**: Windows 7+, macOS 10.12+, Linux
- **Python 版本**: Python 3.6 或更高版本
- **内存**: 至少 2GB RAM
- **磁盘空间**: 至少 500MB

### 推荐配置

- **操作系统**: Windows 10/11, macOS 11+, Ubuntu 20.04+
- **Python 版本**: Python 3.8 或更高版本
- **内存**: 4GB 或更多
- **磁盘空间**: 1GB 或更多

## 安装 Python

### Windows 系统

1. 访问 [Python 官网](https://www.python.org/downloads/)
2. 下载最新版本的 Python 安装程序（推荐 3.10 或 3.11）
3. 运行安装程序，**务必勾选 "Add Python to PATH"**
4. 点击 "Install Now" 完成安装

```powershell
# 验证 Python 安装
python --version

# 验证 pip 安装
pip --version
```

### macOS 系统

```bash
# 使用 Homebrew 安装
brew install python3

# 或者从官网下载安装包
# https://www.python.org/downloads/macos/
```

### Linux 系统

```bash
# Ubuntu/Debian
sudo apt update
sudo apt install python3 python3-pip

# Fedora
sudo dnf install python3 python3-pip

# Arch Linux
sudo pacman -S python python-pip
```

## 安装 Pygame Zero

### 使用 pip 安装（推荐）

```bash
# 安装 Pygame Zero
pip install pgzero

# 验证安装
python -m pgzero --version
```

### 从源码安装

```bash
# 克隆源码
git clone https://github.com/lordmauve/pgzero.git
cd pgzero

# 安装
pip install -e .
```

## 验证安装

创建一个测试文件 `test.py`：

```python
import pgzrun

WIDTH = 800
HEIGHT = 600

def draw():
    screen.fill((255, 255, 255))
    screen.draw.text("Pygame Zero 安装成功！", (200, 300))

pgzrun.go()
```

运行测试：

```bash
pgzrun test.py
```

如果看到窗口显示文字，说明安装成功。

## 开发环境配置

### 使用 VS Code（推荐）

1. 安装 [Visual Studio Code](https://code.visualstudio.com/)
2. 安装 Python 扩展
   - 打开 VS Code
   - 点击左侧扩展图标
   - 搜索 "Python"
   - 安装 Microsoft 官方的 Python 扩展

3. 配置 Python 解释器
   - 按 `Ctrl+Shift+P` 打开命令面板
   - 输入 "Python: Select Interpreter"
   - 选择安装的 Python 版本

### 使用 PyCharm

1. 下载并安装 [PyCharm Community](https://www.jetbrains.com/pycharm/)
2. 创建新项目
3. 在项目设置中配置 Python 解释器

### 使用 IDLE（Python 自带）

```bash
# 直接运行
idle
```

## 项目结构

Pygame Zero 推荐的项目结构：

```
my_game/
├── images/          # 图片资源
│   ├── player.png
│   └── enemy.png
├── sounds/          # 声音资源
│   ├── jump.wav
│   └── music.mp3
├── main.py          # 主程序
└── README.md        # 说明文档
```

### 创建项目目录

```bash
# Windows PowerShell
mkdir my_game
cd my_game
mkdir images
mkdir sounds

# Linux/macOS
mkdir -p my_game/images my_game/sounds
cd my_game
```

## 常见问题

### 问题 1: pip 命令不存在

**解决方案**:

```bash
# Windows
python -m pip install pgzero

# Linux/macOS
python3 -m pip install pgzero
```

### 问题 2: 安装失败

**解决方案**:

```bash
# 升级 pip
python -m pip install --upgrade pip

# 使用国内镜像源
pip install pgzero -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 问题 3: 运行时找不到模块

**解决方案**:

```bash
# 确认安装位置
python -m pip show pgzero

# 重新安装
pip uninstall pgzero
pip install pgzero
```

### 问题 4: 中文显示问题

**解决方案**:

```python
# 在代码开头添加
import sys
import io
sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding='utf-8')
```
