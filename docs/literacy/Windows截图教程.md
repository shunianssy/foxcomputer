# 详细步骤

## 方法一：使用系统自带截图工具（推荐）

### Windows + Shift + S（最常用）
1. 同时按下 `Windows键 + Shift + S`
2. 屏幕变暗，出现截图工具栏
3. 选择截图模式：
   - 矩形截图：框选区域
   - 任意形状截图：自由绘制
   - 窗口截图：点击某个窗口
   - 全屏截图：截取整个屏幕
4. 截图自动保存到剪贴板，可粘贴使用

### 截图工具（Snipping Tool）
1. 按 `Windows键`，搜索"截图工具"
2. 打开后点击"新建"
3. 选择区域进行截图

## 方法二：使用快捷键

| 快捷键 | 功能 |
|--------|------|
| `Print Screen` | 截取全屏到剪贴板 |
| `Alt + Print Screen` | 截取当前窗口到剪贴板 |
| `Windows + Print Screen` | 截取全屏并保存到图片文件夹 |

## 方法三：使用第三方截图软件

### 推荐软件：
- **Snipaste**（免费，强烈推荐）: https://www.snipaste.com/
- **ShareX**（免费开源）: https://getsharex.com/

### Snipaste使用方法：
1. 按 `F1` 开始截图
2. 框选区域
3. 按 `F3` 将截图固定在屏幕上（贴图功能）
4. 支持标注、马赛克等功能

## 截图保存位置

使用 `Windows + Print Screen` 截图的图片保存在：
```
C:\Users\你的用户名\Pictures\Screenshots
```
或
```
此电脑 > 图片 > 屏幕截图
```
