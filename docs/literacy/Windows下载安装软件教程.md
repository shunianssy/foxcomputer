# 详细步骤

## 第一步：下载软件

### 从官网下载（推荐）
1. 打开浏览器
2. 搜索软件名称 + "官网"（如"微信官网"）
3. 进入官方网站
4. 找到"下载"按钮
5. 选择Windows版本
6. 点击下载

### 常用软件官网
| 软件 | 官网地址 |
|------|----------|
| 微信 | https://pc.weixin.qq.com/ |
| QQ | https://im.qq.com/pcqq/index.shtml |
| Chrome浏览器 | https://www.google.com/chrome/ |
| Edge浏览器 | https://www.microsoft.com/edge |
| 7-Zip | https://www.7-zip.org/ |
| VS Code | https://code.visualstudio.com/ |

### ⚠️ 注意事项
- 一定要从官网或正规渠道下载
- 不要点击广告中的下载按钮
- 注意区分"下载"按钮和广告

## 第二步：找到下载的文件

1. 打开浏览器下载列表（Chrome按 `Ctrl + J`）
2. 或打开"下载"文件夹
   - 通常在 `C:\Users\你的用户名\Downloads`

## 第三步：安装软件

### 安装包格式
- `.exe` - 最常见的安装程序
- `.msi` - Windows安装包
- `.zip` - 需要先解压

### 安装步骤
1. 双击安装包
2. 如果出现安全提示，点击"运行"或"是"
3. 阅读许可协议，点击"我同意"
4. 选择安装位置（建议不要装在C盘）
5. 选择附加选项（注意取消勾选不需要的捆绑软件）
6. 点击"安装"
7. 等待安装完成
8. 点击"完成"

## ⚠️ 安装时的注意事项

### 1. 安装位置
- 默认通常在 `C:\Program Files`
- 建议改为其他盘，如 `D:\Program Files`

### 2. 捆绑软件
- 安装时仔细看每一步
- 取消勾选不需要的额外软件
- 选择"自定义安装"可以看到更多选项

### 3. 开机自启
- 很多软件会默认开机自启
- 可以在安装时或软件设置中关闭

## 卸载软件

1. 打开"设置" > "应用" > "已安装的应用"
2. 找到要卸载的软件
3. 点击"..." > "卸载"
4. 按提示完成卸载

或者：
1. 打开"控制面板" > "程序" > "程序和功能"
2. 右键点击软件
3. 选择"卸载"
