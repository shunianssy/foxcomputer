# 详细步骤

## 方法一：使用快捷键（推荐）

### 复制
1. 选中要复制的内容（文字、文件等）
2. 按下 `Ctrl + C`
3. 内容已复制到剪贴板

### 粘贴
1. 将光标移动到要粘贴的位置
2. 按下 `Ctrl + V`
3. 内容已粘贴

### 剪切（移动）
1. 选中要移动的内容
2. 按下 `Ctrl + X`
3. 到目标位置按 `Ctrl + V` 粘贴

## 方法二：使用鼠标右键

1. 选中内容
2. 右键点击
3. 选择"复制"或"粘贴"

## 方法三：使用菜单

在大多数软件中：
- 点击"编辑"菜单
- 选择"复制"或"粘贴"

## 常用快捷键速查表

| 操作 | 快捷键 |
|------|--------|
| 复制 | `Ctrl + C` |
| 粘贴 | `Ctrl + V` |
| 剪切 | `Ctrl + X` |
| 全选 | `Ctrl + A` |
| 撤销 | `Ctrl + Z` |
| 重做 | `Ctrl + Y` |

## 复制文件/文件夹

1. 选中文件或文件夹
2. 按 `Ctrl + C` 复制
3. 进入目标文件夹
4. 按 `Ctrl + V` 粘贴

## 小技巧

- **连续粘贴**：剪贴板内容可以多次粘贴
- **Windows剪贴板历史**：按 `Windows + V` 可查看历史复制记录（需先开启）
  - 开启方法：设置 > 系统 > 剪贴板 > 剪贴板历史记录
