# 详细步骤

## 方法一：使用系统自带功能（Windows 11）

1. 找到需要解压的压缩文件（通常是 .zip 格式）
2. 右键点击该文件
3. 选择"全部提取"
4. 选择解压位置，点击"提取"
5. 完成！

## 方法二：使用解压软件

### 推荐软件：
- **7-Zip**（免费开源，推荐）: https://www.7-zip.org/
- **Bandizip**（免费版）: https://en.bandisoft.com/bandizip/
- **WinRAR**（付费软件，有免费试用）: https://www.rarlab.com/

### 使用步骤：
1. 先下载并安装解压软件
2. 右键点击压缩文件
3. 选择解压选项（如"解压到当前文件夹"或"解压到指定文件夹"）
4. 等待解压完成

## 常见压缩格式

| 格式 | 说明 |
|------|------|
| .zip | 最常见格式，Windows自带支持 |
| .rar | 需要安装WinRAR或Bandizip |
| .7z | 需要安装7-Zip或Bandizip |
