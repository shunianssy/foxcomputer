# 详细步骤

## 方法一：右键菜单（最常用）

1. 在桌面或文件资源管理器中空白处右键
2. 选择"新建" > "文件夹"
3. 输入文件夹名称
4. 按 `Enter` 键确认

## 方法二：使用快捷键

1. 在文件资源管理器中
2. 按 `Ctrl + Shift + N`
3. 输入文件夹名称
4. 按 `Enter` 键确认

## 方法三：使用工具栏按钮

1. 打开文件资源管理器
2. 点击顶部"主页"选项卡
3. 点击"新建文件夹"按钮

## 方法四：在保存文件时创建

当保存文件时：
1. 在保存对话框中点击"新建文件夹"按钮
2. 输入名称
3. 双击进入新文件夹
4. 保存文件

## 文件夹命名规则

### 可以使用：
- 中英文字符
- 数字
- 下划线 `_`
- 连字符 `-`
- 空格

### 不能使用：
- `\` `/` `:` `*` `?` `"` `<` `>` `|`

### 命名建议：
- 使用有意义的名称，便于查找
- 避免名称过长
- 建议用日期开头，如：`2024-01-工作文件`

## 重命名文件夹

1. 选中文件夹
2. 按 `F2` 键
3. 输入新名称
4. 按 `Enter` 确认

或者：
1. 右键点击文件夹
2. 选择"重命名"
3. 输入新名称

## 删除文件夹

1. 选中文件夹
2. 按 `Delete` 键（移到回收站）
3. 或按 `Shift + Delete`（永久删除，谨慎使用！）
