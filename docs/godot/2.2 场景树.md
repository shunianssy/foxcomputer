# 2.2 场景树

## 🌲 什么是场景树？

场景树（SceneTree）是 Godot 中管理所有节点的层级结构。它决定了节点之间的父子关系，以及节点的生命周期和更新顺序。

```
场景树结构：
Root (Viewport)
└── Main (Node2D)
 ├── Player (CharacterBody2D)
 │ ├── Sprite2D
 │ └── CollisionShape2D
 ├── Enemies (Node2D)
 │ ├── Enemy1
 │ └── Enemy2
 └── UI (CanvasLayer)
 ├── ScoreLabel
 └── HealthBar
```

## 🏗 场景的概念

### 场景的定义

场景是一个独立的、可复用的节点集合，通常保存为 `.tscn` 文件：

- **根节点**：场景的入口节点
- **子节点**：组成场景的各个元素
- **脚本**：控制场景行为的代码

### 场景的类型

| 类型 | 说明 | 示例 |
|------|------|------|
| 完整场景 | 包含所有游戏元素 | 主游戏场景 |
| 预制体 | 可复用的游戏对象 | 玩家、敌人、道具 |
| UI 场景 | 用户界面组件 | 菜单、HUD |
| 管理器 | 游戏逻辑管理 | 游戏管理器、音频管理器 |

## 场景文件结构

### .tscn 文件格式

```ini
[gd_scene load_steps=3 format=3 uid="1"]

[ext_resource type="Script" path="res://scripts/player.gd" id="1"]
[ext_resource type="Texture2D" path="res://assets/player.png" id="2"]

[node name="Player" type="CharacterBody2D"]
script = ExtResource("1")

[node name="Sprite2D" type="Sprite2D" parent="."]
texture = ExtResource("2")

[node name="CollisionShape2D" type="CollisionShape2D" parent="."]
```

### 场景资源管理

```text
场景引用的资源：
├── 外部资源 (ext_resource)
│ ├── 脚本文件
│ ├── 图片纹理
│ ├── 音频文件
│ └── 其他场景
└── 内部资源 (sub_resource)
 ├── 材质
 ├── 动画
 └── 碰撞形状
```

## 场景树操作

### 访问场景树

```gdscript
# 获取场景树引用
var tree = get_tree()

# 获取根节点
var root = tree.root

# 获取当前场景
var current_scene = tree.current_scene

# 获取所有节点
var all_nodes = tree.get_nodes_in_group("enemies")
```

### 场景切换

```gdscript
# 切换到新场景
func change_level(level_path: String):
 get_tree().change_scene_to_file(level_path)

# 重新加载当前场景
func restart():
 get_tree().reload_current_scene()

# 切换到场景资源
func change_to_scene(scene: PackedScene):
 get_tree().change_scene_to_packed(scene)
```

### 暂停游戏

```gdscript
# 暂停游戏
func pause_game():
 get_tree().paused = true

# 继续游戏
func resume_game():
 get_tree().paused = false

# 切换暂停状态
func toggle_pause():
 get_tree().paused = not get_tree().paused
```

## 场景实例化

### 预加载场景

```gdscript
# 在脚本顶部预加载（推荐用于常用场景）
const BulletScene = preload("res://scenes/bullet.tscn")

func shoot():
 var bullet = BulletScene.instantiate()
 add_child(bullet)
```

### 动态加载场景

```gdscript
# 运行时加载场景（适合大型资源）
func load_level_async(level_path: String):
 ResourceLoader.load_threaded_request(level_path)
 
 # 等待加载完成
 while ResourceLoader.load_threaded_get_status(level_path) != ResourceLoader.THREAD_LOAD_LOADED:
 await get_tree().process_frame
 
 var scene = ResourceLoader.load_threaded_get(level_path)
 get_tree().change_scene_to_packed(scene)
```

### 实例化示例

```gdscript
# 完整的实例化流程
const EnemyScene = preload("res://scenes/enemy.tscn")

func spawn_enemy(position: Vector2):
 # 实例化场景
 var enemy = EnemyScene.instantiate()
 
 # 设置属性
 enemy.global_position = position
 enemy.health = 100
 
 # 添加到场景树
 get_parent().add_child(enemy)
 
 # 或者添加到特定节点
 $Enemies.add_child(enemy)
```

## 场景树遍历

### 遍历子节点

```gdscript
# 遍历直接子节点
for child in get_children():
 print(child.name)

# 递归遍历所有后代
func traverse_tree(node: Node, depth: int = 0):
 var indent = " ".repeat(depth)
 print(indent + node.name)
 for child in get_children():
 traverse_tree(child, depth + 1)
```

### 查找节点

```gdscript
# 通过名称查找
var player = get_node("Player")
var player = get_node("Enemies/Enemy1") # 路径查找

# 使用 find_child（递归查找）
var sprite = find_child("Sprite2D")

# 通过组查找
var enemies = get_tree().get_nodes_in_group("enemies")

# 通过类型查找
func find_node_by_type(node: Node, type: String) -> Node:
 for child in node.get_children():
 if child.is_class(type):
 return child
 var found = find_node_by_type(child, type)
 if found:
 return found
 return null
```

## 节点组

### 创建和使用组

```gdscript
# 添加到组
add_to_group("enemies")
add_to_group("damageable")

# 从组中移除
remove_from_group("enemies")

# 检查是否在组中
if is_in_group("enemies"):
 print("这是一个敌人")

# 获取组中所有节点
var enemies = get_tree().get_nodes_in_group("enemies")
for enemy in enemies:
 enemy.take_damage(10)

# 通知组中所有节点
get_tree().call_group("enemies", "take_damage", 10)
```

### 组的应用场景

```gdscript
# 敌人组
func kill_all_enemies():
 get_tree().call_group("enemies", "die")

# 可交互对象组
func highlight_interactables():
 for obj in get_tree().get_nodes_in_group("interactable"):
 obj.highlight()

# 存档系统
func save_game():
 var save_data = []
 for node in get_tree().get_nodes_in_group("saveable"):
 save_data.append(node.save())
 return save_data
```

## 父子节点通信

### 从子节点访问父节点

```gdscript
# 获取直接父节点
var parent = get_parent()

# 获取特定类型的父节点
func get_parent_of_type(node: Node, type: String):
 var current = node.get_parent()
 while current:
 if current.is_class(type):
 return current
 current = current.get_parent()
 return null

# 使用示例
var player = get_parent_of_type(self, "Player")
```

### 从父节点访问子节点

```gdscript
# 直接访问
var sprite = $Sprite2D
var health_bar = $UI/HealthBar

# 动态访问
var child_name = "Enemy" + str(index)
var enemy = get_node(child_name)

# 使用 @onready 缓存
@onready var sprite = $Sprite2D
@onready var collision = $CollisionShape2D
```

## 场景树信号

### 常用场景树信号

```gdscript
func _ready():
 # 连接场景树信号
 get_tree().tree_changed.connect(_on_tree_changed)
 get_tree().node_added.connect(_on_node_added)
 get_tree().node_removed.connect(_on_node_removed)

func _on_tree_changed():
 print("场景树结构改变")

func _on_node_added(node: Node):
 print("节点添加: ", node.name)

func _on_node_removed(node: Node):
 print("节点移除: ", node.name)
```

## 场景树组织最佳实践

### 推荐的场景结构

```
游戏项目结构：
├── scenes/
│ ├── levels/ # 关卡场景
│ │ ├── level_1.tscn
│ │ └── level_2.tscn
│ ├── actors/ # 角色/物体预制体
│ │ ├── player.tscn
│ │ ├── enemy.tscn
│ │ └── bullet.tscn
│ ├── ui/ # UI 场景
│ │ ├── main_menu.tscn
│ │ ├── pause_menu.tscn
│ │ └── hud.tscn
│ └── main.tscn # 主场景
├── scripts/
└── assets/
```

### 场景拆分原则

```text
何时创建新场景：
├── 需要复用的对象
├── 独立的游戏实体
├── 复杂的 UI 组件
└── 需要单独管理的系统

何时保持在同一场景：
├── 紧密耦合的组件
├── 简单的 UI 元素
└── 不会复用的独特元素
```
