# 1.1 为什么选择 Godot？

## 🎮 什么是 Godot？

Godot 是一款免费、开源的游戏引擎，由 Juan Linietsky 和 Ariel Manzur 于 2007 年开始开发，2014 年正式开源。它采用 MIT 许可证，这意味着你可以完全免费地使用它开发商业游戏，无需支付任何费用或版税。

## ✨ Godot 的核心优势

### 1. 完全免费且开源

```text
✓ MIT 许可证 - 无需支付任何费用
✓ 源代码完全开放 - 可以自由修改
✓ 无版税 - 商业项目无需分成
✓ 无需账号注册 - 下载即用
```

### 2. 轻量级设计

Godot 引擎本身非常小巧：

| 版本 | 大小（约） |
|------|-----------|
| 标准版 | 60-80 MB |
| .NET 版 | 80-100 MB |

相比之下，其他主流引擎通常需要数 GB 的安装空间。

### 3. 独特的节点系统

Godot 采用独特的节点（Node）和场景（Scene）架构：

```
场景 (Scene)
├── Node2D (根节点)
│   ├── Sprite (精灵节点)
│   ├── CollisionShape2D (碰撞形状)
│   └── Camera2D (相机节点)
```

这种设计使得：
- 游戏对象可以灵活组合
- 代码复用性极高
- 项目结构清晰明了

### 4. 多语言支持

Godot 支持多种编程语言：

| 语言 | 特点 | 适用场景 |
|------|------|----------|
| GDScript | 官方语言，语法简洁 | 大多数游戏开发 |
| C# | 性能优秀，生态丰富 | 需要高性能的项目 |
| C++ | 通过 GDExtension | 底层扩展开发 |

### 5. 强大的跨平台能力

一次开发，多平台发布：

```
支持的导出平台：
├── 桌面端
│   ├── Windows
│   ├── macOS
│   └── Linux
├── 移动端
│   ├── Android
│   └── iOS
├── Web
│   └── HTML5/WebAssembly
└── 主机平台
    ├── PlayStation
    ├── Xbox
    └── Nintendo Switch
```

## 🆚 与其他引擎对比

### Godot vs Unity

| 特性 | Godot | Unity |
|------|-------|-------|
| 许可证 | MIT（完全免费） | 个人版免费，有收入限制 |
| 安装大小 | ~80 MB | ~3 GB |
| 源码访问 | 完全开放 | 不开放 |
| 2D 支持 | 原生 2D 引擎 | 3D 引擎模拟 2D |
| 学习曲线 | 相对平缓 | 较陡峭 |

### Godot vs Unreal Engine

| 特性 | Godot | Unreal |
|------|-------|--------|
| 许可证 | MIT（完全免费） | 免费但有版税 |
| 安装大小 | ~80 MB | ~40 GB |
| 系统要求 | 低配置即可运行 | 需要较高配置 |
| 3D 画质 | 良好 | 顶级 |
| 适用项目 | 中小型项目 | 大型 3A 项目 |

## 🎯 Godot 适合谁？

### 适合使用 Godot 的开发者：

- **独立游戏开发者**：免费、轻量、功能完整
- **游戏开发初学者**：学习曲线平缓，文档友好
- **2D 游戏开发者**：原生 2D 支持，功能强大
- **开源爱好者**：可以参与引擎开发
- **教育机构**：无需授权费用，适合教学

### 可能不太适合的场景：

- 大型 3A 游戏项目（考虑 Unreal）
- 需要大量现成资源商店的项目
- 团队协作的大型项目（Godot 的协作工具相对较少）

## 💡 小结

选择 Godot 的理由：

1. **零成本**：完全免费，无任何隐藏费用
2. **轻量高效**：小巧的体积，快速的启动
3. **易于学习**：直观的界面和友好的文档
4. **灵活强大**：节点系统让一切皆可定制
5. **社区活跃**：不断增长的社区和资源
