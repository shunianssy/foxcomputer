# 2.1 节点系统

## 🌳 什么是节点？

节点（Node）是 Godot 中最基本的构建单元。每个节点都是一个独立的功能模块，可以提供特定的功能：

- **显示图像**：Sprite2D、TextureRect
- **播放声音**：AudioStreamPlayer
- **处理物理**：RigidBody2D、Area2D
- **接收输入**：Control 及其子类
- **组织结构**：Node、Node2D

## 📊 节点继承体系

Godot 的节点采用面向对象的继承体系：

```
Object（所有对象的基类）
└── Node（所有节点的基类）
    ├── Node2D（2D 节点基类）
    │   ├── Sprite2D（精灵）
    │   ├── Camera2D（相机）
    │   ├── CharacterBody2D（角色物理体）
    │   ├── StaticBody2D（静态物理体）
    │   └── Area2D（区域检测）
    ├── Node3D（3D 节点基类）
    │   ├── MeshInstance3D（网格实例）
    │   ├── Camera3D（3D 相机）
    │   └── Light3D（灯光）
    ├── Control（UI 节点基类）
    │   ├── Button（按钮）
    │   ├── Label（文本标签）
    │   └── Panel（面板）
    └── AudioStreamPlayer（音频播放器）
```

## 🔧 常用节点类型

### 基础节点

| 节点类型 | 用途 | 主要属性 |
|----------|------|----------|
| Node | 最基础的节点 | name, process_mode |
| Node2D | 2D 节点基类 | position, rotation, scale |
| Node3D | 3D 节点基类 | position, rotation, scale |
| Control | UI 节点基类 | size, anchor, margin |

### 2D 游戏节点

| 节点类型 | 用途 | 特点 |
|----------|------|------|
| Sprite2D | 显示 2D 图像 | 支持纹理、区域裁剪 |
| AnimatedSprite2D | 播放帧动画 | 支持多动画切换 |
| CharacterBody2D | 可控制的角色 | 内置移动和碰撞处理 |
| StaticBody2D | 静态物理体 | 不会移动的障碍物 |
| RigidBody2D | 动态物理体 | 受物理引擎控制 |
| Area2D | 区域检测 | 检测进入/离开的物体 |
| Camera2D | 2D 相机 | 控制游戏视角 |
| TileMap | 瓦片地图 | 高效渲染重复元素 |

### 3D 游戏节点

| 节点类型 | 用途 | 特点 |
|----------|------|------|
| MeshInstance3D | 显示 3D 模型 | 支持各种网格格式 |
| Camera3D | 3D 相机 | 透视/正交投影 |
| DirectionalLight3D | 平行光 | 模拟太阳光 |
| PointLight3D | 点光源 | 模拟灯泡 |
| CharacterBody3D | 3D 角色控制器 | 3D 移动控制 |

### UI 节点

| 节点类型 | 用途 | 特点 |
|----------|------|------|
| Button | 按钮 | 支持点击、主题样式 |
| Label | 文本显示 | 支持富文本 |
| LineEdit | 单行输入 | 文本输入框 |
| ProgressBar | 进度条 | 显示进度 |
| TextureRect | 图像显示 | UI 中的图片 |

## 🎯 节点的生命周期

每个节点都有一系列生命周期回调函数：

```gdscript
extends Node

# 节点进入场景树时调用（只调用一次）
func _enter_tree():
    print("进入场景树")

# 节点准备就绪时调用（所有子节点都已加载）
func _ready():
    print("准备完成")

# 每帧调用（用于游戏逻辑）
func _process(delta):
    print("每帧更新: ", delta)

# 每物理帧调用（用于物理计算）
func _physics_process(delta):
    print("物理更新: ", delta)

# 节点离开场景树时调用
func _exit_tree():
    print("离开场景树")
```

### 生命周期图示

```
节点创建
    │
    ▼
_enter_tree() ──────► 进入场景树
    │
    ▼
_ready() ───────────► 初始化完成
    │
    ▼
_process() ─────────► 每帧循环
_physics_process() ─► 物理帧循环
    │
    ▼
_exit_tree() ───────► 离开场景树
    │
    ▼
节点销毁
```

## 🔄 处理模式

节点可以设置不同的处理模式：

```gdscript
# 在检查器中设置或通过代码
process_mode = Node.PROCESS_MODE_INHERIT  # 继承父节点
process_mode = Node.PROCESS_MODE_PAUSABLE # 可暂停
process_mode = Node.PROCESS_MODE_WHEN_PAUSED  # 暂停时运行
process_mode = Node.PROCESS_MODE_ALWAYS  # 始终运行
process_mode = Node.PROCESS_MODE_DISABLED # 禁用
```

### 处理模式说明

| 模式 | 说明 | 使用场景 |
|------|------|----------|
| Inherit | 继承父节点的模式 | 默认值 |
| Pausable | 游戏暂停时也暂停 | 大部分游戏对象 |
| When Paused | 游戏暂停时运行 | 暂停菜单 |
| Always | 始终运行 | 背景音乐 |
| Disabled | 完全禁用 | 不需要更新的节点 |

## 🏗️ 节点属性

### 变换属性（Node2D）

```gdscript
# 位置
position = Vector2(100, 200)

# 旋转（弧度）
rotation = PI / 4  # 45度

# 缩放
scale = Vector2(2, 2)

# 全局变换
global_position = Vector2(300, 400)
global_rotation = 0
global_scale = Vector2(1, 1)
```

### 常用属性

```gdscript
# 节点名称
name = "Player"

# 是否可见
visible = true

# 层级顺序（z_index）
z_index = 10

# 鼠标响应
mouse_filter = Control.MOUSE_FILTER_IGNORE
```

## 🎮 节点操作

### 获取节点引用

```gdscript
# 通过路径获取
var sprite = get_node("Sprite2D")
var sprite = $Sprite2D  # 简写形式

# 通过类型获取
var sprites = get_children()

# 获取父节点
var parent = get_parent()

# 获取根节点
var root = get_tree().root

# 查找节点
var node = find_child("Sprite2D")
```

### 动态创建节点

```gdscript
func _ready():
    # 创建新节点
    var sprite = Sprite2D.new()
    
    # 设置属性
    sprite.name = "NewSprite"
    sprite.position = Vector2(100, 100)
    
    # 添加到场景树
    add_child(sprite)
```

### 删除节点

```gdscript
# 队列删除（推荐，安全）
queue_free()

# 立即删除（危险）
free()

# 从父节点移除
get_parent().remove_child(self)
```

## 📐 节点坐标系统

### 本地坐标 vs 全局坐标

```gdscript
# 本地坐标（相对于父节点）
position = Vector2(50, 50)

# 全局坐标（相对于场景根节点）
global_position = Vector2(150, 150)

# 坐标转换
var local_pos = to_local(global_pos)
var global_pos = to_global(local_pos)
```

### 坐标转换示例

```gdscript
# 将屏幕坐标转换为本地坐标
func _input(event):
    if event is InputEventMouseButton:
        var local_pos = to_local(event.position)
        print("本地坐标: ", local_pos)
```

## 💡 最佳实践

### 节点命名规范

```text
推荐命名：
├── Player（大驼峰，角色类）
├── EnemySpawner（大驼峰，功能类）
├── ground_tile（下划线，资源类）
└── UI/Canvas（大驼峰，组织类）

避免命名：
├── node1、node2（无意义数字）
├── sprite（小写，不清晰）
└── @node（特殊字符）
```

### 节点组织建议

```
场景结构建议：
├── 根节点（控制整体逻辑）
│   ├── 视觉节点（Sprite、Mesh）
│   ├── 物理节点（Collision、Body）
│   ├── 音效节点（AudioPlayer）
│   └── 子场景实例
```

### 性能优化

```gdscript
# 缓存节点引用（避免重复 get_node）
@onready var sprite = $Sprite2D

# 禁用不需要的处理
set_process(false)
set_physics_process(false)

# 使用对象池
var bullet_pool = []

func get_bullet():
    for bullet in bullet_pool:
        if not bullet.visible:
            return bullet
    # 池中没有可用对象，创建新的
    var new_bullet = Bullet.instantiate()
    bullet_pool.append(new_bullet)
    return new_bullet
```
