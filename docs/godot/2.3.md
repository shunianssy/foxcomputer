# 2.3 常用节点

## 🎨 2D 显示节点

### Sprite2D - 精灵节点

Sprite2D 用于显示 2D 图像，是最常用的显示节点之一。

```gdscript
extends Sprite2D

func _ready():
    # 设置纹理
    texture = load("res://assets/player.png")
    
    # 设置显示区域（精灵图集）
    region_enabled = true
    region_rect = Rect2(0, 0, 32, 32)
    
    # 设置锚点和偏移
    centered = true
    offset = Vector2(0, 0)
    
    # 翻转
    flip_h = false  # 水平翻转
    flip_v = false  # 垂直翻转
    
    # 调制颜色
    modulate = Color(1, 1, 1, 1)  # RGBA
    
    # 混合模式
    material = ShaderMaterial.new()
```

### AnimatedSprite2D - 动画精灵

用于播放帧动画，适合角色动画。

```gdscript
extends AnimatedSprite2D

func _ready():
    # 播放动画
    play("idle")
    
    # 动画完成信号
    animation_finished.connect(_on_animation_finished)

func _on_animation_finished():
    if animation == "attack":
        play("idle")

func move():
    if animation != "walk":
        play("walk")

func attack():
    play("attack")
```

### 设置 SpriteFrames

```text
1. 选中 AnimatedSprite2D 节点
2. 在检查器中点击 Frames 属性
3. 选择 "新建 SpriteFrames"
4. 点击编辑 SpriteFrames
5. 添加动画并添加帧图片
```

## 🎥 相机节点

### Camera2D - 2D 相机

```gdscript
extends Camera2D

func _ready():
    # 设置跟随目标
    # 通常在编辑器中设置 offset 属性
    
    # 平滑跟随
    position_smoothing_enabled = true
    position_smoothing_speed = 5.0
    
    # 缩放
    zoom = Vector2(1.5, 1.5)
    
    # 限制相机边界
    limit_left = 0
    limit_right = 1920
    limit_top = 0
    limit_bottom = 1080
    
    # 相机抖动
    func shake(intensity: float, duration: float):
        var tween = create_tween()
        for i in range(int(duration * 30)):
            var offset = Vector2(
                randf_range(-intensity, intensity),
                randf_range(-intensity, intensity)
            )
            tween.tween_property(self, "offset", offset, 0.033)
        tween.tween_property(self, "offset", Vector2.ZERO, 0.033)
```

## 💥 物理节点

### CharacterBody2D - 角色物理体

```gdscript
extends CharacterBody2D

# 移动速度
@export var speed: float = 300.0
@export var jump_force: float = 400.0

# 重力
var gravity = ProjectSettings.get_setting("physics/2d/default_gravity")

func _physics_process(delta):
    # 应用重力
    if not is_on_floor():
        velocity.y += gravity * delta
    
    # 移动输入
    var direction = Input.get_axis("move_left", "move_right")
    velocity.x = direction * speed
    
    # 跳跃
    if Input.is_action_just_pressed("jump") and is_on_floor():
        velocity.y = -jump_force
    
    # 应用移动
    move_and_slide()
    
    # 检测碰撞
    for i in get_slide_collision_count():
        var collision = get_slide_collision(i)
        var collider = collision.get_collider()
        print("碰撞对象: ", collider.name)
```

### RigidBody2D - 刚体

```gdscript
extends RigidBody2D

func _ready():
    # 设置质量
    mass = 1.0
    
    # 设置重力缩放
    gravity_scale = 1.0
    
    # 线性速度
    linear_velocity = Vector2(100, 0)
    
    # 角速度
    angular_velocity = 0.0
    
    # 阻尼
    linear_damp = 0.1
    angular_damp = 1.0
    
    # 冻结模式
    freeze = false
    freeze_mode = RigidBody2D.FREEZE_MODE_STATIC

# 施加力
func apply_impulse_force():
    apply_impulse(Vector2(0, -500), Vector2.ZERO)

# 施加冲量
func apply_force_continuous():
    apply_force(Vector2(100, 0))
```

### Area2D - 区域检测

```gdscript
extends Area2D

func _ready():
    # 连接信号
    body_entered.connect(_on_body_entered)
    body_exited.connect(_on_body_exited)
    area_entered.connect(_on_area_entered)

func _on_body_entered(body):
    print("物体进入: ", body.name)
    if body.is_in_group("player"):
        body.take_damage(10)

func _on_body_exited(body):
    print("物体离开: ", body.name)

func _on_area_entered(area):
    print("区域进入: ", area.name)
```

## 🎮 输入节点

### Control - UI 基类

```gdscript
extends Control

func _ready():
    # 连接输入信号
    gui_input.connect(_on_gui_input)
    mouse_entered.connect(_on_mouse_entered)
    mouse_exited.connect(_on_mouse_exited)

func _on_gui_input(event):
    if event is InputEventMouseButton:
        if event.pressed:
            print("鼠标点击")
    elif event is InputEventMouseMotion:
        print("鼠标移动")

func _on_mouse_entered():
    print("鼠标进入")

func _on_mouse_exited():
    print("鼠标离开")
```

## 🔊 音频节点

### AudioStreamPlayer - 音频播放器

```gdscript
extends AudioStreamPlayer

func _ready():
    # 加载音频
    stream = load("res://assets/sounds/bgm.ogg")
    
    # 设置音量（分贝）
    volume_db = 0.0
    
    # 设置音高
    pitch_scale = 1.0
    
    # 循环播放
    stream.loop = true
    
    # 自动播放
    autoplay = true
    
    # 播放
    play()

func play_sound():
    if not playing:
        play()

func stop_sound():
    stop()

func fade_out(duration: float):
    var tween = create_tween()
    tween.tween_property(self, "volume_db", -40.0, duration)
    await tween.finished
    stop()
```

## 🎬 动画节点

### AnimationPlayer - 动画播放器

```gdscript
extends Node2D

@onready var animation_player = $AnimationPlayer

func _ready():
    # 播放动画
    animation_player.play("idle")
    
    # 连接信号
    animation_player.animation_finished.connect(_on_animation_finished)

func _on_animation_finished(anim_name):
    print("动画完成: ", anim_name)

func play_attack():
    animation_player.play("attack")

# 播放并等待完成
func play_and_wait(anim_name: String):
    animation_player.play(anim_name)
    await animation_player.animation_finished
```

### Tween - 补间动画

```gdscript
extends Node2D

func _ready():
    # 创建补间动画
    var tween = create_tween()
    
    # 属性动画
    tween.tween_property(self, "position", Vector2(100, 100), 1.0)
    
    # 链式调用
    tween.tween_property(self, "modulate", Color.RED, 0.5)
    tween.tween_property(self, "scale", Vector2(2, 2), 0.5)
    
    # 设置缓动类型
    tween.set_ease(Tween.EASE_IN_OUT)
    tween.set_trans(Tween.TRANS_ELASTIC)
    
    # 循环
    tween.set_loops(3)
    
    # 回调
    tween.tween_callback(func(): print("动画完成"))
    
    # 等待
    tween.tween_interval(1.0)
```

## 🗺️ 地图节点

### TileMap - 瓦片地图

```gdscript
extends TileMap

func _ready():
    # 设置单元格
    set_cell(0, Vector2i(0, 0), 0, Vector2i(0, 0))
    
    # 获取单元格
    var cell = get_cell_tile_data(0, Vector2i(0, 0))
    
    # 清除单元格
    erase_cell(0, Vector2i(0, 0))
    
    # 获取使用的单元格
    var used_cells = get_used_cells(0)

# 程序化生成地图
func generate_map(width: int, height: int):
    for x in range(width):
        for y in range(height):
            var tile_coords = Vector2i(randi() % 4, 0)
            set_cell(0, Vector2i(x, y), 0, tile_coords)
```

## 📊 节点对比表

| 用途 | 推荐节点 | 替代方案 |
|------|----------|----------|
| 显示静态图片 | Sprite2D | TextureRect |
| 播放帧动画 | AnimatedSprite2D | AnimationPlayer + Sprite2D |
| 玩家控制 | CharacterBody2D | RigidBody2D + 脚本 |
| 静态障碍物 | StaticBody2D | Area2D（仅检测） |
| 区域检测 | Area2D | RayCast2D |
| UI 按钮 | Button | TextureButton |
| 文本显示 | Label | RichTextLabel |
| 背景音乐 | AudioStreamPlayer | AudioStreamPlayer2D |
| 音效 | AudioStreamPlayer2D | AudioStreamPlayer |
| 地图 | TileMap | 手动放置 Sprite2D |
