# 3.3 生命周期函数

## 节点生命周期概述

每个节点从创建到销毁都会经历一系列的生命周期阶段。理解这些阶段对于正确编写游戏逻辑至关重要。

```
节点生命周期流程：

创建节点
 │
 ▼
_enter_tree() ────────► 节点进入场景树
 │
 ▼
_ready() ─────────────► 节点初始化完成
 │
 ▼
_process() ───────────► 每帧更新（循环）
_physics_process() ───► 物理帧更新（循环）
 │
 ▼
_exit_tree() ─────────► 节点离开场景树
 │
 ▼
节点销毁
```

## 🌳 _enter_tree()

当节点进入场景树时调用，可能被多次调用（如场景切换后重新进入）。

```gdscript
extends Node2D

func _enter_tree():
 # 节点刚进入场景树
 # 此时父节点已经设置，但子节点可能还未完全加载
 print("节点进入场景树: ", name)
 print("父节点: ", get_parent())
```

### 使用场景

```gdscript
func _enter_tree():
 # 初始化需要在场景树中的资源
 if get_parent():
 # 可以访问父节点
 pass
 
 # 注册全局信号
 if has_signal("tree_entered"):
 tree_entered.connect(_on_tree_entered)
```

## _ready()

当节点及其所有子节点都加载完成后调用，只调用一次。

```gdscript
extends CharacterBody2D

@onready var sprite = $Sprite2D
@onready var collision = $CollisionShape2D

func _ready():
 # 此时所有子节点都已加载
 # @onready 变量已初始化
 
 # 初始化角色状态
 health = max_health
 
 # 连接信号
 sprite.animation_finished.connect(_on_animation_finished)
 
 # 设置初始动画
 animation_player.play("idle")
 
 print("节点准备完成: ", name)
```

### _ready() 执行顺序

```
场景树结构：
Main
├── Player
│ ├── Sprite2D
│ └── CollisionShape2D
└── UI

_ready() 调用顺序：
1. Sprite2D._ready()
2. CollisionShape2D._ready()
3. Player._ready()
4. UI._ready()
5. Main._ready()

规则：子节点的 _ready() 先于父节点调用
```

### 延迟初始化

```gdscript
func _ready():
 # 延迟到下一帧执行
 call_deferred("_late_init")

func _late_init():
 # 此时所有节点的 _ready() 都已执行
 # 可以安全地访问其他节点
 var other = get_tree().get_first_node_in_group("enemy")
 if other:
 other.connect_signals()
```

## _process()

每帧调用一次，用于处理游戏逻辑。

```gdscript
extends Node2D

func _process(delta):
 # delta: 上一帧到这一帧的时间（秒）
 # 通常约 0.016 秒（60 FPS）
 
 # 更新位置
 position += velocity * delta
 
 # 更新计时器
 timer -= delta
 
 # 更新 UI
 update_ui()
```

### 帧率无关的动画

```gdscript
extends Sprite2D

var rotation_speed: float = 2.0 # 弧度/秒

func _process(delta):
 # 使用 delta 确保不同帧率下动画速度一致
 rotation += rotation_speed * delta
```

### 启用/禁用处理

```gdscript
func _ready():
 # 默认启用
 set_process(true)

func pause():
 set_process(false)

func resume():
 set_process(true)
```

## _physics_process()

在物理帧调用，固定时间步长，适合物理计算。

```gdscript
extends CharacterBody2D

func _physics_process(delta):
 # delta 通常是固定的（默认 1/60 秒）
 # 这使得物理模拟更稳定
 
 # 应用重力
 velocity.y += gravity * delta
 
 # 移动和碰撞检测
 move_and_slide()
 
 # 处理碰撞结果
 for i in get_slide_collision_count():
 var collision = get_slide_collision(i)
 handle_collision(collision)
```

### 物理帧 vs 游戏帧

```gdscript
extends Node

func _process(delta):
 # 游戏帧：每秒可能 30-144 次（取决于硬件）
 # 用于：UI 更新、非物理动画、输入响应
 print("游戏帧 delta: ", delta)

func _physics_process(delta):
 # 物理帧：固定频率（默认每秒 60 次）
 # 用于：物理模拟、碰撞检测、移动
 print("物理帧 delta: ", delta)
```

### 处理模式设置

```gdscript
func _ready():
 # 启用/禁用物理处理
 set_physics_process(true)
 
 # 设置处理模式
 process_mode = Node.PROCESS_MODE_PAUSABLE # 可暂停
 process_mode = Node.PROCESS_MODE_ALWAYS # 始终运行（暂停菜单）
 process_mode = Node.PROCESS_MODE_DISABLED # 禁用
```

## _exit_tree()

当节点离开场景树时调用。

```gdscript
extends Node2D

func _exit_tree():
 # 清理资源
 # 断开信号连接
 # 保存数据
 
 print("节点离开场景树: ", name)
 
 # 断开所有信号
 if is_connected("some_signal", _on_some_signal):
 disconnect("some_signal", _on_some_signal)
```

### 清理资源

```gdscript
extends Node

var timer: Timer
var external_reference: Node

func _ready():
 timer = Timer.new()
 add_child(timer)
 timer.timeout.connect(_on_timer_timeout)

func _exit_tree():
 # 停止计时器
 if timer:
 timer.stop()
 
 # 清理外部引用
 external_reference = null
 
 # 取消延迟调用
 # （节点销毁后延迟调用会失败）
```

## 其他生命周期回调

### _input()

接收输入事件，在 _process() 之前调用。

```gdscript
extends Node2D

func _input(event):
 # 处理输入事件
 if event is InputEventMouseButton:
 if event.pressed and event.button_index == MOUSE_BUTTON_LEFT:
 print("鼠标左键点击: ", event.position)
 
 elif event is InputEventKey:
 if event.pressed and event.keycode == KEY_SPACE:
 print("空格键按下")
```

### _unhandled_input()

处理未被 UI 消费的输入事件。

```gdscript
extends Node2D

func _unhandled_input(event):
 # 只处理未被 UI 消费的事件
 # 适合游戏操作输入
 
 if event is InputEventKey and event.pressed:
 match event.keycode:
 KEY_W, KEY_UP:
 move_up()
 KEY_S, KEY_DOWN:
 move_down()
 KEY_ESCAPE:
 pause_game()
```

### _unhandled_key_input()

专门处理键盘输入（优化版本）。

```gdscript
extends Node2D

func _unhandled_key_input(event):
 # 比 _unhandled_input 更高效
 # 只处理键盘事件
 
 if event.pressed:
 match event.keycode:
 KEY_SPACE:
 jump()
```

## 生命周期实战示例

### 完整的角色脚本

```gdscript
extends CharacterBody2D

# 信号
signal health_changed(new_health: int)
signal died

# 导出变量
@export var max_health: int = 100
@export var speed: float = 200.0
@export var jump_force: float = 400.0

# 节点引用
@onready var sprite = $Sprite2D
@onready var animation_player = $AnimationPlayer
@onready var collision = $CollisionShape2D

# 状态变量
var current_health: int
var is_alive: bool = true
var gravity: float

# 初始化（构造函数）
func _init():
 print("Player _init")

# 进入场景树
func _enter_tree():
 print("Player _enter_tree")

# 准备完成
func _ready():
 print("Player _ready")
 
 # 获取重力设置
 gravity = ProjectSettings.get_setting("physics/2d/default_gravity")
 
 # 初始化状态
 current_health = max_health
 
 # 连接信号
 animation_player.animation_finished.connect(_on_animation_finished)
 
 # 播放初始动画
 animation_player.play("idle")

# 物理更新
func _physics_process(delta):
 if not is_alive:
 return
 
 # 应用重力
 if not is_on_floor():
 velocity.y += gravity * delta
 
 # 处理输入
 handle_input()
 
 # 移动
 move_and_slide()
 
 # 更新动画
 update_animation()

# 处理输入
func handle_input():
 var direction = Input.get_axis("move_left", "move_right")
 velocity.x = direction * speed
 
 if Input.is_action_just_pressed("jump") and is_on_floor():
 velocity.y = -jump_force

# 更新动画
func update_animation():
 if velocity.x != 0:
 animation_player.play("walk")
 sprite.flip_h = velocity.x < 0
 else:
 animation_player.play("idle")

# 受伤
func take_damage(amount: int):
 if not is_alive:
 return
 
 current_health -= amount
 health_changed.emit(current_health)
 
 # 受伤动画
 animation_player.play("hurt")
 
 if current_health <= 0:
 die()

# 死亡
func die():
 is_alive = false
 died.emit()
 animation_player.play("death")

# 离开场景树
func _exit_tree():
 print("Player _exit_tree")
 
 # 清理
 animation_player.animation_finished.disconnect(_on_animation_finished)

# 动画完成回调
func _on_animation_finished(anim_name: String):
 if anim_name == "death":
 queue_free()
```

### 场景管理器示例

```gdscript
extends Node

# 场景管理器 - 展示生命周期使用

var current_scene: Node
var loading: bool = false

func _ready():
 # 获取当前场景
 var root = get_tree().root
 current_scene = root.get_child(root.get_child_count() - 1)

func _input(event):
 if event.is_action_pressed("ui_cancel"):
 toggle_pause()

func change_scene(scene_path: String):
 if loading:
 return
 
 loading = true
 
 # 清理当前场景
 if current_scene:
 current_scene._exit_tree() # 触发清理
 current_scene.queue_free()
 
 # 加载新场景
 var new_scene = load(scene_path)
 current_scene = new_scene.instantiate()
 
 # 添加到场景树
 get_tree().root.add_child(current_scene)
 get_tree().current_scene = current_scene
 
 loading = false

func toggle_pause():
 get_tree().paused = not get_tree().paused
```

## 生命周期调用顺序

```
完整调用顺序（每帧）：

1. _input() - 处理输入事件
2. _unhandled_input() - 处理未消费的输入
3. _process() - 游戏帧更新
4. _physics_process() - 物理帧更新（固定频率）

场景切换时：
1. 新场景._enter_tree()
2. 新场景._ready()
3. 旧场景._exit_tree()
```

## 最佳实践

### 选择正确的回调

```gdscript
# 使用 _ready() 初始化
func _ready():
 # 初始化变量
 # 连接信号
 # 设置初始状态
 pass

# 使用 _process() 处理非物理逻辑
func _process(delta):
 # UI 更新
 # 计时器
 # 非物理动画
 pass

# 使用 _physics_process() 处理物理
func _physics_process(delta):
 # 移动
 # 碰撞检测
 # 物理模拟
 pass

# 使用 _input() 处理输入
func _input(event):
 # 鼠标事件
 # 键盘事件
 # 触摸事件
 pass
```

### 避免常见错误

```gdscript
# 错误：在 _enter_tree 中访问子节点
func _enter_tree():
 # 子节点可能还未加载
 # $Sprite2D.texture = ... # 可能失败

# 正确：在 _ready 中访问子节点
func _ready():
 $Sprite2D.texture = load("res://icon.svg")

# 错误：忘记使用 delta
func _process(delta):
 position.x += 5 # 帧率相关，不稳定

# 正确：使用 delta
func _process(delta):
 position.x += 300 * delta # 帧率无关
```
