# 1.3 第一个项目

## 🎯 项目目标

我们将创建一个简单的"Hello World"项目，包含：

- 一个可移动的角色精灵
- 基本的键盘输入控制
- 简单的碰撞检测

## 📁 创建新项目

### 步骤 1：新建项目

1. 打开 Godot 项目管理器
2. 点击右侧的 **新建** 按钮
3. 填写项目信息：

```text
项目名称：HelloGodot
项目路径：选择一个合适的目录
渲染器：Forward+（推荐，适合大多数项目）
```

### 渲染器选择说明

| 渲染器 | 特点 | 适用场景 |
|--------|------|----------|
| Forward+ | 功能完整，支持高级特效 | 3D 游戏、复杂 2D |
| Mobile | 兼容性好，性能优化 | 移动端游戏 |
| Compatibility | 兼容旧设备 | 低配置设备 |

### 步骤 2：创建项目结构

创建以下文件夹结构：

```
HelloGodot/
├── project.godot
├── scenes/
│   └── main.tscn
├── scripts/
│   └── player.gd
└── assets/
    └── sprites/
```

在 Godot 的文件系统面板中：

1. 右键点击 `res://`
2. 选择 `新建` → `文件夹`
3. 分别创建 `scenes`、`scripts`、`assets` 文件夹

## 🎨 创建主场景

### 步骤 1：创建场景

1. 点击 `场景` → `新建场景`
2. 选择 `其他节点`
3. 搜索并选择 `Node2D`
4. 将其重命名为 `Main`

### 步骤 2：保存场景

- 快捷键：`Ctrl + S`
- 路径：`scenes/main.tscn`

## 🧑 创建玩家角色

### 步骤 1：添加玩家节点

1. 在场景树中右键点击 `Main`
2. 选择 `添加子节点`
3. 搜索 `CharacterBody2D`
4. 将其重命名为 `Player`

### 步骤 2：添加精灵

1. 右键点击 `Player`
2. 添加子节点 `Sprite2D`
3. 在属性检查器中：
   - 点击 `Texture` 属性
   - 选择 `新建 Texture2D`
   - 可以使用内置图标或导入自己的图片

### 步骤 3：添加碰撞体

1. 右键点击 `Player`
2. 添加子节点 `CollisionShape2D`
3. 在属性检查器中：
   - 点击 `Shape` 属性
   - 选择 `新建 RectangleShape2D`
   - 调整形状大小以匹配精灵

此时场景树结构：

```
Main (Node2D)
└── Player (CharacterBody2D)
    ├── Sprite2D
    └── CollisionShape2D
```

## 📝 编写玩家脚本

### 步骤 1：创建脚本

1. 选中 `Player` 节点
2. 点击右上角的 `附加脚本` 按钮（或右键选择）
3. 设置脚本参数：

```text
脚本路径：scripts/player.gd
模板：CharacterBody2D（推荐）
语言：GDScript
```

### 步骤 2：编写移动代码

```gdscript
extends CharacterBody2D

# 移动速度（像素/秒）
@export var speed: float = 200.0

# 重力加速度
var gravity = ProjectSettings.get_setting("physics/2d/default_gravity")

func _physics_process(delta):
    # 应用重力
    if not is_on_floor():
        velocity.y += gravity * delta
    
    # 获取输入方向
    var direction = Input.get_axis("ui_left", "ui_right")
    
    # 水平移动
    if direction:
        velocity.x = direction * speed
    else:
        velocity.x = move_toward(velocity.x, 0, speed)
    
    # 跳跃
    if Input.is_action_just_pressed("ui_accept") and is_on_floor():
        velocity.y = -400.0
    
    # 应用移动
    move_and_slide()
```

### 代码解析

```gdscript
# @export 关键字使变量在检查器中可见可编辑
@export var speed: float = 200.0

# _physics_process 是物理更新函数，每帧调用
# delta 参数表示上一帧到这一帧的时间（秒）
func _physics_process(delta):
    # is_on_floor() 检测是否在地面上
    # velocity 是内置的速度向量
    pass

# Input.get_axis 获取轴输入，返回 -1、0 或 1
var direction = Input.get_axis("ui_left", "ui_right")

# move_and_slide() 自动处理碰撞和滑动
move_and_slide()
```

## 🎮 设置输入映射

Godot 默认提供了一些输入动作：

| 动作名称 | 默认按键 |
|----------|----------|
| ui_left | 左箭头、A |
| ui_right | 右箭头、D |
| ui_up | 上箭头、W |
| ui_down | 下箭头、S |
| ui_accept | 空格、回车 |

### 添加自定义输入

1. 点击 `项目` → `项目设置`
2. 选择 `输入映射` 标签
3. 添加新动作，例如 `jump`
4. 为动作绑定按键

## 🌍 添加地面

### 步骤 1：创建地面节点

1. 在 `Main` 场景中添加子节点 `StaticBody2D`
2. 重命名为 `Ground`

### 步骤 2：添加碰撞形状

1. 为 `Ground` 添加子节点 `CollisionShape2D`
2. 设置形状为 `RectangleShape2D`
3. 调整大小和位置

### 步骤 3：添加视觉表现

1. 为 `Ground` 添加子节点 `ColorRect`
2. 设置颜色和大小

最终场景结构：

```
Main (Node2D)
├── Player (CharacterBody2D)
│   ├── Sprite2D
│   └── CollisionShape2D
└── Ground (StaticBody2D)
    ├── ColorRect
    └── CollisionShape2D
```

## ▶️ 运行项目

### 设置主场景

1. 点击 `项目` → `项目设置`
2. 在 `应用` → `运行` 中
3. 设置 `主场景` 为 `scenes/main.tscn`

### 运行游戏

- 快捷键：`F5`（运行主场景）
- 或 `F6`（运行当前场景）

## 🎯 完整示例代码

### player.gd

```gdscript
extends CharacterBody2D

# 导出变量，可在检查器中修改
@export var speed: float = 200.0
@export var jump_force: float = 400.0

# 获取重力值
var gravity = ProjectSettings.get_setting("physics/2d/default_gravity")

func _physics_process(delta):
    # 应用重力
    if not is_on_floor():
        velocity.y += gravity * delta
    
    # 处理跳跃
    if Input.is_action_just_pressed("ui_accept") and is_on_floor():
        velocity.y = -jump_force
    
    # 获取水平输入
    var direction = Input.get_axis("ui_left", "ui_right")
    
    # 根据输入设置水平速度
    if direction:
        velocity.x = direction * speed
        # 根据移动方向翻转精灵
        $Sprite2D.flip_h = direction < 0
    else:
        # 减速停止
        velocity.x = move_toward(velocity.x, 0, speed)
    
    # 应用移动
    move_and_slide()
```

## 📊 调试技巧

### 打印调试信息

```gdscript
func _physics_process(delta):
    # 打印当前速度
    print("Velocity: ", velocity)
    
    # 打印是否在地面
    print("On floor: ", is_on_floor())
```

### 使用断点

1. 在脚本编辑器中点击行号左侧
2. 出现红色圆点表示断点
3. 运行时会在断点处暂停

### 查看节点信息

```gdscript
func _ready():
    # 打印节点名称
    print("Node name: ", name)
    
    # 打印节点路径
    print("Node path: ", get_path())
    
    # 打印所有子节点
    for child in get_children():
        print("Child: ", child.name)
```
