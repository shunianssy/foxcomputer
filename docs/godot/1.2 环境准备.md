# 1.2 环境准备

## 下载 Godot

### 官方下载地址

访问 Godot 官网下载页面：

```
https://godotengine.org/download
```

### 选择合适的版本

Godot 提供多个版本供选择：

| 版本类型 | 说明 | 适用场景 |
|----------|------|----------|
| Standard | 标准版，支持 GDScript | 大多数项目 |
| .NET (C#) | 支持 C# 编程 | 需要 C# 的项目 |
| Mono | 旧版 .NET 支持 | 维护旧项目 |

### 选择操作系统

```text
Windows 用户：
├── Godot_v4.x_stable_win64.exe（推荐）
├── Godot_v4.x_stable_win64_console.exe（带控制台）
└── Godot_v4.x_stable_win32.exe（32位系统）

macOS 用户：
├── Godot_v4.x_stable_macos.universal.zip
└── 支持 Intel 和 Apple Silicon

Linux 用户：
├── Godot_v4.x_stable_linux.x86_64.zip
└── 需要自行添加执行权限
```

## 安装步骤

### Windows 安装

1. **下载压缩包**
 - 下载 `.zip` 文件并解压
 - 或下载 `.exe` 单文件版本

2. **运行 Godot**
 ```powershell
 # 双击运行 Godot_v4.x_stable_win64.exe
 # 或在命令行中运行
 .\Godot_v4.x_stable_win64.exe
 ```

3. **创建桌面快捷方式**（可选）
 - 右键点击 exe 文件
 - 选择"发送到" → "桌面快捷方式"

### macOS 安装

1. **下载并解压**
 ```bash
 # 解压下载的 zip 文件
 unzip Godot_v4.x_stable_macos.universal.zip
 ```

2. **移动到应用程序文件夹**
 ```bash
 mv Godot.app /Applications/
 ```

3. **首次运行**
 - 右键点击 Godot.app
 - 选择"打开"
 - 在弹出的对话框中点击"打开"

### Linux 安装

1. **下载并解压**
 ```bash
 # 解压文件
 unzip Godot_v4.x_stable_linux.x86_64.zip
 ```

2. **添加执行权限**
 ```bash
 chmod +x Godot_v4.x_stable_linux.x86_64
 ```

3. **运行 Godot**
 ```bash
 ./Godot_v4.x_stable_linux.x86_64
 ```

## 编辑器设置

### 配置语言

1. 打开 `编辑器` → `编辑器设置`
2. 找到 `Interface` → `Editor Language`
3. 选择 `简体中文`（如果可用）

### 配置主题

```text
编辑器设置 → Interface → Theme
├── Preset: 选择预设主题
│ ├── Default（默认）
│ ├── Godot 2（经典风格）
│ └── Custom（自定义）
└── Accent Color: 强调色设置
```

### 常用设置推荐

```text
编辑器设置建议：
├── Interface
│ ├── Editor Language: 简体中文
│ └── Display Scale: 自动检测
├── Editor
│ ├── Auto Save: 启用自动保存
│ └── Auto Save Interval: 5 分钟
└── Docks
 └── FileSystem
 └── TextFileExtensions: 添加常用扩展名
```

## 项目结构

一个典型的 Godot 项目结构：

```
MyGame/
├── project.godot # 项目配置文件
├── icon.svg # 项目图标
├── scenes/ # 场景文件
│ ├── player.tscn
│ ├── enemy.tscn
│ └── main.tscn
├── scripts/ # 脚本文件
│ ├── player.gd
│ └── enemy.gd
├── assets/ # 资源文件
│ ├── sprites/ # 图片资源
│ ├── sounds/ # 音频资源
│ └── fonts/ # 字体资源
└── .godot/ # 引擎缓存（自动生成）
```
