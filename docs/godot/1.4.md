# 1.4 项目设置

## ⚙️ 项目设置概述

项目设置是 Godot 项目配置的核心，通过 `项目` → `项目设置` 访问。这里集中管理所有项目级别的配置。

## 📋 主要配置类别

### 应用配置

```text
应用 (Application)
├── 配置 (Config)
│   ├── 名称 (Name)：游戏名称
│   ├── 描述 (Description)：游戏描述
│   ├── 版本 (Version)：版本号
│   └── 图标 (Icon)：游戏图标
├── 运行 (Run)
│   ├── 主场景 (Main Scene)：启动场景
│   └── 自动加载 (Auto Load)：自动加载的单例
└── 引擎 (Boot Splash)
    ├── 图像 (Image)：启动画面图片
    └── 背景色 (BG Color)：背景颜色
```

### 常用配置示例

#### 基本信息设置

```text
项目设置 → 应用 → 配置
├── Name: "我的游戏"
├── Description: "一个有趣的平台跳跃游戏"
├── Version: "1.0.0"
└── Icon: "res://icon.svg"
```

#### 窗口设置

```text
项目设置 → 显示 → 窗口
├── Size
│   ├── Viewport Width: 1280
│   ├── Viewport Height: 720
│   ├── Window Width Override: 1920
│   └── Window Height Override: 1080
├── Stretch
│   ├── Mode: canvas_items
│   └── Aspect: keep
└── Mode: windowed
```

### 窗口拉伸模式说明

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| disabled | 不拉伸 | 固定分辨率游戏 |
| canvas_items | 拉伸画布内容 | 像素艺术游戏 |
| viewport | 拉伸视口 | 3D 游戏或需要保持比例 |

### 拉伸比例模式

| 模式 | 说明 |
|------|------|
| ignore | 忽略比例，可能变形 |
| keep | 保持比例，可能有黑边 |
| keep_width | 保持宽度，高度可变 |
| keep_height | 保持高度，宽度可变 |
| expand | 扩展显示更多内容 |

## 🎮 输入映射配置

### 添加输入动作

1. 打开 `项目设置` → `输入映射`
2. 在顶部输入框输入动作名称
3. 点击 `添加`

### 绑定按键

```text
动作名称：move_right
├── 键盘按键：D、右箭头
├── 手柄按钮：D-Pad Right
└── 手柄轴：Left Stick X (positive)
```

### 代码中使用输入

```gdscript
# 检测按键按下
if Input.is_action_just_pressed("jump"):
    jump()

# 获取轴输入值（-1 到 1）
var horizontal = Input.get_axis("move_left", "move_right")

# 获取向量输入（返回归一化向量）
var movement = Input.get_vector("move_left", "move_right", "move_up", "move_down")
```

### 推荐的输入动作命名

### 通过代码访问项目设置

```gdscript
# 读取项目设置
var gravity = ProjectSettings.get_setting("physics/2d/default_gravity")
var game_name = ProjectSettings.get_setting("application/config/name")

# 设置项目设置（运行时）
ProjectSettings.set_setting("physics/2d/default_gravity", 500)

# 保存项目设置（通常不需要）
ProjectSettings.save()
```

## 🔄 自动加载（全局单例）

### 添加自动加载

1. 打开 `项目设置` → `自动加载`
2. 选择脚本文件
3. 设置节点名称
4. 点击 `添加`

### 创建全局管理器

```gdscript
# scripts/game_manager.gd
extends Node

# 全局变量
var score: int = 0
var player_health: int = 100

# 信号
signal score_changed(new_score)
signal game_over

# 全局方法
func add_score(points: int):
    score += points
    score_changed.emit(score)

func reset_game():
    score = 0
    player_health = 100
```

### 使用全局单例

```gdscript
# 在任何脚本中都可以直接访问
func _on_enemy_killed():
    GameManager.add_score(100)
    print("Current score: ", GameManager.score)
```
