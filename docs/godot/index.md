# Godot 完整教程

## 📖 教程简介

Godot 是一款免费、开源的游戏引擎，以其轻量级、跨平台和独特的节点系统而闻名。本教程从零开始，带你全面掌握 Godot 游戏开发的方方面面。

## 🎯 学习目标

- 理解 Godot 的核心概念和设计哲学
- 掌握场景、节点和脚本的基础知识
- 学会使用 GDScript 进行游戏编程
- 了解信号系统和节点通信机制
- 掌握 2D 和 3D 游戏开发技巧

4. **参与社区**：加入 Godot 社区，与其他开发者交流
