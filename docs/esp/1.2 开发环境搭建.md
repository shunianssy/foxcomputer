# 开发环境搭建

## 1. 环境准备

### 1.1 硬件要求

#### 开发板选择
- **ESP32 DevKitC**: 标准开发板，适合大多数应用
- **ESP32-S2-Kaluga-1**: 音频开发板
- **ESP32-S3-DevKitC**: 支持AI和摄像头
- **ESP8266 NodeMCU**: 入门级开发板
- **ESP32-C3-DevKitM**: 低成本开发板

#### 必备配件
- USB数据线（推荐使用优质线缆）
- 面包板和杜邦线（用于原型开发）
- 传感器和模块（根据项目需求）
- JTAG调试器（可选，用于高级调试）

### 1.2 软件要求

#### 操作系统
- Windows 10/11
- macOS 10.15+
- Linux (Ubuntu 20.04+, Debian 11+)

#### 必需软件
- **Python 3.8+**: 用于ESP-IDF构建系统
- **Git**: 版本控制和代码下载
- **CMake**: 构建工具
- **Ninja**: 快速构建工具
- **编译器**: GCC for RISC-V/Xtensa

#### 可选软件
- **VS Code**: 推荐的代码编辑器
- **PlatformIO**: 跨平台开发工具
- **Arduino IDE**: 简单易用的开发环境
- **Thonny IDE**: MicroPython开发工具

## 2. ESP-IDF开发环境搭建

### 2.1 Windows系统安装

#### 方法一: 使用在线安装器（推荐）

1. **下载安装器**
   ```bash
   # 访问乐鑫官网下载ESP-IDF安装器
   https://dl.espressif.com/dl/esp-idf/
   # 选择: esp-idf-tools-setup-x.x.x.exe
   ```

2. **运行安装器**
   - 双击运行安装程序
   - 选择安装路径（建议使用默认路径）
   - 选择要安装的ESP-IDF版本
   - 等待安装完成（可能需要20-30分钟）

3. **验证安装**
   ```bash
   # 打开ESP-IDF命令提示符
   # 运行以下命令验证
   idf.py --version
   ```

#### 方法二: 手动安装

1. **安装依赖工具**
   ```bash
   # 下载并安装以下工具
   - Python 3.8+: https://www.python.org/downloads/
   - Git: https://git-scm.com/download/win
   - CMake: https://cmake.org/download/
   ```

2. **克隆ESP-IDF仓库**
   ```bash
   # 克隆ESP-IDF到指定目录
   git clone --recursive https://github.com/espressif/esp-idf.git
   
   # 切换到指定版本（可选）
   cd esp-idf
   git checkout v5.1
   git submodule update --init --recursive
   ```

3. **安装依赖**
   ```bash
   # 运行安装脚本
   install.bat esp32
   ```

4. **配置环境变量**
   ```bash
   # 每次使用前运行
   export.bat
   ```

### 2.2 macOS系统安装

1. **安装Homebrew（如果未安装）**
   ```bash
   /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
   ```

2. **安装依赖工具**
   ```bash
   brew install cmake ninja dfu-util
   brew install python3
   brew install git
   ```

3. **克隆ESP-IDF仓库**
   ```bash
   git clone --recursive https://github.com/espressif/esp-idf.git
   cd esp-idf
   git checkout v5.1
   git submodule update --init --recursive
   ```

4. **安装ESP-IDF依赖**
   ```bash
   ./install.sh esp32
   ```

5. **设置环境变量**
   ```bash
   # 添加到 ~/.zshrc 或 ~/.bash_profile
   . ~/esp/esp-idf/export.sh
   ```

### 2.3 Linux系统安装

1. **安装依赖包**
   ```bash
   # Ubuntu/Debian
   sudo apt-get update
   sudo apt-get install git wget flex bison gperf python3 python3-pip python3-venv cmake ninja-build ccache libffi-dev libssl-dev dfu-util libusb-1.0-0
   
   # Fedora
   sudo dnf install git wget flex bison gperf python3 python3-pip cmake ninja-build ccache dfu-util libusb-devel
   
   # Arch Linux
   sudo pacman -S git wget flex bison gperf python3 python3-pip cmake ninja-build ccache dfu-util libusb
   ```

2. **克隆ESP-IDF仓库**
   ```bash
   git clone --recursive https://github.com/espressif/esp-idf.git
   cd esp-idf
   git checkout v5.1
   git submodule update --init --recursive
   ```

3. **安装ESP-IDF依赖**
   ```bash
   ./install.sh esp32
   ```

4. **设置环境变量**
   ```bash
   # 添加到 ~/.bashrc 或 ~/.zshrc
   . ~/esp/esp-idf/export.sh
   ```

## 3. VS Code开发环境配置

### 3.1 安装VS Code

1. **下载并安装VS Code**
   - 访问: https://code.visualstudio.com/
   - 下载对应系统的安装包
   - 运行安装程序

### 3.2 安装ESP-IDF插件

1. **打开VS Code扩展面板**
   - 按 `Ctrl+Shift+X` (Windows/Linux)
   - 按 `Cmd+Shift+X` (macOS)

2. **搜索并安装插件**
   - 搜索: "ESP-IDF"
   - 安装: "Espressif ESP-IDF" 官方插件

3. **配置插件**
   - 按 `F1` 打开命令面板
   - 输入: "ESP-IDF: Configure ESP-IDF extension"
   - 选择ESP-IDF路径
   - 选择目标芯片类型

### 3.3 创建第一个项目

1. **使用示例项目**
   ```bash
   # 复制示例项目
   cd ~/esp
   cp -r $IDF_PATH/examples/get-started/hello_world my_project
   cd my_project
   ```

2. **配置项目**
   ```bash
   # 设置目标芯片
   idf.py set-target esp32
   
   # 配置项目参数
   idf.py menuconfig
   ```

3. **编译和烧录**
   ```bash
   # 编译项目
   idf.py build
   
   # 烧录到设备
   idf.py -p COM3 flash
   
   # 查看串口输出
   idf.py -p COM3 monitor
   ```

## 4. Arduino IDE环境搭建

### 4.1 安装Arduino IDE

1. **下载Arduino IDE**
   - 访问: https://www.arduino.cc/en/software
   - 下载Arduino IDE 2.x版本

2. **安装Arduino IDE**
   - 运行安装程序
   - 完成安装

### 4.2 配置ESP开发板支持

1. **添加ESP开发板URL**
   - 打开Arduino IDE
   - 进入 File > Preferences
   - 在"Additional Board Manager URLs"中添加:
   ```
   https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
   ```

2. **安装开发板包**
   - 进入 Tools > Board > Boards Manager
   - 搜索 "esp32"
   - 安装 "esp32 by Espressif Systems"

3. **选择开发板**
   - 进入 Tools > Board
   - 选择对应的ESP开发板型号
   - 选择正确的COM端口

### 4.3 安装必要的库

1. **打开库管理器**
   - 进入 Tools > Manage Libraries

2. **搜索并安装常用库**
   - WiFi
   - WebServer
   - HTTPClient
   - PubSubClient (MQTT)
   - Wire (I2C)
   - SPI

### 4.4 编写和上传第一个程序

```cpp
#include <Arduino.h>

// LED引脚定义
#define LED_PIN 2

void setup() {
    // 初始化串口
    Serial.begin(115200);
    
    // 设置LED引脚为输出
    pinMode(LED_PIN, OUTPUT);
    
    Serial.println("ESP32 Arduino IDE Setup Complete!");
}

void loop() {
    // 点亮LED
    digitalWrite(LED_PIN, HIGH);
    Serial.println("LED ON");
    delay(1000);
    
    // 熄灭LED
    digitalWrite(LED_PIN, LOW);
    Serial.println("LED OFF");
    delay(1000);
}
```

## 5. MicroPython环境搭建

### 5.1 安装MicroPython固件

1. **下载MicroPython固件**
   - 访问: https://micropython.org/download/
   - 选择对应的ESP芯片型号
   - 下载最新的固件文件

2. **安装烧录工具**
   ```bash
   # 安装esptool
   pip install esptool
   ```

3. **擦除Flash并烧录固件**
   ```bash
   # 擦除Flash
   esptool.py --chip esp32 --port COM3 erase_flash
   
   # 烧录MicroPython固件
   esptool.py --chip esp32 --port COM3 --baud 460800 write_flash -z 0x1000 esp32-micropython.bin
   ```

### 5.2 安装Thonny IDE

1. **下载Thonny IDE**
   - 访问: https://thonny.org/
   - 下载对应系统的安装包

2. **安装Thonny IDE**
   - 运行安装程序
   - 完成安装

3. **配置Thonny**
   - 打开Thonny IDE
   - 进入 Tools > Options > Interpreter
   - 选择 "MicroPython (ESP32)"
   - 选择正确的COM端口
   - 点击 "Install or update MicroPython"

### 5.3 编写第一个MicroPython程序

```python
from machine import Pin
import time

# 定义LED引脚
led = Pin(2, Pin.OUT)

# 主循环
while True:
    led.on()
    print("LED ON")
    time.sleep(1)
    
    led.off()
    print("LED OFF")
    time.sleep(1)
```

## 6. PlatformIO环境搭建

### 6.1 安装PlatformIO

1. **安装VS Code（如果未安装）**
   - 参考前面的VS Code安装步骤

2. **安装PlatformIO插件**
   - 打开VS Code
   - 进入扩展面板
   - 搜索 "PlatformIO IDE"
   - 安装插件

### 6.2 创建PlatformIO项目

1. **创建新项目**
   - 点击PlatformIO图标
   - 选择 "Create New Project"
   - 输入项目名称
   - 选择开发板型号
   - 选择框架（Arduino/ESP-IDF/MicroPython）

2. **项目结构**
   ```
   my_project/
   ├── .pio/
   ├── include/
   ├── lib/
   ├── src/
   │   └── main.cpp
   ├── test/
   ├── platformio.ini
   └── README.md
   ```

3. **配置platformio.ini**
   ```ini
   [env:esp32dev]
   platform = espressif32
   board = esp32dev
   framework = arduino
   
   monitor_speed = 115200
   upload_speed = 921600
   ```

### 6.3 编译和上传

1. **编译项目**
   - 点击底部工具栏的 "Build" 按钮
   - 或使用快捷键 `Ctrl+Alt+B`

2. **上传到设备**
   - 点击 "Upload" 按钮
   - 或使用快捷键 `Ctrl+Alt+U`

3. **串口监视器**
   - 点击 "Serial Monitor" 按钮
   - 或使用快捷键 `Ctrl+Alt+S`

## 7. 常见问题排查

### 7.1 驱动问题

#### Windows系统
- **CP210x驱动**: https://www.silabs.com/developers/usb-to-uart-bridge-vcp-drivers
- **CH340驱动**: https://www.wch.cn/download/CH341SER_EXE.html

#### macOS系统
- 通常不需要额外驱动
- 如有问题，尝试重启电脑

#### Linux系统
- 添加用户到dialout组:
  ```bash
  sudo usermod -a -G dialout $USER
  ```
- 重新登录使更改生效

### 7.2 编译错误

#### Python版本问题
```bash
# 检查Python版本
python --version
# 应该是Python 3.8或更高版本
```

#### 依赖包缺失
```bash
# 重新安装ESP-IDF依赖
./install.sh esp32
```

#### 路径问题
```bash
# 避免路径中包含中文或特殊字符
# 使用英文路径
```

### 7.3 烧录失败

#### 检查串口连接
```bash
# 列出可用串口
```

## 8. 开发环境最佳实践

### 8.1 项目管理

#### 使用版本控制
```bash
# 初始化Git仓库
git init

# 创建.gitignore
cat > .gitignore << EOF
build/
*.pyc
__pycache__/
.pio/
.vscode/
EOF
```

#### 项目结构
```
my_project/
├── docs/              # 文档
├── examples/          # 示例代码
├── include/           # 头文件
├── lib/               # 第三方库
├── src/               # 源代码
├── test/              # 测试代码
├── README.md          # 项目说明
└── LICENSE            # 许可证
```

### 8.2 代码规范

#### ESP-IDF代码风格
- 遵循Google C++代码风格
- 使用4空格缩进
- 函数名使用snake_case
- 常量使用UPPER_CASE

#### Arduino代码风格
- 函数名使用camelCase
- 变量名使用camelCase
- 常量使用UPPER_CASE
- 使用2空格缩进

#### MicroPython代码风格
- 遵循PEP 8规范
- 使用4空格缩进
- 函数和变量名使用snake_case

### 8.3 调试技巧

#### 使用日志输出
```c
// ESP-IDF
ESP_LOGI(TAG, "Value: %d", value);

// Arduino
Serial.printf("Value: %d\n", value);

// MicroPython
print(f"Value: {value}")
```

#### 使用断点调试
- ESP-IDF支持JTAG调试
- 需要JTAG调试器
- 在VS Code中配置调试器

#### 性能分析
```c
// 使用ESP-IDF性能分析工具
esp_timer_start();
// ... 代码执行 ...
esp_timer_stop();
```
