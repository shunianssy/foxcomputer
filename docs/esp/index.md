# ESP 硬件开发教程

ESP系列芯片是由乐鑫信息科技(Espressif Systems)开发的一款低成本、低功耗的WiFi+蓝牙系统级芯片(SoC)。本教程将带你从零开始学习ESP硬件开发，涵盖ESP8266和ESP32两大主流芯片。

## 为什么选择 ESP 系列？

### 优势特点

1. **性价比极高**：ESP8266模块价格低至10元以内，ESP32也在20-40元区间
2. **功能强大**：集成WiFi和蓝牙（ESP32），支持多种外设接口
3. **社区活跃**：拥有庞大的开发者社区，资料丰富
4. **开发便捷**：支持Arduino IDE、MicroPython、ESP-IDF等多种开发环境
5. **文档完善**：官方提供详细的技术文档和示例代码

### ESP8266 vs ESP32 对比

| 特性 | ESP8266 | ESP32 |
|------|---------|-------|
| CPU | 单核 80MHz | 双核 240MHz |
| WiFi | 802.11 b/g/n | 802.11 b/g/n |
| 蓝牙 | 不支持 | BLE + 经典蓝牙 |
| GPIO | 17个 | 34个 |
| ADC | 1个 10位 | 18个 12位 |
| DAC | 无 | 2个 8位 |
| 触摸传感器 | 无 | 10个 |
| 价格 | 10-15元 | 25-45元 |

## 学习建议

1. **硬件准备**：建议购买ESP32开发板（推荐ESP32-DevKitC或NodeMCU-32S），配合面包板、杜邦线和常用传感器
2. **循序渐进**：按照章节顺序学习，每学完一节都要动手实践
3. **多看文档**：养成查阅官方文档的习惯，这是解决问题的最佳途径
4. **参与社区**：遇到问题可以在ESP官方论坛、GitHub Issues等平台寻求帮助

## 开发工具推荐

- **Arduino IDE**：入门首选，简单易用
- **PlatformIO**：专业开发工具，功能强大
- **VS Code + ESP-IDF**：官方开发框架，适合进阶开发
- **Thonny IDE**：MicroPython开发推荐

## 硬件购买建议

### 推荐开发板

1. **ESP32-DevKitC**：官方开发板，稳定性好
2. **NodeMCU-32S**：社区流行，价格实惠
3. **ESP32-S3-DevKitC**：最新S3系列，支持AI加速

### 必备配件

- 面包板（830点）
- 杜邦线（公对公、公对母、母对母各一套）
- USB数据线（Micro USB或Type-C，根据开发板选择）
- 3.3V/5V电源模块
- 常用电子元件（LED、电阻、按钮开关等）

### 推荐传感器模块

- DHT11/DHT22 温湿度传感器
- BMP280 气压传感器
- MPU6050 六轴传感器
- OLED显示屏（SSD1306）
- 继电器模块
- 红外接收/发射模块
