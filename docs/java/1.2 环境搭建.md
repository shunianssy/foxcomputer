# 1.2 环境搭建

## JDK 简介

JDK（Java Development Kit）是 Java 开发工具包，包含：

- **JRE（Java Runtime Environment）**：Java 运行时环境
- **JVM（Java Virtual Machine）**：Java 虚拟机
- **编译器（javac）**：将 Java 源代码编译为字节码
- **调试器（jdb）**：用于调试 Java 程序
- **其他工具**：jar、javadoc 等

## 下载 JDK

### 方式一：Oracle JDK

1. 访问 Oracle 官网：https://www.oracle.com/java/technologies/downloads/
2. 选择合适的版本（推荐 JDK 17 或 JDK 21 LTS 版本）
3. 根据操作系统选择对应的安装包

### 方式二：OpenJDK（推荐）

OpenJDK 是开源免费的 JDK 实现：

1. 访问：https://adoptium.net/
2. 选择 LTS 版本（如 JDK 17 或 JDK 21）
3. 下载对应操作系统的安装包

## 安装 JDK

### Windows 系统

1. 双击下载的 .exe 安装包
2. 按照安装向导完成安装
3. 记住安装路径（如 `C:\Program Files\Java\jdk-17`）

### macOS 系统

1. 双击 .dmg 文件
2. 按照提示完成安装

### Linux 系统

```bash
# Ubuntu/Debian
sudo apt update
sudo apt install openjdk-17-jdk

# CentOS/RHEL
sudo yum install java-17-openjdk-devel
```

## 配置环境变量

### Windows 系统

1. 右键"此电脑" → "属性" → "高级系统设置"
2. 点击"环境变量"
3. 新建系统变量：

```
变量名：JAVA_HOME
变量值：C:\Program Files\Java\jdk-17
```

4. 编辑 Path 变量，添加：

```
%JAVA_HOME%\bin
```

### macOS/Linux 系统

编辑 `~/.bash_profile` 或 `~/.zshrc` 文件：

```bash
# 设置 JAVA_HOME
export JAVA_HOME=/usr/lib/jvm/java-17-openjdk
export PATH=$JAVA_HOME/bin:$PATH
```

使配置生效：

```bash
source ~/.bash_profile
# 或
source ~/.zshrc
```

## 验证安装

打开命令行，输入以下命令：

```bash
# 查看 Java 版本
java -version

# 查看编译器版本
javac -version
```

成功输出示例：

```
java version "17.0.2" 2022-01-18 LTS
Java(TM) SE Runtime Environment (build 17.0.2+8-LTS-86)
Java HotSpot(TM) 64-Bit Server VM (build 17.0.2+8-LTS-86, mixed mode, sharing)
```

## 第一个 Java 项目

### 使用命令行

1. 创建文件 `HelloWorld.java`：

```java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}
```

2. 编译代码：

```bash
javac HelloWorld.java
```

3. 运行程序：

```bash
java HelloWorld
```

输出：

```
Hello, Java!
```

### 使用 IntelliJ IDEA

1. 创建新项目，选择 Java
2. 创建类文件 `HelloWorld.java`
3. 输入代码
4. 右键选择 "Run 'HelloWorld.main()'"
