# 1.4 代码规范

## 为什么需要代码规范

良好的代码规范能够：

- 提高代码可读性
- 便于团队协作
- 减少维护成本
- 降低出错概率

## 命名规范

### 包名

全小写，使用域名反转：

```java
// 正确
package com.example.project;
package org.apache.commons;

// 错误
package com.Example.Project;  // 不应有大写字母
```

### 类名

大驼峰命名法（PascalCase）：

```java
// 正确
public class UserController { }
public class OrderService { }
public class HttpConnection { }

// 错误
public class userController { }  // 首字母应大写
public class User_Controller { }  // 不应使用下划线
```

### 方法名

小驼峰命名法（camelCase），以动词开头：

```java
// 正确
public void getUserName() { }
public void calculateTotal() { }
public void saveToFile() { }

// 错误
public void GetUserName() { }  // 首字母应小写
public void get_user_name() { }  // 不应使用下划线
```

### 变量名

小驼峰命名法：

```java
// 正确
int studentAge = 18;
String userName = "张三";
double totalPrice = 99.99;

// 错误
int StudentAge = 18;  // 首字母应小写
int student_age = 18;  // 不应使用下划线
```

### 常量名

全大写，下划线分隔：

```java
// 正确
public static final int MAX_SIZE = 100;
public static final String DEFAULT_CHARSET = "UTF-8";
public static final double PI = 3.14159;

// 错误
public static final int maxSize = 100;  // 应全大写
public static final int MAXSIZE = 100;  // 应使用下划线分隔
```

## 代码格式

### 缩进

使用 4 个空格缩进（不推荐使用 Tab）：

```java
public class Example {
    public void method() {
        if (condition) {
            // 4 个空格缩进
            doSomething();
        }
    }
}
```

### 大括号

K&R 风格（左大括号不换行）：

```java
// 推荐
if (condition) {
    doSomething();
}

// 不推荐
if (condition)
{
    doSomething();
}
```

### 行长度

每行代码不超过 120 个字符，超长应换行：

```java
// 正确：在运算符后换行
String message = "这是一个很长的字符串" +
        "需要换行显示" +
        "以保持代码整洁";

// 正确：方法参数换行
public void processOrder(String orderId,
                         String customerName,
                         double amount) {
    // 方法体
}
```

### 空格

#### 运算符两侧

```java
// 正确
int result = a + b * c;
boolean flag = (x > 0) && (y < 10);

// 错误
int result=a+b*c;
boolean flag=(x>0)&&(y<10);
```

#### 逗号后

```java
// 正确
public void method(int a, int b, int c) { }
int[] arr = {1, 2, 3, 4, 5};

// 错误
public void method(int a,int b,int c) { }
```

#### 关键字后

```java
// 正确
if (condition) { }
for (int i = 0; i < 10; i++) { }
while (running) { }

// 错误
if(condition) { }
for(int i = 0; i < 10; i++) { }
```

### 空行

```java
public class Example {
    // 类成员变量之间
    private int id;
    private String name;
    
    // 静态变量
    private static final int MAX_SIZE = 100;
    
    // 构造方法
    public Example() {
    }
    
    // 方法之间空一行
    public void method1() {
    }
    
    public void method2() {
    }
}
```

## 注释规范

### 类注释

```java
/**
 * 用户服务类
 * 提供用户相关的业务操作
 * 
 * @author 张三
 * @version 1.0
 * @since 2024-01-01
 */
public class UserService {
    // 类体
}
```

### 方法注释

```java
/**
 * 根据用户ID获取用户信息
 * 
 * @param userId 用户ID，不能为空
 * @return 用户信息对象，如果不存在返回 null
 * @throws IllegalArgumentException 当 userId 为空时抛出
 */
public User getUserById(String userId) {
    // 方法实现
}
```

### 代码块注释

```java
public void process() {
    // 1. 验证参数
    validateParams();
    
    // 2. 处理业务逻辑
    doProcess();
    
    // 3. 保存结果
    saveResult();
}
```

## 最佳实践

### 1. 避免魔法数字

```java
// 错误
if (status == 1) {
    // 1 代表什么？
}

// 正确
public static final int STATUS_ACTIVE = 1;
if (status == STATUS_ACTIVE) {
    // 清晰明了
}
```

### 2. 方法长度控制

单个方法不超过 80 行，超过应拆分：

```java
// 不推荐：一个方法做太多事
public void processOrder(Order order) {
    // 验证订单 20 行
    // 计算价格 30 行
    // 保存订单 20 行
    // 发送通知 15 行
}

// 推荐：拆分为多个方法
public void processOrder(Order order) {
    validateOrder(order);
    calculatePrice(order);
    saveOrder(order);
    sendNotification(order);
}
```

### 3. 避免深层嵌套

```java
// 不推荐：嵌套过深
public void process(User user) {
    if (user != null) {
        if (user.isActive()) {
            if (user.hasPermission()) {
                doSomething();
            }
        }
    }
}

// 推荐：提前返回
public void process(User user) {
    if (user == null) {
        return;
    }
    if (!user.isActive()) {
        return;
    }
    if (!user.hasPermission()) {
        return;
    }
    doSomething();
}
```

### 4. 使用 try-with-resources

```java
// 不推荐
FileInputStream fis = null;
try {
    fis = new FileInputStream("file.txt");
    // 使用流
} finally {
    if (fis != null) {
        fis.close();
    }
}

// 推荐：自动关闭资源
try (FileInputStream fis = new FileInputStream("file.txt")) {
    // 使用流
}
```

## IDE 代码格式化

### IntelliJ IDEA

- 格式化代码：`Ctrl + Alt + L`
- 优化导入：`Ctrl + Alt + O`
- 设置代码风格：`Settings → Editor → Code Style → Java`

### Eclipse

- 格式化代码：`Ctrl + Shift + F`
- 优化导入：`Ctrl + Shift + O`

## 代码检查工具

### Checkstyle

检查代码是否符合规范：

```xml
<!-- pom.xml 配置 -->
<plugin>
    <groupId>org.apache.maven.plugins</groupId>
    <artifactId>maven-checkstyle-plugin</artifactId>
    <version>3.3.0</version>
</plugin>
```

### SonarQube

代码质量分析平台，可检测：

- 代码规范问题
- 潜在 Bug
- 代码重复
- 安全漏洞

本节学习了 Java 代码规范，包括：

- 命名规范（类、方法、变量、常量）
- 代码格式（缩进、大括号、空格、空行）
- 注释规范
- 最佳实践
- 常用工具

遵循代码规范是成为优秀程序员的第一步！
