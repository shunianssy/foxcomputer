# 3.1 条件语句

## if 语句

### 基本 if 语句

```java
int age = 18;

if (age >= 18) {
    System.out.println("成年人");
}
```

### if-else 语句

```java
int age = 16;

if (age >= 18) {
    System.out.println("成年人");
} else {
    System.out.println("未成年人");
}
```

### if-else if-else 语句

```java
int score = 85;

if (score >= 90) {
    System.out.println("优秀");
} else if (score >= 80) {
    System.out.println("良好");
} else if (score >= 60) {
    System.out.println("及格");
} else {
    System.out.println("不及格");
}
```

### 嵌套 if 语句

```java
int age = 25;
boolean hasLicense = true;

if (age >= 18) {
    if (hasLicense) {
        System.out.println("可以驾驶");
    } else {
        System.out.println("需要先考取驾照");
    }
} else {
    System.out.println("年龄不够");
}
```

## 条件表达式

### 比较运算符

```java
int a = 10, b = 20;

// 等于
boolean isEqual = a == b;       // false

// 不等于
boolean notEqual = a != b;      // true

// 大于、小于
boolean greater = a > b;        // false
boolean less = a < b;           // true

// 大于等于、小于等于
boolean greaterOrEqual = a >= b;  // false
boolean lessOrEqual = a <= b;     // true
```

### 逻辑运算符

```java
int age = 25;
boolean hasLicense = true;

// 逻辑与（&&）：两个条件都为 true
if (age >= 18 && hasLicense) {
    System.out.println("可以驾驶");
}

// 逻辑或（||）：至少一个条件为 true
boolean isMember = false;
if (age >= 18 || isMember) {
    System.out.println("可以进入");
}

// 逻辑非（!）：取反
boolean isActive = false;
if (!isActive) {
    System.out.println("账户未激活");
}
```

## 最佳实践

### 1. 使用大括号

```java
// 推荐：始终使用大括号
if (condition) {
    doSomething();
}

// 不推荐：省略大括号
if (condition)
    doSomething();
```

### 2. 避免深层嵌套

```java
// 不推荐：嵌套过深
public void process(User user) {
    if (user != null) {
        if (user.isActive()) {
            if (user.hasPermission()) {
                doSomething();
            }
        }
    }
}

// 推荐：提前返回
public void process(User user) {
    if (user == null) {
        return;
    }
    if (!user.isActive()) {
        return;
    }
    if (!user.hasPermission()) {
        return;
    }
    doSomething();
}
```

### 3. 使用有意义的条件

```java
// 不推荐：魔法数字
if (status == 1) {
    // ...
}

// 推荐：使用常量
public static final int STATUS_ACTIVE = 1;
if (status == STATUS_ACTIVE) {
    // ...
}

// 或者使用布尔变量
boolean isActive = status == STATUS_ACTIVE;
if (isActive) {
    // ...
}
```

## 实践示例

### 示例 1：判断成绩等级

```java
public class GradeCalculator {
    public static void main(String[] args) {
        int score = 85;
        String grade;
        
        if (score >= 90) {
            grade = "A";
        } else if (score >= 80) {
            grade = "B";
        } else if (score >= 70) {
            grade = "C";
        } else if (score >= 60) {
            grade = "D";
        } else {
            grade = "F";
        }
        
        System.out.println("成绩 " + score + " 的等级是 " + grade);
    }
}
```

### 示例 2：登录验证

```java
public class LoginValidator {
    public static void main(String[] args) {
        String username = "admin";
        String password = "123456";
        boolean isLocked = false;
        
        if (isLocked) {
            System.out.println("账户已被锁定");
        } else if (username.equals("admin") && password.equals("123456")) {
            System.out.println("登录成功");
        } else {
            System.out.println("用户名或密码错误");
        }
    }
}
```
