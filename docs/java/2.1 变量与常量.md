# 2.1 变量与常量

## 变量

变量是程序中存储数据的基本单元。在 Java 中，变量必须先声明后使用。

### 变量声明

```java
// 声明变量
int age;
String name;

// 声明并初始化
int age = 25;
String name = "张三";

// 同时声明多个变量
int a = 1, b = 2, c = 3;
```

### 变量命名规则

1. 由字母、数字、下划线(_)、美元符号($)组成
2. 不能以数字开头
3. 不能使用 Java 关键字
4. 区分大小写

```java
// 合法变量名
int age = 18;
String userName = "张三";
double _price = 99.9;
float $rate = 0.05f;

// 非法变量名
int 123abc;        // 不能以数字开头
String class;      // 不能使用关键字
double my-score;   // 不能包含连字符
```

### 变量命名约定

使用小驼峰命名法（camelCase）：

```java
// 推荐
int studentAge = 18;
String firstName = "张";
double totalPrice = 99.99;

// 不推荐
int StudentAge;     // 首字母应小写
int student_age;    // 不应使用下划线
```

## 常量

常量是值不可改变的变量，使用 `final` 关键字修饰。

### 常量声明

```java
// 声明常量
final int MAX_SIZE = 100;
final double PI = 3.14159;
final String APP_NAME = "MyApp";

// 常量必须初始化
final int NUM;      // 编译错误
NUM = 10;           // 编译错误

// 正确写法
final int NUM = 10;
```

### 常量命名约定

全大写，单词间用下划线分隔：

```java
// 推荐
public static final int MAX_CONNECTIONS = 100;
public static final String DEFAULT_CHARSET = "UTF-8";
public static final double TAX_RATE = 0.08;

// 不推荐
public static final int maxConnections = 100;  // 应全大写
public static final int MAXCONNECTIONS = 100;  // 应使用下划线
```

### 常量的应用场景

```java
public class Constants {
    // 数学常量
    public static final double PI = 3.14159;
    public static final double E = 2.71828;
    
    // 配置常量
    public static final int MAX_RETRY = 3;
    public static final int TIMEOUT = 5000;
    
    // 状态常量
    public static final int STATUS_PENDING = 0;
    public static final int STATUS_SUCCESS = 1;
    public static final int STATUS_FAILED = 2;
}
```

## 变量作用域

变量的作用域决定了变量可以被访问的范围。

### 局部变量

在方法、代码块中声明的变量，作用域仅限于声明它的代码块。

```java
public void method() {
    int a = 10;  // 局部变量
    
    if (a > 5) {
        int b = 20;  // 局部变量，仅在此 if 块内有效
        System.out.println(a);  // 可以访问 a
        System.out.println(b);  // 可以访问 b
    }
    
    System.out.println(a);  // 可以访问 a
    // System.out.println(b);  // 编译错误：b 不存在
}
```

### 成员变量

在类中声明的变量，作用域为整个类。

```java
public class Person {
    // 成员变量（实例变量）
    private String name;
    private int age;
    
    public void introduce() {
        // 可以访问成员变量
        System.out.println("我叫 " + name);
    }
    
    public void setAge(int age) {
        // 参数 age 与成员变量 age 同名
        // 使用 this 区分
        this.age = age;
    }
}
```

### 静态变量

使用 `static` 修饰的变量，属于类，所有实例共享。

```java
public class Counter {
    // 静态变量
    public static int count = 0;
    
    public Counter() {
        count++;  // 每创建一个对象，count 加 1
    }
    
    public static int getCount() {
        return count;
    }
}

// 使用
Counter c1 = new Counter();
Counter c2 = new Counter();
System.out.println(Counter.count);  // 输出：2
```

## 变量初始化

### 默认初始化

成员变量有默认值：

| 数据类型 | 默认值 |
|----------|--------|
| byte, short, int, long | 0 |
| float, double | 0.0 |
| char | '\u0000' |
| boolean | false |
| 引用类型 | null |

```java
public class DefaultValues {
    // 成员变量有默认值
    byte b;        // 0
    short s;       // 0
    int i;         // 0
    long l;        // 0L
    float f;       // 0.0f
    double d;      // 0.0
    char c;        // '\u0000'
    boolean bool;  // false
    String str;    // null
}
```

### 局部变量必须初始化

```java
public void method() {
    int a;  // 局部变量没有默认值
    // System.out.println(a);  // 编译错误：可能未初始化
    
    a = 10;  // 初始化后才能使用
    System.out.println(a);  // 正确
}
```

## var 关键字（Java 10+）

Java 10 引入了 `var` 关键字，可以自动推断局部变量类型。

```java
// 使用 var 声明局部变量
var name = "张三";           // 推断为 String
var age = 25;               // 推断为 int
var price = 99.99;          // 推断为 double
var list = new ArrayList<String>();  // 推断为 ArrayList<String>

// var 只能用于局部变量
// var x;  // 编译错误：必须初始化
// var y = null;  // 编译错误：无法推断类型
```

## 实践示例

### 示例 1：计算圆的面积

```java
public class CircleArea {
    public static void main(String[] args) {
        // 常量
        final double PI = 3.14159;
        
        // 变量
        double radius = 5.0;
        double area = PI * radius * radius;
        
        System.out.printf("半径为 %.2f 的圆，面积为 %.2f%n", radius, area);
    }
}
```

### 示例 2：变量作用域演示

```java
public class ScopeDemo {
    // 成员变量
    private int value = 100;
    
    public void show() {
        // 局部变量
        int value = 200;
        
        System.out.println("局部变量 value: " + value);        // 200
        System.out.println("成员变量 value: " + this.value);   // 100
    }
    
    public static void main(String[] args) {
        ScopeDemo demo = new ScopeDemo();
        demo.show();
    }
}
```
