# Java 入门教程

## 教程简介

Java 是一门面向对象的编程语言，具有跨平台、安全性高、稳定性强等特点。本教程从零开始，带你全面掌握 Java 编程的基础知识和核心概念。

## 学习目标

- 理解 Java 的核心语法和面向对象编程思想
- 掌握数据类型、流程控制、数组等基础知识
- 学会面向对象编程的核心概念：类、对象、继承、多态
- 了解异常处理和集合框架
- 掌握常用 API 的使用方法

## 学习建议

1. **循序渐进**：按照章节顺序学习，每章都有示例代码
2. **动手实践**：边学边写代码，加深理解
3. **阅读文档**：遇到问题时，官方文档是最好的老师
4. **项目驱动**：尝试用 Java 做一个小项目巩固知识
