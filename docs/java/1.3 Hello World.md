# 1.3 Hello World

## 第一个 Java 程序

让我们从经典的 "Hello World" 程序开始学习 Java。

```java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

## 程序结构解析

### 1. 类定义

```java
public class HelloWorld {
    // 类体
}
```

- `public`：访问修饰符，表示类是公开的
- `class`：关键字，用于定义类
- `HelloWorld`：类名，必须与文件名相同

### 2. 主方法

```java
public static void main(String[] args) {
    // 方法体
}
```

- `public`：方法是公开的
- `static`：静态方法，可通过类名直接调用
- `void`：无返回值
- `main`：方法名，是程序的入口点
- `String[] args`：命令行参数

### 3. 输出语句

```java
System.out.println("Hello, World!");
```

- `System`：系统类
- `out`：标准输出流
- `println`：打印并换行

## 编译与运行

### 编译

使用 `javac` 编译器将源代码编译为字节码：

```bash
javac HelloWorld.java
```

编译后生成 `HelloWorld.class` 文件。

### 运行

使用 `java` 命令运行字节码：

```bash
java HelloWorld
```

注意：运行时不需要加 `.class` 后缀。

## 程序执行流程

```
源代码 (.java)
    ↓
编译器 (javac)
    ↓
字节码 (.class)
    ↓
类加载器
    ↓
字节码验证器
    ↓
解释器/JIT编译器
    ↓
运行结果
```

## 输出方法详解

### println 方法

打印内容并换行：

```java
System.out.println("Hello");  // 输出后换行
System.out.println("World");  // 输出后换行
// 输出：
// Hello
// World
```

### print 方法

打印内容不换行：

```java
System.out.print("Hello");
System.out.print("World");
// 输出：HelloWorld
```

### printf 方法

格式化输出：

```java
String name = "张三";
int age = 25;
System.out.printf("姓名：%s，年龄：%d岁%n", name, age);
// 输出：姓名：张三，年龄：25岁
```

常用格式符：

| 格式符 | 说明 | 示例 |
|--------|------|------|
| %s | 字符串 | "Hello" |
| %d | 整数 | 123 |
| %f | 浮点数 | 3.14 |
| %n | 换行 | - |
| %t | 日期时间 | - |

## 注释

### 单行注释

```java
// 这是单行注释

```

### 多行注释

```java
/*
 * 这是多行注释
 * 可以跨越多行
 */
int b = 20;
```

### 文档注释

```java
/**
 * 这是一个文档注释
 * 用于生成 API 文档
 * @param args 命令行参数
 */
public static void main(String[] args) {
    // 方法体
}
```

## 标识符命名规则

### 规则

1. 由字母、数字、下划线(_)、美元符号($)组成
2. 不能以数字开头
3. 不能使用 Java 关键字
4. 区分大小写

### 约定

| 类型 | 命名规则 | 示例 |
|------|----------|------|
| 类名 | 大驼峰命名法 | `HelloWorld` |
| 方法名 | 小驼峰命名法 | `getUserName` |
| 变量名 | 小驼峰命名法 | `studentAge` |
| 常量名 | 全大写，下划线分隔 | `MAX_VALUE` |
| 包名 | 全小写 | `com.example` |

## 实践练习

### 练习 1：个人信息输出

```java
public class PersonalInfo {
    public static void main(String[] args) {
        System.out.println("========== 个人信息 ==========");
        System.out.println("姓名：张三");
        System.out.println("年龄：25");
        System.out.println("职业：Java 开发工程师");
        System.out.println("==============================");
    }
}
```

### 练习 2：使用格式化输出

```java
public class FormatOutput {
    public static void main(String[] args) {
        String course = "Java";
        int duration = 30;
        double price = 199.99;
        
        System.out.println("课程信息");
        System.out.println("-------------------");
        System.out.printf("课程名称：%s%n", course);
        System.out.printf("课程时长：%d 天%n", duration);
        System.out.printf("课程价格：%.2f 元%n", price);
    }
}
```

## 常见错误

### 1. 类名与文件名不匹配

```java
// 文件名：Test.java
public class HelloWorld {  // 错误：类名应为 Test
    public static void main(String[] args) {
        System.out.println("Hello");
    }
}
```

### 2. 漏掉分号

```java
System.out.println("Hello")  // 错误：缺少分号
```

### 3. 大小写错误

```java
system.out.println("Hello");  // 错误：System 首字母应大写
```

### 4. main 方法拼写错误

```java
public static void Main(String[] args) {  // 错误：main 应小写
    System.out.println("Hello");
}
```
