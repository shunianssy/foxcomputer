# 环境变量

## 环境变量简介

环境变量是 Docker 容器配置的重要方式，用于在容器运行时传递配置信息。环境变量可以在容器启动时设置，也可以在 Dockerfile 中定义。

## 设置环境变量

### 1. 在 Dockerfile 中设置

```dockerfile
# 设置单个环境变量
ENV APP_ENV=production
ENV APP_PORT=8080

# 设置多个环境变量
ENV APP_ENV=production \
    APP_PORT=8080 \
    DEBUG=false

# 使用环境变量
ENV PATH="/app/bin:${PATH}"
ENV PYTHONUNBUFFERED=1
```

### 2. 在运行时设置

```bash
# 设置单个环境变量
docker run -d -e APP_ENV=production nginx

# 设置多个环境变量
docker run -d \
  -e APP_ENV=production \
  -e APP_PORT=8080 \
  -e DEBUG=false \
  nginx

# 使用宿主机的环境变量
docker run -d -e APP_ENV=$APP_ENV nginx
```

### 3. 从文件读取环境变量

创建 `.env` 文件：

```env
APP_ENV=production
APP_PORT=8080
DEBUG=false
DB_HOST=mysql
DB_PORT=3306
DB_NAME=appdb
DB_USER=appuser
DB_PASSWORD=secret
```

使用 `.env` 文件：

```bash
# 从文件读取环境变量
docker run -d --env-file .env myapp:latest

# 指定 .env 文件路径
docker run -d --env-file /path/to/.env myapp:latest
```

### 4. 使用 ARG 和 ENV

```dockerfile
# 定义构建参数
ARG APP_ENV=production
ARG APP_VERSION=1.0

# 使用构建参数设置环境变量
ENV APP_ENV=${APP_ENV}
ENV APP_VERSION=${APP_VERSION}

# 构建时传递参数
# docker build --build-arg APP_ENV=development --build-arg APP_VERSION=2.0 .
```

## 环境变量的使用

### 在应用中使用环境变量

#### Python 应用

```python
import os

# 读取环境变量
app_env = os.getenv('APP_ENV', 'development')
app_port = int(os.getenv('APP_PORT', '8000'))
debug = os.getenv('DEBUG', 'false').lower() == 'true'

# 使用环境变量
if app_env == 'production':
    print('Running in production mode')
else:
    print('Running in development mode')
```

#### Node.js 应用

```javascript
// 读取环境变量
const appEnv = process.env.APP_ENV || 'development';
const appPort = process.env.APP_PORT || 3000;
const debug = process.env.DEBUG === 'true';

// 使用环境变量
if (appEnv === 'production') {
    console.log('Running in production mode');
} else {
    console.log('Running in development mode');
}
```

#### Go 应用

```go
import (
    "os"
    "strconv"
)

// 读取环境变量
appEnv := os.Getenv("APP_ENV")
if appEnv == "" {
    appEnv = "development"
}

appPort, _ := strconv.Atoi(os.Getenv("APP_PORT"))
if appPort == 0 {
    appPort = 8080
}

debug := os.Getenv("DEBUG") == "true"
```

## 环境变量最佳实践

### 1. 使用有意义的变量名

```bash
# 推荐：使用有意义的名称
APP_ENV=production
APP_PORT=8080
DB_HOST=mysql
DB_PASSWORD=secret

# 不推荐：使用模糊的名称
ENV=prod
PORT=8080
HOST=mysql
PWD=secret
```

### 2. 提供默认值

```python
# 推荐：提供默认值
app_env = os.getenv('APP_ENV', 'development')

# 不推荐：不提供默认值
app_env = os.getenv('APP_ENV')
```

### 3. 分离敏感信息

```env
# .env 文件（不提交到版本控制）
DB_PASSWORD=secret
API_KEY=your_api_key

# .env.example 文件（提交到版本控制）
DB_PASSWORD=your_password_here
API_KEY=your_api_key_here
```

### 4. 使用环境变量文件

```bash
# 推荐：使用 .env 文件
docker run -d --env-file .env myapp:latest

# 不推荐：在命令行中设置大量环境变量
docker run -d \
  -e APP_ENV=production \
  -e APP_PORT=8080 \
  -e DEBUG=false \
  -e DB_HOST=mysql \
  -e DB_PORT=3306 \
  -e DB_NAME=appdb \
  -e DB_USER=appuser \
  -e DB_PASSWORD=secret \
  myapp:latest
```

```bash
  --name web-app \
  --env-file .env \
  -p 8080:8080 \

```

### 2. 数据库配置

```bash
# MySQL 配置
docker run -d \
  --name mysql \
  -e MYSQL_ROOT_PASSWORD=rootpassword \
  -e MYSQL_DATABASE=appdb \
  -e MYSQL_USER=appuser \
  -e MYSQL_PASSWORD=userpassword \
  mysql:8.0

# PostgreSQL 配置
docker run -d \
  --name postgres \
  -e POSTGRES_DB=appdb \
  -e POSTGRES_USER=appuser \
  -e POSTGRES_PASSWORD=userpassword \
  postgres:15
```

### 3. 多环境配置

```env
# .env.development
APP_ENV=development
APP_PORT=8080
DEBUG=true
DB_HOST=localhost
DB_PORT=3306
```

```env
# .env.production
APP_ENV=production
APP_PORT=80
DEBUG=false

DB_PORT=3306
```

```bash
# 开发环境
docker run -d --env-file .env.development myapp:latest

# 生产环境

```

### 4. 配置文件模板

```dockerfile
FROM python:3.11-slim

WORKDIR /app

# 复制配置模板
COPY config.template.py /app/config.py.template

# 复制应用代码
COPY . .

# 启动脚本
COPY entrypoint.sh /app/entrypoint.sh
RUN chmod +x /app/entrypoint.sh

ENTRYPOINT ["/app/entrypoint.sh"]
CMD ["python", "app.py"]
```

```bash
#!/bin/bash
# entrypoint.sh

# 替换配置文件中的环境变量
envsubst < /app/config.py.template > /app/config.py

# 执行传入的命令
exec "$@"
```

```python
# config.template.py
APP_ENV = '${APP_ENV}'
APP_PORT = ${APP_PORT}
DEBUG = ${DEBUG}
DB_HOST = '${DB_HOST}'
DB_PORT = ${DB_PORT}
```

## 环境变量安全

### 1. 不要在 Dockerfile 中存储敏感信息

```dockerfile
# 不推荐：在 Dockerfile 中存储敏感信息
ENV DB_PASSWORD=secret
ENV API_KEY=your_api_key

# 推荐：在运行时传递敏感信息
# docker run -d -e DB_PASSWORD=secret myapp:latest
```

### 2. 使用 Docker Secrets（Swarm 模式）

```bash
# 创建 secret
echo "secret_password" | docker secret create db_password -

# 在服务中使用 secret
docker service create \
  --name myapp \
  --secret db_password \
  myapp:latest
```

### 3. 使用 .env 文件并添加到 .gitignore

```gitignore
# .gitignore
.env
.env.local
.env.*.local
```

### 4. 使用环境变量管理工具

```bash
# 使用 direnv
# 安装 direnv
brew install direnv  # macOS
sudo apt install direnv  # Linux

# 在项目目录创建 .envrc
export APP_ENV=production
export APP_PORT=8080

# 允许 direnv
direnv allow
```

## 环境变量调试

### 查看容器环境变量

```bash
# 查看所有环境变量
docker exec <容器ID或名称> env

# 查看特定环境变量
docker exec <容器ID或名称> printenv APP_ENV

# 使用 grep 过滤
docker exec <容器ID或名称> env | grep APP_
```

### 检查环境变量是否正确设置

```bash
# 运行测试容器
docker run --rm \
  -e APP_ENV=production \
  -e APP_PORT=8080 \
  alpine env | grep APP_
```

## 环境变量与配置文件

### 1. 环境变量优先级

环境变量的优先级通常高于配置文件：

```python
import os
import configparser

# 从环境变量读取
app_env = os.getenv('APP_ENV')

# 如果环境变量不存在，从配置文件读取
if not app_env:
    config = configparser.ConfigParser()
    config.read('config.ini')
    app_env = config['DEFAULT']['APP_ENV']
```

### 2. 混合使用环境变量和配置文件

```python
import os
import yaml

# 加载配置文件
with open('config.yaml', 'r') as f:
    config = yaml.safe_load(f)

# 使用环境变量覆盖配置
config['app']['env'] = os.getenv('APP_ENV', config['app']['env'])
config['app']['port'] = int(os.getenv('APP_PORT', config['app']['port']))
config['app']['debug'] = os.getenv('DEBUG', str(config['app']['debug'])).lower() == 'true'
```
