# 容器网络

## Docker 网络基础

Docker 网络允许容器之间以及容器与外部世界进行通信。Docker 提供了多种网络驱动，以满足不同的网络需求。

## 网络驱动类型

### 1. Bridge 网络（默认）

Bridge 网络是 Docker 的默认网络模式，适用于单主机上的容器通信。

```bash
# 查看默认网络
docker network ls

# 查看默认 bridge 网络详情
docker network inspect bridge
```

#### 创建自定义 Bridge 网络

```bash
# 创建自定义 bridge 网络
docker network create my-bridge-network

# 创建带子网的 bridge 网络
docker network create \
  --driver bridge \
  --subnet=172.20.0.0/16 \
  --ip-range=172.20.10.0/24 \
  --gateway=172.20.10.1 \
  my-custom-network
```

#### 连接容器到网络

```bash
# 运行容器时指定网络
docker run -d --name web1 --network my-bridge-network nginx

# 将已存在的容器连接到网络
docker network connect my-bridge-network web2

# 断开容器与网络的连接
docker network disconnect my-bridge-network web2
```

### 2. Host 网络

Host 网络模式让容器共享宿主机的网络命名空间，容器直接使用宿主机的网络。

```bash
# 使用 host 网络运行容器
docker run -d --name web --network host nginx

# 注意：容器将直接使用宿主机的网络栈
# 端口映射不再需要，容器直接监听宿主机端口
```

#### 使用场景

- 需要高性能网络的应用
- 需要直接访问宿主机网络接口的应用
- 网络监控工具

### 3. None 网络

None 网络模式给容器提供独立的网络环境，没有任何网络连接。

```bash
# 使用 none 网络运行容器
docker run -d --name isolated --network none nginx

# 容器将没有网络连接，只能通过本地回环接口通信
```

#### 使用场景

- 高安全性要求的应用
- 不需要网络连接的应用
- 自定义网络配置

### 4. Overlay 网络

Overlay 网络用于跨主机的容器通信，通常与 Docker Swarm 或 Kubernetes 配合使用。

```bash
# 创建 overlay 网络
docker network create --driver overlay my-overlay-network

# 注意：需要 Docker Swarm 模式
# docker swarm init
```

## 网络配置

### 查看网络信息

```bash
# 列出所有网络
docker network ls

# 查看网络详细信息
docker network inspect <网络名称>

# 查看网络中的容器
docker network inspect <网络名称> | grep -A 10 "Containers"
```

### 删除网络

```bash
# 删除网络
docker network rm <网络名称>

# 删除所有未使用的网络
docker network prune

# 强制删除网络（即使有容器连接）
docker network rm -f <网络名称>
```

## 容器间通信

### 同一网络中的容器通信

```bash
# 创建网络
docker network create app-network

# 启动 Web 服务器
docker run -d --name web --network app-network nginx

# 启动应用服务器
docker run -d --name app --network app-network python:3.11-slim

# 应用服务器可以通过容器名称访问 Web 服务器
# 在 app 容器中执行
docker exec app ping web
docker exec app curl http://web
```

### 不同网络中的容器通信

```bash
# 创建两个网络
docker network create frontend-network
docker network create backend-network

# 启动前端容器
docker run -d --name frontend --network frontend-network nginx

# 启动后端容器
docker run -d --name backend --network backend-network python:3.11-slim

# 将前端容器连接到后端网络
docker network connect backend-network frontend

# 现在前端容器可以访问后端容器
docker exec frontend ping backend
```

## 端口映射

### 基本端口映射

```bash
# 映射单个端口
docker run -d -p 8080:80 nginx

# 映射多个端口
docker run -d -p 8080:80 -p 8443:443 nginx

# 映射所有端口
docker run -d -P nginx
```

### 绑定到特定地址

```bash
# 绑定到 localhost
docker run -d -p 127.0.0.1:8080:80 nginx

# 绑定到特定网络接口
docker run -d -p 192.168.1.100:8080:80 nginx

# 绑定到所有接口
docker run -d -p 0.0.0.0:8080:80 nginx
```

### UDP 端口映射

```bash
# 映射 UDP 端口
docker run -d -p 53:53/udp dns-server
```

## DNS 配置

### 容器 DNS 解析

```bash
# 查看容器的 DNS 配置
docker inspect <容器ID或名称> | grep -A 10 "Dns"

# 运行容器时指定 DNS 服务器
docker run -d --dns 8.8.8.8 --dns 8.8.4.4 nginx

# 运行容器时指定 DNS 搜索域
docker run -d --dns-search example.com nginx
```

### 自定义 DNS

```bash
# 创建网络时指定 DNS
docker network create \
  --driver bridge \
  --dns 8.8.8.8 \
  --dns 8.8.4.4 \
  my-network

# 运行容器时指定 DNS
docker run -d --network my-network --dns 8.8.8.8 nginx
```

## 实际应用示例

### Web 应用架构

```bash
# 创建网络
docker network create web-app-network

# 启动数据库
docker run -d \
  --name mysql \
  --network web-app-network \
  -e MYSQL_ROOT_PASSWORD=123456 \
  -e MYSQL_DATABASE=appdb \
  mysql:8.0

# 启动后端应用
docker run -d \
  --name backend \
  --network web-app-network \
  -e DB_HOST=mysql \
  -e DB_PASSWORD=123456 \
  myapp:backend

# 启动前端应用
docker run -d \
  --name frontend \
  --network web-app-network \
  -p 80:80 \
  myapp:frontend

# 前端可以通过容器名称访问后端
# 后端可以通过容器名称访问数据库
```

### 负载均衡

```bash
# 创建网络
docker network create lb-network

# 启动多个后端实例
docker run -d --name backend1 --network lb-network myapp:backend
docker run -d --name backend2 --network lb-network myapp:backend
docker run -d --name backend3 --network lb-network myapp:backend

# 启动负载均衡器
docker run -d \
  --name nginx-lb \
  --network lb-network \
  -p 80:80 \
  -v $(pwd)/nginx.conf:/etc/nginx/nginx.conf \
  nginx

# nginx.conf 配置示例
# upstream backend {
#     server backend1;
#     server backend2;
#     server backend3;
# }
```

### 微服务架构

```bash
# 创建网络
docker network create microservices-network

# 启动各个微服务
docker run -d --name user-service --network microservices-network -p 8001:8000 user-service:latest
docker run -d --name order-service --network microservices-network -p 8002:8000 order-service:latest
docker run -d --name payment-service --network microservices-network -p 8003:8000 payment-service:latest
docker run -d --name notification-service --network microservices-network -p 8004:8000 notification-service:latest

# API 网关
docker run -d \
  --name api-gateway \
  --network microservices-network \
  -p 80:80 \
  api-gateway:latest

# 微服务之间可以通过容器名称相互通信
```

## 网络安全

### 网络隔离

```bash
# 创建隔离的网络
docker network create isolated-network

# 只允许特定容器连接
docker run -d --name secure-app --network isolated-network secure-app:latest

# 其他容器无法访问该网络
```

### 网络策略

```bash
# 使用 Docker Swarm 的网络策略（需要 Swarm 模式）
# 限制容器间的通信
docker service create \
  --name secure-service \
  --network secure-network \
  --network-alias secure \
  secure-service:latest
```

## 网络故障排除

### 检查网络连接

```bash
# 检查容器是否可以访问外部网络
docker exec <容器ID或名称> ping google.com

# 检查容器间的连接
docker exec <容器ID或名称> ping <另一个容器名称>

# 检查端口是否开放
docker exec <容器ID或名称> netstat -tlnp
```

### 查看网络日志

```bash
# 查看 Docker 网络日志
journalctl -u docker

# 查看容器网络配置
docker inspect <容器ID或名称> | grep -A 20 "NetworkSettings"
```

### 重置网络

```bash
# 停止所有容器
docker stop $(docker ps -aq)

# 删除所有网络
docker network prune

# 重启 Docker 服务
sudo systemctl restart docker
```

## 最佳实践

### 1. 使用自定义网络

```bash
# 推荐：创建自定义网络
docker network create my-network
docker run -d --name app --network my-network myapp:latest

# 不推荐：使用默认网络
docker run -d --name app myapp:latest
```

### 2. 使用有意义的网络名称

```bash
# 推荐：使用有意义的名称
docker network create frontend-network
docker network create backend-network
docker network create database-network

# 不推荐：使用通用名称
docker network create network1
docker network create network2
```

### 3. 合理规划网络

```bash
# 推荐：规划网络子网
docker network create \
  --subnet=10.0.0.0/24 \
  --gateway=10.0.0.1 \
  app-network

# 不推荐：使用默认配置
docker network create app-network
```

### 4. 限制网络访问

```bash
# 推荐：限制容器访问外部网络
docker run -d \
  --name secure-app \
  --network secure-network \
  --network-alias secure \
  secure-app:latest

# 不推荐：允许所有网络访问
docker run -d --name app app:latest
```
