# 数据卷

## 数据卷简介

数据卷（Volume）是 Docker 提供的用于数据持久化和共享的机制。数据卷独立于容器的生命周期，即使容器被删除，数据卷中的数据仍然保留。

## 数据卷的优势

1. **持久化存储**：数据独立于容器，容器删除后数据仍然存在
2. **性能优化**：数据卷直接绕过容器的文件系统，提供更好的性能
3. **数据共享**：多个容器可以共享同一个数据卷
4. **备份恢复**：可以方便地备份和恢复数据
5. **跨平台**：数据卷可以在不同操作系统间迁移

## 数据卷类型

### 1. 命名卷（Named Volume）

命名卷由 Docker 管理，存储在 Docker 的特定目录中。

```bash
# 创建命名卷
docker volume create my-volume

# 查看数据卷
docker volume ls

# 查看数据卷详细信息
docker volume inspect my-volume
```

### 2. 匿名卷（Anonymous Volume）

匿名卷在创建容器时自动生成，没有指定名称。

```bash
# 创建匿名卷
docker run -d -v /data nginx

# 查看匿名卷
docker volume ls
```

### 3. 绑定挂载（Bind Mount）

绑定挂载将宿主机目录或文件挂载到容器中。

```bash
# 挂载宿主机目录
docker run -d -v /host/path:/container/path nginx

# 挂载单个文件
docker run -d -v /host/file.txt:/container/file.txt nginx
```

## 数据卷操作

### 创建数据卷

```bash
# 创建命名卷
docker volume create my-data

# 创建带标签的数据卷
docker volume create \
  --label app=myapp \
  --label env=production \
  my-data

# 创建带驱动的数据卷
docker volume create \
  --driver local \
  --opt type=tmpfs \
  --opt device=tmpfs \
  --opt o=size=100m,uid=1000 \
  my-tmpfs
```

### 查看数据卷

```bash
# 列出所有数据卷
docker volume ls

# 查看数据卷详细信息
docker volume inspect my-data

# 只显示数据卷名称
docker volume ls -q

# 格式化输出
docker volume ls --format "table {{.Name}}\t{{.Driver}}\t{{.Scope}}"
```

### 删除数据卷

```bash
# 删除指定数据卷
docker volume rm my-data

# 删除多个数据卷
docker volume rm volume1 volume2 volume3

# 删除所有未使用的数据卷
docker volume prune

# 强制删除所有数据卷
docker volume prune -f
```

### 备份数据卷

```bash
# 方法 1：使用临时容器备份
docker run --rm \
  -v my-data:/data \
  -v $(pwd):/backup \
  alpine tar czf /backup/my-data-backup.tar.gz /data

# 方法 2：直接复制数据
docker run --rm \
  -v my-data:/data \
  -v $(pwd):/backup \
  alpine cp -r /data /backup/
```

### 恢复数据卷

```bash
# 恢复数据卷
docker run --rm \
  -v my-data:/data \
  -v $(pwd):/backup \
  alpine sh -c "cd /data && tar xzf /backup/my-data-backup.tar.gz --strip 1"
```

## 使用数据卷

### 在容器中使用数据卷

```bash
# 使用命名卷
docker run -d \
  --name my-app \
  -v my-data:/app/data \
  myapp:latest

# 使用匿名卷
docker run -d \
  --name my-app \
  -v /app/data \
  myapp:latest

# 使用绑定挂载
docker run -d \
  --name my-app \
  -v /host/path:/app/data \
  myapp:latest
```

### 只读挂载

```bash
# 只读挂载数据卷
docker run -d \
  --name my-app \
  -v my-data:/app/data:ro \
  myapp:latest

# 只读挂载宿主机目录
docker run -d \
  --name my-app \
  -v /host/path:/app/data:ro \
  myapp:latest
```

### 多个数据卷

```bash
# 挂载多个数据卷
docker run -d \
  --name my-app \
  -v data1:/app/data1 \
  -v data2:/app/data2 \
  -v data3:/app/data3 \
  myapp:latest
```

## 实际应用示例

### 1. 数据库持久化

```bash
# MySQL 数据持久化
docker run -d \
  --name mysql \
  -v mysql-data:/var/lib/mysql \
  -e MYSQL_ROOT_PASSWORD=123456 \
  mysql:8.0

# PostgreSQL 数据持久化
docker run -d \
  --name postgres \
  -v postgres-data:/var/lib/postgresql/data \
  -e POSTGRES_PASSWORD=123456 \
  postgres:15

# Redis 数据持久化
docker run -d \
  --name redis \
  -v redis-data:/data \
  redis:alpine
```

### 2. Web 应用数据持久化

```bash
# 持久化上传文件
docker run -d \
  --name web-app \
  -v uploads:/app/uploads \
  -v logs:/app/logs \
  myapp:latest

# 持久化配置文件
docker run -d \
  --name web-app \
  -v /host/config:/app/config:ro \
  myapp:latest
```

### 3. 多容器共享数据

```bash
# 创建共享数据卷
docker volume create shared-data

# 容器 1 写入数据
docker run -d \
  --name writer \
  -v shared-data:/data \
  writer-app:latest

# 容器 2 读取数据
docker run -d \
  --name reader \
  -v shared-data:/data:ro \
  reader-app:latest
```

### 4. 开发环境数据同步

```bash
# 同步代码到容器
docker run -d \
  --name dev-env \
  -v $(pwd):/app \
  node:18

# 修改宿主机代码会立即同步到容器中
```

## 数据卷驱动

### 1. Local 驱动（默认）

```bash
# 创建本地数据卷
docker volume create \
  --driver local \
  --opt type=tmpfs \
  --opt device=tmpfs \
  --opt o=size=100m,uid=1000 \
  my-tmpfs
```

### 2. NFS 驱动

```bash
# 创建 NFS 数据卷
docker volume create \
  --driver local \
  --opt type=nfs \
  --opt o=addr=192.168.1.100,rw \
  --opt device=:/path/to/nfs/share \
  nfs-volume
```

### 3. 第三方驱动

```bash
# 安装第三方驱动（示例：convoy）
docker plugin install --grant-all-permissions \
  rancher/convoy:latest

# 使用第三方驱动创建数据卷
docker volume create \
  --driver convoy \
  --opt size=10GB \
  my-convoy-volume
```

## 数据卷最佳实践

### 1. 使用命名卷

```bash
# 推荐：使用命名卷
docker volume create my-data
docker run -d -v my-data:/app/data myapp:latest

# 不推荐：使用匿名卷
docker run -d -v /app/data myapp:latest
```

### 2. 合理规划数据卷

```bash
# 推荐：使用有意义的名称
docker volume create mysql-data
docker volume create postgres-data
docker volume create redis-data

# 不推荐：使用通用名称
docker volume create data1
docker volume create data2
```

### 3. 定期备份数据卷

```bash
# 创建备份脚本
#!/bin/bash
BACKUP_DIR="/backup"
VOLUME_NAME="my-data"
DATE=$(date +%Y%m%d_%H%M%S)

docker run --rm \
  -v ${VOLUME_NAME}:/data \
  -v ${BACKUP_DIR}:/backup \
  alpine tar czf /backup/${VOLUME_NAME}_${DATE}.tar.gz /data
```

### 4. 监控数据卷使用情况

```bash
# 查看数据卷使用情况
docker system df -v

# 查看特定数据卷的使用情况
docker volume inspect my-data | grep -A 10 "Mountpoint"
```

### 5. 清理未使用的数据卷

```bash
# 清理未使用的数据卷
docker volume prune

# 定期清理（添加到 crontab）
0 0 * * 0 docker volume prune -f
```

## 数据卷故障排除

### 检查数据卷

```bash
# 检查数据卷是否存在
docker volume ls | grep my-data

# 检查数据卷详细信息
docker volume inspect my-data

# 检查数据卷内容
docker run --rm -v my-data:/data alpine ls -la /data
```

### 修复数据卷权限

```bash
# 修复数据卷权限
docker run --rm \
  -v my-data:/data \
  alpine chown -R 1000:1000 /data
```

### 迁移数据卷

```bash
# 迁移数据卷到新位置
docker run --rm \
  -v old-data:/old \
  -v new-data:/new \
  alpine cp -r /old/. /new/
```

## 数据卷与绑定挂载的选择

### 数据卷适用场景

- 需要持久化数据
- 多个容器需要共享数据
- 需要更好的性能
- 需要备份和恢复

### 绑定挂载适用场景

- 开发环境代码同步
- 需要直接访问宿主机文件
- 需要特定的文件系统特性
- 临时数据存储

## 总结

本章介绍了 Docker 数据卷的基本概念和使用方法。通过合理使用数据卷，我们可以：

1. 实现数据持久化
2. 在容器间共享数据
3. 提高数据访问性能
4. 方便地备份和恢复数据
