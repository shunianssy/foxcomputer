# Dockerfile

## Dockerfile 简介

Dockerfile 是一个文本文件，包含了构建 Docker 镜像所需的所有指令。通过 Dockerfile，我们可以自动化地构建镜像，确保构建过程的可重复性和一致性。

## Dockerfile 基本结构

一个典型的 Dockerfile 包含以下部分：

1. 基础镜像（FROM）
2. 维护者信息（MAINTAINER）
3. 镜像操作指令（RUN、COPY、ADD 等）
4. 容器启动指令（CMD、ENTRYPOINT）

## 常用指令详解

### FROM - 基础镜像

指定构建镜像的基础镜像。

```dockerfile
# 使用官方镜像
FROM ubuntu:22.04
FROM nginx:latest
FROM python:3.11-slim

# 使用多阶段构建
FROM node:18 AS builder
FROM python:3.11 AS runtime
```

### MAINTAINER - 维护者信息

指定镜像的维护者信息（已废弃，推荐使用 LABEL）。

```dockerfile
# 旧方式（已废弃）
MAINTAINER yourname@example.com

# 新方式（推荐）
LABEL maintainer="yourname@example.com"
```

### RUN - 执行命令

在镜像构建过程中执行命令。

```dockerfile
# shell 形式
RUN apt-get update && apt-get install -y \
    curl \
    vim \
    git

# exec 形式
RUN ["/bin/bash", "-c", "echo hello"]

# 清理缓存
RUN apt-get update && apt-get install -y python3 \
    && apt-get clean \
    && rm -rf /var/lib/apt/lists/*
```

### COPY - 复制文件

从构建上下文复制文件到镜像中。

```dockerfile
# 复制文件
COPY app.py /app/

# 复制目录
COPY ./src /app/src

# 使用通配符
COPY *.txt /app/

# 指定用户和权限
COPY --chown=www:www ./html /usr/share/nginx/html
```

### ADD - 添加文件

类似 COPY，但支持自动解压缩和远程 URL。

```dockerfile
# 复制文件（类似 COPY）
ADD app.py /app/

# 自动解压缩
ADD archive.tar.gz /app/

# 从 URL 下载
ADD https://example.com/file.tar.gz /app/
```

### CMD - 容器启动命令

指定容器启动时默认执行的命令。

```dockerfile
# exec 形式（推荐）
CMD ["python", "app.py"]
CMD ["nginx", "-g", "daemon off;"]

# shell 形式
CMD python app.py
CMD nginx -g 'daemon off;'

# 作为 ENTRYPOINT 的参数
CMD ["--help"]
```

### ENTRYPOINT - 入口点

配置容器启动时执行的命令，不会被 docker run 的参数覆盖。

```dockerfile
# exec 形式
ENTRYPOINT ["python", "app.py"]

# shell 形式
ENTRYPOINT python app.py

# 与 CMD 配合使用
ENTRYPOINT ["python"]
CMD ["app.py"]
```

### ENV - 环境变量

设置环境变量。

```dockerfile
# 设置单个环境变量
ENV APP_ENV=production
ENV APP_PORT=8080

# 设置多个环境变量
ENV APP_ENV=production \
    APP_PORT=8080 \
    DEBUG=false

# 在后续指令中使用
ENV PATH="/app/bin:${PATH}"
RUN echo $APP_ENV
```

### ARG - 构建参数

定义构建时的变量，只在构建过程中有效。

```dockerfile
# 定义构建参数
ARG VERSION=1.0
ARG BUILD_DATE

# 使用构建参数
LABEL version=${VERSION}
LABEL build-date=${BUILD_DATE}

# 在构建时传递
# docker build --build-arg VERSION=2.0 .
```

### EXPOSE - 暴露端口

声明容器运行时监听的端口。

```dockerfile
# 暴露单个端口
EXPOSE 80

# 暴露多个端口
EXPOSE 80 443

# 指定协议
EXPOSE 80/tcp
EXPOSE 53/udp
```

### VOLUME - 数据卷

创建挂载点，用于数据持久化。

```dockerfile
# 创建数据卷
VOLUME ["/data"]
VOLUME ["/var/log/app", "/var/lib/app"]

# 在运行时挂载
# docker run -v /host/path:/data myimage
```

### USER - 用户

指定运行容器时的用户。

```dockerfile
# 使用用户名
USER nginx
USER appuser

# 使用 UID
USER 1000

# 先创建用户
RUN groupadd -r appuser && useradd -r -g appuser appuser
USER appuser
```

### WORKDIR - 工作目录

设置工作目录，后续指令都在此目录下执行。

```dockerfile
# 设置工作目录
WORKDIR /app

# 如果目录不存在会自动创建
WORKDIR /app/src

# 使用环境变量
ENV APP_HOME=/app
WORKDIR $APP_HOME
```

### LABEL - 元数据

为镜像添加元数据。

```dockerfile
# 添加标签
LABEL version="1.0"
LABEL description="My application"
LABEL maintainer="yourname@example.com"

# 一次性添加多个标签
LABEL version="1.0" \
      description="My application" \
      maintainer="yourname@example.com"
```

### SHELL - 壳程序

指定 RUN、CMD、ENTRYPOINT 使用的默认 shell。

```dockerfile
# 指定 shell
SHELL ["/bin/bash", "-c", "-o", "pipefail"]

# Windows 示例
SHELL ["powershell", "-command"]
```

### ONBUILD - 触发指令

在当前镜像被作为基础镜像时触发执行。

```dockerfile
# 在子镜像构建时执行
ONBUILD COPY . /app/src
ONBUILD RUN pip install -r /app/src/requirements.txt
```

## 实际示例

### Python Web 应用

```dockerfile
# 使用 Python 3.11 slim 版本作为基础镜像
FROM python:3.11-slim

# 设置工作目录
WORKDIR /app

# 设置环境变量
ENV PYTHONDONTWRITEBYTECODE=1
ENV PYTHONUNBUFFERED=1

# 复制依赖文件
COPY requirements.txt .

# 安装依赖
RUN pip install --no-cache-dir -r requirements.txt

# 复制应用代码
COPY . .

# 暴露端口
EXPOSE 8000

# 启动应用
CMD ["python", "app.py"]
```

### Node.js 应用

```dockerfile
# 使用 Node.js 18 作为基础镜像
FROM node:18-alpine

# 设置工作目录
WORKDIR /app

# 复制 package 文件
COPY package*.json ./

# 安装依赖
RUN npm ci --only=production

# 复制应用代码
COPY . .

# 暴露端口
EXPOSE 3000

# 启动应用
CMD ["node", "index.js"]
```

### Nginx 静态网站

```dockerfile
# 使用 Nginx 作为基础镜像
FROM nginx:alpine

# 删除默认配置
RUN rm /etc/nginx/conf.d/default.conf

# 复制自定义配置
COPY nginx.conf /etc/nginx/conf.d/

# 复制静态文件
COPY html /usr/share/nginx/html

# 暴露端口
EXPOSE 80

# 启动 Nginx
CMD ["nginx", "-g", "daemon off;"]
```

## 最佳实践

### 1. 使用官方基础镜像

```dockerfile
# 推荐
FROM python:3.11-slim
FROM node:18-alpine

# 不推荐
FROM ubuntu:22.04
# 然后手动安装 Python
```

### 2. 合并 RUN 指令

```dockerfile
# 推荐
RUN apt-get update && apt-get install -y \
    curl \
    vim \
    git \
    && apt-get clean \
    && rm -rf /var/lib/apt/lists/*

# 不推荐
RUN apt-get update
RUN apt-get install -y curl
RUN apt-get install -y vim
```

### 3. 使用 .dockerignore

创建 `.dockerignore` 文件，排除不需要的文件：

```
.git
.gitignore
__pycache__
*.pyc
.env
node_modules
*.md
```

### 4. 利用缓存

将不常变化的指令放在前面：

```dockerfile
# 推荐
COPY requirements.txt .
RUN pip install -r requirements.txt
COPY . .

# 不推荐
COPY . .
RUN pip install -r requirements.txt
```

### 5. 使用多阶段构建

```dockerfile
# 构建阶段
FROM node:18 AS builder
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

# 运行阶段
FROM nginx:alpine
COPY --from=builder /app/dist /usr/share/nginx/html
```

### 6. 最小化镜像层数

```dockerfile
# 推荐
RUN apt-get update && \
    apt-get install -y curl vim && \
    apt-get clean && \
    rm -rf /var/lib/apt/lists/*

# 不推荐
RUN apt-get update
RUN apt-get install -y curl
RUN apt-get install -y vim
```

### 7. 使用特定版本标签

```dockerfile
# 推荐
FROM python:3.11.2-slim
FROM node:18.14.0-alpine

# 不推荐
FROM python:3.11-slim
FROM node:18-alpine
```
