# 第一个容器

## 运行第一个容器

### Hello World 容器

让我们从最简单的例子开始，运行一个 Hello World 容器：

```bash
docker run hello-world
```

这个命令会：
1. 检查本地是否有 hello-world 镜像
2. 如果没有，从 Docker Hub 拉取镜像
3. 创建并启动容器
4. 容器运行完成后输出欢迎信息
5. 容器自动退出

### 运行交互式容器

运行一个交互式的 Ubuntu 容器：

```bash
docker run -it ubuntu bash
```

参数说明：
- `-i` (interactive): 保持标准输入打开
- `-t` (tty): 分配一个伪终端
- `ubuntu`: 镜像名称
- `bash`: 要执行的命令

进入容器后，你可以像在普通 Linux 系统中一样执行命令：

```bash
# 查看系统信息
cat /etc/os-release

# 更新包列表
apt-get update

# 安装工具
apt-get install -y curl

# 退出容器
exit
```

## 容器基本操作

### 后台运行容器

使用 `-d` 参数让容器在后台运行：

```bash
# 运行 Nginx 容器
docker run -d --name my-nginx -p 80:80 nginx

# 参数说明：
# -d: 后台运行
# --name: 指定容器名称
# -p: 端口映射（宿主机端口:容器端口）
```

### 查看容器

```bash
# 查看运行中的容器
docker ps

# 查看所有容器（包括停止的）
docker ps -a

# 查看容器详细信息
docker inspect <容器ID或名称>
```

### 停止和启动容器

```bash
# 停止容器
docker stop <容器ID或名称>

# 启动已停止的容器
docker start <容器ID或名称>

# 重启容器
docker restart <容器ID或名称>
```

### 删除容器

```bash
# 删除已停止的容器
docker rm <容器ID或名称>

# 强制删除运行中的容器
docker rm -f <容器ID或名称>

# 删除所有已停止的容器
docker container prune
```

## 常用容器示例

### Web 服务器

```bash
# 运行 Nginx
docker run -d --name web-server -p 8080:80 nginx

# 访问 http://localhost:8080 查看 Nginx 欢迎页面
```

### 数据库

```bash
# 运行 MySQL
docker run -d \
  --name mysql-db \
  -e MYSQL_ROOT_PASSWORD=123456 \
  -p 3306:3306 \
  mysql:8.0

# 参数说明：
# -e: 设置环境变量
# MYSQL_ROOT_PASSWORD: 设置 root 密码
```

```bash
# 运行 PostgreSQL
docker run -d \
  --name postgres-db \
  -e POSTGRES_PASSWORD=123456 \
  -p 5432:5432 \
  postgres:15
```

```bash
# 运行 Redis
docker run -d \
  --name redis-server \
  -p 6379:6379 \
  redis:alpine
```

### 开发环境

```bash
# 运行 Python 环境
docker run -it --name python-dev python:3.11 bash

# 在容器中安装包
pip install requests

# 运行 Python 脚本
python -c "print('Hello from Docker!')"
```

```bash
# 运行 Node.js 环境
docker run -it --name node-dev node:18 bash

# 在容器中运行 Node.js
node -e "console.log('Hello from Docker!')"
```

## 容器与宿主机交互

### 端口映射

将容器端口映射到宿主机：

```bash
# 映射单个端口
docker run -d -p 8080:80 nginx

# 映射多个端口
docker run -d -p 8080:80 -p 8443:443 nginx

# 随机端口映射
docker run -d -p 80 nginx
```

### 文件挂载

将宿主机目录挂载到容器：

```bash
# 挂载单个目录
docker run -d -p 8080:80 \
  -v /path/to/host/html:/usr/share/nginx/html \
  nginx

# 挂载多个目录
docker run -d -p 8080:80 \
  -v /path/to/host/html:/usr/share/nginx/html \
  -v /path/to/host/conf:/etc/nginx/conf.d \
  nginx

# 只读挂载
docker run -d -p 8080:80 \
  -v /path/to/host/html:/usr/share/nginx/html:ro \
  nginx
```

### 环境变量

```bash
# 设置单个环境变量
docker run -d -e APP_ENV=production nginx

# 设置多个环境变量
docker run -d \
  -e APP_ENV=production \
  -e APP_PORT=8080 \
  -e DEBUG=false \
  nginx

# 从文件读取环境变量
docker run -d --env-file .env nginx
```

## 查看容器日志

```bash
# 查看容器日志
docker logs <容器ID或名称>

# 实时查看日志
docker logs -f <容器ID或名称>

# 查看最后 100 行日志
docker logs --tail 100 <容器ID或名称>

# 查看最近 10 分钟的日志
docker logs --since 10m <容器ID或名称>
```

## 进入运行中的容器

```bash
# 使用 exec 进入容器
docker exec -it <容器ID或名称> bash

# 如果容器没有 bash，尝试 sh
docker exec -it <容器ID或名称> sh

# 在容器中执行单个命令
docker exec <容器ID或名称> ls -la
```

## 容器资源限制

```bash
# 限制内存使用
docker run -d --memory="512m" nginx

# 限制 CPU 使用
docker run -d --cpus="1.5" nginx

# 同时限制内存和 CPU
docker run -d \
  --memory="1g" \
  --cpus="2.0" \
  nginx
```

## 实践示例

### 部署一个简单的 Web 应用

```bash
# 1. 创建项目目录
mkdir my-web-app
cd my-web-app

# 2. 创建 index.html 文件
echo '<h1>Hello Docker!</h1>' > index.html

# 3. 运行 Nginx 容器并挂载目录
docker run -d \
  --name my-web \
  -p 8080:80 \
  -v $(pwd):/usr/share/nginx/html \
  nginx

# 4. 访问 http://localhost:8080
```

### 运行数据库并连接

```bash
# 1. 启动 MySQL 容器
docker run -d \
  --name mysql-test \
  -e MYSQL_ROOT_PASSWORD=123456 \
  -e MYSQL_DATABASE=testdb \
  -p 3306:3306 \
  mysql:8.0

# 2. 等待 MySQL 启动完成
sleep 30

# 3. 连接到 MySQL
docker exec -it mysql-test mysql -uroot -p123456

# 4. 在 MySQL 中执行 SQL
CREATE TABLE users (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100),
    email VARCHAR(100)
);

INSERT INTO users (name, email) VALUES ('Alice', 'alice@example.com');
INSERT INTO users (name, email) VALUES ('Bob', 'bob@example.com');

SELECT * FROM users;

# 5. 退出 MySQL
exit
```
