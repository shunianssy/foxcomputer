# 多阶段构建

## 多阶段构建简介

多阶段构建允许在一个 Dockerfile 中使用多个 FROM 指令，每个 FROM 指令开始一个新的构建阶段。这样可以显著减小最终镜像的大小，因为只有需要的文件会被复制到最终镜像中。

## 基本语法

```dockerfile
# 第一阶段：构建
FROM <基础镜像> AS <阶段名称>
<构建指令>

# 第二阶段：运行
FROM <基础镜像>
COPY --from=<阶段名称> <源路径> <目标路径>
<运行指令>
```

## 实际应用示例

### 1. Node.js 应用

```dockerfile
# 构建阶段
FROM node:18 AS builder

WORKDIR /app

# 复制 package 文件
COPY package*.json ./

# 安装依赖
RUN npm ci

# 复制源代码
COPY . .

# 构建应用
RUN npm run build

# 运行阶段
FROM node:18-alpine AS runtime

WORKDIR /app

# 从构建阶段复制构建产物
COPY --from=builder /app/dist ./dist
COPY --from=builder /app/node_modules ./node_modules
COPY --from=builder /app/package.json ./

# 暴露端口
EXPOSE 3000

# 启动应用
CMD ["node", "dist/index.js"]
```

### 2. React 应用

```dockerfile
# 构建阶段
FROM node:18 AS builder

WORKDIR /app

# 复制 package 文件
COPY package*.json ./

# 安装依赖
RUN npm ci

# 复制源代码
COPY . .

# 构建静态文件
RUN npm run build

# 运行阶段
FROM nginx:alpine AS runtime

# 从构建阶段复制构建产物
COPY --from=builder /app/build /usr/share/nginx/html

# 复制 nginx 配置
COPY nginx.conf /etc/nginx/conf.d/default.conf

# 暴露端口
EXPOSE 80

# 启动 Nginx
CMD ["nginx", "-g", "daemon off;"]
```

### 3. Python 应用

```dockerfile
# 构建阶段
FROM python:3.11 AS builder

WORKDIR /app

# 复制依赖文件
COPY requirements.txt .

# 安装依赖到用户目录
RUN pip install --user -r requirements.txt

# 运行阶段
FROM python:3.11-slim AS runtime

WORKDIR /app

# 创建非 root 用户
RUN groupadd -r appuser && useradd -r -g appuser appuser

# 从构建阶段复制依赖
COPY --from=builder /root/.local /root/.local

# 复制应用代码
COPY . .

# 设置权限
RUN chown -R appuser:appuser /app

# 切换用户
USER appuser

# 设置环境变量
ENV PATH=/root/.local/bin:$PATH

# 暴露端口
EXPOSE 8000

# 启动应用
CMD ["python", "app.py"]
```

### 4. Go 应用

```dockerfile
# 构建阶段
FROM golang:1.21 AS builder

WORKDIR /app

# 复制 go mod 文件
COPY go.* ./

# 下载依赖
RUN go mod download

# 复制源代码
COPY . .

# 构建应用
RUN CGO_ENABLED=0 GOOS=linux go build -ldflags="-w -s" -o app

# 运行阶段
FROM alpine:latest AS runtime

# 安装 CA 证书
RUN apk --no-cache add ca-certificates tzdata

WORKDIR /app

# 从构建阶段复制二进制文件
COPY --from=builder /app/app .

# 创建非 root 用户
RUN addgroup -g 1000 appuser && \
    adduser -D -u 1000 -G appuser appuser

# 设置权限
RUN chown -R appuser:appuser /app

# 切换用户
USER appuser

# 暴露端口
EXPOSE 8080

# 启动应用
CMD ["./app"]
```

### 5. Java 应用

```dockerfile
# 构建阶段
FROM maven:3.9 AS builder

WORKDIR /app

# 复制 pom.xml
COPY pom.xml .

# 下载依赖（利用缓存）
RUN mvn dependency:go-offline

# 复制源代码
COPY src ./src

# 构建应用
RUN mvn clean package -DskipTests

# 运行阶段
FROM openjdk:17-jre-slim AS runtime

WORKDIR /app

# 从构建阶段复制 JAR 文件
COPY --from=builder /app/target/*.jar app.jar

# 创建非 root 用户
RUN groupadd -r appuser && useradd -r -g appuser appuser

# 设置权限
RUN chown -R appuser:appuser /app

# 切换用户
USER appuser

# 暴露端口
EXPOSE 8080

# 启动应用
CMD ["java", "-jar", "app.jar"]
```

### 6. Rust 应用

```dockerfile
# 构建阶段
FROM rust:1.75 AS builder

WORKDIR /app

# 复制 Cargo 文件
COPY Cargo.toml Cargo.lock ./

# 创建一个虚拟的 main.rs 来预构建依赖
RUN mkdir src && \
    echo "fn main() {}" > src/main.rs && \
    cargo build --release && \
    rm -rf src

# 复制源代码
COPY src ./src

# 构建应用
RUN cargo build --release

# 运行阶段
FROM alpine:latest AS runtime

# 安装运行时依赖
RUN apk --no-cache add ca-certificates

WORKDIR /app

# 从构建阶段复制二进制文件
COPY --from=builder /app/target/release/app .

# 创建非 root 用户
RUN addgroup -g 1000 appuser && \
    adduser -D -u 1000 -G appuser appuser

# 设置权限
RUN chown -R appuser:appuser /app

# 切换用户
USER appuser

# 暴露端口
EXPOSE 8080

# 启动应用
CMD ["./app"]
```

## 高级用法

### 1. 多个构建阶段

```dockerfile
# 依赖安装阶段
FROM node:18 AS deps
WORKDIR /app
COPY package*.json ./
RUN npm ci

# 构建阶段
FROM node:18 AS builder
WORKDIR /app
COPY --from=deps /app/node_modules ./node_modules
COPY . .
RUN npm run build

# 测试阶段
FROM node:18 AS tester
WORKDIR /app
COPY --from=deps /app/node_modules ./node_modules
COPY . .
RUN npm test

# 运行阶段
FROM node:18-alpine AS runtime
WORKDIR /app
COPY --from=builder /app/dist ./dist
COPY package.json ./
EXPOSE 3000
CMD ["node", "dist/index.js"]
```

### 2. 条件复制

```dockerfile
# 构建阶段
FROM node:18 AS builder
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

# 开发环境
FROM node:18-alpine AS development
WORKDIR /app
COPY --from=builder /app/node_modules ./node_modules
COPY . .
EXPOSE 3000
CMD ["npm", "run", "dev"]

# 生产环境
FROM node:18-alpine AS production
WORKDIR /app
COPY --from=builder /app/dist ./dist
COPY package.json ./
EXPOSE 3000
CMD ["node", "dist/index.js"]
```

构建特定阶段：

```bash
# 构建开发环境
docker build --target development -t myapp:dev .

# 构建生产环境
docker build --target production -t myapp:prod .
```

### 3. 使用外部镜像作为阶段

```dockerfile
# 使用外部镜像
FROM nginx:alpine AS base

# 构建阶段
FROM node:18 AS builder
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

# 运行阶段
FROM base
COPY --from=builder /app/dist /usr/share/nginx/html
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
```

## 多阶段构建的优势

### 1. 减小镜像大小

```dockerfile
# 不使用多阶段构建
FROM node:18
WORKDIR /app
COPY . .
RUN npm install && npm run build
CMD ["node", "dist/index.js"]

# 镜像大小：约 1GB

# 使用多阶段构建
FROM node:18 AS builder
WORKDIR /app
COPY . .
RUN npm install && npm run build

FROM node:18-alpine
WORKDIR /app
COPY --from=builder /app/dist ./dist
CMD ["node", "dist/index.js"]

# 镜像大小：约 150MB
```

### 2. 提高安全性

```dockerfile
# 构建阶段包含构建工具
FROM golang:1.21 AS builder
# 包含 git、gcc 等构建工具

# 运行阶段只包含运行时
FROM alpine:latest
# 只包含必要的运行时文件
```

### 3. 简化构建流程

```dockerfile
# 所有构建步骤在一个 Dockerfile 中
FROM maven:3.9 AS builder
# 构建 Java 应用

FROM openjdk:17-jre-slim
# 运行 Java 应用
```

## 构建特定阶段

```bash
# 构建特定阶段
docker build --target <阶段名称> -t <镜像名> .

# 示例
docker build --target builder -t myapp:builder .
docker build --target tester -t myapp:tester .
docker build --target production -t myapp:prod .
```

## 最佳实践

### 1. 合理命名阶段

```dockerfile
# 推荐：使用有意义的名称
FROM node:18 AS deps
FROM node:18 AS builder
FROM node:18 AS tester
FROM node:18-alpine AS runtime

# 不推荐：使用默认名称
FROM node:18
FROM node:18-alpine
```

### 2. 利用缓存

```dockerfile
# 推荐：将不常变化的指令放在前面
FROM node:18 AS builder
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

# 不推荐：将常变化的指令放在前面
FROM node:18 AS builder
WORKDIR /app
COPY . .
RUN npm ci
RUN npm run build
```

### 3. 使用最小的基础镜像

```dockerfile
# 推荐：使用 alpine 版本
FROM node:18-alpine
FROM python:3.11-slim

# 不推荐：使用完整版本
FROM node:18
FROM python:3.11
```

### 4. 清理构建产物

```dockerfile
# 推荐：清理不必要的文件
FROM golang:1.21 AS builder
WORKDIR /app
COPY . .
RUN CGO_ENABLED=0 GOOS=linux go build -ldflags="-w -s" -o app

# 不推荐：不清理构建产物
FROM golang:1.21 AS builder
WORKDIR /app
COPY . .
RUN CGO_ENABLED=0 GOOS=linux go build -o app
```

## 总结

多阶段构建是 Docker 构建优化的重要技术，它可以：
1. 显著减小最终镜像的大小
2. 提高镜像的安全性
3. 简化构建流程
4. 支持构建不同环境的镜像

通过合理使用多阶段构建，我们可以构建出高效、安全、可维护的 Docker 镜像。
