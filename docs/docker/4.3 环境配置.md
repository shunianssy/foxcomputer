# 环境配置

## 环境配置简介

在开发、测试和生产环境中，应用程序通常需要不同的配置。Docker Compose 提供了多种方式来管理不同环境的配置。

## 多文件配置

### 基础配置文件

创建 `docker-compose.yml`：

```yaml
version: '3.8'

services:
  app:
    image: myapp:latest
    ports:
      - "8000:8000"
    environment:
      - DB_HOST=db
      - DB_PASSWORD=${DB_PASSWORD}
    depends_on:
      - db
  
  db:
    image: mysql:8.0
    environment:
      MYSQL_ROOT_PASSWORD: ${DB_PASSWORD}
      MYSQL_DATABASE: appdb
    volumes:
      - db-data:/var/lib/mysql

volumes:
  db-data:
```

### 开发环境配置

创建 `docker-compose.override.yml`：

```yaml
version: '3.8'

services:
  app:
    volumes:
      - .:/app
    environment:
      - DEBUG=true
    command: python manage.py runserver 0.0.0.0:8000
  
  db:
    ports:
      - "3306:3306"
```

### 生产环境配置

创建 `docker-compose.prod.yml`：

```yaml
version: '3.8'

services:
  app:
    image: myapp:latest
    environment:
      - DEBUG=false
      - DB_PASSWORD=${DB_PASSWORD}
    restart: always
    deploy:
      replicas: 3
      resources:
        limits:
          cpus: '0.5'
          memory: 512M
        reservations:
          cpus: '0.25'
          memory: 256M
  
  db:
    environment:
      MYSQL_ROOT_PASSWORD: ${DB_PASSWORD}
    restart: always
    deploy:
      resources:
        limits:
          cpus: '1.0'
          memory: 1G
        reservations:
          cpus: '0.5'
          memory: 512M
```

### 使用不同配置

```bash
# 开发环境（自动加载 docker-compose.override.yml）
docker-compose up -d

# 生产环境
docker-compose -f docker-compose.yml -f docker-compose.prod.yml up -d
```

## 环境变量

### 创建环境变量文件

创建 `.env` 文件：

```env
# 通用配置
DB_PASSWORD=example
APP_NAME=myapp
APP_VERSION=1.0
```

创建 `.env.development` 文件：

```env
# 开发环境配置
DEBUG=true
LOG_LEVEL=debug
DB_HOST=localhost
```

创建 `.env.production` 文件：

```env
# 生产环境配置
DEBUG=false
LOG_LEVEL=info
DB_HOST=db
```

### 在 Compose 文件中使用环境变量

```yaml
version: '3.8'

services:
  app:
    image: ${APP_NAME}:${APP_VERSION}
    environment:
      - DEBUG=${DEBUG}
      - LOG_LEVEL=${LOG_LEVEL}
      - DB_HOST=${DB_HOST}
      - DB_PASSWORD=${DB_PASSWORD}
```

### 指定环境变量文件

```bash
# 使用开发环境变量
docker-compose --env-file .env.development up -d

# 使用生产环境变量
docker-compose --env-file .env.production up -d
```

## 配置文件管理

### 配置文件模板

创建 `config.template.json`：

```json
{
  "app": {
    "name": "${APP_NAME}",
    "version": "${APP_VERSION}",
    "debug": ${DEBUG},
    "log_level": "${LOG_LEVEL}"
  },
  "database": {
    "host": "${DB_HOST}",
    "port": ${DB_PORT},
    "name": "${DB_NAME}",
    "user": "${DB_USER}",
    "password": "${DB_PASSWORD}"
  }
}
```

### 使用 entrypoint 替换配置

创建 `entrypoint.sh`：

```bash
#!/bin/bash

# 替换配置文件中的环境变量
envsubst < /app/config.template.json > /app/config.json

# 执行传入的命令
exec "$@"
```

在 `docker-compose.yml` 中使用：

```yaml
version: '3.8'

services:
  app:
    image: myapp:latest
    entrypoint: ["/app/entrypoint.sh"]
    command: ["python", "app.py"]
    volumes:
      - ./config.template.json:/app/config.template.json
    environment:
      - APP_NAME=${APP_NAME}
      - APP_VERSION=${APP_VERSION}
      - DEBUG=${DEBUG}
      - DB_HOST=${DB_HOST}
      - DB_PASSWORD=${DB_PASSWORD}
```

## 开发环境配置

### 开发环境特点

- 启用调试模式
- 挂载源代码
- 使用本地数据库
- 详细日志输出
- 热重载

### 开发环境 Compose 配置

```yaml
version: '3.8'

services:
  app:
    build:
      context: .
      dockerfile: Dockerfile.dev
    ports:
      - "8000:8000"
    volumes:
      - .:/app
      - /app/node_modules
    environment:
      - DEBUG=true
      - LOG_LEVEL=debug
      - DB_HOST=db
      - DB_PASSWORD=dev_password
    command: npm run dev
    depends_on:
      - db
  
  db:
    image: mysql:8.0
    ports:
      - "3306:3306"
    environment:
      MYSQL_ROOT_PASSWORD: dev_password
      MYSQL_DATABASE: appdb
    volumes:
      - db-data:/var/lib/mysql

volumes:
  db-data:
```

## 生产环境配置

### 生产环境特点

- 禁用调试模式
- 使用生产数据库
- 最小日志级别
- 资源限制
- 自动重启
- 健康检查

### 生产环境 Compose 配置

```yaml
version: '3.8'

services:
  nginx:
    image: nginx:alpine
    ports:
      - "80:80"
      - "443:443"
    volumes:
      - ./nginx.conf:/etc/nginx/nginx.conf:ro
      - ./ssl:/etc/nginx/ssl:ro
    depends_on:
      - app
    restart: always
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost/health"]
      interval: 30s
      timeout: 10s
      retries: 3
  
  app:
    image: myapp:latest
    environment:
      - DEBUG=false
      - LOG_LEVEL=error
      - DB_HOST=db
      - DB_PASSWORD=${DB_PASSWORD}
      - REDIS_HOST=redis
    depends_on:
      db:
        condition: service_healthy
      redis:
        condition: service_healthy
    restart: always
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:8000/health"]
      interval: 30s
      timeout: 10s
      retries: 3
    deploy:
      replicas: 3
      resources:
        limits:
          cpus: '0.5'
          memory: 512M
        reservations:
          cpus: '0.25'
          memory: 256M
      restart_policy:
        condition: on-failure
        delay: 5s
        max_attempts: 3
  
  db:
    image: mysql:8.0
    environment:
      MYSQL_ROOT_PASSWORD: ${DB_PASSWORD}
      MYSQL_DATABASE: appdb
    volumes:
      - db-data:/var/lib/mysql
    restart: always
    healthcheck:
      test: ["CMD", "mysqladmin", "ping", "-h", "localhost"]
      interval: 10s
      timeout: 5s
      retries: 5
    deploy:
      resources:
        limits:
          cpus: '1.0'
          memory: 1G
        reservations:
          cpus: '0.5'
          memory: 512M
      restart_policy:
        condition: on-failure
        delay: 5s
        max_attempts: 3
  
  redis:
    image: redis:alpine
    volumes:
      - redis-data:/data
    restart: always
    healthcheck:
      test: ["CMD", "redis-cli", "ping"]
      interval: 10s
      timeout: 5s
      retries: 5
    deploy:
      resources:
        limits:
          cpus: '0.5'
          memory: 256M
        reservations:
          cpus: '0.25'
          memory: 128M
      restart_policy:
        condition: on-failure
        delay: 5s
        max_attempts: 3

volumes:
  db-data:
  redis-data:
```

## 配置管理最佳实践

### 1. 分离敏感信息

```env
# .env（不提交到版本控制）
DB_PASSWORD=secret
API_KEY=your_api_key
```

```env
# .env.example（提交到版本控制）
DB_PASSWORD=your_password_here
API_KEY=your_api_key_here
```

### 2. 使用配置文件

```yaml
version: '3.8'

services:
  app:
    image: myapp:latest
    configs:
      - source: app_config
        target: /app/config.json

configs:
  app_config:
    file: ./config.json
```

### 3. 使用密钥管理

```yaml
version: '3.8'

services:
  app:
    image: myapp:latest
    secrets:
      - db_password
      - api_key

secrets:
  db_password:
    file: ./secrets/db_password.txt
  api_key:
    file: ./secrets/api_key.txt
```

### 4. 环境变量验证

创建 `validate-env.sh`：

```bash
#!/bin/bash

# 检查必需的环境变量
required_vars=("DB_PASSWORD" "API_KEY" "APP_NAME")

for var in "${required_vars[@]}"; do
    if [ -z "${!var}" ]; then
        echo "Error: $var is not set"
        exit 1
    fi
done

echo "All required environment variables are set"
```

在 `docker-compose.yml` 中使用：

```yaml
version: '3.8'

services:
  app:
    image: myapp:latest
    entrypoint: ["/app/validate-env.sh"]
    command: ["python", "app.py"]
```

## 总结

本章介绍了 Docker Compose 的环境配置方法。通过合理管理不同环境的配置，我们可以：

1. 分离开发和生产环境
2. 保护敏感信息
3. 简化配置管理
4. 提高部署效率
