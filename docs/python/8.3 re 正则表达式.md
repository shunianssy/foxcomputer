# 8.3 re 正则表达式

re 模块用于处理正则表达式。

## 基本使用

```python
import re

# 匹配
pattern = r"\d+"
text = "abc 123 def 456"

# 查找所有匹配
matches = re.findall(pattern, text)
print(matches)  # ['123', '456']

# 搜索第一个匹配
match = re.search(pattern, text)
if match:
    print(match.group())  # 123

# 替换
result = re.sub(pattern, "NUM", text)
print(result)  # abc NUM def NUM
```

## 常用模式

```python
import re

# 匹配邮箱
email_pattern = r"[\w.-]+@[\w.-]+\.\w+"
emails = re.findall(email_pattern, "联系: a@b.com")

# 匹配手机号
phone_pattern = r"1[3-9]\d{9}"
phones = re.findall(phone_pattern, "电话: 13812345678")
```

## 小结

本章要点：

1. **re.findall()**：查找所有匹配
2. **re.search()**：搜索第一个匹配
3. **re.sub()**：替换

> **提示**：使用原始字符串 r"" 定义正则表达式
