## 第一个 Python 程序

### 交互式模式

打开终端，输入 `python` 或 `python3` 进入交互式模式：

```python
>>> print("Hello, World!")
Hello, World!
>>> 
```

### 脚本模式

创建文件 `hello.py`：

```python

# 这是我的第一个 Python 程序

print("Hello, World!")
```

运行脚本：

```bash
python hello.py
# 输出: Hello, World!
```

## print() 函数详解

`print()` 是 Python 中最常用的输出函数。

### 基本用法

```python
# 输出字符串
print("Hello, Python!")

# 输出数字
print(123)
print(3.14)

# 输出表达式结果
print(1 + 2)  # 输出: 3
print(10 / 3)  # 输出: 3.3333333333333335
```

### 多参数输出

```python
# 多个参数用逗号分隔，自动添加空格
print("Hello", "World", "!")  # 输出: Hello World !

# 使用 sep 参数自定义分隔符
print("2024", "01", "15", sep="-")  # 输出: 2024-01-15
print("A", "B", "C", sep="")  # 输出: ABC
```

### 结尾字符

```python
# 默认结尾是换行符 \n
print("第一行")
print("第二行")

# 使用 end 参数自定义结尾
print("不换行", end=" ")
print("继续输出")  # 输出: 不换行 继续输出

# 输出后不换行
print("Loading", end="")
print("...Done")  # 输出: Loading...Done
```

### 格式化输出

```python
name = "张三"
age = 25

# 方法一：f-string（推荐，Python 3.6+）
print(f"我叫{name}，今年{age}岁")

# 方法二：format 方法
print("我叫{}，今年{}岁".format(name, age))

# 方法三：百分号格式化（旧式）
print("我叫%s，今年%d岁" % (name, age))

# 格式化数字
pi = 3.14159265
print(f"圆周率：{pi:.2f}")  # 输出: 圆周率：3.14
print(f"百分比：{0.856:.1%}")  # 输出: 百分比：85.6%
```

## 注释

注释是代码中的说明文字，不会被执行。

### 单行注释

```python
# 这是一个单行注释
print("Hello")  # 这也是单行注释（行尾注释）
```

### 多行注释

```python
"""
这是一个多行注释
可以写很多行
通常用于函数或类的文档说明
"""

'''
这也是多行注释
使用单引号也可以
'''
```

### 文档字符串（Docstring）

```python
def greet(name):
    """
    向指定的人打招呼
    
    参数:
        name: 要打招呼的人名
    
    返回:
        问候语字符串
    """
    return f"Hello, {name}!"

# 查看文档字符串
print(greet.__doc__)
```

## 基本输入

使用 `input()` 函数获取用户输入：

```python
# 基本输入
name = input("请输入你的名字：")
print(f"你好，{name}！")

# 注意：input() 返回的是字符串类型
age = input("请输入你的年龄：")
print(f"你的年龄是 {age}")
print(f"类型是 {type(age)}")  # <class 'str'>

# 需要转换为数字类型
age = int(input("请输入你的年龄："))
print(f"明年你 {age + 1} 岁")
```

### 输入验证示例

```python
# 安全的数字输入
def get_number(prompt):
    """
    获取用户输入的数字，带有错误处理
    """
    while True:
        try:
            value = float(input(prompt))
            return value
        except ValueError:
            print("输入无效，请输入一个数字！")

# 使用示例
num = get_number("请输入一个数字：")
print(f"你输入的数字是：{num}")
```

## 代码缩进

Python 使用缩进来表示代码块，这是 Python 的重要特性。

```python
# 正确的缩进
if True:
    print("条件为真")
    print("这行也属于 if 块")
print("这行不属于 if 块")

# 错误的缩进（会报错）
# if True:
# print("缺少缩进")  # IndentationError
```

### 缩进规则

```python
# 使用 4 个空格作为一级缩进（推荐）
if True:
    if True:
        print("两级缩进")

# 不要混用空格和制表符
# 建议在编辑器中设置：将 Tab 转换为 4 个空格
```

## 实战练习

### 练习一：个人信息卡片

```python
# 个人信息卡片程序
print("=" * 30)
print("       个人信息卡片")
print("=" * 30)

name = input("姓名：")
age = input("年龄：")
city = input("城市：")
hobby = input("爱好：")

print("-" * 30)
print(f"姓名：{name}")
print(f"年龄：{age}岁")
print(f"城市：{city}")
print(f"爱好：{hobby}")
print("=" * 30)
```

### 练习二：简单计算器

```python
# 简单计算器
print("简单计算器")
print("-" * 20)

num1 = float(input("请输入第一个数字："))
num2 = float(input("请输入第二个数字："))

print(f"{num1} + {num2} = {num1 + num2}")
print(f"{num1} - {num2} = {num1 - num2}")
print(f"{num1} × {num2} = {num1 * num2}")
print(f"{num1} ÷ {num2} = {num1 / num2:.2f}")
```

### 练习三：温度转换

```python
# 摄氏度与华氏度转换
celsius = float(input("请输入摄氏度："))
fahrenheit = celsius * 9 / 5 + 32

print(f"{celsius}°C = {fahrenheit}°F")
```
