# 8.4 pathlib

pathlib 是 Python 3.4+ 引入的面向对象的路径操作模块。

## 基本使用

```python
from pathlib import Path

# 创建路径对象
p = Path(".")
print(p)

# 当前目录
print(Path.cwd())

# 路径拼接
file_path = Path("folder") / "subfolder" / "file.txt"
print(file_path)

# 父目录
print(file_path.parent)

# 文件名和扩展名
print(file_path.name)      # file.txt
print(file_path.stem)      # file
print(file_path.suffix)    # .txt
```

## 文件操作

```python
from pathlib import Path

p = Path("example.txt")

# 检查
print(p.exists())
print(p.is_file())
print(p.is_dir())

# 读写
p.write_text("Hello, World!", encoding="utf-8")
content = p.read_text(encoding="utf-8")

# 遍历目录
for item in Path(".").iterdir():
    print(item)

# glob 匹配
for py_file in Path(".").glob("*.py"):
    print(py_file)
```

## 小结

本章要点：

1. **Path()**：创建路径对象
2. **/ 运算符**：拼接路径
3. **exists()/is_file()/is_dir()**：检查路径
4. **read_text()/write_text()**：读写文件

> **提示**：pathlib 比 os.path 更直观易用
