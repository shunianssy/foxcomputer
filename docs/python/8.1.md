# 8.1 os 与 sys

os 和 sys 是 Python 中用于与操作系统交互的标准库模块。

## os 模块

```python
import os

# 当前工作目录
print(os.getcwd())

# 列出目录内容
print(os.listdir("."))

# 创建目录
os.makedirs("a/b/c", exist_ok=True)

# 检查路径
print(os.path.exists("file.txt"))
print(os.path.isfile("file.txt"))
print(os.path.isdir("directory"))
```

### 路径操作

```python
import os

# 路径拼接
path = os.path.join("folder", "subfolder", "file.txt")

# 获取文件名和目录名
print(os.path.basename("/path/to/file.txt"))  # file.txt
print(os.path.dirname("/path/to/file.txt"))   # /path/to

# 分割扩展名
print(os.path.splitext("file.txt"))  # ('file', '.txt')
```

## sys 模块

```python
import sys

# Python 版本
print(sys.version)

# 命令行参数
print(sys.argv)

# 模块搜索路径
print(sys.path)
```

## 小结

本章要点：

1. **os.getcwd()**：获取当前目录
2. **os.listdir()**：列出目录内容
3. **os.path.join()**：拼接路径
4. **sys.argv**：命令行参数

> 💡 **提示**：使用 os.path 处理路径可以跨平台兼容。
