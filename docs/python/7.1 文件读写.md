# 7.1 文件读写

文件操作是 Python 编程中常见的任务。

## 打开文件

```python
# 基本语法：open(filename, mode)
# 模式：r(读), w(写), a(追加), b(二进制)

# 推荐：使用 with 语句自动关闭
with open("example.txt", "r", encoding="utf-8") as file:
    content = file.read()
```

## 读取文件

```python
# 读取整个文件
with open("example.txt", "r", encoding="utf-8") as file:
    content = file.read()

# 逐行读取
with open("example.txt", "r", encoding="utf-8") as file:
    for line in file:
        print(line.strip())

# 读取所有行为列表
with open("example.txt", "r", encoding="utf-8") as file:
    lines = file.readlines()
```

## 写入文件

```python
# 写入字符串
with open("output.txt", "w", encoding="utf-8") as file:
    file.write("Hello, World!\n")

# 追加内容
with open("output.txt", "a", encoding="utf-8") as file:
    file.write("追加的内容\n")
```

## 小结

本章要点：

1. **open()**：打开文件，指定模式和编码
2. **with 语句**：自动管理文件资源
3. **read()**：读取全部内容
4. **write()**：写入字符串

> 💡 **提示**：始终使用 with 语句打开文件，确保文件正确关闭。
