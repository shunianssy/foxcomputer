# 6.2 集合

集合是无序、不重复元素的可变容器。

## 集合基础

### 创建集合

```python
# 创建空集合（注意：{} 是空字典）
empty_set = set()

# 创建有元素的集合
fruits = {"apple", "banana", "orange"}
numbers = set([1, 2, 3, 2, 1])  # 自动去重
print(numbers)  # 输出: {1, 2, 3}

# 集合推导式
squares = {x**2 for x in range(5)}
print(squares)  # 输出: {0, 1, 4, 9, 16}
```

### 集合操作

```python
fruits = {"apple", "banana", "orange"}

# 添加元素
fruits.add("grape")

# 删除元素
fruits.remove("banana")     # 不存在会报错
fruits.discard("pear")      # 不存在不报错

# 成员判断
print("apple" in fruits)    # True
```

## 集合运算

```python
a = {1, 2, 3, 4, 5}
b = {4, 5, 6, 7, 8}

# 并集
print(a | b)              # {1, 2, 3, 4, 5, 6, 7, 8}

# 交集
print(a & b)              # {4, 5}

# 差集
print(a - b)              # {1, 2, 3}

# 对称差集
print(a ^ b)              # {1, 2, 3, 6, 7, 8}
```

## 小结

本章要点：

1. **创建集合**：set() 或 {}
2. **添加元素**：add()、update()
3. **删除元素**：remove()、discard()
4. **集合运算**：| 并集、& 交集、- 差集

> **提示**：集合最适合用于去重和成员判断
