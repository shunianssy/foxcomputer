# 1.2 环境搭建

在开始 Python 编程之前，我们需要先搭建开发环境。本章将介绍如何在 Windows、macOS 和 Linux 系统上安装 Python。

## Python 版本选择

目前 Python 主要有两个版本：

| 版本 | 状态 | 说明 |
|------|------|------|
| Python 2.x | 已停止维护 | 不推荐使用 |
| Python 3.x | 当前主流 | 推荐使用 3.10+ |

> **建议**：推荐使用 Python 3.10 或更高版本

## Windows 安装

### 方法一：官网安装包

1. **下载 Python**

   访问 [Python 官网](https://www.python.org/downloads/) 下载最新版本。

2. **运行安装程序**

   ```powershell
   # 安装时务必勾选 "Add Python to PATH"
   # 这会将 Python 添加到系统环境变量
   ```

3. **验证安装**

   ```powershell
   # 打开命令提示符或 PowerShell
   python --version
   # 输出: Python 3.12.x
   
   pip --version
   # 输出: pip 24.x from ...
   ```

### 方法二：Microsoft Store

1. 打开 Microsoft Store
2. 搜索 "Python"
3. 选择 Python 3.12 并安装

### 方法三：使用 winget（推荐）

```powershell
# 使用 Windows 包管理器安装
winget install Python.Python.3.12
```

## macOS 安装

### 方法一：官网安装包

1. 访问 [Python 官网](https://www.python.org/downloads/macos/) 下载 macOS 安装包
2. 运行 .pkg 文件，按提示安装
3. 验证安装：

```bash
python3 --version
pip3 --version
```

### 方法二：Homebrew（推荐）

```bash
# 安装 Homebrew（如果未安装）
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 使用 Homebrew 安装 Python
brew install python

# 验证安装
python3 --version
```

## Linux 安装

大多数 Linux 发行版已预装 Python，但版本可能较旧。

### Ubuntu/Debian

```bash
# 更新包列表
sudo apt update

# 安装 Python 3
sudo apt install python3 python3-pip

# 验证安装
python3 --version
pip3 --version
```

### CentOS/RHEL

```bash
# 安装 EPEL 源
sudo yum install epel-release

# 安装 Python 3
sudo yum install python3 python3-pip

# 验证安装
python3 --version
```

### Fedora

```bash
# 安装 Python 3
sudo dnf install python3 python3-pip

# 验证安装
python3 --version
```

## 虚拟环境管理

虚拟环境可以为每个项目创建独立的 Python 环境，避免依赖冲突。

### 使用 venv（Python 内置）

```bash
# 创建虚拟环境
python -m venv myenv

# 激活虚拟环境
# Windows
myenv\Scripts\activate

# macOS/Linux
source myenv/bin/activate

# 退出虚拟环境
deactivate
```

### 使用 conda（推荐）

```bash
# 安装 Miniconda（轻量级 Anaconda）
# 下载地址: https://docs.conda.io/en/latest/miniconda.html

# 创建虚拟环境
conda create -n myenv python=3.12

# 激活虚拟环境
conda activate myenv

# 退出虚拟环境
conda deactivate
```

## pip 包管理

pip 是 Python 的包管理工具，用于安装和管理第三方库。

### 常用命令

```bash
# 安装包
pip install package_name

# 安装指定版本
pip install package_name==1.0.0

# 升级包
pip install --upgrade package_name

# 卸载包
pip uninstall package_name

# 查看已安装的包
pip list

# 导出依赖
pip freeze > requirements.txt

# 从 requirements.txt 安装
pip install -r requirements.txt

# 配置国内镜像源（加速下载）
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
```

### 常用国内镜像源

| 镜像源 | 地址 |
|--------|------|

## 验证环境

创建一个测试文件验证环境是否配置正确：

```python
# test_env.py
import sys
import platform

print(f"Python 版本: {sys.version}")
print(f"Python 路径: {sys.executable}")
print(f"操作系统: {platform.system()} {platform.release()}")
print(f"处理器架构: {platform.machine()}")
```

运行测试：

```bash
python test_env.py
```

## 小结

环境搭建要点：

1. **选择版本**：推荐 Python 3.10+
2. **正确安装**：Windows 用户记得勾选 "Add Python to PATH"
3. **使用虚拟环境**：避免依赖冲突
4. **配置镜像源**：加速包下载
5. **选择合适的编辑器**：VS Code 或 PyCharm

> **提示**：良好的开发环境是高效编程的基础
