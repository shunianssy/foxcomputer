# 5.3 封装与属性

封装是面向对象编程的核心概念之一，它隐藏对象的内部实现细节，只暴露必要的接口。

## 访问控制

### 公有属性

```python
class Person:
    def __init__(self, name):
        self.name = name  # 公有属性，可以直接访问

person = Person("张三")
print(person.name)  # 输出: 张三
person.name = "李四"  # 可以直接修改
```

### 受保护属性

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self._age = age  # 受保护属性（约定，单下划线）
    
    def get_age(self):
        return self._age

person = Person("张三", 25)
# 可以访问，但不推荐
print(person._age)  # 输出: 25
```

### 私有属性

```python
class BankAccount:
    def __init__(self, owner, balance):
        self.owner = owner
        self.__balance = balance  # 私有属性（名称改编，双下划线）
    
    def get_balance(self):
        return self.__balance
    
    def deposit(self, amount):
        if amount > 0:
            self.__balance += amount
            return True
        return False

account = BankAccount("张三", 1000)
print(account.get_balance())  # 输出: 1000

# 无法直接访问私有属性
# print(account.__balance)  # AttributeError

# 名称改编后可以访问（不推荐）
print(account._BankAccount__balance)  # 输出: 1000
```

## 属性装饰器

### 基本用法

```python
class Temperature:
    """温度类"""
    
    def __init__(self, celsius=0):
        self._celsius = celsius
    
    @property
    def celsius(self):
        """获取摄氏温度"""
        return self._celsius
    
    @celsius.setter
    def celsius(self, value):
        """设置摄氏温度"""
        if value < -273.15:
            raise ValueError("温度不能低于绝对零度")
        self._celsius = value
    
    @property
    def fahrenheit(self):
        """获取华氏温度（只读）"""
        return self._celsius * 9 / 5 + 32
    
    @property
    def kelvin(self):
        """获取开尔文温度（只读）"""
        return self._celsius + 273.15


# 使用示例
temp = Temperature(25)
print(f"摄氏: {temp.celsius}°C")        # 输出: 25°C
print(f"华氏: {temp.fahrenheit}°F")     # 输出: 77.0°F
print(f"开尔文: {temp.kelvin}K")        # 输出: 298.15K

# 修改温度
temp.celsius = 30
print(f"新摄氏: {temp.celsius}°C")      # 输出: 30°C
```

### 删除属性

```python
class Person:
    def __init__(self, name):
        self._name = name
    
    @property
    def name(self):
        return self._name
    
    @name.setter
    def name(self, value):
        self._name = value
    
    @name.deleter
    def name(self):
        print("删除名字")
        del self._name


person = Person("张三")
print(person.name)  # 输出: 张三

del person.name     # 输出: 删除名字
```

## 数据验证

```python
class Student:
    """学生类"""
    
    def __init__(self, name, score):
        self.name = name
        self.score = score  # 通过 setter 验证
    
    @property
    def score(self):
        return self._score
    
    @score.setter
    def score(self, value):
        if not isinstance(value, (int, float)):
            raise TypeError("成绩必须是数字")
        if not 0 <= value <= 100:
            raise ValueError("成绩必须在 0-100 之间")
        self._score = value
    
    @property
    def grade(self):
        """等级（计算属性）"""
        if self._score >= 90:
            return "A"
        elif self._score >= 80:
            return "B"
        elif self._score >= 70:
            return "C"
        elif self._score >= 60:
            return "D"
        else:
            return "F"


# 使用示例
student = Student("张三", 85)
print(f"{student.name}: {student.score}分, 等级{student.grade}")
# 输出: 张三: 85分, 等级B

# 验证
try:
    student.score = 150
except ValueError as e:
    print(f"错误: {e}")  # 输出: 错误: 成绩必须在 0-100 之间
```

## 小结

本章要点：

1. **访问控制**：公有、受保护（_）、私有（__）
2. **@property**：将方法变成属性
3. **@xxx.setter**：设置属性值
4. **@xxx.deleter**：删除属性
5. **只读属性**：只定义 getter，不定义 setter
6. **数据验证**：在 setter 中验证数据

> **提示**：使用属性装饰器可以在保持简洁语法的同时
