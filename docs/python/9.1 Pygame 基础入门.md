# 9.1 Pygame 基础入门

Pygame 是 Python 最流行的游戏开发库，基于 SDL 库构建，适合开发 2D 游戏。


## 第一个 Pygame 窗口

```python
import pygame
import sys

# 初始化 Pygame
pygame.init()

# 设置窗口大小（宽度, 高度）
SCREEN_WIDTH = 800
SCREEN_HEIGHT = 600

# 创建窗口
screen = pygame.display.set_mode((SCREEN_WIDTH, SCREEN_HEIGHT))

# 设置窗口标题
pygame.display.set_caption("我的第一个 Pygame 游戏")

# 设置窗口背景色（RGB 格式）
BACKGROUND_COLOR = (135, 206, 235)  # 天蓝色

# 游戏主循环
clock = pygame.time.Clock()  # 创建时钟对象，控制帧率
running = True

while running:
    # 事件处理
    for event in pygame.event.get():
        # 点击关闭按钮时退出
        if event.type == pygame.QUIT:
            running = False
    
    # 填充背景色
    screen.fill(BACKGROUND_COLOR)
    
    # 更新显示
    pygame.display.flip()
    
    # 控制帧率为 60 FPS
    clock.tick(60)

# 退出 Pygame
pygame.quit()
sys.exit()
```

## Pygame 核心概念

### 1. 初始化与退出

```python
import pygame

# 初始化所有模块
pygame.init()

# 初始化特定模块
pygame.display.init()  # 显示模块
pygame.mixer.init()    # 音频模块
pygame.font.init()     # 字体模块

# 退出
pygame.quit()
```

### 2. 显示 Surface

```python
import pygame

pygame.init()

# 创建主显示窗口（Surface）
screen = pygame.display.set_mode((800, 600))

# 创建额外的 Surface 对象
# 参数：(宽度, 高度), 是否有透明通道, 像素深度
surface = pygame.Surface((100, 100), pygame.SRCALPHA, 32)

# 在 Surface 上绘制
surface.fill((255, 0, 0, 128))  # 半透明红色

# 将 Surface 绘制到主窗口
# 参数：源 Surface, 位置坐标
screen.blit(surface, (100, 100))

pygame.display.flip()  # 更新显示
```

```python
import pygame
```

### 4. 游戏循环结构

```python
import pygame
import sys

pygame.init()

screen = pygame.display.set_mode((800, 600))
clock = pygame.time.Clock()

# 游戏状态变量
running = True

def handle_events():
    """处理所有事件"""
    global running
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
        elif event.type == pygame.KEYDOWN:
            if event.key == pygame.K_ESCAPE:
                running = False

def update():
    """更新游戏状态"""
    pass  # 在这里更新游戏逻辑

def draw():
    """绘制游戏画面"""
    screen.fill((0, 0, 0))  # 清屏
    # 在这里绘制游戏对象
    pygame.display.flip()    # 更新显示

# 主游戏循环
while running:
    handle_events()  # 处理事件
    update()         # 更新状态
    draw()           # 绘制画面
    clock.tick(60)   # 控制帧率

pygame.quit()
sys.exit()
```

## 小结

本章要点：

1. **pygame.init()**：初始化所有 Pygame 模块
2. **pygame.display.set_mode()**：创建游戏窗口
3. **pygame.event.get()**：获取事件队列
4. **screen.fill()**：填充背景色
5. **pygame.display.flip()**：更新显示
6. **clock.tick()**：控制帧率

> 💡 **提示**：游戏循环是 Pygame 的核心，遵循"事件处理 → 状态更新 → 画面绘制"的模式。
