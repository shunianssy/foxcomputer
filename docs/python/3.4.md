# 3.4 循环控制

循环控制语句用于改变循环的正常执行流程，包括 break、continue 和 else 子句。

## break 语句

break 用于完全跳出循环，不再执行剩余的循环。

### 基本用法

```python
# 在 for 循环中使用 break
for i in range(10):
    if i == 5:
        break
    print(i, end=" ")
# 输出: 0 1 2 3 4

# 在 while 循环中使用 break
count = 0
while True:
    print(count, end=" ")
    count += 1
    if count >= 5:
        break
# 输出: 0 1 2 3 4
```

### 查找元素

```python
# 查找列表中的元素
numbers = [1, 3, 5, 7, 9, 2, 4, 6, 8]
target = 7
found = False

for i, num in enumerate(numbers):
    if num == target:
        print(f"找到 {target}，位置在 {i}")
        found = True
        break

if not found:
    print(f"未找到 {target}")
```

### 嵌套循环中的 break

```python
# break 只跳出最内层循环
for i in range(3):
    for j in range(3):
        if j == 1:
            break  # 只跳出内层循环
        print(f"({i}, {j})", end=" ")
    print()

# 输出:
# (0, 0)
# (1, 0)
# (2, 0)

# 跳出多层循环（使用标志变量）
found = False
target = 5

for i in range(3):
    for j in range(3):
        if i * 3 + j == target:
            print(f"找到目标位置：({i}, {j})")
            found = True
            break
    if found:
        break
```

## continue 语句

continue 用于跳过当前迭代，直接进入下一次迭代。

### 基本用法

```python
# 跳过偶数
for i in range(10):
    if i % 2 == 0:
        continue
    print(i, end=" ")
# 输出: 1 3 5 7 9

# 跳过特定值
numbers = [1, 2, 0, 4, 0, 5, 6]

for num in numbers:
    if num == 0:
        continue
    print(f"100 / {num} = {100 / num}")
```

### 过滤数据

```python
# 过滤无效数据
students = [
    {"name": "张三", "score": 85},
    {"name": "李四", "score": None},  # 缺考
    {"name": "王五", "score": 78},
    {"name": "赵六", "score": None},  # 缺考
    {"name": "钱七", "score": 92}
]

print("有效成绩：")
for student in students:
    if student["score"] is None:
        continue
    print(f"  {student['name']}: {student['score']}分")
```

## else 子句

Python 的循环可以带有 else 子句，在循环正常结束时执行。

### for-else

```python
# 循环正常结束执行 else
for i in range(5):
    print(i, end=" ")
else:
    print("\n循环正常结束")

# 使用 break 时 else 不执行
for i in range(5):
    if i == 3:
        break
    print(i, end=" ")
else:
    print("\n这行不会执行")
```

### while-else

```python
# while-else 示例
count = 0

while count < 3:
    print(f"计数：{count}")
    count += 1
else:
    print("循环正常结束")
```

### 实际应用：查找元素

```python
# 使用 for-else 查找元素
numbers = [1, 3, 5, 7, 9]
target = 4

for num in numbers:
    if num == target:
        print(f"找到 {target}")
        break
else:
    print(f"未找到 {target}")

# 输出: 未找到 4
```

### 判断素数

```python
# 判断一个数是否为素数
def is_prime(n):
    """判断 n 是否为素数"""
    if n < 2:
        return False
    
    for i in range(2, int(n ** 0.5) + 1):
        if n % i == 0:
            return False
    else:
        return True

# 测试
for num in range(2, 20):
    if is_prime(num):
        print(f"{num} 是素数")
```

## 循环优化技巧

### 避免在循环中重复计算

```python
# 不好的写法
import math

numbers = range(1000000)
result = []

for num in numbers:
    result.append(math.sqrt(num) * math.pi)

# 好的写法：将不变的计算移到循环外
sqrt_pi = math.sqrt
pi = math.pi

for num in numbers:
    result.append(sqrt_pi(num) * pi)
```

### 使用内置函数和列表推导式

```python
# 不好的写法
numbers = range(1000)
squares = []

for num in numbers:
    squares.append(num ** 2)

# 好的写法：使用列表推导式
squares = [num ** 2 for num in numbers]

# 更好的写法：使用内置函数
squares = list(map(lambda x: x ** 2, numbers))
```

### 使用 enumerate 代替 range(len())

```python
# 不好的写法
fruits = ["apple", "banana", "orange"]

for i in range(len(fruits)):
    print(f"{i}: {fruits[i]}")

# 好的写法
for i, fruit in enumerate(fruits):
    print(f"{i}: {fruit}")
```

## 实战练习

### 练习一：猜数字游戏

```python
import random

secret = random.randint(1, 100)
max_attempts = 7

print("猜数字游戏（1-100），你有 7 次机会")

for attempt in range(1, max_attempts + 1):
    guess = int(input(f"第 {attempt} 次猜测："))
    
    if guess < secret:
        print("太小了")
    elif guess > secret:
        print("太大了")
    else:
        print(f"恭喜！你用了 {attempt} 次猜对了！")
        break
else:
    print(f"游戏结束！正确答案是 {secret}")
```

### 练习二：登录限制

```python
# 限制登录次数
correct_password = "123456"
max_attempts = 3

for attempt in range(1, max_attempts + 1):
    password = input("请输入密码：")
    
    if password == correct_password:
```

### 练习三：找出所有素数

```python
# 找出指定范围内的所有素数
def find_primes(start, end):
    """找出 start 到 end 之间的所有素数"""
    primes = []
    
    for num in range(max(2, start), end + 1):
        for i in range(2, int(num ** 0.5) + 1):
            if num % i == 0:
                break
        else:
            primes.append(num)
    
    return primes

# 测试
primes = find_primes(1, 100)
print(f"1-100 之间的素数：{primes}")
print(f"共 {len(primes)} 个素数")
```

### 练习五：模拟进度条

```python
import time

total = 50

print("处理进度：")

for i in range(total + 1):
    progress = "=" * i
    remaining = " " * (total - i)

print("\n处理完成！")
```

## 常见错误

### 错误使用 break 和 continue

```python
# 错误：在循环外使用 break
# if x > 10:
#     break  # SyntaxError: 'break' outside loop

# 正确：在循环内使用
while True:
    x = int(input("输入数字："))
    if x > 10:
        break
```

### else 子句位置错误

```python
# 错误：else 与 if 配对，而不是 for
for i in range(5):
    if i > 10:
        print("大于10")
else:  # 这个 else 属于 for，不是 if
    print("循环结束")
```

## 小结

本章要点：

1. **break**：完全跳出循环
2. **continue**：跳过当前迭代，继续下一次
3. **else**：循环正常结束时执行
4. **pass**：空操作占位符
5. **循环优化**：避免重复计算，使用内置函数

> 💡 **提示**：合理使用 break 和 continue 可以让循环逻辑更清晰。else 子句在查找场景中特别有用，可以避免使用额外的标志变量。
