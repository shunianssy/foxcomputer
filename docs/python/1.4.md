# 1.4 代码规范

良好的代码规范能提高代码的可读性和可维护性。Python 社区遵循 PEP 8 编码规范。

## PEP 8 简介

PEP 8 是 Python 官方的编码风格指南，全称是 "Style Guide for Python Code"。

### 核心原则

> "代码被阅读的次数远多于被编写的次数。" —— Guido van Rossum

1. **可读性优先**：代码应该清晰易读
2. **一致性**：项目内保持统一的风格
3. **简洁明了**：避免不必要的复杂性

## 命名规范

### 变量命名

```python
# 推荐：小写字母，单词间用下划线分隔（snake_case）
user_name = "张三"
total_count = 100
is_active = True

# 不推荐
userName = "张三"  # 驼峰命名（Java 风格）
UserName = "张三"  # Pascal 命名
```

### 常量命名

```python
# 常量：全大写，单词间用下划线分隔
MAX_CONNECTIONS = 100
DEFAULT_TIMEOUT = 30
PI = 3.14159

# 使用常量
timeout = DEFAULT_TIMEOUT
```

### 函数命名

```python
# 函数名：小写，下划线分隔，动词开头
def get_user_info(user_id):
    """获取用户信息"""
    pass

def calculate_total_price(items):
    """计算总价"""
    pass

def is_valid_email(email):
    """检查邮箱是否有效"""
    pass
```

### 类命名

```python
# 类名：大驼峰命名（PascalCase）
class UserProfile:
    pass

class ShoppingCart:
    pass

class HttpRequestHandler:
    pass
```

### 模块和包命名

```python
# 模块名：小写，可用下划线
# my_module.py
# data_processor.py

# 包名：小写，不推荐下划线
# mypackage/
#   __init__.py
#   core.py
```

## 缩进与空格

### 缩进

```python
# 使用 4 个空格缩进（推荐）
def calculate(a, b):
    if a > b:
        return a - b
    else:
        return b - a

# 不要混用 Tab 和空格
```

### 空格使用

```python
# 运算符两边加空格
result = a + b * c

# 逗号后面加空格
numbers = [1, 2, 3, 4, 5]

# 函数参数等号两边不加空格
def greet(name="World"):
    print(f"Hello, {name}")

# 冒号前不加空格，后面加空格（切片除外）
if x > 0:
    pass

# 切片中冒号两边不加空格
data = numbers[1:3]
data = numbers[1:10:2]
```

### 空行使用

```python
# 模块级别：两个空行分隔顶层函数和类
def function_one():
    pass


def function_two():
    pass


class MyClass:
    pass


# 类级别：一个空行分隔方法
class Calculator:
    def add(self, a, b):
        return a + b
    
    def subtract(self, a, b):
        return a - b
    
    def multiply(self, a, b):
        return a * b
```

## 导入规范

### 导入顺序

```python
# 1. 标准库
import os
import sys
from datetime import datetime

# 2. 第三方库
import requests
import numpy as np

# 3. 本地模块
from myproject import utils
from myproject.models import User
```

### 导入风格

```python
# 推荐：每个模块单独导入
import os
import sys

# 不推荐
import os, sys

# 推荐：从模块导入多个对象
from collections import OrderedDict, defaultdict

# 避免：使用 * 导入所有
from os import *  # 不推荐，可能造成命名冲突
```

## 行长度与换行

### 行长度限制

```python
# 每行最多 79 个字符（PEP 8 推荐）
# 或 88 个字符（Black 格式化工具默认）

# 长行换行方式
# 方法一：括号内换行（推荐）
long_list = [
    "item1", "item2", "item3",
    "item4", "item5", "item6"
]

# 方法二：反斜杠换行
total = first_value + second_value + \
        third_value + fourth_value

# 方法三：表达式换行
result = some_function(
    arg1, arg2,
    arg3, arg4
)
```

## 注释规范

### 行内注释

```python
# 行内注释：代码后至少两个空格，注释以 # 和一个空格开始
x = x + 1  # 补偿边界值
```

### 块注释

```python
# 块注释：每行以 # 和一个空格开始
# 计算列表中所有元素的总和
# 使用内置的 sum 函数
# 返回整数或浮点数
total = sum(numbers)
```

### 文档字符串（Docstring）

```python
def calculate_average(numbers):
    """
    计算数字列表的平均值。
    
    Args:
        numbers: 数字列表，不能为空。
    
    Returns:
        float: 列表中数字的平均值。
    
    Raises:
        ValueError: 如果列表为空。
    
    Examples:
        >>> calculate_average([1, 2, 3, 4, 5])
        3.0
    """
    if not numbers:
        raise ValueError("列表不能为空")
    return sum(numbers) / len(numbers)
```

## 常见问题示例

### 好的代码示例

```python
def get_user_by_id(user_id: int) -> dict:
    """
    根据用户ID获取用户信息。
    
    Args:
        user_id: 用户ID，必须为正整数。
    
    Returns:
        包含用户信息的字典，如果用户不存在返回 None。
    """
    if user_id <= 0:
        raise ValueError("用户ID必须为正整数")
    
    users = {
        1: {"name": "张三", "age": 25},
        2: {"name": "李四", "age": 30},
    }
    
    return users.get(user_id)


def calculate_discount(price: float, discount_rate: float) -> float:
    """
    计算折扣后的价格。
    
    Args:
        price: 原价
        discount_rate: 折扣率（0-1之间）
    
    Returns:
        折扣后的价格
    """
    if not 0 <= discount_rate <= 1:
        raise ValueError("折扣率必须在 0 到 1 之间")
    
    return price * (1 - discount_rate)
```

## 小结

代码规范要点：

1. **命名规范**：变量用 snake_case，类用 PascalCase
2. **缩进**：使用 4 个空格
3. **空格与空行**：合理使用提高可读性
4. **注释**：写有意义的注释和文档字符串
5. **工具**：使用 Black、Ruff 等工具自动格式化

> 💡 **提示**：良好的代码规范是一种习惯，从开始学习编程就养成好习惯，会让你的代码更专业、更易维护。
