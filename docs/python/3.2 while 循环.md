# 3.2 while 循环

while 循环用于在条件为真时重复执行代码块。

## 基本语法

```python
# while 循环基本结构
count = 0

while count < 5:
    print(count)
    count += 1

# 输出: 0 1 2 3 4
```

## 循环流程

```python
# 计算 1 到 100 的和
total = 0
num = 1

while num <= 100:
    total += num
    num += 1

print(f"1 到 100 的和：{total}")  # 输出: 5050
```

## while-else 结构

```python
# while-else：循环正常结束时执行 else
count = 0

while count < 3:
    print(f"计数：{count}")
    count += 1
else:
    print("循环正常结束")

# 输出:
# 计数：0
# 计数：1
# 计数：2
# 循环正常结束

# 如果使用 break 跳出循环，else 不会执行
count = 0

while count < 10:
    if count == 3:
        break
    print(f"计数：{count}")
    count += 1
else:
    print("这行不会执行")
```

## 无限循环

```python
# 无限循环
while True:
    user_input = input("请输入内容（输入 q 退出）：")
    if user_input.lower() == 'q':
        print("退出程序")
        break
    print(f"你输入了：{user_input}")
```

## 循环控制

### break 语句

```python
# break：跳出整个循环
i = 0

while True:
    print(i)
    i += 1
    if i >= 5:
        break  # 跳出循环

print("循环结束")
```

### continue 语句

```python
# continue：跳过本次迭代，继续下一次
i = 0

while i < 10:
    i += 1
    if i % 2 == 0:  # 跳过偶数
        continue
    print(i)  # 只打印奇数

# 输出: 1 3 5 7 9
```

## 嵌套循环

```python
# 嵌套 while 循环
i = 1

while i <= 3:
    j = 1
    while j <= 3:
        print(f"({i}, {j})", end=" ")
        j += 1
    print()  # 换行
    i += 1

# 输出:
# (1, 1) (1, 2) (1, 3)
# (2, 1) (2, 2) (2, 3)
# (3, 1) (3, 2) (3, 3)
```

## 实用示例

### 猜数字游戏

```python
import random

# 生成随机数
secret = random.randint(1, 100)
attempts = 0

print("猜数字游戏（1-100）")

while True:
    guess = int(input("请输入你的猜测："))
    attempts += 1
    
    if guess < secret:
        print("太小了，再试试！")
    elif guess > secret:
        print("太大了，再试试！")
    else:
        print(f"恭喜你猜对了！用了 {attempts} 次")
        break
```

### 用户输入验证

```python
# 验证用户输入
while True:
    password = input("请设置密码（至少6位）：")
    
    if len(password) < 6:
        print("密码太短，请重新输入")
        continue
    
    confirm = input("请再次输入密码：")
    
    if password == confirm:
        print("密码设置成功")
        break
    else:
        print("两次密码不一致，请重新设置")
```

```python
# 计算阶乘
n = int(input("请输入一个正整数："))
factorial = 1

while i <= n:
```

### 查找列表元素

```python
# 查找列表中的元素
fruits = ["apple", "banana", "orange", "grape", "mango"]
target = "orange"

index = 0
found = False

while index < len(fruits):
    if fruits[index] == target:
        found = True
        break
    index += 1

if found:
    print(f"找到 {target}，位置在 {index}")
else:
    print(f"未找到 {target}")
```

## 实战练习

### 练习一：斐波那契数列

```python
# 输出斐波那契数列前 n 项
n = int(input("请输入要输出的项数："))

a, b = 0, 1
count = 0

print("斐波那契数列：")
while count < n:
    print(a, end=" ")
    a, b = b, a + b
    count += 1
print()
```

### 练习二：数字反转

```python
# 反转一个整数
num = int(input("请输入一个整数："))
original = num
reversed_num = 0

while num > 0:
    digit = num % 10
    reversed_num = reversed_num * 10 + digit
    num //= 10

print(f"{original} 反转后是 {reversed_num}")
```

### 练习三：最大公约数

```python
# 使用辗转相除法求最大公约数
a = int(input("请输入第一个数："))
b = int(input("请输入第二个数："))

original_a, original_b = a, b

while b != 0:
    a, b = b, a % b

print(f"{original_a} 和 {original_b} 的最大公约数是 {a}")
```

### 练习四：菜单系统

```python
# 简单的菜单系统
def show_menu():
    print("\n===== 菜单 =====")
    print("1. 添加项目")
    print("2. 查看项目")
    print("3. 删除项目")
    print("4. 退出")
    print("================")

items = []

while True:
    show_menu()
    choice = input("请选择操作（1-4）：")
    
    if choice == '1':
        item = input("请输入要添加的项目：")
        items.append(item)
        print(f"已添加：{item}")
    elif choice == '2':
        if items:
            print("当前项目：")
            for i, item in enumerate(items, 1):
                print(f"  {i}. {item}")
        else:
            print("暂无项目")
    elif choice == '3':
        if items:
            print("当前项目：", items)
            index = int(input("请输入要删除的项目编号：")) - 1
            if 0 <= index < len(items):
                removed = items.pop(index)
                print(f"已删除：{removed}")
            else:
                print("无效的编号")
        else:
            print("暂无项目可删除")
    elif choice == '4':
        print("感谢使用，再见！")
        break
    else:
        print("无效的选择，请重新输入")
```

## 常见错误

### 忘记更新循环变量

```python
# 错误示例：无限循环
i = 0
# while i < 5:
#     print(i)
#     # 忘记 i += 1

# 正确写法
i = 0
while i < 5:
    print(i)
    i += 1
```

### 条件永远为真

```python
# 错误示例：条件永远为真
# while True:
#     print("这会无限循环")

# 正确写法：确保有退出条件
count = 0
while True:
    print(count)
    count += 1
    if count >= 5:
        break
```

## 小结

本章要点：

1. **while 循环**：条件为真时重复执行
2. **while-else**：循环正常结束时执行 else
3. **break**：跳出整个循环
4. **continue**：跳过本次迭代
5. **无限循环**：while True 配合 break 使用

> **提示**：使用 while 循环时，一定要确保循环条件最终会变为 False
