# 2.1 变量与赋值

变量是存储数据的容器。Python 中的变量不需要声明类型，直接赋值即可使用。

## 变量定义

### 基本赋值

```python
# 变量定义与赋值
name = "张三"          # 字符串
age = 25              # 整数
height = 1.75         # 浮点数
is_student = True     # 布尔值

# 打印变量
print(name)           # 输出: 张三
print(age)            # 输出: 25
print(height)         # 输出: 1.75
print(is_student)     # 输出: True
```

### 多重赋值

```python
# 同时给多个变量赋相同的值
a = b = c = 100
print(a, b, c)  # 输出: 100 100 100

# 同时给多个变量赋不同的值
x, y, z = 1, 2, 3
print(x, y, z)  # 输出: 1 2 3

# 交换变量的值（Python 特性）
a, b = 10, 20
a, b = b, a
print(a, b)  # 输出: 20 10
```

### 解包赋值

```python
# 列表解包
numbers = [1, 2, 3]
a, b, c = numbers
print(a, b, c)  # 输出: 1 2 3

# 元组解包
point = (10, 20)
x, y = point
print(x, y)  # 输出: 10 20

# 使用 * 收集剩余元素
first, *rest = [1, 2, 3, 4, 5]
print(first)  # 输出: 1
print(rest)   # 输出: [2, 3, 4, 5]

head, *middle, tail = [1, 2, 3, 4, 5]
print(head)    # 输出: 1
print(middle)  # 输出: [2, 3, 4]
print(tail)    # 输出: 5
```

## 命名规则

### 合法的变量名

```python
# 合法的变量名
name = "张三"
user_name = "李四"
userName = "王五"      # 合法但不推荐
_name = "赵六"        # 合法但不推荐
name1 = "孙七"
NAME = "周八"         # 通常用于常量
```

### 非法的变量名

```python
# 非法的变量名（会报错）
# 1name = "张三"      # 不能以数字开头
# user-name = "李四"  # 不能包含连字符
# class = "一班"      # 不能使用关键字
# my name = "王五"    # 不能包含空格
```

### 命名规范

```python
# 推荐：小写字母 + 下划线（snake_case）
user_name = "张三"
total_count = 100
is_active = True

# 不推荐
userName = "张三"     # 驼峰命名（Java 风格）
UserName = "张三"     # Pascal 命名（类名风格）
```

## 动态类型

Python 是动态类型语言，变量可以随时改变类型：

```python
# 变量类型可以改变
x = 100
print(type(x))  # <class 'int'>

x = "Hello"
print(type(x))  # <class 'str'>

x = [1, 2, 3]
print(type(x))  # <class 'list'>
```

## 类型检查

### type() 函数

```python
# 检查变量类型
name = "张三"
age = 25
height = 1.75
is_student = True

print(type(name))       # <class 'str'>
print(type(age))        # <class 'int'>
print(type(height))     # <class 'float'>
print(type(is_student)) # <class 'bool'>
```

### isinstance() 函数

```python
# 检查变量是否为指定类型
value = 100

print(isinstance(value, int))     # True
print(isinstance(value, str))     # False
print(isinstance(value, (int, str)))  # True（检查多个类型）

# 继承关系检查
class Animal:
    pass

class Dog(Animal):
    pass

dog = Dog()
print(isinstance(dog, Dog))     # True
print(isinstance(dog, Animal))  # True
```

## 变量作用域

### 局部变量与全局变量

```python
# 全局变量
message = "全局消息"

def show_message():
    # 局部变量
    message = "局部消息"
    print(message)  # 输出: 局部消息

show_message()
print(message)  # 输出: 全局消息
```

### global 关键字

```python
counter = 0

def increment():
    global counter  # 声明使用全局变量
    counter += 1

increment()
increment()
print(counter)  # 输出: 2
```

### nonlocal 关键字

```python
def outer():
    count = 0
    
    def inner():
        nonlocal count  # 引用外层函数的变量
        count += 1
        return count
    
    return inner

counter = outer()
print(counter())  # 输出: 1
print(counter())  # 输出: 2
```

## 常量

Python 没有真正的常量，约定用全大写命名表示常量：

```python
# 约定：全大写表示常量（不应修改）
PI = 3.14159
MAX_SIZE = 100
DEFAULT_TIMEOUT = 30

# 使用常量
radius = 5
area = PI * radius ** 2
print(f"圆的面积: {area}")
```

## 删除变量

```python
# 使用 del 删除变量
x = 100
print(x)  # 输出: 100

del x
# print(x)  # NameError: name 'x' is not defined
```

## 实战练习

### 练习一：变量交换

```python
# 不使用第三个变量交换两个数
a = 10
b = 20

print(f"交换前: a={a}, b={b}")
a, b = b, a
print(f"交换后: a={a}, b={b}")
```

### 练习二：计算圆的面积和周长

```python
# 计算圆的面积和周长
PI = 3.14159

radius = float(input("请输入圆的半径："))

area = PI * radius ** 2
circumference = 2 * PI * radius

print(f"圆的面积: {area:.2f}")
print(f"圆的周长: {circumference:.2f}")
```

### 练习三：解包练习

```python
# 解包用户信息
user_info = ["张三", 25, "北京", "工程师"]

name, age, city, job = user_info

print(f"姓名: {name}")
print(f"年龄: {age}")
print(f"城市: {city}")
print(f"职业: {job}")
```

## 小结

本章要点：

1. **变量定义**：直接赋值，无需声明类型
2. **命名规则**：字母、数字、下划线，不能以数字开头
3. **命名规范**：使用 snake_case 风格
4. **动态类型**：变量可以随时改变类型
5. **作用域**：注意局部变量和全局变量的区别

> 💡 **提示**：好的变量名应该能清楚地表达变量的用途，避免使用 a、b、x 这样的单字母变量名（循环变量除外）。
