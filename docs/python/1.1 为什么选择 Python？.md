# 1.1 为什么选择 Python？

Python 是一门简洁、优雅且功能强大的编程语言，被广泛应用于 Web 开发、数据分析、人工智能、自动化运维等领域。

## Python 的核心特点

### 简洁易学

Python 的语法非常接近自然语言，代码可读性极高：

```python
# Python 代码示例：打印 Hello World
print("Hello, World!")

# 计算列表中的偶数
numbers = [1, 2, 3, 4, 5, 6]
even_numbers = [n for n in numbers if n % 2 == 0]
print(even_numbers)  # 输出: [2, 4, 6]
```

### 跨平台兼容

Python 支持 Windows、macOS、Linux 等主流操作系统，一次编写，处处运行。

### 丰富的库生态

Python 拥有海量的第三方库，几乎覆盖所有领域：

| 领域 | 常用库 |
|------|--------|
| Web 开发 | Django, Flask, FastAPI |
| 数据分析 | Pandas, NumPy, Polars |
| 机器学习 | TensorFlow, PyTorch, Scikit-learn |
| 网络爬虫 | Scrapy, BeautifulSoup, Requests |
| 自动化运维 | Ansible, Fabric, Paramiko |
| 科学计算 | SciPy, Matplotlib, SymPy |
| 游戏开发 | Pygame, Arcade |
| GUI 开发 | Tkinter, PyQt, PySide |

### 解释型语言

Python 是解释型语言，无需编译，修改代码后可直接运行，非常适合快速开发和调试。

## Python 的应用领域

### Web 开发

```python
# Flask 示例
from flask import Flask

app = Flask(__name__)

@app.route('/')
def hello():
    return 'Hello, World!'

if __name__ == '__main__':
    app.run()
```

### 数据分析

```python
import pandas as pd

# 读取 CSV 文件并分析数据
df = pd.read_csv('data.csv')
print(df.describe())  # 统计摘要
print(df.head())      # 查看前几行
```

### 自动化脚本

```python
import os
import shutil

# 批量整理文件
for file in os.listdir('.'):
    if file.endswith('.txt'):
        shutil.move(file, 'text_files/')
```

### 机器学习

```python
from sklearn.linear_model import LinearRegression
import numpy as np

# 简单的线性回归
X = np.array([[1], [2], [3], [4]])
y = np.array([2, 4, 6, 8])

model = LinearRegression()
model.fit(X, y)
print(model.predict([[5]]))  # 预测结果
```
