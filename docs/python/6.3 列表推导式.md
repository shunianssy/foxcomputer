# 6.3 列表推导式

列表推导式是 Python 中创建列表的简洁方式。

## 基本语法

```python
# 基本形式：[expression for item in iterable]
squares = [x**2 for x in range(5)]
print(squares)  # [0, 1, 4, 9, 16]

# 带条件：[expression for item in iterable if condition]
evens = [x for x in range(10) if x % 2 == 0]
print(evens)  # [0, 2, 4, 6, 8]

# 带条件表达式
labels = ["偶数" if x % 2 == 0 else "奇数" for x in range(5)]
print(labels)  # ['偶数', '奇数', '偶数', '奇数', '偶数']
```

## 嵌套循环

```python
# 嵌套循环
matrix = [[i * j for j in range(1, 4)] for i in range(1, 4)]
print(matrix)  # [[1, 2, 3], [2, 4, 6], [3, 6, 9]]

# 展平嵌套列表
flat = [x for row in matrix for x in row]
print(flat)  # [1, 2, 3, 2, 4, 6, 3, 6, 9]
```

## 其他推导式

```python
# 字典推导式
squares_dict = {x: x**2 for x in range(5)}
print(squares_dict)  # {0: 0, 1: 1, 2: 4, 3: 9, 4: 16}

# 集合推导式
squares_set = {x**2 for x in [-2, -1, 0, 1, 2]}
print(squares_set)  # {0, 1, 4}

# 生成器表达式
squares_gen = (x**2 for x in range(5))
print(list(squares_gen))  # [0, 1, 4, 9, 16]
```

## 小结

本章要点：

1. **基本语法**：[expression for item in iterable]
2. **带条件**：[expression for item in iterable if condition]
3. **嵌套循环**：多个 for 子句
4. **字典/集合推导式**：{key: value for ...}

> **提示**：列表推导式简洁高效，但不要过度使用
