# 7.2 异常处理

异常处理用于捕获和处理程序运行时的错误。

## 基本语法

```python
# try-except 基本结构
try:
    result = 10 / 0
except ZeroDivisionError:
    print("除数不能为零")

# 捕获多种异常
try:
    numbers = [1, 2, 3]
    print(numbers[5])
except (IndexError, KeyError) as e:
    print(f"错误: {e}")
```

## 完整结构

```python
try:
    file = open("data.txt", "r")
    data = file.read()
except FileNotFoundError:
    print("文件不存在")
except Exception as e:
    print(f"其他错误: {e}")
else:
    print("读取成功")
finally:
    print("清理资源")
```

## 抛出异常

```python
def set_age(age):
    if age < 0:
        raise ValueError("年龄不能为负数")
    return age

try:
    set_age(-5)
except ValueError as e:
    print(e)
```

## 小结

本章要点：

1. **try-except**：捕获异常
2. **else**：无异常时执行
3. **finally**：始终执行
4. **raise**：抛出异常

> 💡 **提示**：只捕获你能处理的异常，不要使用空的 except 捕获所有异常。
