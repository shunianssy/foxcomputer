# 2.2 数字类型

Python 支持多种数字类型，包括整数、浮点数和复数。

## 整数（int）

### 基本使用

```python
# 整数定义
a = 100
b = -50
c = 0

print(type(a))  # <class 'int'>

# 大整数（Python 支持任意大小的整数）
big_number = 10 ** 100  # 10 的 100 次方
print(big_number)
```

### 不同进制表示

```python
# 十进制（默认）
decimal = 100

# 二进制（0b 或 0B 开头）
binary = 0b1010  # 等于 10

# 八进制（0o 或 0O 开头）
octal = 0o12     # 等于 10

# 十六进制（0x 或 0X 开头）
hexadecimal = 0xA  # 等于 10

print(f"二进制 0b1010 = {binary}")
print(f"八进制 0o12 = {octal}")
print(f"十六进制 0xA = {hexadecimal}")
```

### 进制转换

```python
num = 255

# 转换为二进制字符串
print(bin(num))   # 输出: 0b11111111

# 转换为八进制字符串
print(oct(num))   # 输出: 0o377

# 转换为十六进制字符串
print(hex(num))   # 输出: 0xff

# 去掉前缀
print(bin(num)[2:])  # 输出: 11111111
print(hex(num)[2:])  # 输出: ff
```

## 浮点数（float）

### 基本使用

```python
# 浮点数定义
a = 3.14
b = -0.5
c = 2.0

print(type(a))  # <class 'float'>

# 科学计数法
large = 1.23e10   # 1.23 × 10^10
small = 1.23e-10  # 1.23 × 10^-10

print(large)  # 输出: 12300000000.0
print(small)  # 输出: 1.23e-10
```

### 浮点数精度问题

```python
# 浮点数精度问题
result = 0.1 + 0.2
print(result)  # 输出: 0.30000000000000004

# 使用 Decimal 处理精确计算
from decimal import Decimal

a = Decimal('0.1')
b = Decimal('0.2')
print(a + b)  # 输出: 0.3
```

### 四舍五入

```python
# round() 函数
pi = 3.14159265

print(round(pi))      # 输出: 3
print(round(pi, 2))   # 输出: 3.14
print(round(pi, 4))   # 输出: 3.1416

# 注意：round() 使用银行家舍入法
print(round(2.5))  # 输出: 2（舍入到最近的偶数）
print(round(3.5))  # 输出: 4
```

## 复数（complex）

```python
# 复数定义
c1 = 3 + 4j
c2 = complex(3, 4)  # 等价于 3 + 4j

print(type(c1))  # <class 'complex'>

# 获取实部和虚部
print(c1.real)  # 输出: 3.0
print(c1.imag)  # 输出: 4.0

# 获取共轭复数
print(c1.conjugate())  # 输出: (3-4j)

# 复数运算
c3 = 1 + 2j
c4 = 3 + 4j
print(c3 + c4)  # 输出: (4+6j)
print(c3 * c4)  # 输出: (-5+10j)

# 获取模（绝对值）
print(abs(c1))  # 输出: 5.0
```

## 数学运算符

### 基本运算

```python
a, b = 10, 3

# 加法
print(a + b)   # 输出: 13

# 减法
print(a - b)   # 输出: 7

# 乘法
print(a * b)   # 输出: 30

# 除法（结果为浮点数）
print(a / b)   # 输出: 3.3333333333333335

# 整除（向下取整）
print(a // b)  # 输出: 3

# 取余
print(a % b)   # 输出: 1

# 幂运算
print(a ** b)  # 输出: 1000
print(2 ** 10) # 输出: 1024
```

### 运算符优先级

```python
# 运算符优先级（从高到低）
# 1. ** 幂运算
# 2. +x, -x 正负号
# 3. *, /, //, % 乘除
# 4. +, - 加减

result = 2 + 3 * 4 ** 2
# 计算顺序: 4**2 = 16, 3*16 = 48, 2+48 = 50
print(result)  # 输出: 50

# 使用括号改变优先级
result = (2 + 3) * 4 ** 2
print(result)  # 输出: 80
```

### 增量赋值

```python
# 增量赋值运算符
x = 10

x += 5   # 等价于 x = x + 5
print(x)  # 输出: 15

x -= 3   # 等价于 x = x - 3
print(x)  # 输出: 12

x *= 2   # 等价于 x = x * 2
print(x)  # 输出: 24

x //= 5  # 等价于 x = x // 5
print(x)  # 输出: 4
```

## 数学函数

### 内置函数

```python
# 绝对值
print(abs(-10))    # 输出: 10

# 最大值、最小值
print(max(1, 5, 3, 2))   # 输出: 5
print(min(1, 5, 3, 2))   # 输出: 1

# 幂运算
print(pow(2, 10))  # 输出: 1024
print(pow(2, 3, 5)) # 输出: 3 (2^3 % 5)

# 求和
print(sum([1, 2, 3, 4, 5]))  # 输出: 15
```

### math 模块

```python
import math

# 常用常量
print(math.pi)   # 输出: 3.141592653589793
print(math.e)    # 输出: 2.718281828459045

# 向上取整和向下取整
print(math.ceil(3.2))   # 输出: 4
print(math.floor(3.8))  # 输出: 3

# 平方根
print(math.sqrt(16))    # 输出: 4.0

# 对数
print(math.log(10))     # 自然对数
print(math.log10(100))  # 以 10 为底的对数，输出: 2.0
print(math.log2(8))     # 以 2 为底的对数，输出: 3.0

# 三角函数
print(math.sin(math.pi / 2))  # 输出: 1.0
print(math.cos(0))            # 输出: 1.0
print(math.tan(math.pi / 4))  # 输出: 0.9999999999999999

# 角度与弧度转换
print(math.degrees(math.pi))  # 输出: 180.0
print(math.radians(180))      # 输出: 3.141592653589793
```

## 类型转换

```python
# 字符串转数字
a = int("100")
b = float("3.14")

print(a)  # 输出: 100
print(b)  # 输出: 3.14

# 浮点数转整数
c = int(3.9)
print(c)  # 输出: 3（直接截断，不是四舍五入）

# 整数转浮点数
d = float(10)
print(d)  # 输出: 10.0

# 布尔值转数字
print(int(True))   # 输出: 1
print(int(False))  # 输出: 0
```

## 实战练习

### 练习一：计算 BMI

```python
# 计算身体质量指数（BMI）
height = float(input("请输入身高（米）："))
weight = float(input("请输入体重（千克）："))

bmi = weight / (height ** 2)

print(f"您的 BMI 指数为：{bmi:.2f}")

# 判断体重状况
if bmi < 18.5:
    print("体重过轻")
elif bmi < 24:
    print("体重正常")
elif bmi < 28:
    print("体重过重")
else:
    print("肥胖")
```

### 练习二：数字反转

```python
# 反转一个三位数
num = int(input("请输入一个三位数："))

# 方法一：数学运算
a = num // 100        # 百位
b = (num // 10) % 10  # 十位
c = num % 10          # 个位

reversed_num = c * 100 + b * 10 + a
print(f"反转后的数字：{reversed_num}")

# 方法二：字符串
reversed_num = int(str(num)[::-1])
print(f"反转后的数字：{reversed_num}")
```

### 练习三：计算阶乘

```python
# 计算阶乘
n = int(input("请输入一个正整数："))

# 方法一：循环
factorial = 1
for i in range(1, n + 1):
    factorial *= i
print(f"{n}! = {factorial}")

# 方法二：math 模块
import math
print(f"{n}! = {math.factorial(n)}")
```

## 小结

本章要点：

1. **整数**：支持任意大小，可使用不同进制表示
2. **浮点数**：注意精度问题，精确计算使用 Decimal
3. **复数**：使用 j 表示虚部
4. **运算符**：/ 普通除法，// 整除，% 取余，** 幂运算
5. **math 模块**：提供丰富的数学函数

> 💡 **提示**：进行浮点数比较时要特别小心，由于精度问题，`0.1 + 0.2 == 0.3` 返回 False。
