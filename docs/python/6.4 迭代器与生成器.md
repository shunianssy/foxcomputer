# 6.4 迭代器与生成器

迭代器和生成器是 Python 中处理序列数据的重要工具。

## 迭代器

```python
# 可迭代对象与迭代器
numbers = [1, 2, 3]
it = iter(numbers)

print(next(it))  # 1
print(next(it))  # 2
print(next(it))  # 3
# print(next(it))  # StopIteration
```

### 自定义迭代器

```python
class Counter:
    """自定义迭代器：计数器"""
    
    def __init__(self, start, end):
        self.current = start
        self.end = end
    
    def __iter__(self):
        return self
    
    def __next__(self):
        if self.current > self.end:
            raise StopIteration
        value = self.current
        self.current += 1
        return value


counter = Counter(1, 5)
for num in counter:
    print(num)  # 输出: 1 2 3 4 5
```

## 生成器

### 使用 yield

```python
def count_up(n):
    """生成器函数：从 1 数到 n"""
    i = 1
    while i <= n:
        yield i
        i += 1


for num in count_up(5):
    print(num)  # 输出: 1 2 3 4 5
```

### 生成器表达式

```python
# 生成器表达式
squares = (x**2 for x in range(5))
print(list(squares))  # [0, 1, 4, 9, 16]

# 惰性计算，节省内存
import sys
list_data = [x for x in range(10000)]
gen_data = (x for x in range(10000))

print(sys.getsizeof(list_data))  # 较大
print(sys.getsizeof(gen_data))   # 较小
```

## 小结

本章要点：

1. **迭代器**：实现 __iter__ 和 __next__ 方法
2. **生成器函数**：使用 yield 返回值
3. **生成器表达式**：(expression for item in iterable)
4. **惰性计算**：按需生成，节省内存

> 💡 **提示**：处理大数据集时，使用生成器可以显著节省内存。
