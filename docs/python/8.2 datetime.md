# 8.2 datetime

datetime 模块用于处理日期和时间。

## 基本使用

```python
from datetime import datetime, date, time, timedelta

# 当前日期时间
now = datetime.now()
print(now)

# 当前日期
today = date.today()
print(today)

# 创建日期时间
dt = datetime(2024, 1, 15, 10, 30, 0)
print(dt)

# 访问属性
print(dt.year, dt.month, dt.day)
```

## 格式化

```python
from datetime import datetime

now = datetime.now()

# 格式化输出
print(now.strftime("%Y-%m-%d %H:%M:%S"))

# 解析字符串
dt = datetime.strptime("2024-01-15 10:30:00", "%Y-%m-%d %H:%M:%S")
```

## 时间运算

```python
from datetime import datetime, timedelta

now = datetime.now()

# 时间差
delta = timedelta(days=7)
future = now + delta
past = now - delta

# 计算差值
diff = future - now
print(diff.days)
```

## 小结

本章要点：

1. **datetime.now()**：当前时间
2. **strftime()**：格式化输出
3. **strptime()**：解析字符串
4. **timedelta**：时间差运算

> **提示**：处理时区时，使用 zoneinfo 模块
