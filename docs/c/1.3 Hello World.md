# 1.3 Hello World

现在让我们编写第一个 C 语言程序——经典的 "Hello World"。通过这个简单的程序，我们将了解 C 语言程序的基本结构。

## 第一个 C 程序

```c
#include <stdio.h>

int main(void) {
 printf("Hello, World!\n");
 return 0;
}
```

## 程序结构解析

### 1. 预处理指令

```c
#include <stdio.h>
```

- `#include` 是预处理指令，用于包含头文件
- `<stdio.h>` 是标准输入输出头文件
- 该文件包含了 `printf` 等函数的声明

### 2. main 函数

```c
int main(void) {
 // 函数体
 return 0;
}
```

- `main` 是程序的入口函数
- `int` 表示返回类型为整数
- `void` 表示不接受参数
- `return 0` 表示程序正常结束

### 3. 输出语句

```c
printf("Hello, World!\n");
```

- `printf` 是格式化输出函数
- `"Hello, World!\n"` 是字符串字面量
- `\n` 是换行符
- 每条语句以分号 `;` 结束

## 编译与运行

### 使用 GCC 编译

```bash
# 编译程序
gcc hello.c -o hello

# 运行程序
./hello # Linux/macOS
hello.exe # Windows
```

### 输出结果

```
Hello, World!
```

## 程序的编译过程

C 程序从源代码到可执行文件经历四个阶段：

```
源代码 (.c)
 ↓ 预处理
预处理后的代码 (.i)
 ↓ 编译
汇编代码 (.s)
 ↓ 汇编
目标文件 (.o/.obj)
 ↓ 链接
可执行文件 (.exe/无后缀)
```

### 分步编译演示

```bash
# 1. 预处理：展开头文件和宏
gcc -E hello.c -o hello.i

# 2. 编译：生成汇编代码
gcc -S hello.i -o hello.s

# 3. 汇编：生成目标文件
gcc -c hello.s -o hello.o

# 4. 链接：生成可执行文件
gcc hello.o -o hello
```

## printf 函数详解

`printf` 是 C 语言中最常用的输出函数：

```c
#include <stdio.h>

int main(void) {
 /* 基本输出 */
 printf("Hello, World!\n");
 
 /* 输出整数 */
 int age = 25;
 printf("年龄: %d\n", age);
 
 /* 输出浮点数 */
 float height = 175.5f;
 printf("身高: %.1f cm\n", height);
 
 /* 输出字符 */
 char grade = 'A';
 printf("等级: %c\n", grade);
 
 /* 输出字符串 */
 printf("姓名: %s\n", "张三");
 
 /* 多个格式化输出 */
 printf("姓名: %s, 年龄: %d, 身高: %.1f cm\n", "张三", 25, 175.5);
 
 return 0;
}
```

### 常用格式说明符

| 格式符 | 说明 | 示例 |
|--------|------|------|
| `%d` | 有符号十进制整数 | `printf("%d", 42);` |
| `%u` | 无符号十进制整数 | `printf("%u", 42u);` |
| `%f` | 浮点数 | `printf("%f", 3.14);` |
| `%.nf` | 保留 n 位小数 | `printf("%.2f", 3.14159);` |
| `%c` | 单个字符 | `printf("%c", 'A');` |
| `%s` | 字符串 | `printf("%s", "Hello");` |
| `%p` | 指针地址 | `printf("%p", ptr);` |
| `%x` | 十六进制整数 | `printf("%x", 255);` |
| `%o` | 八进制整数 | `printf("%o", 64);` |
| `%%` | 百分号 | `printf("%%");` |

### 转义字符

| 转义符 | 说明 |
|--------|------|
| `\n` | 换行 |
| `\t` | 水平制表符 |
| `\r` | 回车 |
| `\\` | 反斜杠 |
| `\'` | 单引号 |
| `\"` | 双引号 |
| `\0` | 空字符（字符串结束符） |

## 带参数的 main 函数

```c
#include <stdio.h>

int main(int argc, char *argv[]) {
 printf("参数个数: %d\n", argc);
 
 for (int i = 0; i < argc; i++) {
 printf("参数 %d: %s\n", i, argv[i]);
 }
 
 return 0;
}
```

运行示例：

```bash
./hello world 123
```

输出：

```
参数个数: 3
参数 0: ./hello
参数 1: world
参数 2: 123
```

## 注释

C 语言支持两种注释方式：

```c
#include <stdio.h>

/*
 * 这是多行注释
 * 可以跨越多行
 * 用于详细说明
 */
int main(void) {
 // 这是单行注释
 // 用于简短说明
 
 printf("Hello, World!\n"); // 行末注释
 
 /* 也可以在代码中间使用 */
 int x = 10; /* 定义变量 x */
 
 return 0; // 返回 0 表示程序正常结束
}
```

## 完整示例：个人信息输出

```c
#include <stdio.h>

/*
 * 程序名称：个人信息输出
 * 功能：演示 printf 的各种用法
 * 作者：FoxComputer
 */

int main(void) {
 /* 定义变量 */
 char name[] = "张三";
 int age = 25;
 float height = 175.5f;
 char gender = 'M';
 double score = 89.5;
 
 /* 输出标题 */
 printf("========== 个人信息 ==========\n");
 
 /* 输出各项信息 */
 printf("姓名: %s\n", name);
 printf("性别: %c\n", gender);
 printf("年龄: %d 岁\n", age);
 printf("身高: %.1f cm\n", height);
 printf("成绩: %.2f 分\n", score);
 
 /* 输出分隔线 */
 printf("==============================\n");
 
 /* 格式化对齐输出 */
 printf("%-10s: %s\n", "姓名", name);
 printf("%-10s: %c\n", "性别", gender);
 printf("%-10s: %d 岁\n", "年龄", age);
 printf("%-10s: %.1f cm\n", "身高", height);
 
 return 0;
}
```

输出：

```
========== 个人信息 ==========
姓名: 张三
性别: M
年龄: 25 岁
身高: 175.5 cm
成绩: 89.50 分
==============================
姓名 : 张三
性别 : M
年龄 : 25 岁
身高 : 175.5 cm
```

## 常见错误

### 1. 忘记分号

```c
/* 错误 */
printf("Hello, World!\n")
/* 正确 */
printf("Hello, World!\n");
```

### 2. 忘记头文件

```c
/* 错误：未包含 stdio.h */
int main(void) {
 printf("Hello\n"); /* 编译器可能警告 */
 return 0;
}

/* 正确 */
#include <stdio.h>
int main(void) {
 printf("Hello\n");
 return 0;
}
```

### 3. 格式符不匹配

```c
/* 错误：格式符与数据类型不匹配 */
int x = 10;
printf("%f\n", x); /* 错误：应该用 %d */

/* 正确 */
printf("%d\n", x);
```

### 4. 忘记 return

```c
/* 不推荐：虽然 C99 允许省略 */
int main(void) {
 printf("Hello\n");
}

/* 推荐：明确返回 */
int main(void) {
 printf("Hello\n");
 return 0;
}
```

## 小结

Hello World 程序要点：

1. **程序结构**：头文件包含 + main 函数
2. **预处理**：`#include` 用于包含头文件
3. **main 函数**：程序的入口点
4. **printf**：格式化输出函数
5. **编译运行**：gcc 编译，./ 运行

> **提示**：养成良好的编码习惯，包括添加注释、使用正确的缩进、遵循命名规范等。这些习惯将使你的代码更易读、更易维护。
