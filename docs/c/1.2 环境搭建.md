# 1.2 环境搭建

在开始学习 C 语言之前，我们需要先搭建开发环境。本章将介绍如何在 Windows、Linux 和 macOS 上安装 C 语言编译器和开发工具。

## 编译器选择

### GCC（GNU Compiler Collection）

GCC 是最流行的 C 语言编译器，支持多种平台：

- **优点**：免费、开源、跨平台、标准支持好
- **适用**：Linux、macOS、Windows（MinGW）

### Clang

Clang 是 LLVM 项目的一部分，编译速度快：

- **优点**：编译速度快、错误信息友好、模块化设计
- **适用**：macOS（Xcode 默认）、Linux、Windows

### MSVC（Microsoft Visual C++）

MSVC 是微软提供的编译器：

- **优点**：Windows 平台优化好、调试功能强大
- **适用**：Windows 平台开发

## Windows 环境搭建

### 方法一：安装 MinGW-w64

1. **下载 MinGW-w64**

访问 [MinGW-w64 官网](https://www.mingw-w64.org/) 或使用 MSYS2：

```powershell
# 使用 winget 安装 MSYS2
winget install MSYS2.MSYS2
```

2. **安装 GCC**

在 MSYS2 终端中执行：

```bash
# 更新包数据库
pacman -Syu

# 安装 GCC 工具链
pacman -S mingw-w64-x86_64-gcc mingw-w64-x86_64-make
```

3. **配置环境变量**

将以下路径添加到系统 PATH：

```
C:\msys64\mingw64\bin
```

4. **验证安装**

```powershell
gcc --version
```

### 方法二：安装 Visual Studio

1. 下载 [Visual Studio Community](https://visualstudio.microsoft.com/)
2. 安装时选择"使用 C++ 的桌面开发"
3. 使用 Visual Studio 或 Developer Command Prompt

## Linux 环境搭建

### Ubuntu/Debian

```bash
# 更新包列表
sudo apt update

# 安装 GCC 和相关工具
sudo apt install build-essential gdb

# 验证安装
gcc --version
gdb --version
```

### CentOS/RHEL/Fedora

```bash
# CentOS/RHEL
sudo yum groupinstall "Development Tools"

# Fedora
sudo dnf groupinstall "Development Tools"

# 验证安装
gcc --version
```

### Arch Linux

```bash
# 安装 GCC 工具链
sudo pacman -S base-devel gdb

# 验证安装
gcc --version
```

## macOS 环境搭建

### 安装 Xcode Command Line Tools

```bash
# 安装命令行工具
xcode-select --install

# 验证安装
gcc --version
clang --version
```

### 使用 Homebrew 安装 GCC

```bash
# 安装 Homebrew（如果未安装）
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 安装 GCC
brew install gcc

# 验证安装
gcc-13 --version
```

### 编辑器/IDE

| 工具 | 特点 | 适用平台 |
|------|------|----------|
| VS Code | 轻量、插件丰富、免费 | 全平台 |
| CLion | JetBrains 出品、功能强大 | 全平台 |

### VS Code 配置

1. **安装 VS Code**

从 [官网](https://code.visualstudio.com/) 下载安装

2. **安装扩展**

推荐安装以下扩展：

- C/C++（Microsoft）
- C/C++ Extension Pack
- Code Runner
- C/C++ Helper

3. **配置 tasks.json**

创建 `.vscode/tasks.json`：

```json
{
    "version": "2.0.0",
    "tasks": [
        {
            "type": "cppbuild",
            "label": "C 编译",
            "command": "gcc",
            "args": [
                "-fdiagnostics-color=always",
                "-g",
                "${file}",
                "-o",
                "${fileDirname}/${fileBasenameNoExtension}.exe"
            ],
            "options": {
                "cwd": "${fileDirname}"
            },
            "problemMatcher": ["$gcc"],
            "group": {
                "kind": "build",
                "isDefault": true
            }
        }
    ]
}
```

4. **配置 launch.json**

创建 `.vscode/launch.json`：

```json
{
    "version": "0.2.0",
    "configurations": [
        {
            "name": "C 调试",
            "type": "cppdbg",
            "request": "launch",
            "program": "${fileDirname}/${fileBasenameNoExtension}.exe",
            "args": [],
            "stopAtEntry": false,
            "cwd": "${fileDirname}",
            "environment": [],
            "externalConsole": false,
            "MIMode": "gdb",
            "miDebuggerPath": "gdb",
            "preLaunchTask": "C 编译"
        }
    ]
}
```

## 编译与运行

### 基本编译命令

```bash
# 编译单个文件
gcc hello.c -o hello

# 运行程序
./hello          # Linux/macOS
hello.exe        # Windows
```

### 常用编译选项

```bash
# 添加调试信息
gcc -g hello.c -o hello

# 开启警告
gcc -Wall hello.c -o hello

# 指定 C 标准
gcc -std=c11 hello.c -o hello

# 优化级别
gcc -O2 hello.c -o hello

# 组合使用
gcc -Wall -g -std=c11 hello.c -o hello
```

### 多文件编译

```bash
# 编译多个源文件
gcc main.c utils.c -o program

# 分步编译
gcc -c main.c -o main.o
gcc -c utils.c -o utils.o
gcc main.o utils.o -o program
```

## Makefile 使用

创建 `Makefile` 文件：

```makefile
# 编译器设置
CC = gcc
CFLAGS = -Wall -g -std=c11

# 目标文件
TARGET = program

# 源文件
SRCS = main.c utils.c
OBJS = $(SRCS:.c=.o)

# 默认目标
all: $(TARGET)

# 链接
$(TARGET): $(OBJS)
	$(CC) $(CFLAGS) -o $@ $^

# 编译
%.o: %.c
	$(CC) $(CFLAGS) -c $< -o $@

# 清理
clean:
	rm -f $(OBJS) $(TARGET)

# 伪目标
.PHONY: all clean
```

使用 Makefile：

```bash
# 编译
make

# 清理
make clean
```

## 验证环境

创建测试文件 `hello.c`：

```c
#include <stdio.h>

int main(void) {
    printf("Hello, C!\n");
    printf("编译器版本: %s\n", 
#ifdef __GNUC__
        "GCC"
#elif _MSC_VER
        "MSVC"
#elif __clang__
        "Clang"
#else
        "Unknown"
#endif
    );
    return 0;
}
```

编译运行：

```bash
gcc hello.c -o hello && ./hello
```

预期输出：

```
Hello, C!
编译器版本: GCC
```

## 小结

环境搭建要点：

1. **选择编译器**：GCC 是最通用的选择
2. **安装工具**：根据操作系统选择合适的安装方式
3. **配置编辑器**：VS Code 是推荐的轻量级选择
4. **验证环境**：编译运行测试程序确认配置正确

> 💡 **提示**：如果遇到问题，请检查环境变量是否正确配置，编译器路径是否在 PATH 中。Windows 用户建议使用 MSYS2 或 WSL 获得更好的开发体验。
