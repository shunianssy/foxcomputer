# 7.1 Admin 配置

Django Admin 是一个功能强大的后台管理系统，本章介绍如何配置和使用 Admin 后台。

## 基本配置

### 创建管理员

```bash
python manage.py createsuperuser
```

### 注册模型

```python
# blog/admin.py
from django.contrib import admin
from .models import Article, Category, Tag

@admin.register(Article)
class ArticleAdmin(admin.ModelAdmin):
 list_display = ['title', 'author', 'status', 'created_at']
 list_filter = ['status', 'category']
 search_fields = ['title', 'content']

admin.site.register(Category)
admin.site.register(Tag)
```

### 访问 Admin

访问 `/admin/` 即可进入后台管理系统。

## Admin 站点配置

### 修改站点信息

```python
# urls.py
from django.contrib import admin

admin.site.site_header = '我的博客管理'
admin.site.site_title = '博客后台'
admin.site.index_title = '欢迎使用博客管理系统'
```

### 自定义 Admin 样式

```python
# settings.py
INSTALLED_APPS = [
 'django.contrib.admin',
 # ...
]
```

## 模型注册方式

### 方式一：装饰器

```python
@admin.register(Article)
class ArticleAdmin(admin.ModelAdmin):
 pass
```

### 方式二：注册函数

```python
class ArticleAdmin(admin.ModelAdmin):
 pass

admin.site.register(Article, ArticleAdmin)
```

## 基本选项

```python
@admin.register(Article)
class ArticleAdmin(admin.ModelAdmin):
 # 列表显示字段
 list_display = ['title', 'author', 'status', 'created_at']
 
 # 列表过滤
 list_filter = ['status', 'category', 'created_at']
 
 # 搜索字段
 search_fields = ['title', 'content', 'author__username']
 
 # 排序
 ordering = ['-created_at']
 
 # 每页显示数量
 list_per_page = 20
 
 # 日期分层导航
 date_hierarchy = 'created_at'
 
 # 外键自动完成
 autocomplete_fields = ['author', 'category']
 
 # 只读字段
 readonly_fields = ['created_at', 'updated_at']
```

## 小结

Admin 配置的关键点：

1. **创建管理员**：`createsuperuser` 命令
2. **注册模型**：装饰器或注册函数
3. **站点配置**：自定义标题和样式
4. **列表选项**：显示、过滤、搜索

> **提示**：Django Admin 是开箱即用的后台系统，通过简单配置即可满足大部分需求。
