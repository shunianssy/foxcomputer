# 7.2 ModelAdmin

ModelAdmin 类提供了丰富的选项来自定义 Admin 界面。本章详细介绍 ModelAdmin 的各种配置。

## 列表显示

### list_display

```python
@admin.register(Article)
class ArticleAdmin(admin.ModelAdmin):
    list_display = ['title', 'author', 'status', 'get_views', 'created_at']
    
    def get_views(self, obj):
        return f"{obj.views} 次"
    get_views.short_description = '浏览量'
    get_views.admin_order_field = 'views'
```

### 自定义列

```python
def status_badge(self, obj):
    colors = {
        'draft': 'gray',
        'published': 'green',
        'archived': 'red'
    }
    return format_html(
        '<span style="color: {};">{}</span>',
        colors.get(obj.status, 'black'),
        obj.get_status_display()
    )
status_badge.short_description = '状态'
```

## 列表过滤

### list_filter

```python
class ArticleAdmin(admin.ModelAdmin):
    list_filter = [
        'status',
        'category',
        ('created_at', admin.DateFieldListFilter),
    ]
```

### 自定义过滤器

```python
class StatusFilter(admin.SimpleListFilter):
    title = '文章状态'
    parameter_name = 'status'
    
    def lookups(self, request, model_admin):
        return [
            ('published', '已发布'),
            ('draft', '草稿'),
        ]
    
    def queryset(self, request, queryset):
        if self.value():
            return queryset.filter(status=self.value())

class ArticleAdmin(admin.ModelAdmin):
    list_filter = [StatusFilter]
```

## 搜索功能

```python
class ArticleAdmin(admin.ModelAdmin):
    search_fields = ['title', 'content', 'author__username']
    search_help_text = '搜索标题、内容或作者'
```

## 编辑表单

### fields 和 fieldsets

```python
class ArticleAdmin(admin.ModelAdmin):
    # 简单字段顺序
    fields = ['title', 'content', 'status']
    
    # 分组字段
    fieldsets = (
        ('基本信息', {
            'fields': ('title', 'slug', 'category')
        }),
        ('内容', {
            'fields': ('content',),
            'classes': ('collapse',),
        }),
        ('发布选项', {
            'fields': ('status', 'publish_date'),
            'classes': ('wide',),
        }),
    )
```

### 排除字段

```python
class ArticleAdmin(admin.ModelAdmin):
    exclude = ['views', 'created_at']
```

### 只读字段

```python
class ArticleAdmin(admin.ModelAdmin):
    readonly_fields = ['created_at', 'updated_at', 'slug']
```

## 内联编辑

### TabularInline

```python
class CommentInline(admin.TabularInline):
    model = Comment
    extra = 1
    readonly_fields = ['created_at']

class ArticleAdmin(admin.ModelAdmin):
    inlines = [CommentInline]
```

### StackedInline

```python
class CommentInline(admin.StackedInline):
    model = Comment
    extra = 0
```

## 小结

ModelAdmin 的关键点：

1. **list_display**：列表显示字段
2. **list_filter**：列表过滤器
3. **search_fields**：搜索字段
4. **fieldsets**：表单分组
5. **inlines**：内联编辑

> 💡 **提示**：合理使用 ModelAdmin 选项可以大大提高后台管理效率。
