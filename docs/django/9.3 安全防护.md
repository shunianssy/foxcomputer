# 9.3 安全防护

Web 应用安全是开发中的重要环节。本章介绍 Django 中的常见安全防护措施。

## Django 内置安全

### CSRF 防护

```python
# settings.py
CSRF_USE_SESSIONS = True
CSRF_COOKIE_SECURE = True
CSRF_COOKIE_HTTPONLY = True
```

```html
<!-- 模板中 -->
<form method="post">
    {% csrf_token %}
    ...
</form>
```

### XSS 防护

```python
# settings.py
SECURE_BROWSER_XSS_FILTER = True
```

Django 模板默认转义 HTML：

```html
{{ content }}  <!-- 自动转义 -->
{{ content|safe }}  <!-- 不转义（谨慎使用） -->
```

### SQL 注入防护

使用 ORM 避免直接拼接 SQL：

```python
# 安全
Article.objects.filter(title=title)

# 不安全（避免）
Article.objects.raw(f"SELECT * FROM article WHERE title = '{title}'")
```

### Clickjacking 防护

```python
# settings.py
X_FRAME_OPTIONS = 'DENY'

# 或使用中间件
MIDDLEWARE = [
    'django.middleware.clickjacking.XFrameOptionsMiddleware',
]
```

## HTTPS 配置

### 强制 HTTPS

```python
# settings.py
SECURE_SSL_REDIRECT = True
SECURE_PROXY_SSL_HEADER = ('HTTP_X_FORWARDED_PROTO', 'https')
SESSION_COOKIE_SECURE = True
CSRF_COOKIE_SECURE = True
```

### HSTS

```python
SECURE_HSTS_SECONDS = 31536000  # 1 年
SECURE_HSTS_INCLUDE_SUBDOMAINS = True
SECURE_HSTS_PRELOAD = True
```

## 密码安全

### 密码验证

```python

    {'NAME': 'django.contrib.auth.password_validation.MinimumLengthValidator',
     'OPTIONS': {'min_length': 10}},
    {'NAME': 'django.contrib.auth.password_validation.CommonPasswordValidator'},
```

## 输入验证

### 表单验证

```python
from django import forms

class ArticleForm(forms.Form):
    title = forms.CharField(max_length=200)
    content = forms.CharField()
    
    def clean_title(self):
        title = self.cleaned_data['title']
        # 验证逻辑
        if '<script>' in title.lower():
            raise forms.ValidationError('非法内容')
        return title
```

### 文件上传验证

```python
def clean_file(self):
    file = self.cleaned_data['file']
    
    # 检查文件类型
    allowed_types = ['application/pdf', 'image/jpeg']
    if file.content_type not in allowed_types:
        raise forms.ValidationError('不支持的文件类型')
    
    # 检查文件大小
    if file.size > 10 * 1024 * 1024:
        raise forms.ValidationError('文件大小不能超过 10MB')
    
    return file
```

## 小结

安全防护的关键点：

1. **CSRF 防护**：表单添加 token
2. **XSS 防护**：模板自动转义
3. **SQL 注入**：使用 ORM
4. **HTTPS**：强制 SSL
5. **密码安全**：强密码策略

> 💡 **提示**：安全是一个持续的过程，定期检查和更新安全配置。
