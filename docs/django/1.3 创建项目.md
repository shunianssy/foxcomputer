# 1.3 创建项目

环境准备就绪后，让我们创建第一个 Django 项目。本章将带你了解 Django 项目的结构和基本操作。

## 创建项目

使用 Django 提供的命令行工具创建项目：

```bash
# 创建项目（注意末尾的点号）
django-admin startproject mysite .

# 或者指定项目名称
django-admin startproject mysite
```

> 💡 **提示**：末尾的点号 `.` 表示在当前目录创建项目，不会额外创建同名文件夹。

## 项目结构

创建完成后，项目目录结构如下：

```text
mysite/
├── manage.py           # 项目管理脚本
└── mysite/             # 项目配置目录
    ├── __init__.py     # Python 包标识
    ├── settings.py     # 项目配置文件
    ├── urls.py         # URL 路由配置
    ├── asgi.py         # ASGI 服务器入口
    └── wsgi.py         # WSGI 服务器入口
```

### 文件说明

| 文件 | 作用 |
|------|------|
| `manage.py` | 命令行工具，用于运行服务器、创建应用等 |
| `settings.py` | 项目配置，包括数据库、中间件、应用等 |
| `urls.py` | URL 路由配置，定义 URL 与视图的映射 |
| `wsgi.py` | WSGI 服务器入口，用于生产部署 |
| `asgi.py` | ASGI 服务器入口，支持异步和 WebSocket |

## 运行开发服务器

Django 内置了轻量级开发服务器：

```bash
# 运行开发服务器
python manage.py runserver

# 指定端口
python manage.py runserver 8080

# 允许外部访问
python manage.py runserver 0.0.0.0:8000
```

访问 http://127.0.0.1:8000/，你将看到 Django 的欢迎页面。

## 创建应用

Django 项目由多个应用组成，每个应用负责一个独立的功能模块：

```bash
# 创建应用
python manage.py startapp blog
```

应用目录结构：

```text
blog/
├── __init__.py         # Python 包标识
├── admin.py            # Admin 后台配置
├── apps.py             # 应用配置
├── models.py           # 数据模型
├── tests.py            # 测试文件
├── views.py            # 视图函数
└── migrations/         # 数据库迁移文件
    └── __init__.py
```

## 注册应用

创建应用后，需要在 `settings.py` 中注册：

```python
# mysite/settings.py

INSTALLED_APPS = [
    'django.contrib.admin',
    'django.contrib.auth',
    'django.contrib.contenttypes',
    'django.contrib.sessions',
    'django.contrib.messages',
    'django.contrib.staticfiles',
    # 添加自定义应用
    'blog',
]
```

## 第一个视图

在 `blog/views.py` 中创建第一个视图：

```python
# blog/views.py
from django.http import HttpResponse

def hello(request):
    """
    简单的 Hello World 视图
    """
    return HttpResponse("Hello, Django!")
```

## 配置 URL

创建 `blog/urls.py` 文件：

```python
# blog/urls.py
from django.urls import path
from . import views

urlpatterns = [
    path('hello/', views.hello, name='hello'),
]
```

在项目 `urls.py` 中包含应用的 URL：

```python
# mysite/urls.py
from django.contrib import admin
from django.urls import path, include

urlpatterns = [
    path('admin/', admin.site.urls),
    path('blog/', include('blog.urls')),  # 包含 blog 应用的 URL
]
```

## 项目配置详解

`settings.py` 是最重要的配置文件：

```python
# mysite/settings.py

# 安全密钥（生产环境必须修改）
SECRET_KEY = 'django-insecure-your-secret-key-here'

# 调试模式（生产环境必须关闭）
DEBUG = True

# 允许的主机
ALLOWED_HOSTS = []

# 已安装的应用
INSTALLED_APPS = [
    # Django 内置应用
    'django.contrib.admin',
    'django.contrib.auth',
    'django.contrib.contenttypes',
    'django.contrib.sessions',
    'django.contrib.messages',
    'django.contrib.staticfiles',
    # 自定义应用
    'blog',
]

# 中间件
MIDDLEWARE = [
    'django.middleware.security.SecurityMiddleware',
    'django.contrib.sessions.middleware.SessionMiddleware',
    'django.middleware.common.CommonMiddleware',
    'django.middleware.csrf.CsrfViewMiddleware',
    'django.contrib.auth.middleware.AuthenticationMiddleware',
    'django.contrib.messages.middleware.MessageMiddleware',
    'django.middleware.clickjacking.XFrameOptionsMiddleware',
]

# URL 配置
ROOT_URLCONF = 'mysite.urls'

# 模板配置
TEMPLATES = [
    {
        'BACKEND': 'django.template.backends.django.DjangoTemplates',
        'DIRS': [],
        'APP_DIRS': True,
        'OPTIONS': {
            'context_processors': [
                'django.template.context_processors.debug',
                'django.template.context_processors.request',
                'django.contrib.auth.context_processors.auth',
                'django.contrib.messages.context_processors.messages',
            ],
        },
    },
]

# WSGI 应用
WSGI_APPLICATION = 'mysite.wsgi.application'

# 数据库配置
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.sqlite3',
        'NAME': BASE_DIR / 'db.sqlite3',
    }
}

# 静态文件
STATIC_URL = 'static/'
```

## 常用管理命令

| 命令 | 作用 |
|------|------|
| `python manage.py runserver` | 运行开发服务器 |
| `python manage.py startapp` | 创建新应用 |
| `python manage.py makemigrations` | 创建数据库迁移 |
| `python manage.py migrate` | 执行数据库迁移 |
| `python manage.py createsuperuser` | 创建管理员账户 |
| `python manage.py shell` | 进入交互式 Shell |
| `python manage.py collectstatic` | 收集静态文件 |

## 小结

创建 Django 项目的关键步骤：

1. **创建项目**：使用 `django-admin startproject`
2. **创建应用**：使用 `python manage.py startapp`
3. **注册应用**：在 `settings.py` 中添加
4. **编写视图**：在 `views.py` 中定义
5. **配置 URL**：在 `urls.py` 中映射

> 💡 **提示**：Django 的项目结构遵循"约定优于配置"原则，按照标准结构组织代码可以减少很多配置工作。
