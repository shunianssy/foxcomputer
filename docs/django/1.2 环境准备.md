# 1.2 环境准备

在开始 Django 开发之前，我们需要搭建一个完整的开发环境。本章将指导你完成所有必要的准备工作。

## Python 版本要求

Django 对 Python 版本有特定要求：

| Django 版本 | Python 版本支持 |
|-------------|-----------------|
| Django 5.0 | Python 3.10+ |
| Django 4.2 LTS | Python 3.8+ |
| Django 4.1 | Python 3.8+ |
| Django 4.0 | Python 3.8+ |

> **推荐**：建议使用 Python 3.10 或更高版本，以获得最新的语言特性支持。

## 创建虚拟环境

虚拟环境是 Python 开发的最佳实践，它可以隔离项目依赖：

### Windows 系统

```powershell
# 创建虚拟环境
python -m venv venv

# 激活虚拟环境
.\venv\Scripts\activate

# 看到命令行前面出现 (venv) 表示激活成功
```

### macOS / Linux 系统

```bash
# 创建虚拟环境
python3 -m venv venv

# 激活虚拟环境
source venv/bin/activate

# 看到命令行前面出现 (venv) 表示激活成功
```

## 安装 Django

激活虚拟环境后，使用 pip 安装 Django：

```bash
# 安装最新版本
pip install django

# 安装指定版本
pip install django==4.2.7

# 验证安装
python -m django --version
# 输出: 5.0.x 或你安装的版本
```

## 项目依赖管理

建议使用 `requirements.txt` 管理项目依赖：

```bash
# 生成依赖文件
pip freeze > requirements.txt

# 从依赖文件安装
pip install -r requirements.txt
```

一个典型的 Django 项目 `requirements.txt`：

```text
Django==5.0
django-crispy-forms==2.1
Pillow==10.1.0
python-dotenv==1.0.0
```

## 配置环境变量

使用 `.env` 文件管理敏感配置：

```bash
# 安装 python-dotenv
pip install python-dotenv
```

创建 `.env` 文件：

```env
DEBUG=True
SECRET_KEY=your-secret-key-here
DATABASE_URL=sqlite:///db.sqlite3
ALLOWED_HOSTS=localhost,127.0.0.1
```

## 验证环境

创建一个简单的测试脚本验证环境配置：

```python
# test_env.py
import sys
import django

print(f"Python 版本: {sys.version}")
print(f"Django 版本: {django.VERSION}")
print("环境配置成功！")
```

运行测试：

```bash
python test_env.py
```

## 常见问题解决

### 问题 1：pip 安装速度慢

使用国内镜像源加速：

```bash
# 临时使用
pip install django -i https://pypi.tuna.tsinghua.edu.cn/simple

# 永久配置
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
```

### 问题 2：虚拟环境激活失败

Windows 系统可能需要调整执行策略：

```powershell
# 以管理员身份运行 PowerShell
Set-ExecutionPolicy RemoteSigned
```

### 问题 3：找不到 django 命令

确保虚拟环境已激活，并且 pip 安装在虚拟环境中：

```bash
# 检查 pip 位置
where pip # Windows
which pip # macOS/Linux

# 应该显示 venv 目录下的路径
```

## 小结

环境准备的关键步骤：

1. **安装 Python**：确保版本兼容
2. **创建虚拟环境**：隔离项目依赖
3. **安装 Django**：使用 pip 安装
4. **配置开发工具**：选择合适的 IDE
5. **验证环境**：确保一切正常

> **提示**：良好的环境配置是成功的一半。养成使用虚拟环境的习惯，可以避免很多依赖冲突问题。
