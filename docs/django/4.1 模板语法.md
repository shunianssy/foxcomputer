# 4.1 模板语法

Django 模板系统提供了简洁而强大的语法来生成 HTML 页面。本章介绍模板的基本语法和常用功能。

## 模板基础

### 变量

使用双花括号输出变量：

```html
<!-- 输出变量 -->
<h1>{{ article.title }}</h1>
<p>{{ article.content }}</p>

<!-- 输出对象属性 -->
<span>作者：{{ article.author.username }}</span>

<!-- 输出字典值 -->
<span>{{ settings.SITE_NAME }}</span>

<!-- 输出列表元素 -->
<span>{{ items.0 }}</span>
```

### 过滤器

使用管道符 `|` 应用过滤器：

```html
<!-- 大小写转换 -->
{{ name|upper }}          <!-- 大写 -->
{{ name|lower }}          <!-- 小写 -->
{{ name|title }}          <!-- 标题格式 -->
{{ name|capfirst }}       <!-- 首字母大写 -->

<!-- 文本处理 -->
{{ content|truncatewords:30 }}     <!-- 截取30个单词 -->
{{ content|truncatechars:100 }}    <!-- 截取100个字符 -->
{{ content|wordcount }}            <!-- 单词数 -->
{{ content|linebreaks }}           <!-- 换行转 <p> 和 <br> -->
{{ content|linebreaksbr }}         <!-- 换行转 <br> -->

<!-- 日期格式 -->
{{ article.created_at|date:"Y-m-d H:i" }}
{{ article.created_at|date:"Y年m月d日" }}
{{ article.created_at|timesince }}  <!-- 多久之前 -->

<!-- 数字格式 -->
{{ price|floatformat:2 }}    <!-- 保留2位小数 -->
{{ number|add:5 }}           <!-- 加法 -->

<!-- 默认值 -->
{{ article.summary|default:"暂无摘要" }}
{{ article.author|default_if_none:"匿名" }}

<!-- 长度 -->
{{ articles|length }}        <!-- 列表长度 -->
{{ content|length }}         <!-- 字符串长度 -->

<!-- 安全输出 -->
{{ html_content|safe }}      <!-- 不转义 HTML -->
{{ content|escape }}         <!-- 转义 HTML -->

<!-- 列表操作 -->
{{ items|join:", " }}        <!-- 用逗号连接 -->
{{ items|first }}            <!-- 第一个元素 -->
{{ items|last }}             <!-- 最后一个元素 -->
{{ items|slice:":3" }}       <!-- 切片 -->

<!-- URL 编码 -->
{{ query|urlencode }}
{{ path|iriencode }}
```

### 常用过滤器对照表

| 过滤器 | 说明 | 示例 |
|--------|------|------|
| `upper` | 大写 | `{{ name|upper }}` |
| `lower` | 小写 | `{{ name|lower }}` |
| `title` | 标题格式 | `{{ name|title }}` |
| `date` | 日期格式 | `{{ dt|date:"Y-m-d" }}` |
| `time` | 时间格式 | `{{ dt|time:"H:i" }}` |
| `default` | 默认值 | `{{ val|default:"N/A" }}` |
| `length` | 长度 | `{{ list|length }}` |
| `truncatewords` | 截取单词 | `{{ text|truncatewords:10 }}` |
| `truncatechars` | 截取字符 | `{{ text|truncatechars:50 }}` |
| `safe` | 安全输出 | `{{ html|safe }}` |
| `escape` | HTML 转义 | `{{ text|escape }}` |
| `join` | 连接列表 | `{{ list|join:", " }}` |
| `add` | 加法 | `{{ num|add:5 }}` |
| `slice` | 切片 | `{{ list|slice:":5" }}` |

## 标签

### if 条件标签

```html
<!-- 基本 if -->
{% if article.is_published %}
    <span class="badge">已发布</span>
{% endif %}

<!-- if-else -->
{% if user.is_authenticated %}
    <p>欢迎，{{ user.username }}</p>
{% else %}
    <a href="/login/">请登录</a>
{% endif %}

<!-- if-elif-else -->
{% if article.status == 'published' %}
    <span class="status published">已发布</span>
{% elif article.status == 'draft' %}
    <span class="status draft">草稿</span>
{% else %}
    <span class="status archived">已归档</span>
{% endif %}

<!-- 条件运算符 -->
{% if article.views > 100 %}
    <span>热门文章</span>
{% endif %}

{% if article.views >= 100 and article.views < 500 %}
    <span>中等热度</span>
{% endif %}

{% if article.category == "技术" or article.category == "编程" %}
    <span>技术文章</span>
{% endif %}

{% if not article.is_deleted %}
    <span>正常</span>
{% endif %}

<!-- in 运算符 -->
{% if article.status in 'published,featured' %}
    <span>可见</span>
{% endif %}

{% if user.id in article.likes.all %}
    <span>已点赞</span>
{% endif %}
```

### for 循环标签

```html
<!-- 基本循环 -->
{% for article in articles %}
    <article>
        <h2>{{ article.title }}</h2>
        <p>{{ article.content|truncatewords:50 }}</p>
    </article>
{% endfor %}

<!-- 循环变量 -->
{% for article in articles %}
    <tr class="{% cycle 'odd' 'even' %}">
        <td>{{ forloop.counter }}</td>        <!-- 从1开始的索引 -->
        <td>{{ forloop.counter0 }}</td>       <!-- 从0开始的索引 -->
        <td>{{ forloop.revcounter }}</td>     <!-- 倒序索引（从1开始） -->
        <td>{{ forloop.revcounter0 }}</td>    <!-- 倒序索引（从0开始） -->
        <td>{{ forloop.first }}</td>          <!-- 是否第一个 -->
        <td>{{ forloop.last }}</td>           <!-- 是否最后一个 -->
        <td>{{ forloop.parentloop }}</td>     <!-- 父循环 -->
        <td>{{ article.title }}</td>
    </tr>
{% endfor %}

<!-- empty 分支 -->
{% for article in articles %}
    <article>{{ article.title }}</article>
{% empty %}
    <p>暂无文章</p>
{% endfor %}

<!-- 嵌套循环 -->
{% for category in categories %}
    <h2>{{ category.name }}</h2>
    <ul>
    {% for article in category.articles.all %}
        <li>{{ forloop.parentloop.counter }}.{{ forloop.counter }} {{ article.title }}</li>
    {% endfor %}
    </ul>
{% endfor %}

<!-- 遍历字典 -->
{% for key, value in settings.items %}
    <p>{{ key }}: {{ value }}</p>
{% endfor %}
```

### forloop 变量

| 变量 | 说明 |
|------|------|
| `forloop.counter` | 当前循环索引（从1开始） |
| `forloop.counter0` | 当前循环索引（从0开始） |
| `forloop.revcounter` | 倒序索引（到1结束） |
| `forloop.revcounter0` | 倒序索引（到0结束） |
| `forloop.first` | 是否第一次迭代 |
| `forloop.last` | 是否最后一次迭代 |
| `forloop.parentloop` | 父级循环对象 |

### 其他常用标签

```html
<!-- csrf_token：CSRF 保护 -->
<form method="post">
    {% csrf_token %}
    ...
</form>

<!-- url：URL 反向解析 -->
<a href="{% url 'blog:article_detail' pk=article.pk %}">查看详情</a>
<a href="{% url 'blog:category' slug=category.slug %}">{{ category.name }}</a>

<!-- static：静态文件 -->
{% load static %}
<link rel="stylesheet" href="{% static 'css/style.css' %}">
<img src="{% static 'images/logo.png' %}" alt="Logo">

<!-- with：变量别名 -->
{% with total=articles.count %}
    <p>共 {{ total }} 篇文章</p>
{% endwith %}

{% with article.author as author %}
    <p>作者：{{ author.username }}</p>
{% endwith %}

<!-- include：包含其他模板 -->
{% include 'blog/_article_card.html' %}
{% include 'blog/_article_card.html' with article=featured_article %}

<!-- block：定义块（用于继承） -->
{% block title %}默认标题{% endblock %}

<!-- extends：继承模板 -->
{% extends 'base.html' %}

<!-- comment：注释 -->
{% comment %}
    这是多行注释
    不会显示在页面上
{% endcomment %}

{# 这是单行注释 #}

<!-- autoescape：自动转义控制 -->
{% autoescape off %}
    {{ html_content }}
{% endautoescape %}

<!-- spaceless：移除空白 -->
{% spaceless %}
    <div>
        <span>内容</span>
    </div>
{% endspaceless %}
<!-- 输出：<div><span>内容</span></div> -->

<!-- verbatim：禁用模板解析 -->
{% verbatim %}
    {{ this will not be parsed }}
{% endverbatim %}

<!-- now：当前时间 -->
<p>当前时间：{% now "Y-m-d H:i:s" %}</p>

<!-- cycle：循环值 -->
{% for article in articles %}
    <tr class="{% cycle 'row1' 'row2' %}">
        <td>{{ article.title }}</td>
    </tr>
{% endfor %}

<!-- debug：调试信息 -->
{% debug %}
```

## 模板加载

### 加载静态文件

```html
{% load static %}

<!-- CSS -->
<link rel="stylesheet" href="{% static 'css/style.css' %}">

<!-- JavaScript -->
<script src="{% static 'js/main.js' %}"></script>

<!-- 图片 -->
<img src="{% static 'images/logo.png' %}" alt="Logo">

<!-- 使用变量 -->
{% static "images/" as image_path %}
<img src="{{ image_path }}logo.png">
```

### 加载自定义标签

```html
{% load my_tags %}

<!-- 使用自定义标签 -->
{% my_custom_tag arg1 arg2 %}

<!-- 使用自定义过滤器 -->
{{ value|my_filter }}
```

## 模板上下文

### 视图传递上下文

```python
# views.py
def article_list(request):
    return render(request, 'blog/article_list.html', {
        'articles': articles,
        'categories': categories,
        'current_category': category,
        'page_title': '文章列表',
    })
```

### 内置上下文处理器

Django 自动注入以下变量：

```html
<!-- 用户信息 -->
{{ user }}
{{ user.is_authenticated }}
{{ user.username }}

<!-- 请求信息 -->
{{ request }}
{{ request.path }}
{{ request.GET.q }}

<!-- 消息框架 -->
{% if messages %}
    {% for message in messages %}
        <div class="alert alert-{{ message.tags }}">
            {{ message }}
        </div>
    {% endfor %}
{% endif %}

<!-- CSRF Token -->
{% csrf_token %}
```

## 模板注释

```html
{# 单行注释 #}

{% comment %}
    多行注释
    可以跨越多行
{% endcomment %}

{# 注释可以包含 {{ variable }} 和 {% tag %} #}
```

## 转义与安全

### 自动转义

Django 默认转义 HTML：

```html
<!-- 如果 content 是 "<script>alert('xss')</script>" -->
{{ content }}
<!-- 输出：&lt;script&gt;alert('xss')&lt;/script&gt; -->
```

### 安全输出

```html
<!-- 使用 safe 过滤器 -->
{{ html_content|safe }}

<!-- 使用 autoescape 标签 -->
{% autoescape off %}
    {{ html_content }}
{% endautoescape %}
```

> ⚠️ **警告**：使用 `safe` 过滤器时要确保内容是安全的，否则可能导致 XSS 攻击。

## 小结

模板语法的关键点：

1. **变量**：使用 `{{ variable }}` 输出
2. **过滤器**：使用 `|` 管道符处理数据
3. **标签**：使用 `{% tag %}` 实现逻辑
4. **条件**：`if`、`elif`、`else`
5. **循环**：`for` 循环及 `forloop` 变量

> 💡 **提示**：模板应该只负责展示逻辑，避免在模板中编写复杂的业务逻辑。
