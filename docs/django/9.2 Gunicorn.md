# 9.2 Gunicorn

Gunicorn 是一个 Python WSGI HTTP 服务器，是 Django 生产部署的标准选择。

## 安装配置

### 安装

```bash
pip install gunicorn
```

### 基本运行

```bash
# 基本运行
gunicorn myproject.wsgi:application

# 指定端口
gunicorn myproject.wsgi:application --bind 0.0.0.0:8000

# 指定工作进程数
gunicorn myproject.wsgi:application --workers 4
```

## Gunicorn 配置

### 配置文件

```python
# gunicorn.conf.py
import multiprocessing

# 绑定地址
bind = '127.0.0.1:8000'

# 工作进程数（推荐 2-4 x CPU核心数）
workers = multiprocessing.cpu_count() * 2 + 1

# 工作模式
worker_class = 'sync'  # sync, gevent, eventlet

# 每个工作进程的线程数
threads = 2

# 最大并发请求数
worker_connections = 1000

# 超时时间
timeout = 30

# 守护进程
daemon = False

# 进程 ID 文件
pidfile = '/var/run/gunicorn.pid'

# 日志
accesslog = '/var/log/gunicorn/access.log'
errorlog = '/var/log/gunicorn/error.log'
loglevel = 'info'

# 进程名
proc_name = 'myproject'

# 最大请求数后重启
max_requests = 1000
max_requests_jitter = 50
```

### 使用配置文件

```bash
gunicorn -c gunicorn.conf.py myproject.wsgi:application
```

## Systemd 服务

### 创建服务文件

```ini
# /etc/systemd/system/gunicorn.service
[Unit]
Description=Gunicorn daemon for MyProject
After=network.target

[Service]
User=www-data
Group=www-data
WorkingDirectory=/var/www/myproject
ExecStart=/var/www/myproject/venv/bin/gunicorn \
          --workers 3 \
          --bind unix:/var/www/myproject/gunicorn.sock \
          --access-logfile /var/log/gunicorn/access.log \
          --error-logfile /var/log/gunicorn/error.log \
          myproject.wsgi:application

[Install]
WantedBy=multi-user.target
```

### 管理服务

```bash
# 启动服务
sudo systemctl start gunicorn

# 停止服务
sudo systemctl stop gunicorn

# 重启服务
sudo systemctl restart gunicorn

# 开机自启
sudo systemctl enable gunicorn

# 查看状态
sudo systemctl status gunicorn
```

## Nginx 配置

### 反向代理

```nginx
# /etc/nginx/sites-available/myproject
upstream myproject {
    server unix:/var/www/myproject/gunicorn.sock fail_timeout=0;
}

server {
    listen 80;
    server_name example.com www.example.com;

    # 重定向到 HTTPS
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name example.com www.example.com;

    # SSL 配置
    ssl_certificate /etc/letsencrypt/live/example.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/example.com/privkey.pem;

    # 静态文件
    location /static/ {
        alias /var/www/myproject/staticfiles/;
        expires 30d;
    }

    # 媒体文件
    location /media/ {
        alias /var/www/myproject/media/;
        expires 7d;
    }

    # 代理到 Gunicorn
    location / {
        proxy_pass http://myproject;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_connect_timeout 30s;
        proxy_read_timeout 30s;
    }
}
```

### 启用站点

```bash
sudo ln -s /etc/nginx/sites-available/myproject /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl restart nginx
```

## 性能优化

### Worker 数量计算

```
workers = (2 x CPU核心数) + 1
```

### 使用 gevent

```bash
pip install gevent
```

```python
# gunicorn.conf.py
worker_class = 'gevent'
workers = multiprocessing.cpu_count() * 2 + 1
```


## 小结

Gunicorn 部署的关键点：

1. **配置文件**：gunicorn.conf.py
2. **Systemd 服务**：开机自启
3. **Nginx 代理**：处理静态文件和 SSL
4. **性能优化**：Worker 数量、gevent

> 💡 **提示**：Gunicorn + Nginx 是 Django 生产部署的标准组合，稳定可靠。
