# 2.4 模型关系

Django ORM 支持三种模型关系：一对一、一对多、多对多。理解这些关系是设计数据库结构的关键。

## 一对一关系（OneToOneField）

一对一关系用于两个模型之间的唯一关联，常用于扩展用户模型。

### 定义一对一关系

```python
from django.db import models
from django.contrib.auth.models import User

class Profile(models.Model):
    """用户资料扩展"""
    user = models.OneToOneField(
        User,
        on_delete=models.CASCADE,
        primary_key=True,
        related_name='profile'
    )
    avatar = models.ImageField('头像', upload_to='avatars/')
    bio = models.TextField('个人简介', blank=True)
    website = models.URLField('个人网站', blank=True)
    
    class Meta:
        verbose_name = '用户资料'
        verbose_name_plural = '用户资料'
    
    def __str__(self):
        return f"{self.user.username} 的资料"
```

### 一对一关系操作

```python
# 创建用户资料
user = User.objects.get(username='admin')
profile = Profile.objects.create(
    user=user,
    bio='这是我的个人简介'
)

# 正向查询：从 User 到 Profile
user = User.objects.get(username='admin')
profile = user.profile  # 使用 related_name

# 反向查询：从 Profile 到 User
profile = Profile.objects.get(user_id=1)
user = profile.user

# 获取或创建
profile, created = Profile.objects.get_or_create(
    user=user,
    defaults={'bio': '默认简介'}
)
```

### 使用场景

1. **扩展用户模型**：添加额外的用户信息
2. **配置表**：每个主记录对应一个配置
3. **详情表**：将不常用的字段分离存储

## 一对多关系（ForeignKey）

一对多是最常见的关系类型，如文章与评论、分类与文章。

### 定义一对多关系

```python
class Category(models.Model):
    """文章分类"""
    name = models.CharField('分类名称', max_length=50)
    
    class Meta:
        verbose_name = '分类'
        verbose_name_plural = '分类'
    
    def __str__(self):
        return self.name

class Article(models.Model):
    """文章"""
    title = models.CharField('标题', max_length=200)
    content = models.TextField('内容')
    category = models.ForeignKey(
        Category,
        on_delete=models.SET_NULL,
        null=True,
        blank=True,
        related_name='articles',
        verbose_name='分类'
    )
    author = models.ForeignKey(
        User,
        on_delete=models.CASCADE,
        related_name='articles',
        verbose_name='作者'
    )
    
    class Meta:
        verbose_name = '文章'
        verbose_name_plural = '文章'
    
    def __str__(self):
        return self.title
```

### on_delete 选项

| 选项 | 说明 |
|------|------|
| `CASCADE` | 级联删除，删除父记录时同时删除子记录 |
| `PROTECT` | 保护模式，有子记录时禁止删除父记录 |
| `SET_NULL` | 设为 NULL，需要 null=True |
| `SET_DEFAULT` | 设为默认值，需要 default 值 |
| `SET()` | 设为指定值或函数返回值 |
| `DO_NOTHING` | 不做任何操作，可能导致数据不一致 |

```python
class Comment(models.Model):
    article = models.ForeignKey(
        Article,
        on_delete=models.CASCADE,  # 删除文章时删除所有评论
        related_name='comments'
    )
    
class Article(models.Model):
    category = models.ForeignKey(
        Category,
        on_delete=models.SET_NULL,  # 删除分类时文章的分类设为 NULL
        null=True
    )
    
    reviewer = models.ForeignKey(
        User,
        on_delete=models.SET(get_default_reviewer),  # 自定义函数
        related_name='reviewed_articles'
    )
```

### 一对多关系操作

```python
# 创建文章并关联分类
category = Category.objects.get(name='技术')
article = Article.objects.create(
    title='Django 教程',
    content='...',
    category=category,
    author=user
)

# 正向查询：从 Article 到 Category
article = Article.objects.get(pk=1)
category = article.category

# 反向查询：从 Category 到 Articles
category = Category.objects.get(name='技术')
articles = category.articles.all()  # 使用 related_name

# 反向添加
category.articles.create(
    title='新文章',
    content='...',
    author=user
)

# 过滤关联数据
category.articles.filter(status='published')

# 统计关联数量
category.articles.count()
```

## 多对多关系（ManyToManyField）

多对多关系用于两个模型之间的多重关联，如文章与标签、学生与课程。

### 定义多对多关系

```python
class Tag(models.Model):
    """标签"""
    name = models.CharField('标签名', max_length=30)
    
    class Meta:
        verbose_name = '标签'
        verbose_name_plural = '标签'
    
    def __str__(self):
        return self.name

class Article(models.Model):
    """文章"""
    title = models.CharField('标题', max_length=200)
    content = models.TextField('内容')
    tags = models.ManyToManyField(
        Tag,
        blank=True,
        related_name='articles',
        verbose_name='标签'
    )
```

### 多对多关系操作

```python
# 添加标签
article = Article.objects.get(pk=1)
tag1 = Tag.objects.get(name='Python')
tag2 = Tag.objects.get(name='Django')

# 添加单个标签
article.tags.add(tag1)

# 添加多个标签
article.tags.add(tag1, tag2)

# 创建并添加
tag = article.tags.create(name='Web')

# 移除标签
article.tags.remove(tag1)

# 移除所有标签
article.tags.clear()

# 设置标签（替换现有标签）
article.tags.set([tag1, tag2])

# 查询文章的标签
article.tags.all()

# 查询标签下的文章
tag = Tag.objects.get(name='Python')
tag.articles.all()

# 查询包含特定标签的文章
Article.objects.filter(tags__name='Python')

# 查询包含多个标签的文章
Article.objects.filter(tags__in=[tag1, tag2])

# 查询同时包含多个标签的文章
from django.db.models import Count
Article.objects.annotate(
    tag_count=Count('tags')
).filter(
    tags__in=[tag1, tag2]
).filter(
    tag_count=2
)
```

### 自定义中间表

当多对多关系需要额外字段时，使用中间表：

```python
class Article(models.Model):
    title = models.CharField(max_length=200)
    tags = models.ManyToManyField(
        'Tag',
        through='ArticleTag',
        related_name='articles'
    )

class Tag(models.Model):
    name = models.CharField(max_length=30)

class ArticleTag(models.Model):
    """文章-标签中间表"""
    article = models.ForeignKey(Article, on_delete=models.CASCADE)
    tag = models.ForeignKey(Tag, on_delete=models.CASCADE)
    added_at = models.DateTimeField(auto_now_add=True)
    added_by = models.ForeignKey(User, on_delete=models.SET_NULL, null=True)
    
    class Meta:
        unique_together = ['article', 'tag']  # 防止重复
```

使用中间表：

```python
# 创建关联（需要通过中间表）
ArticleTag.objects.create(
    article=article,
    tag=tag,
    added_by=user
)

# 查询
article_tags = ArticleTag.objects.filter(article=article)
for at in article_tags:
    print(f"{at.tag.name} - 添加于 {at.added_at}")
```

## 自关联

模型可以与自身建立关系：

### 一对多自关联

```python
class Category(models.Model):
    """分类（支持多级）"""
    name = models.CharField('名称', max_length=50)
    parent = models.ForeignKey(
        'self',
        on_delete=models.CASCADE,
        null=True,
        blank=True,
        related_name='children'
    )
    
    def __str__(self):
        return self.name
    
    def get_ancestors(self):
        """获取所有祖先分类"""
        ancestors = []
        parent = self.parent
        while parent:
            ancestors.append(parent)
            parent = parent.parent
        return ancestors
    
    def get_descendants(self):
        """获取所有后代分类"""
        descendants = list(self.children.all())
        for child in self.children.all():
            descendants.extend(child.get_descendants())
        return descendants
```

### 多对多自关联

```python
class Person(models.Model):
    """用户"""
    name = models.CharField('姓名', max_length=50)
    friends = models.ManyToManyField(
        'self',
        symmetrical=False,  # 非对称关系（A 关注 B，B 不一定关注 A）
        related_name='followers'
    )
    
    def __str__(self):
        return self.name

# 使用
person1 = Person.objects.get(name='Alice')
person2 = Person.objects.get(name='Bob')

# person1 关注 person2
person1.friends.add(person2)

# person1 的关注列表
person1.friends.all()

# person2 的粉丝列表
person2.followers.all()
```

## 关联查询优化

### select_related（外键优化）

```python
# 不使用 select_related（N+1 问题）
articles = Article.objects.all()
for article in articles:
    print(article.category.name)  # 每次循环都查询一次

# 使用 select_related（一次查询）
articles = Article.objects.select_related('category', 'author')
for article in articles:
    print(article.category.name)  # 不会额外查询
```

### prefetch_related（多对多优化）

```python
# 不使用 prefetch_related
articles = Article.objects.all()
for article in articles:
    print([tag.name for tag in article.tags.all()])  # N+1 问题

# 使用 prefetch_related
articles = Article.objects.prefetch_related('tags')
for article in articles:
    print([tag.name for tag in article.tags.all()])  # 只查询两次
```

### 组合使用

```python
# 同时优化外键和多对多
articles = Article.objects.select_related(
    'author',
    'category'
).prefetch_related(
    'tags',
    'comments'
)

# 使用 Prefetch 自定义预加载
from django.db.models import Prefetch

articles = Article.objects.prefetch_related(
    Prefetch(
        'tags',
        queryset=Tag.objects.filter(name__startswith='P'),
        to_attr='p_tags'
    )
)
```

## 小结

模型关系的关键点：

1. **一对一**：使用 `OneToOneField`，适合扩展模型
2. **一对多**：使用 `ForeignKey`，最常见的关类型
3. **多对多**：使用 `ManyToManyField`，可自定义中间表
4. **自关联**：模型与自身建立关系
5. **查询优化**：使用 `select_related` 和 `prefetch_related`

> 💡 **提示**：设计模型关系时，要考虑数据的实际业务逻辑。合理使用 `related_name` 可以让反向查询更直观。
