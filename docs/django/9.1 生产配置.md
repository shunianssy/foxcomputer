# 9.1 生产配置

将 Django 项目部署到生产环境需要进行一系列配置调整。本章介绍生产环境的最佳实践。

## 安全设置

### 关键配置

```python
# settings.py

# 生产环境必须关闭 DEBUG
DEBUG = False

# 设置允许的主机
ALLOWED_HOSTS = ['example.com', 'www.example.com']

# 使用环境变量管理密钥
import os
from dotenv import load_dotenv

load_dotenv()

SECRET_KEY = os.environ.get('SECRET_KEY')

# 安全设置
SECURE_SSL_REDIRECT = True # 强制 HTTPS
SECURE_PROXY_SSL_HEADER = ('HTTP_X_FORWARDED_PROTO', 'https')
SESSION_COOKIE_SECURE = True # Cookie 只通过 HTTPS 传输
CSRF_COOKIE_SECURE = True
SECURE_BROWSER_XSS_FILTER = True
SECURE_CONTENT_TYPE_NOSNIFF = True
X_FRAME_OPTIONS = 'DENY'
SECURE_HSTS_SECONDS = 31536000 # HSTS 一年
SECURE_HSTS_INCLUDE_SUBDOMAINS = True
SECURE_HSTS_PRELOAD = True
```

### 环境变量管理

```bash
# .env
DEBUG=False
SECRET_KEY=your-secret-key-here
DATABASE_URL=postgres://user:password@localhost/dbname
ALLOWED_HOSTS=example.com,www.example.com
```

```python
# settings.py
import os
from pathlib import Path

SECRET_KEY = os.environ.get('SECRET_KEY')
DEBUG = os.environ.get('DEBUG', 'False') == 'True'
ALLOWED_HOSTS = os.environ.get('ALLOWED_HOSTS', '').split(',')
```

## 数据库配置

### PostgreSQL

```python
# settings.py
import os

DATABASES = {
 'default': {
 'ENGINE': 'django.db.backends.postgresql',
 'NAME': os.environ.get('DB_NAME'),
 'USER': os.environ.get('DB_USER'),
 'PASSWORD': os.environ.get('DB_PASSWORD'),
 'HOST': os.environ.get('DB_HOST', 'localhost'),
 'PORT': os.environ.get('DB_PORT', '5432'),
 'CONN_MAX_AGE': 600, # 连接池
 }
}
```

### 使用 dj-database-url

```bash
pip install dj-database-url
```

```python
import dj_database_url

DATABASES = {
 'default': dj_database_url.config(
 default=os.environ.get('DATABASE_URL')
 )
}
```

## 静态文件配置

```python
# settings.py

STATIC_URL = '/static/'
STATIC_ROOT = BASE_DIR / 'staticfiles'
STATICFILES_DIRS = [BASE_DIR / 'static']

# 使用 WhiteNoise
MIDDLEWARE = [
 'django.middleware.security.SecurityMiddleware',
 'whitenoise.middleware.WhiteNoiseMiddleware',
 # ...
]

STATICFILES_STORAGE = 'whitenoise.storage.CompressedManifestStaticFilesStorage'
```

## 日志配置

```python
# settings.py

LOGGING = {
 'version': 1,
 'disable_existing_loggers': False,
 'formatters': {
 'verbose': {
 'format': '{levelname} {asctime} {module} {message}',
 'style': '{',
 },
 },
 'handlers': {
 'file': {
 'level': 'ERROR',
 'class': 'logging.FileHandler',
 'filename': 'logs/django.log',
 'formatter': 'verbose',
 },
 'console': {
 'class': 'logging.StreamHandler',
 'formatter': 'verbose',
 },
 },
 'loggers': {
 'django': {
 'handlers': ['file', 'console'],
 'level': 'ERROR',
 'propagate': True,
 },
 },
}
```

## 多环境配置

### 分离配置文件

```text
project/
├── settings/
│ ├── __init__.py
│ ├── base.py # 公共配置
│ ├── development.py
│ ├── production.py
│ └── testing.py
```

```python
# settings/production.py
from .base import *

DEBUG = False
ALLOWED_HOSTS = ['example.com']

# settings/development.py
from .base import *

DEBUG = True
ALLOWED_HOSTS = ['*']
```

```python
# manage.py
import os

if __name__ == '__main__':
 os.environ.setdefault('DJANGO_SETTINGS_MODULE', 'settings.development')
```

## 小结

生产配置的关键点：

1. **安全设置**：关闭 DEBUG、设置 ALLOWED_HOSTS
2. **环境变量**：敏感信息使用环境变量
3. **数据库**：使用 PostgreSQL
4. **静态文件**：WhiteNoise 或 CDN
5. **日志**：配置日志系统

> **提示**：生产环境配置要特别注意安全性，所有敏感信息都应该使用环境变量管理。
