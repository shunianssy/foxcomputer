# 4.4 静态文件

静态文件包括 CSS、JavaScript、图片等资源文件。Django 提供了完善的静态文件管理机制。

## 静态文件配置

### 基本配置

```python
# settings.py

# 静态文件 URL 前缀
STATIC_URL = '/static/'

# 静态文件收集目录（生产环境）
STATIC_ROOT = BASE_DIR / 'staticfiles'

# 静态文件搜索目录（开发环境）
STATICFILES_DIRS = [
    BASE_DIR / 'static',
]

# 静态文件查找器
STATICFILES_FINDERS = [
    'django.contrib.staticfiles.finders.FileSystemFinder',
    'django.contrib.staticfiles.finders.AppDirectoriesFinder',
]
```

### 目录结构

```text
project/
├── static/                  # 项目级静态文件
│   ├── css/
│   │   ├── base.css
│   │   └── blog.css
│   ├── js/
│   │   ├── base.js
│   │   └── blog.js
│   ├── images/
│   │   ├── logo.png
│   │   └── favicon.ico
│   └── fonts/
│       └── custom.woff2
├── blog/
│   └── static/              # 应用级静态文件
│       └── blog/
│           ├── css/
│           └── js/
└── staticfiles/             # 收集后的静态文件（生产环境）
```

## 模板中使用静态文件

### 加载静态文件

```html
{% load static %}

<!-- CSS -->
<link rel="stylesheet" href="{% static 'css/style.css' %}">

<!-- JavaScript -->
<script src="{% static 'js/main.js' %}"></script>

<!-- 图片 -->
<img src="{% static 'images/logo.png' %}" alt="Logo">

<!-- 使用变量 -->
{% static 'images/' as image_path %}
<img src="{{ image_path }}banner.jpg" alt="Banner">
```

### 完整示例

```html
{% load static %}
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>我的网站</title>
    
    <!-- Favicon -->
    <link rel="icon" href="{% static 'images/favicon.ico' %}">
    
    <!-- CSS -->
    <link rel="stylesheet" href="{% static 'css/bootstrap.min.css' %}">
    <link rel="stylesheet" href="{% static 'css/style.css' %}">
    
    <!-- 自定义 CSS -->
    {% block css %}{% endblock %}
</head>
<body>
    <!-- Logo -->
    <img src="{% static 'images/logo.png' %}" alt="Logo" class="logo">
    
    <!-- 内容 -->
    {% block content %}{% endblock %}
    
    <!-- JavaScript -->
    <script src="{% static 'js/jquery.min.js' %}"></script>
    <script src="{% static 'js/bootstrap.bundle.min.js' %}"></script>
    <script src="{% static 'js/main.js' %}"></script>
    
    <!-- 自定义 JavaScript -->
    {% block js %}{% endblock %}
</body>
</html>
```

## 媒体文件配置

媒体文件是用户上传的文件，如头像、附件等。

### 配置媒体文件

```python
# settings.py

# 媒体文件 URL
MEDIA_URL = '/media/'

# 媒体文件存储目录
MEDIA_ROOT = BASE_DIR / 'media'
```

### 开发环境配置

```python
# urls.py
from django.conf import settings
from django.conf.urls.static import static

urlpatterns = [
    path('admin/', admin.site.urls),
    # ... 其他 URL
]

# 开发环境下添加媒体文件服务
if settings.DEBUG:
    urlpatterns += static(
        settings.MEDIA_URL,
        document_root=settings.MEDIA_ROOT
    )
```

### 模板中使用媒体文件

```html
<!-- 用户头像 -->
<img src="{{ user.profile.avatar.url }}" alt="Avatar">

<!-- 文章封面 -->
<img src="{{ article.cover.url }}" alt="Cover">

<!-- 使用 MEDIA_URL -->
<img src="{{ MEDIA_URL }}uploads/sample.jpg">
```

### 模型中使用媒体文件

```python
# models.py
from django.db import models

def upload_to(instance, filename):
    """自定义上传路径"""
    return f'articles/{instance.author.id}/{filename}'

class Article(models.Model):
    title = models.CharField(max_length=200)
    content = models.TextField()
    cover = models.ImageField(
        '封面图片',
        upload_to=upload_to,  # 自定义上传路径
        blank=True
    )
    attachment = models.FileField(
        '附件',
        upload_to='attachments/%Y/%m/',
        blank=True
    )
```

## 静态文件收集

### 收集静态文件

```bash
# 收集所有静态文件到 STATIC_ROOT
python manage.py collectstatic

# 收集前确认
python manage.py collectstatic --dry-run

# 清除已收集的文件
python manage.py collectstatic --clear

# 忽略特定应用
python manage.py collectstatic --ignore django.contrib.admin
```

### 收集过程

```
开发环境:
┌─────────────┐     ┌─────────────┐
│  static/    │     │  blog/static│
│  项目静态    │     │  应用静态    │
└──────┬──────┘     └──────┬──────┘
       │                   │
       └───────┬───────────┘
               │ collectstatic
               ▼
       ┌─────────────┐
       │ staticfiles/│
       │ 收集后静态   │
       └─────────────┘
```

## 静态文件存储后端

### 默认存储后端

```python
# settings.py
STATICFILES_STORAGE = 'django.contrib.staticfiles.storage.StaticFilesStorage'
```

### ManifestStaticFilesStorage

自动为静态文件添加版本号，解决缓存问题：

```python
# settings.py
STATICFILES_STORAGE = 'django.contrib.staticfiles.storage.ManifestStaticFilesStorage'
```

使用后，静态文件会自动添加哈希值：

```
原始: /static/css/style.css
处理后: /static/css/style.abc123.css
```

### 自定义存储后端

```python
# storages.py
from django.contrib.staticfiles.storage import StaticFilesStorage

class CustomStaticStorage(StaticFilesStorage):
    """自定义静态文件存储"""
    
    def url(self, name):
        """自定义 URL 生成"""
        url = super().url(name)
        # 添加 CDN 域名
        if hasattr(settings, 'CDN_DOMAIN'):
            return f"https://{settings.CDN_DOMAIN}{url}"
        return url
```

```

INSTALLED_APPS = [
    # ...

```

### django-storages

使用云存储服务：

```bash
pip install django-storages boto3
```

```python
# settings.py
INSTALLED_APPS = [
    # ...
    'storages',
]

# AWS S3 配置
AWS_ACCESS_KEY_ID = 'your-access-key'
AWS_SECRET_ACCESS_KEY = 'your-secret-key'
AWS_STORAGE_BUCKET_NAME = 'your-bucket'
AWS_S3_REGION_NAME = 'ap-east-1'

# 静态文件使用 S3
STATICFILES_STORAGE = 'storages.backends.s3boto3.S3StaticStorage'
STATIC_URL = f'https://{AWS_S3_REGION_NAME}.amazonaws.com/{AWS_STORAGE_BUCKET_NAME}/static/'

# 媒体文件使用 S3
DEFAULT_FILE_STORAGE = 'storages.backends.s3boto3.S3Boto3Storage'
MEDIA_URL = f'https://{AWS_S3_REGION_NAME}.amazonaws.com/{AWS_STORAGE_BUCKET_NAME}/media/'
```

## 生产环境配置

### Nginx 配置

```nginx
server {
    listen 80;
    server_name example.com;
    
    # 静态文件
    location /static/ {
        alias /var/www/project/staticfiles/;
        expires 30d;
        add_header Cache-Control "public, immutable";
    }
    
    # 媒体文件
    location /media/ {
        alias /var/www/project/media/;
        expires 7d;
    }
    
    # 应用
    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

### 1. 目录组织

    ├── bootstrap/

### 2. 版本控制

```python
# 使用 ManifestStaticFilesStorage
STATICFILES_STORAGE = 'django.contrib.staticfiles.storage.ManifestStaticFilesStorage'
```

### 3. CDN 配置

```python
# settings.py
CDN_DOMAIN = 'cdn.example.com'

# 模板中使用

```

### 4. 缓存策略

```nginx
# 静态文件长期缓存
location /static/ {
    expires 1y;
    add_header Cache-Control "public, immutable";
}

# 媒体文件短期缓存
location /media/ {
    expires 7d;
}
```

## 小结

静态文件管理的关键点：

1. **配置**：`STATIC_URL`、`STATIC_ROOT`、`STATICFILES_DIRS`
2. **模板使用**：`{% static %}` 标签
3. **媒体文件**：用户上传的文件，使用 `MEDIA_ROOT`
4. **收集**：`collectstatic` 命令
5. **生产环境**：Nginx 或 WhiteNoise

> 💡 **提示**：开发环境和生产环境的静态文件处理方式不同。开发时 Django 自动处理，生产环境需要配置 Web 服务器或使用 WhiteNoise。
