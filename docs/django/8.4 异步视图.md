# 8.4 异步视图

Django 3.1+ 支持异步视图，可以使用 async/await 语法处理异步操作。本章介绍异步视图的使用方法。

## 异步视图基础

### 基本语法

```python
from django.http import HttpResponse
import asyncio

async def async_view(request):
 """异步视图"""
 await asyncio.sleep(1)
 return HttpResponse('Hello, async Django!')
```

### 异步类视图

```python
from django.views import View

class AsyncView(View):
 async def get(self, request):
 await asyncio.sleep(1)
 return HttpResponse('Async GET')
 
 async def post(self, request):
 await asyncio.sleep(1)
 return HttpResponse('Async POST')
```

## 异步数据库操作

### 同步转异步

```python
from asgiref.sync import sync_to_async

@sync_to_async
def get_articles():
 return list(Article.objects.all())

async def article_list(request):
 articles = await get_articles()
 return JsonResponse({'articles': articles})
```

### 使用 async ORM（Django 4.1+）

```python
async def article_list(request):
 articles = Article.objects.all()
 result = []
 async for article in articles:
 result.append({
 'id': article.id,
 'title': article.title,
 })
 return JsonResponse({'articles': result})
```

### 并发请求

```python
import httpx
import asyncio

async def fetch_multiple(request):
 urls = [
 'https://api.example.com/users',
 'https://api.example.com/posts',
 'https://api.example.com/comments',
 ]
 
 async with httpx.AsyncClient() as client:
 tasks = [client.get(url) for url in urls]
 responses = await asyncio.gather(*tasks)
 
 results = [r.json() for r in responses]
 return JsonResponse({'data': results})
```

## 异步中间件

```python
class AsyncMiddleware:
 """异步中间件"""
 
 def __init__(self, get_response):
 self.get_response = get_response
 
 async def __call__(self, request):
 # 请求前
 await self.process_request(request)
 
 response = await self.get_response(request)
 
 # 响应后
 await self.process_response(request, response)
 
 return response
 
 async def process_request(self, request):
 await asyncio.sleep(0)
 
 async def process_response(self, request, response):
 return response
```

## 异步任务

### 使用 Celery

```python
# tasks.py
from celery import shared_task

@shared_task
def send_email_task(email, subject, message):
 # 发送邮件
 pass

# views.py
async def send_email(request):
 send_email_task.delay('user@example.com', '主题', '内容')
 return JsonResponse({'status': 'queued'})
```

### 使用 BackgroundTasks

```python
from django.http import JsonResponse
import asyncio

async def background_task(name):
 await asyncio.sleep(10)
 print(f'后台任务完成: {name}')

async def start_task(request):
 asyncio.create_task(background_task('task1'))
 return JsonResponse({'status': 'started'})
```

## 注意事项

### 同步异步混用

```python
# 错误：在异步视图中调用同步代码
async def bad_view(request):
 articles = Article.objects.all() # 会阻塞
 return JsonResponse({})

# 正确：使用 sync_to_async
async def good_view(request):
 articles = await sync_to_async(list)(Article.objects.all())
 return JsonResponse({})
```

## 小结

异步视图的关键点：

1. **async def**：定义异步视图
2. **sync_to_async**：同步转异步
3. **async ORM**：Django 4.1+ 支持
4. **httpx**：异步 HTTP 请求

> **提示**：异步视图适合 I/O 密集型操作，如调用外部 API。对于 CPU 密集型任务，还是应该使用 Celery。
