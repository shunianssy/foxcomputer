# 8.2 信号机制

Django 信号允许某些发送者通知一组接收者某些操作已经发生。本章介绍信号机制的使用方法。

## 内置信号

### 常用信号

| 信号 | 说明 |
|------|------|
| pre_save | 保存前触发 |
| post_save | 保存后触发 |
| pre_delete | 删除前触发 |
| post_delete | 删除后触发 |
| m2m_changed | 多对多关系变化 |
| request_started | 请求开始 |
| request_finished | 请求结束 |

### post_save 示例

```python
from django.db.models.signals import post_save
from django.dispatch import receiver
from django.contrib.auth.models import User

@receiver(post_save, sender=User)
def create_user_profile(sender, instance, created, **kwargs):
 """用户创建后自动创建资料"""
 if created:
 Profile.objects.create(user=instance)

@receiver(post_save, sender=User)
def save_user_profile(sender, instance, **kwargs):
 """保存用户时保存资料"""
 instance.profile.save()
```

### pre_delete 示例

```python
from django.db.models.signals import pre_delete

@receiver(pre_delete, sender=Article)
def archive_article(sender, instance, **kwargs):
 """删除文章前归档"""
 ArchivedArticle.objects.create(
 title=instance.title,
 content=instance.content,
 original_id=instance.id
 )
```

## 自定义信号

### 定义信号

```python
# signals.py
from django.dispatch import Signal

# 定义信号
order_created = Signal()
order_paid = Signal()
order_shipped = Signal()
```

### 发送信号

```python
# views.py
from .signals import order_created

def create_order(request):
 order = Order.objects.create(...)
 
 # 发送信号
 order_created.send(
 sender=Order,
 order=order,
 user=request.user
 )
 
 return redirect('order_detail', pk=order.pk)
```

### 接收信号

```python
# receivers.py
from django.dispatch import receiver
from .signals import order_created

@receiver(order_created)
def send_order_notification(sender, **kwargs):
 """发送订单通知"""
 order = kwargs.get('order')
 user = kwargs.get('user')
 
 # 发送邮件通知
 send_mail(
 f'新订单 #{order.id}',
 f'您有新的订单',
 'noreply@example.com',
 [user.email]
 )

@receiver(order_created)
def update_inventory(sender, **kwargs):
 """更新库存"""
 order = kwargs.get('order')
 for item in order.items.all():
 item.product.stock -= item.quantity
 item.product.save()
```

## 信号注册

### 方式一：装饰器

```python
@receiver(post_save, sender=User)
def my_handler(sender, **kwargs):
 pass
```

### 方式二：手动连接

```python
from django.db.models.signals import post_save

def my_handler(sender, **kwargs):
 pass

post_save.connect(my_handler, sender=User)
```

### 在 AppConfig 中注册

```python
# apps.py
from django.apps import AppConfig

class BlogConfig(AppConfig):
 name = 'blog'
 
 def ready(self):
 # 导入信号处理器
 import blog.signals
```

## 实用示例

### 日志记录

```python
from django.db.models.signals import post_save, post_delete
import logging

logger = logging.getLogger(__name__)

@receiver(post_save, sender=Article)
def log_article_save(sender, instance, created, **kwargs):
 if created:
 logger.info(f'文章创建: {instance.title}')
 else:
 logger.info(f'文章更新: {instance.title}')

@receiver(post_delete, sender=Article)
def log_article_delete(sender, instance, **kwargs):
 logger.info(f'文章删除: {instance.title}')
```

### 缓存清理

```python
from django.core.cache import cache
from django.db.models.signals import post_save, post_delete

@receiver([post_save, post_delete], sender=Article)
def clear_article_cache(sender, instance, **kwargs):
 """清除文章缓存"""
 cache.delete(f'article_{instance.pk}')
 cache.delete('article_list')
```

## 小结

信号机制的关键点：

1. **内置信号**：pre_save、post_save 等
2. **自定义信号**：Signal() 定义
3. **发送信号**：signal.send()
4. **接收信号**：@receiver 装饰器

> **提示**：信号适合处理解耦的业务逻辑，但不要过度使用，复杂逻辑还是放在视图或模型方法中更清晰。
