# 5.3 表单渲染

Django 提供了多种表单渲染方式，可以根据需求选择合适的渲染方法。本章介绍如何在模板中渲染表单。

## 基本渲染方式

### 手动渲染字段

```html
<form method="post">
    {% csrf_token %}
    
    <div class="form-group">
        <label for="{{ form.title.id_for_label }}">{{ form.title.label }}</label>
        {{ form.title }}
        {% if form.title.errors %}
            <span class="error">{{ form.title.errors.0 }}</span>
        {% endif %}
    </div>
    
    <div class="form-group">
        <label for="{{ form.content.id_for_label }}">{{ form.content.label }}</label>
        {{ form.content }}
        {% if form.content.errors %}
            <span class="error">{{ form.content.errors.0 }}</span>
        {% endif %}
    </div>
    
    <button type="submit">提交</button>
</form>
```

### 自动渲染

```html
<!-- 渲染所有字段（段落格式）-->
{{ form.as_p }}

<!-- 渲染所有字段（列表格式）-->
{{ form.as_ul }}

<!-- 渲染所有字段（表格格式）-->
{{ form.as_table }}
```

### 循环渲染

```html
<form method="post">
    {% csrf_token %}
    
    {% for field in form %}
    <div class="form-group {% if field.errors %}has-error{% endif %}">
        <label for="{{ field.id_for_label }}">
            {{ field.label }}
            {% if field.field.required %}<span class="required">*</span>{% endif %}
        </label>
        
        {{ field }}
        
        {% if field.help_text %}
        <small class="form-text text-muted">{{ field.help_text }}</small>
        {% endif %}
        
        {% if field.errors %}
        <div class="invalid-feedback">
            {% for error in field.errors %}
                {{ error }}
            {% endfor %}
        </div>
        {% endif %}
    </div>
    {% endfor %}
    
    <button type="submit">提交</button>
</form>
```

## 字段属性

### 访问字段属性

```html
<!-- 字段标签 -->
{{ field.label }}
{{ field.label_tag }}

<!-- 字段 ID -->
{{ field.id_for_label }}

<!-- 字段值 -->
{{ field.value }}

<!-- 字段 HTML -->
{{ field.as_widget }}

<!-- 帮助文本 -->
{{ field.help_text }}

<!-- 错误信息 -->
{{ field.errors }}
{{ field.errors.as_text }}

<!-- 是否必填 -->
{{ field.field.required }}

<!-- 字段类型 -->
{{ field.field.widget.input_type }}
```

### 添加 CSS 类

```python
# forms.py
class ArticleForm(forms.Form):
    title = forms.CharField(
        widget=forms.TextInput(attrs={
            'class': 'form-control',
            'placeholder': '请输入标题'
        })
    )
    
    content = forms.CharField(
        widget=forms.Textarea(attrs={
            'class': 'form-control',
            'rows': 10
        })
    )
```

### 动态添加属性

```python
# forms.py
class ArticleForm(forms.ModelForm):
    class Meta:
        model = Article
        fields = ['title', 'content']
    
    def __init__(self, *args, **kwargs):
        super().__init__(*args, **kwargs)
        
        # 为所有字段添加 CSS 类
        for field in self.fields.values():
            field.widget.attrs['class'] = 'form-control'
        
        # 为特定字段添加属性
        self.fields['title'].widget.attrs.update({
            'placeholder': '请输入标题',
            'autofocus': True
        })
```

## Bootstrap 风格表单

### 基本样式

```html
<form method="post">
    {% csrf_token %}
    
    {% for field in form %}
    <div class="mb-3">
        <label for="{{ field.id_for_label }}" class="form-label">
            {{ field.label }}
            {% if field.field.required %}
                <span class="text-danger">*</span>
            {% endif %}
        </label>
        
        {% if field.field.widget.input_type == 'checkbox' %}
        <div class="form-check">
            {{ field }}
            <label class="form-check-label" for="{{ field.id_for_label }}">
                {{ field.label }}
            </label>
        </div>
        {% else %}
        {{ field }}
        {% endif %}
        
        {% if field.help_text %}
        <div class="form-text">{{ field.help_text }}</div>
        {% endif %}
        
        {% if field.errors %}
        <div class="invalid-feedback d-block">
            {% for error in field.errors %}{{ error }}{% endfor %}
        </div>
        {% endif %}
    </div>
    {% endfor %}
    
    <button type="submit" class="btn btn-primary">提交</button>
</form>
```

## 自定义表单模板

### 创建表单模板片段

```html
<!-- templates/blog/_form.html -->
{% load static %}

<form method="post" enctype="multipart/form-data" class="form">
    {% csrf_token %}
    
    <!-- 非字段错误 -->
    {% if form.non_field_errors %}
    <div class="alert alert-danger">
        {% for error in form.non_field_errors %}
            <p>{{ error }}</p>
        {% endfor %}
    </div>
    {% endif %}
    
    <!-- 字段循环 -->
    {% for field in form.hidden_fields %}
        {{ field }}
    {% endfor %}
    
    {% for field in form.visible_fields %}
    <div class="form-group {% if field.errors %}has-error{% endif %}">
        <label for="{{ field.id_for_label }}" class="form-label">
            {{ field.label }}
            {% if field.field.required %}
                <span class="text-danger">*</span>
            {% endif %}
        </label>
        
        {{ field }}
        
        {% if field.help_text %}
        <small class="form-text text-muted">{{ field.help_text }}</small>
        {% endif %}
        
        {% if field.errors %}
        <div class="invalid-feedback">
            {% for error in field.errors %}{{ error }}{% if not forloop.last %}<br>{% endif %}{% endfor %}
        </div>
        {% endif %}
    </div>
    {% endfor %}
    
    <!-- 提交按钮 -->
    <div class="form-group">
        <button type="submit" class="btn btn-primary">
            {{ button_text|default:"提交" }}
        </button>
    </div>
</form>
```

### 使用模板片段

```html
{% include 'blog/_form.html' with form=form button_text="创建文章" %}
```

## 自定义 Widget 模板

### 创建自定义 Widget

```python
# widgets.py
from django import forms

class CustomDateInput(forms.DateInput):
    template_name = 'widgets/custom_date.html'

class CustomSelect(forms.Select):
    template_name = 'widgets/custom_select.html'
```

### Widget 模板

```html
<!-- templates/widgets/custom_date.html -->
<div class="input-group">
    <input type="{{ widget.type }}" 
           name="{{ widget.name }}" 
           {% if widget.value != None %}value="{{ widget.value }}"{% endif %}
           {% include "django/forms/widgets/attrs.html" %}
           class="form-control">
    <span class="input-group-text">
        <i class="bi bi-calendar"></i>
    </span>
</div>
```

### 使用自定义 Widget

```python
# forms.py
from .widgets import CustomDateInput

class ArticleForm(forms.ModelForm):
    class Meta:
        model = Article
        fields = ['title', 'content', 'publish_date']
        widgets = {
            'publish_date': CustomDateInput(),
        }
```

## 表单分组

### 分组表单

```python
# forms.py
class AdvancedSearchForm(forms.Form):
    # 基本搜索
    keyword = forms.CharField(label='关键词')
    category = forms.ModelChoiceField(queryset=Category.objects.all(), required=False)
    
    # 高级搜索
    author = forms.ModelChoiceField(queryset=User.objects.all(), required=False)
    date_from = forms.DateField(required=False)
    date_to = forms.DateField(required=False)
    
    # 排序
    sort_by = forms.ChoiceField(choices=[
        ('-created_at', '最新发布'),
        ('views', '最多浏览'),
        ('title', '标题排序'),
    ])
```

## 小结

表单渲染的关键点：

1. **基本渲染**：`as_p`、`as_ul`、`as_table`
2. **手动渲染**：完全控制字段显示
3. **循环渲染**：统一渲染所有字段
4. **CSS 类**：通过 widget attrs 添加样式
5. **第三方库**：django-crispy-forms 简化渲染

> 💡 **提示**：对于简单表单，可以使用自动渲染。对于复杂表单，建议手动渲染以获得更好的控制。
