# 4.2 模板继承

模板继承是 Django 模板系统最强大的功能之一。通过继承，可以创建一个基础模板，然后在子模板中覆盖特定区块。

## 模板继承基础

### 基础模板

创建一个包含公共结构的基础模板：

```html
<!-- templates/base.html -->
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>{% block title %}我的网站{% endblock %}</title>
    
    <!-- CSS -->
    {% block css %}
    <link rel="stylesheet" href="{% static 'css/base.css' %}">
    {% endblock %}
</head>
<body>
    <!-- 导航栏 -->
    <nav class="navbar">
        <div class="container">
            <a class="navbar-brand" href="{% url 'home' %}">网站名称</a>
            <ul class="navbar-nav">
                <li><a href="{% url 'blog:article_list' %}">博客</a></li>
                <li><a href="{% url 'about' %}">关于</a></li>
            </ul>
        </div>
    </nav>
    
    <!-- 主内容区 -->
    <main class="container">
        {% block content %}
        {% endblock %}
    </main>
    
    <!-- 侧边栏 -->
    <aside class="sidebar">
        {% block sidebar %}
        <div class="widget">
            <h3>分类</h3>
            {% include 'blog/_categories.html' %}
        </div>
        {% endblock %}
    </aside>
    
    <!-- 页脚 -->
    <footer class="footer">
        <div class="container">
            <p>&copy; 2024 我的网站. All rights reserved.</p>
        </div>
    </footer>
    
    <!-- JavaScript -->
    {% block js %}
    <script src="{% static 'js/base.js' %}"></script>
    {% endblock %}
</body>
</html>
```

### 子模板

继承并覆盖基础模板：

```html
<!-- templates/blog/article_list.html -->
{% extends 'base.html' %}
{% load static %}

{% block title %}文章列表 - {{ block.super }}{% endblock %}

{% block css %}
{{ block.super }}
<link rel="stylesheet" href="{% static 'css/blog.css' %}">
{% endblock %}

{% block content %}
<div class="article-list">
    <h1>文章列表</h1>
    
    {% for article in articles %}
    <article class="article-card">
        <h2><a href="{{ article.get_absolute_url }}">{{ article.title }}</a></h2>
        <p>{{ article.content|truncatewords:50 }}</p>
        <div class="meta">
            <span>{{ article.created_at|date:"Y-m-d" }}</span>
            <span>{{ article.category.name }}</span>
        </div>
    </article>
    {% empty %}
    <p>暂无文章</p>
    {% endfor %}
    
    <!-- 分页 -->
    {% include 'blog/_pagination.html' with page_obj=page_obj %}
</div>
{% endblock %}

{% block sidebar %}
{{ block.super }}
<div class="widget">
    <h3>热门文章</h3>
    {% include 'blog/_hot_articles.html' %}
</div>
{% endblock %}
```

## block 标签详解

### 定义块

```html
<!-- 基本块定义 -->
{% block content %}
    <p>默认内容</p>
{% endblock %}

<!-- 带名称的结束标签（推荐） -->
{% block content %}
    <p>默认内容</p>
{% endblock content %}

<!-- 空块 -->
{% block extra_head %}{% endblock %}
```

### 覆盖块

```html
<!-- 完全覆盖 -->
{% block title %}新标题{% endblock %}

<!-- 保留父级内容 -->
{% block title %}新标题 - {{ block.super }}{% endblock %}

<!-- 追加内容 -->
{% block css %}
{{ block.super }}
<link rel="stylesheet" href="{% static 'css/custom.css' %}">
{% endblock %}
```

### block.super

`block.super` 用于获取父模板中块的内容：

```html
<!-- 父模板 -->
{% block title %}我的网站{% endblock %}

<!-- 子模板 -->
{% block title %}文章列表 - {{ block.super }}{% endblock %}
<!-- 输出：文章列表 - 我的网站 -->
```

## 多层继承

### 三层继承示例

```html
<!-- templates/base.html -->
<!DOCTYPE html>
<html>
<head>
    <title>{% block title %}网站{% endblock %}</title>
</head>
<body>
    {% block content %}{% endblock %}
</body>
</html>

<!-- templates/blog/base.html -->
{% extends 'base.html' %}

{% block content %}
<div class="blog-layout">
    <main class="main-content">
        {% block main %}{% endblock %}
    </main>
    <aside class="sidebar">
        {% block sidebar %}{% endblock %}
    </aside>
</div>
{% endblock %}

<!-- templates/blog/article_detail.html -->
{% extends 'blog/base.html' %}

{% block title %}{{ article.title }} - 博客{% endblock %}

{% block main %}
<article>
    <h1>{{ article.title }}</h1>
    <div class="content">{{ article.content|safe }}</div>
</article>
{% endblock %}

{% block sidebar %}
<h3>相关文章</h3>
{% include 'blog/_related.html' %}
{% endblock %}
```

## include 标签

### 基本用法

```html
<!-- 包含模板片段 -->
{% include 'blog/_article_card.html' %}

<!-- 传递变量 -->
{% include 'blog/_article_card.html' with article=featured_article %}

<!-- 仅传递指定变量 -->
{% include 'blog/_article_card.html' with article=article only %}
```

### 模板片段示例

```html
<!-- templates/blog/_article_card.html -->
<article class="card">
    <h3><a href="{{ article.get_absolute_url }}">{{ article.title }}</a></h3>
    <p>{{ article.content|truncatewords:30 }}</p>
    <div class="meta">
        <span>{{ article.created_at|date:"Y-m-d" }}</span>
        <span>{{ article.views }} 阅读</span>
    </div>
</article>

<!-- 使用方式 -->
{% for article in articles %}
    {% include 'blog/_article_card.html' with article=article %}
{% endfor %}
```

### 分页组件

```html
<!-- templates/blog/_pagination.html -->
{% if page_obj.has_other_pages %}
<nav class="pagination">
    {% if page_obj.has_previous %}
    <a href="?page={{ page_obj.previous_page_number }}" class="prev">上一页</a>
    {% endif %}
    
    <span class="current">
        第 {{ page_obj.number }} 页，共 {{ page_obj.paginator.num_pages }} 页
    </span>
    
    {% if page_obj.has_next %}
    <a href="?page={{ page_obj.next_page_number }}" class="next">下一页</a>
    {% endif %}
</nav>
{% endif %}

<!-- 使用 -->
{% include 'blog/_pagination.html' with page_obj=page_obj %}
```

## 模板组织最佳实践

### 目录结构

```text
templates/
├── base.html              # 基础模板
├── blog/
│   ├── base.html          # 博客基础模板
│   ├── article_list.html  # 文章列表
│   ├── article_detail.html# 文章详情
│   ├── article_form.html  # 文章表单
│   └── _partials/         # 部分模板
│       ├── _article_card.html
│       ├── _pagination.html
│       ├── _sidebar.html
│       └── _comments.html
├── accounts/
│   ├── login.html
│   ├── register.html
│   └── profile.html
└── errors/
    ├── 404.html
    ├── 500.html
    └── 403.html
```

### 命名约定

| 模板类型 | 命名规则 | 示例 |
|----------|----------|------|
| 基础模板 | `base.html` | `base.html` |
| 页面模板 | 功能名称 | `article_list.html` |
| 部分模板 | `_` 前缀 | `_article_card.html` |
| 表单模板 | `_form` 后缀 | `article_form.html` |
| 错误页面 | 状态码 | `404.html` |

### 常见布局模式

```html
<!-- templates/base.html -->
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    {% block meta %}
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    {% endblock %}
    
    <title>{% block title %}{% endblock %}</title>
    
    {% block css %}
    <link rel="stylesheet" href="{% static 'css/main.css' %}">
    {% endblock %}
    
    {% block extra_head %}{% endblock %}
</head>
<body class="{% block body_class %}{% endblock %}">
    {% block header %}
    <header>{% include '_header.html' %}</header>
    {% endblock %}
    
    {% block main %}
    <main>
        {% block content %}{% endblock %}
    </main>
    {% endblock %}
    
    {% block sidebar %}
    <aside>{% include '_sidebar.html' %}</aside>
    {% endblock %}
    
    {% block footer %}
    <footer>{% include '_footer.html' %}</footer>
    {% endblock %}
    
    {% block js %}

    {% endblock %}
    
    {% block extra_js %}{% endblock %}

</html>
```

## 完整示例

### 基础模板

```html
<!-- templates/base.html -->
{% load static %}
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta name="description" content="{% block meta_description %}{% endblock %}">
    <title>{% block title %}我的博客{% endblock %}</title>
    
    {% block css %}
    <link rel="stylesheet" href="{% static 'css/bootstrap.min.css' %}">
    <link rel="stylesheet" href="{% static 'css/style.css' %}">
    {% endblock %}
</head>
<body>
    <!-- 导航栏 -->
    {% block navbar %}
    <nav class="navbar navbar-expand-lg navbar-dark bg-dark">
        <div class="container">
            <a class="navbar-brand" href="{% url 'home' %}">我的博客</a>
            <div class="navbar-nav ms-auto">
                {% if user.is_authenticated %}
                    <a class="nav-link" href="{% url 'accounts:profile' %}">{{ user.username }}</a>
                    <a class="nav-link" href="{% url 'accounts:logout' %}">退出</a>
                {% else %}
                    <a class="nav-link" href="{% url 'accounts:login' %}">登录</a>
                {% endif %}
            </div>
        </div>
    </nav>
    {% endblock %}
    
    <!-- 消息提示 -->
    {% if messages %}
    <div class="container mt-3">
        {% for message in messages %}
        <div class="alert alert-{{ message.tags }} alert-dismissible fade show">
            {{ message }}
            <button type="button" class="btn-close" data-bs-dismiss="alert"></button>
        </div>
        {% endfor %}
    </div>
    {% endif %}
    
    <!-- 主内容 -->
    <div class="container my-4">
        <div class="row">
            <div class="col-lg-8">
                {% block content %}{% endblock %}
            </div>
            <div class="col-lg-4">
                {% block sidebar %}
                {% include 'blog/_sidebar.html' %}
                {% endblock %}
            </div>
        </div>
    </div>
    
    <!-- 页脚 -->
    {% block footer %}
    <footer class="bg-dark text-light py-4 mt-5">
        <div class="container text-center">
            <p>&copy; 2024 我的博客. All rights reserved.</p>
        </div>
    </footer>
    {% endblock %}
    
    {% block js %}
    <script src="{% static 'js/bootstrap.bundle.min.js' %}"></script>
    <script src="{% static 'js/main.js' %}"></script>
    {% endblock %}
</body>
</html>
```

### 文章详情页

```html
<!-- templates/blog/article_detail.html -->
{% extends 'base.html' %}
{% load static %}

{% block title %}{{ article.title }} - 我的博客{% endblock %}

{% block meta_description %}{{ article.content|truncatewords:30 }}{% endblock %}

{% block css %}
{{ block.super }}
<link rel="stylesheet" href="{% static 'css/article.css' %}">
{% endblock %}

{% block content %}
<article class="article-detail">
    <header class="article-header">
        <h1>{{ article.title }}</h1>
        <div class="article-meta">
            <span><i class="icon-user"></i> {{ article.author.username }}</span>
            <span><i class="icon-calendar"></i> {{ article.created_at|date:"Y年m月d日" }}</span>
            <span><i class="icon-eye"></i> {{ article.views }} 阅读</span>
        </div>
    </header>
    
    <div class="article-content">
        {{ article.content|safe }}
    </div>
    
    <footer class="article-footer">
        <div class="tags">
            {% for tag in article.tags.all %}
            <a href="{% url 'blog:tag' tag.slug %}" class="tag">#{{ tag.name }}</a>
            {% endfor %}
        </div>
    </footer>
</article>

<!-- 评论区 -->
<section class="comments mt-4">
    <h3>评论 ({{ article.comments.count }})</h3>
    {% include 'blog/_comments.html' with comments=article.comments.all %}
    {% include 'blog/_comment_form.html' %}
</section>
{% endblock %}

{% block sidebar %}
{{ block.super }}
<div class="widget">
    <h4>相关文章</h4>
    {% include 'blog/_related_articles.html' %}
</div>
{% endblock %}
```

## 小结

模板继承的关键点：

1. **extends**：继承父模板
2. **block**：定义可覆盖的区块
3. **block.super**：获取父模板块内容
4. **include**：包含模板片段
5. **多层继承**：支持多层模板继承

> 💡 **提示**：合理使用模板继承和 include，可以大幅减少重复代码，保持模板的 DRY（Don't Repeat Yourself）原则。
