# 7.4 Admin 美化

Django Admin 默认界面简洁，可以通过多种方式进行美化。本章介绍 Admin 美化的方法。

## 自定义 CSS 和 JS

### 添加静态文件

```python
# admin.py
class ArticleAdmin(admin.ModelAdmin):
    class Media:
        css = {
            'all': ('css/admin/custom.css',)
        }
        js = ('js/admin/custom.js',)
```

### 自定义模板

```text
templates/
└── admin/
    ├── base_site.html      # 基础模板
    ├── change_list.html    # 列表页
    └── change_form.html    # 编辑页
```

### 覆盖基础模板

```html
<!-- templates/admin/base_site.html -->
{% extends "admin/base_site.html" %}

{% block extrastyle %}
{{ block.super }}
<link rel="stylesheet" href="{% static 'css/admin.css' %}">
{% endblock %}

{% block branding %}
<h1>我的博客管理</h1>
{% endblock %}
```

## 自定义 Dashboard

```python
# admin.py
from django.utils.html import format_html

class MyAdminSite(admin.AdminSite):
    site_header = '我的管理后台'
    site_title = '管理系统'
    index_title = '欢迎使用'
    
    def index(self, request, extra_context=None):
        extra_context = extra_context or {}
        extra_context['dashboard'] = self.get_dashboard_data()
        return super().index(request, extra_context)
    
    def get_dashboard_data(self):
        return {
            'articles': Article.objects.count(),
            'users': User.objects.count(),
        }

admin_site = MyAdminSite(name='myadmin')
```

## 小结

Admin 美化的关键点：

1. **自定义 CSS/JS**：添加样式和脚本
2. **覆盖模板**：自定义页面结构
3. **第三方主题**：jazzmin、simpleui、grappelli
4. **自定义 Dashboard**：个性化首页

> 💡 **提示**：选择合适的第三方主题可以快速美化 Admin，但也要考虑维护成本。
