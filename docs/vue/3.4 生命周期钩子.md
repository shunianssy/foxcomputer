# 3.4 生命周期钩子

## 🔄 生命周期概述

每个 Vue 组件实例在创建时都需要经历一系列的初始化步骤，比如设置数据监听、编译模板、挂载实例到 DOM 等。同时，组件也会经历销毁的过程。在这些过程中，Vue 提供了生命周期钩子函数，让我们能够在特定阶段执行代码。

## 📊 生命周期图示

```
创建阶段
├── beforeCreate
├── created
├── beforeMount
└── mounted

更新阶段
├── beforeUpdate
└── updated

销毁阶段
├── beforeUnmount
└── unmounted
```

## 🎯 组合式 API 钩子

### onMounted

组件挂载完成后调用：

```vue
<script setup>
import { ref, onMounted } from 'vue'

const data = ref(null)

onMounted(() => {
  console.log('组件已挂载')
  
  // DOM 已经可用
  const element = document.getElementById('my-element')
  console.log(element)
  
  // 发起数据请求
  fetchData()
})

async function fetchData() {
  const response = await fetch('/api/data')
  data.value = await response.json()
}
</script>

<template>
  <div id="my-element">
    {{ data }}
  </div>
</template>
```

### onUpdated

组件更新后调用：

```vue
<script setup>
import { ref, onUpdated } from 'vue'

const count = ref(0)

onUpdated(() => {
  console.log('组件已更新')
  console.log('新的 count 值:', count.value)
  
  // 注意：不要在这里修改响应式数据，可能导致无限循环
})

function increment() {
  count.value++
}
</script>

<template>
  <button @click="increment">{{ count }}</button>
</template>
```

### onUnmounted

组件卸载后调用：

```vue
<script setup>
import { ref, onMounted, onUnmounted } from 'vue'

const timer = ref(null)

onMounted(() => {
  // 设置定时器
  timer.value = setInterval(() => {
    console.log('定时器运行中...')
  }, 1000)
})

onUnmounted(() => {
  // 清理定时器，防止内存泄漏
  clearInterval(timer.value)
  console.log('组件已卸载，定时器已清理')
})
</script>
```

### onBeforeMount 和 onBeforeUpdate

```vue
<script setup>
import { ref, onBeforeMount, onBeforeUpdate } from 'vue'

const count = ref(0)

onBeforeMount(() => {
  console.log('组件即将挂载，DOM 还未渲染')
})

onBeforeUpdate(() => {
  console.log('组件即将更新，DOM 还是旧状态')
  console.log('当前 count:', count.value)
})

function increment() {
  count.value++
}
</script>

<template>
  <button @click="increment">{{ count }}</button>
</template>
```

### onBeforeUnmount

```vue
<script setup>
import { onBeforeUnmount } from 'vue'

onBeforeUnmount(() => {
  console.log('组件即将卸载')
  // 可以在这里做一些清理前的准备工作
})
</script>
```

## 🔧 其他钩子函数

### onErrorCaptured

捕获后代组件的错误：

```vue
<script setup>
import { ref, onErrorCaptured } from 'vue'

const error = ref(null)

onErrorCaptured((err, instance, info) => {
  console.error('捕获到错误:', err)
  console.error('错误来源:', info)
  
  error.value = err.message
  
  // 返回 false 阻止错误继续传播
  return false
})
</script>

<template>
  <div v-if="error" class="error">
    发生错误: {{ error }}
  </div>
  <slot v-else />
</template>
```

### onRenderTracked 和 onRenderTriggered（调试用）

```vue
<script setup>
import { ref, onRenderTracked, onRenderTriggered } from 'vue'

const count = ref(0)

// 追踪依赖收集
onRenderTracked((e) => {
  console.log('依赖收集:', e)
})

// 追踪触发更新的依赖
onRenderTriggered((e) => {
  console.log('触发更新:', e)
})
</script>
```

## 📊 钩子函数对比

| 选项式 API | 组合式 API | 说明 |
|------------|------------|------|
| `beforeCreate` | `setup()` | 组件实例初始化之前 |
| `created` | `setup()` | 组件实例创建完成 |
| `beforeMount` | `onBeforeMount` | 挂载之前 |
| `mounted` | `onMounted` | 挂载完成 |
| `beforeUpdate` | `onBeforeUpdate` | 更新之前 |
| `updated` | `onUpdated` | 更新完成 |
| `beforeUnmount` | `onBeforeUnmount` | 卸载之前 |
| `unmounted` | `onUnmounted` | 卸载完成 |

## 🎨 实际应用示例

### 数据请求组件

```vue
<script setup>
import { ref, onMounted, onUnmounted } from 'vue'

const props = defineProps({
  url: {
    type: String,
    required: true
  }
})

const data = ref(null)
const loading = ref(false)
const error = ref(null)
const controller = ref(null)

async function fetchData() {
  // 取消之前的请求
  if (controller.value) {
    controller.value.abort()
  }
  
  controller.value = new AbortController()
  loading.value = true
  error.value = null
  
  try {
    const response = await fetch(props.url, {
      signal: controller.value.signal
    })
    
    if (!response.ok) {
      throw new Error(`HTTP error! status: ${response.status}`)
    }
    
    data.value = await response.json()
  } catch (err) {
    if (err.name !== 'AbortError') {
      error.value = err.message
    }
  } finally {
    loading.value = false
  }
}

onMounted(() => {
  fetchData()
})

// 当 URL 变化时重新请求
import { watch } from 'vue'
watch(() => props.url, () => {
  fetchData()
})

onUnmounted(() => {
  // 组件卸载时取消请求
  if (controller.value) {
    controller.value.abort()
  }
})
</script>

<template>
  <div class="data-fetcher">
    <div v-if="loading" class="loading">加载中...</div>
    <div v-else-if="error" class="error">{{ error }}</div>
    <slot v-else-if="data" :data="data" />
  </div>
</template>
```

### 事件监听组件

```vue
<script setup>
import { ref, onMounted, onUnmounted } from 'vue'

const mouseX = ref(0)
const mouseY = ref(0)
const isOnline = ref(navigator.onLine)

function handleMouseMove(e) {
  mouseX.value = e.clientX
  mouseY.value = e.clientY
}

function handleOnline() {
  isOnline.value = true
}

function handleOffline() {
  isOnline.value = false
}

onMounted(() => {
  // 添加事件监听
  window.addEventListener('mousemove', handleMouseMove)
  window.addEventListener('online', handleOnline)
  window.addEventListener('offline', handleOffline)
})

onUnmounted(() => {
  // 移除事件监听
  window.removeEventListener('mousemove', handleMouseMove)
  window.removeEventListener('online', handleOnline)
  window.removeEventListener('offline', handleOffline)
})
</script>

<template>
  <div class="event-listener">
    <p>鼠标位置: X={{ mouseX }}, Y={{ mouseY }}</p>
    <p>网络状态: {{ isOnline ? '在线' : '离线' }}</p>
  </div>
</template>
```

### 可复用定时器

```vue
<script setup>
import { ref, onMounted, onUnmounted } from 'vue'

const props = defineProps({
  interval: {
    type: Number,
    default: 1000
  }
})

const emit = defineEmits(['tick'])

const count = ref(0)
let timer = null

function start() {
  if (timer) return
  timer = setInterval(() => {
    count.value++
    emit('tick', count.value)
  }, props.interval)
}

function stop() {
  if (timer) {
    clearInterval(timer)
    timer = null
  }
}

function reset() {
  stop()
  count.value = 0
}

onMounted(() => {
  start()
})

onUnmounted(() => {
  stop()
})

// 暴露方法给父组件
defineExpose({
  start,
  stop,
  reset
})
</script>

<template>
  <div class="timer">
    <span>{{ count }}</span>
    <button @click="stop">暂停</button>
    <button @click="start">继续</button>
    <button @click="reset">重置</button>
  </div>
</template>
```

### 窗口大小监听

```vue
<script setup>
import { ref, onMounted, onUnmounted } from 'vue'

const windowSize = ref({
  width: window.innerWidth,
  height: window.innerHeight
})

function handleResize() {
  windowSize.value = {
    width: window.innerWidth,
    height: window.innerHeight
  }
}

onMounted(() => {
  window.addEventListener('resize', handleResize)
})

onUnmounted(() => {
  window.removeEventListener('resize', handleResize)
})
</script>

<template>
  <div class="window-size">
    <p>窗口大小: {{ windowSize.width }} x {{ windowSize.height }}</p>
    <p>设备类型: {{ windowSize.width < 768 ? '移动端' : '桌面端' }}</p>
  </div>
</template>
```

### 组合式函数封装

```javascript
// composables/useLifecycle.js
import { onMounted, onUnmounted } from 'vue'

/**
 * 封装事件监听的生命周期管理
 */
export function useEventListener(target, event, callback) {
  onMounted(() => {
    target.addEventListener(event, callback)
  })
  
  onUnmounted(() => {
    target.removeEventListener(event, callback)
  })
}

/**
 * 封装定时器的生命周期管理
 */
export function useInterval(callback, interval = 1000) {
  let timer = null
  
  onMounted(() => {
    timer = setInterval(callback, interval)
  })
  
  onUnmounted(() => {
    if (timer) {
      clearInterval(timer)
    }
  })
  
  return {
    stop: () => clearInterval(timer)
  }
}
```

```vue
<script setup>
import { ref } from 'vue'
import { useEventListener, useInterval } from './composables/useLifecycle'

const mouseX = ref(0)
const mouseY = ref(0)
const count = ref(0)

// 使用封装的生命周期钩子
useEventListener(window, 'mousemove', (e) => {
  mouseX.value = e.clientX
  mouseY.value = e.clientY
})

useInterval(() => {
  count.value++
}, 1000)
</script>

<template>
  <div>
    <p>鼠标: {{ mouseX }}, {{ mouseY }}</p>
    <p>计数: {{ count }}</p>
  </div>
</template>
```

## 📝 总结

| 钩子 | 触发时机 | 常见用途 |
|------|----------|----------|
| `onMounted` | DOM 挂载完成 | 请求数据、DOM 操作 |
| `onUpdated` | 数据更新后 | DOM 更新后的操作 |
| `onUnmounted` | 组件卸载后 | 清理定时器、事件监听 |
| `onBeforeMount` | 挂载前 | 很少使用 |
| `onBeforeUpdate` | 更新前 | 获取更新前的 DOM 状态 |
| `onBeforeUnmount` | 卸载前 | 清理前的准备工作 |

**最佳实践**：
- 在 `onMounted` 中进行 DOM 操作和数据请求
- 在 `onUnmounted` 中清理副作用（定时器、事件监听等）
- 避免在 `onUpdated` 中修改响应式数据
- 将生命周期逻辑封装成组合式函数复用
