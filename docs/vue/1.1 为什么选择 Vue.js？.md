# 1.1 为什么选择 Vue.js？

Vue.js 是一个渐进式 JavaScript 框架，用于构建用户界面。它的核心库专注于视图层，易于上手，同时也便于与第三方库或既有项目整合。

## Vue.js 的特点

### 1. 渐进式框架

Vue 可以根据需求逐步采用：
- 可以作为一个简单的库嵌入现有页面
- 也可以作为完整的框架构建复杂的单页应用

### 2. 响应式数据绑定

```vue
<script setup>
import { ref } from 'vue'

const message = ref('Hello Vue!')
</script>

<template>
  <p>{{ message }}</p>
  <input v-model="message" />
</template>
```

当数据变化时，视图会自动更新。

### 3. 组件化开发

```vue
<!-- MyComponent.vue -->
<script setup>
defineProps({
  title: String
})
</script>

<template>
  <div class="card">
    <h2>{{ title }}</h2>
    <slot />
  </div>
</template>
```

### 4. 虚拟 DOM

Vue 使用虚拟 DOM 来优化渲染性能，只更新变化的部分。

### 5. 丰富的生态系统

- Vue Router - 路由管理
- Pinia - 状态管理
- Vite - 构建工具
- Vue Test Utils - 测试工具

## Vue.js vs 其他框架

| 特性 | Vue.js | React | Angular |
|------|--------|-------|---------|
| 学习曲线 | 低 | 中等 | 较高 |
| 模板语法 | HTML 模板 | JSX | HTML 模板 |
| 状态管理 | Pinia | Redux/Context | RxJS/NgRx |
| 路由 | Vue Router | React Router | Angular Router |
| 类型支持 | TypeScript | TypeScript | TypeScript |

## Vue 3 的新特性

### Composition API

```vue
<script setup>
import { ref, computed, onMounted } from 'vue'

const count = ref(0)
const doubled = computed(() => count.value * 2)

onMounted(() => {
  console.log('组件已挂载')
})
</script>
```

### 更好的 TypeScript 支持

Vue 3 从底层使用 TypeScript 重写，提供了更好的类型推断。

### 更小的打包体积

Vue 3 的打包体积更小，Tree-shaking 支持更好。

### 更快的渲染性能

Vue 3 优化了虚拟 DOM 算法，渲染性能显著提升。

## 小结

Vue.js 是一个优秀的渐进式 JavaScript 框架，具有以下优势：

1. **易于学习**：语法简洁，文档完善
2. **灵活渐进**：可以按需使用
3. **性能优秀**：虚拟 DOM + 响应式系统
4. **生态完善**：官方提供完整的解决方案
5. **社区活跃**：丰富的第三方库和插件

> **提示**：Vue.js 是学习现代前端框架的最佳选择之一，无论你是初学者还是有经验的开发者，都能快速上手并构建高质量的应用。
