# 2.3 计算属性

## 🎯 计算属性概述

计算属性（Computed Properties）用于声明式地描述依赖于其他响应式数据的值。当依赖的数据变化时，计算属性会自动重新计算。

## 📊 基础用法

### 使用 computed

```vue
<script setup>
import { ref, computed } from 'vue'

const firstName = ref('张')
const lastName = ref('三')

// 计算属性
const fullName = computed(() => {
  return firstName.value + lastName.value
})

// 计算属性自动追踪依赖
// 当 firstName 或 lastName 变化时，fullName 自动更新
</script>

<template>
  <p>姓名: {{ fullName }}</p>
  <input v-model="firstName" placeholder="姓" />
  <input v-model="lastName" placeholder="名" />
</template>
```

### 计算属性 vs 方法

```vue
<script setup>
import { ref, computed } from 'vue'

const items = ref([1, 2, 3, 4, 5])

// 计算属性：有缓存，依赖不变则不重新计算
const reversedItems = computed(() => {
  console.log('计算属性执行')
  return [...items.value].reverse()
})

// 方法：每次调用都会执行
function getReversedItems() {
  console.log('方法执行')
  return [...items.value].reverse()
}
</script>

<template>
  <!-- 计算属性：多次访问只计算一次 -->
  <p>{{ reversedItems }}</p>
  <p>{{ reversedItems }}</p>
  
  <!-- 方法：每次调用都会执行 -->
  <p>{{ getReversedItems() }}</p>
  <p>{{ getReversedItems() }}</p>
</template>
```

## ✏️ 可写计算属性

计算属性默认是只读的，但也可以提供 setter：

```vue
<script setup>
import { ref, computed } from 'vue'

const firstName = ref('张')
const lastName = ref('三')

// 可写计算属性
const fullName = computed({
  // getter
  get() {
    return firstName.value + lastName.value
  },
  // setter
  set(newValue) {
    // 假设名字是两个字符
    firstName.value = newValue[0]
    lastName.value = newValue.slice(1)
  }
})

// 修改 fullName 会触发 setter
function changeName() {
  fullName.value = '李四'  // firstName = '李', lastName = '四'
}
</script>

<template>
  <p>姓名: {{ fullName }}</p>
  <input v-model="fullName" placeholder="输入全名" />
  <button @click="changeName">改为李四</button>
</template>
```

## 🎨 实际应用示例

### 商品筛选

```vue
<script setup>
import { ref, computed } from 'vue'

const searchQuery = ref('')
const selectedCategory = ref('all')

const products = ref([
  { id: 1, name: '苹果', price: 5, category: 'fruit' },
  { id: 2, name: '香蕉', price: 3, category: 'fruit' },
  { id: 3, name: '胡萝卜', price: 2, category: 'vegetable' },
  { id: 4, name: '西红柿', price: 4, category: 'vegetable' }
])

// 筛选后的商品
const filteredProducts = computed(() => {
  let result = products.value

  // 按分类筛选
  if (selectedCategory.value !== 'all') {
    result = result.filter(p => p.category === selectedCategory.value)
  }

  // 按搜索词筛选
  if (searchQuery.value) {
    result = result.filter(p => 
      p.name.includes(searchQuery.value)
    )
  }

  return result
})

// 统计信息
const productStats = computed(() => {
  return {
    total: products.value.length,
    filtered: filteredProducts.value.length,
    totalPrice: filteredProducts.value.reduce((sum, p) => sum + p.price, 0)
  }
})
</script>

<template>
  <div class="product-filter">
    <!-- 搜索和筛选 -->
    <div class="controls">
      <input v-model="searchQuery" placeholder="搜索商品" />
      <select v-model="selectedCategory">
        <option value="all">全部分类</option>
        <option value="fruit">水果</option>
        <option value="vegetable">蔬菜</option>
      </select>
    </div>

    <!-- 商品列表 -->
    <ul>
      <li v-for="product in filteredProducts" :key="product.id">
        {{ product.name }} - ¥{{ product.price }}
      </li>
    </ul>

    <!-- 统计信息 -->
    <p>
      显示 {{ productStats.filtered }} / {{ productStats.total }} 件商品，
      总价 ¥{{ productStats.totalPrice }}
    </p>
  </div>
</template>
```

### 表单验证

```vue
<script setup>
import { reactive, computed } from 'vue'

const form = reactive({
  username: '',
  email: '',
  password: '',
  confirmPassword: ''
})

// 用户名验证
const usernameError = computed(() => {
  if (!form.username) return '请输入用户名'
  if (form.username.length < 3) return '用户名至少 3 个字符'
  if (form.username.length > 20) return '用户名最多 20 个字符'
  return ''
})

// 邮箱验证
const emailError = computed(() => {
  if (!form.email) return '请输入邮箱'
  const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/
  if (!emailRegex.test(form.email)) return '请输入有效的邮箱地址'
  return ''
})

// 密码验证
const passwordError = computed(() => {
  if (!form.password) return '请输入密码'
  if (form.password.length < 6) return '密码至少 6 个字符'
  return ''
})

// 确认密码验证
const confirmPasswordError = computed(() => {
  if (!form.confirmPassword) return '请确认密码'
  if (form.password !== form.confirmPassword) return '两次密码不一致'
  return ''
})

// 表单是否有效
const isValid = computed(() => {
  return !usernameError.value && 
         !emailError.value && 
         !passwordError.value && 
         !confirmPasswordError.value
})

// 提交函数
function onSubmit() {
  if (isValid.value) {
    console.log('提交成功:', form)
  }
}
</script>

<template>
  <form @submit.prevent="onSubmit">
    <div>
      <label>用户名</label>
      <input v-model="form.username" />
      <span class="error" v-if="usernameError">{{ usernameError }}</span>
    </div>

    <div>
      <label>邮箱</label>
      <input v-model="form.email" type="email" />
      <span class="error" v-if="emailError">{{ emailError }}</span>
    </div>

    <div>
      <label>密码</label>
      <input v-model="form.password" type="password" />
      <span class="error" v-if="passwordError">{{ passwordError }}</span>
    </div>

    <div>
      <label>确认密码</label>
      <input v-model="form.confirmPassword" type="password" />
      <span class="error" v-if="confirmPasswordError">{{ confirmPasswordError }}</span>
    </div>

    <button type="submit" :disabled="!isValid">
      提交
    </button>
  </form>
</template>

<style scoped>
.error {
  color: red;
  font-size: 12px;
}

button:disabled {
  opacity: 0.5;
  cursor: not-allowed;
}
</style>
```

### 分页组件

```vue
<script setup>
import { ref, computed } from 'vue'

const items = ref(
  Array.from({ length: 100 }, (_, i) => ({ id: i + 1, name: `项目 ${i + 1}` }))
)

const currentPage = ref(1)
const pageSize = ref(10)

// 总页数
const totalPages = computed(() => {
  return Math.ceil(items.value.length / pageSize.value)
})

// 当前页数据
const currentPageItems = computed(() => {
  const start = (currentPage.value - 1) * pageSize.value
  const end = start + pageSize.value
  return items.value.slice(start, end)
})

// 页码列表
const pageNumbers = computed(() => {
  const pages = []
  for (let i = 1; i <= totalPages.value; i++) {
    pages.push(i)
  }
  return pages
})

// 分页信息
const pageInfo = computed(() => {
  const start = (currentPage.value - 1) * pageSize.value + 1
  const end = Math.min(currentPage.value * pageSize.value, items.value.length)
  return `显示 ${start}-${end} 条，共 ${items.value.length} 条`
})

function goToPage(page) {
  if (page >= 1 && page <= totalPages.value) {
    currentPage.value = page
  }
}
</script>

<template>
  <div class="pagination-demo">
    <!-- 数据列表 -->
    <ul>
      <li v-for="item in currentPageItems" :key="item.id">
        {{ item.name }}
      </li>
    </ul>

    <!-- 分页信息 -->
    <p>{{ pageInfo }}</p>

    <!-- 分页控件 -->
    <div class="pagination">
      <button @click="goToPage(1)" :disabled="currentPage === 1">
        首页
      </button>
      <button @click="goToPage(currentPage - 1)" :disabled="currentPage === 1">
        上一页
      </button>

      <button
        v-for="page in pageNumbers"
        :key="page"
        @click="goToPage(page)"
        :class="{ active: page === currentPage }"
      >
        {{ page }}
      </button>

      <button @click="goToPage(currentPage + 1)" :disabled="currentPage === totalPages">
        下一页
      </button>
      <button @click="goToPage(totalPages)" :disabled="currentPage === totalPages">
        末页
      </button>
    </div>
  </div>
</template>

<style scoped>
.pagination button {
  margin: 0 2px;
  padding: 5px 10px;
}

.pagination button.active {
  background: #42b883;
  color: white;
}

.pagination button:disabled {
  opacity: 0.5;
  cursor: not-allowed;
}
</style>
```

## ⚠️ 注意事项

### 避免副作用

```vue
<script setup>
import { ref, computed } from 'vue'

const count = ref(0)

// ❌ 错误：在计算属性中产生副作用
const badComputed = computed(() => {
  count.value++  // 不要这样做！
  return count.value * 2
})

// ✅ 正确：纯计算
const goodComputed = computed(() => {
  return count.value * 2
})
</script>
```

### 避免异步操作

```vue
<script setup>
import { ref, computed } from 'vue'

const data = ref(null)

// ❌ 错误：计算属性中不能使用异步
const badComputed = computed(async () => {
  const response = await fetch('/api/data')
  return response.json()
})

// ✅ 正确：使用 watch 或 watchEffect
import { watchEffect } from 'vue'

watchEffect(async () => {
  const response = await fetch('/api/data')
  data.value = await response.json()
})
</script>
```

## 📝 总结

| 特性 | 说明 |
|------|------|
| 缓存 | 依赖不变则不重新计算 |
| 响应式 | 自动追踪依赖 |
| 只读 | 默认只读，可提供 setter |
| 纯函数 | 不应有副作用 |

**最佳实践**：
- 使用计算属性处理派生数据
- 复杂计算使用计算属性（有缓存）
- 需要副作用的场景使用 `watch`
