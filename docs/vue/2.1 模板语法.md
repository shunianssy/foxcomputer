# 2.1 模板语法

## 模板语法概述

Vue 使用基于 HTML 的模板语法，允许开发者声明式地将 DOM 绑定到底层组件实例的数据上。

## 🔤 文本插值

### 基础插值

使用双大括号（Mustache 语法）进行文本插值：

```vue
<script setup>
import { ref } from 'vue'

const message = ref('Hello Vue!')
const count = ref(0)
</script>

<template>
 <!-- 基础文本插值 -->
 <p>{{ message }}</p>
 
 <!-- 支持表达式 -->
 <p>{{ count + 1 }}</p>
 
 <!-- 支持三元表达式 -->
 <p>{{ count > 0 ? '正数' : '非正数' }}</p>
 
 <!-- 支持调用方法 -->
 <p>{{ message.toUpperCase() }}</p>
</template>
```

### 插值限制

```vue
<template>
 <!-- 正确：支持表达式 -->
 <p>{{ 1 + 1 }}</p>
 <p>{{ Math.random() }}</p>
 
 <!-- 错误：不支持语句 -->
 <p>{{ let a = 1 }}</p>
 <p>{{ if (true) { return 1 } }}</p>
</template>
```

## 原始 HTML

使用 `v-html` 指令输出原始 HTML：

```vue
<script setup>
import { ref } from 'vue'

const rawHtml = '<span style="color: red;">这是红色文字</span>'
</script>

<template>
 <!-- 普通插值：HTML 会被转义 -->
 <p>普通插值: {{ rawHtml }}</p>
 
 <!-- v-html：输出原始 HTML -->
 <p>v-html: <span v-html="rawHtml"></span></p>
</template>
```

::: warning 安全警告
在网站上动态渲染任意 HTML 是非常危险的，容易导致 XSS 攻击。请只对可信内容使用 `v-html`，永远不要用在用户提交的内容上。
:::

## 属性绑定

使用 `v-bind` 指令绑定属性：

```vue
<script setup>
import { ref } from 'vue'

const url = 'https://vuejs.org'
const id = 'container'
const isActive = true
const textColor = 'blue'
</script>

<template>
 <!-- 基础属性绑定 -->
 <a v-bind:href="url">Vue 官网</a>
 
 <!-- 缩写形式 -->
 <a :href="url">Vue 官网</a>
 
 <!-- 动态属性名 -->
 <div :[attrName]="attrValue">动态属性</div>
 
 <!-- 多属性绑定 -->
 <div v-bind="{ id, class: 'active' }">多属性绑定</div>
</template>
```

### 布尔型属性

```vue
<script setup>
const isDisabled = true
</script>

<template>
 <!-- 布尔属性 -->
 <button :disabled="isDisabled">按钮</button>
 
 <!-- isDisabled 为 true 时渲染 disabled -->
 <!-- isDisabled 为 false 时移除 disabled -->
</template>
```

## class 与 style 绑定

### class 绑定

```vue
<script setup>
import { ref } from 'vue'

const isActive = ref(true)
const hasError = ref(false)

const classObject = {
 active: true,
 'text-danger': false
}

const classArray = ['btn', 'btn-primary']
</script>

<template>
 <!-- 对象语法 -->
 <div :class="{ active: isActive }">对象语法</div>
 
 <!-- 多个类 -->
 <div :class="{ active: isActive, 'text-danger': hasError }">
 多个类
 </div>
 
 <!-- 绑定对象 -->
 <div :class="classObject">绑定对象</div>
 
 <!-- 数组语法 -->
 <div :class="['btn', 'btn-primary']">数组语法</div>
 
 <!-- 数组 + 对象 -->
 <div :class="['btn', { active: isActive }]">混合语法</div>
</template>
```

### style 绑定

```vue
<script setup>
import { ref } from 'vue'

const activeColor = ref('red')
const fontSize = ref(20)

const styleObject = {
 color: 'red',
 fontSize: '14px'
}

const styleArray = [
 { color: 'blue' },
 { fontSize: '16px' }
]
</script>

<template>
 <!-- 对象语法 -->
 <div :style="{ color: activeColor, fontSize: fontSize + 'px' }">
 对象语法
 </div>
 
 <!-- 绑定对象 -->
 <div :style="styleObject">绑定对象</div>
 
 <!-- 数组语法 -->
 <div :style="styleArray">数组语法</div>
 
 <!-- 多重值（浏览器支持哪个用哪个） -->
 <div :style="{ display: ['-webkit-box', '-ms-flexbox', 'flex'] }">
 多重值
 </div>
</template>
```

## 条件渲染

### v-if、v-else-if、v-else

```vue
<script setup>
import { ref } from 'vue'

const score = ref(85)
</script>

<template>
 <div v-if="score >= 90">
 优秀
 </div>
 <div v-else-if="score >= 80">
 良好
 </div>
 <div v-else-if="score >= 60">
 及格
 </div>
 <div v-else>
 不及格
 </div>
</template>
```

### v-show

```vue
<script setup>
import { ref } from 'vue'

const isVisible = ref(true)
</script>

<template>
 <!-- v-show：切换 display 属性 -->
 <div v-show="isVisible">
 这个元素始终存在于 DOM 中
 </div>
</template>
```

### v-if vs v-show

| 特性 | v-if | v-show |
|------|------|--------|
| 切换方式 | 销毁/重建组件 | CSS display 切换 |
| 初始渲染 | 条件为 false 不渲染 | 始终渲染 |
| 性能 | 切换开销大 | 初始渲染开销大 |
| 适用场景 | 条件很少改变 | 需要频繁切换 |

### template 上使用 v-if

```vue
<script setup>
import { ref } from 'vue'

const showContent = ref(true)
</script>

<template>
 <!-- 在 template 上使用 v-if -->
 <template v-if="showContent">
 <h1>标题</h1>
 <p>段落 1</p>
 <p>段落 2</p>
 </template>
</template>
```

## 列表渲染

### v-for 基础

```vue
<script setup>
import { ref } from 'vue'

const items = ref([
 { id: 1, name: '苹果', price: 5 },
 { id: 2, name: '香蕉', price: 3 },
 { id: 3, name: '橙子', price: 4 }
])

const numbers = ref([1, 2, 3, 4, 5])
</script>

<template>
 <!-- 遍历数组 -->
 <ul>
 <li v-for="item in items" :key="item.id">
 {{ item.name }} - ¥{{ item.price }}
 </li>
 </ul>
 
 <!-- 带索引 -->
 <ul>
 <li v-for="(item, index) in items" :key="item.id">
 {{ index + 1 }}. {{ item.name }}
 </li>
 </ul>
 
 <!-- 遍历数字 -->
 <span v-for="n in 10" :key="n">{{ n }}</span>
</template>
```

### 遍历对象

```vue
<script setup>
const user = {
 name: '张三',
 age: 25,
 city: '北京'
}
</script>

<template>
 <!-- 遍历值 -->
 <ul>
 <li v-for="value in user" :key="value">
 {{ value }}
 </li>
 </ul>
 
 <!-- 遍历键值 -->
 <ul>
 <li v-for="(value, key) in user" :key="key">
 {{ key }}: {{ value }}
 </li>
 </ul>
 
 <!-- 遍历键值和索引 -->
 <ul>
 <li v-for="(value, key, index) in user" :key="key">
 {{ index }}. {{ key }}: {{ value }}
 </li>
 </ul>
</template>
```

### key 的重要性

```vue
<script setup>
import { ref } from 'vue'

const items = ref([
 { id: 1, text: '项目 1' },
 { id: 2, text: '项目 2' }
])
</script>

<template>
 <!-- 正确：使用唯一 id 作为 key -->
 <div v-for="item in items" :key="item.id">
 {{ item.text }}
 </div>
 
 <!-- 不推荐：使用索引作为 key -->
 <div v-for="(item, index) in items" :key="index">
 {{ item.text }}
 </div>
</template>
```

::: tip 最佳实践
始终为 `v-for` 提供唯一的 `key` 属性，除非你确定不需要复用 DOM 元素。
:::

## 事件处理

### 基础事件绑定

```vue
<script setup>
import { ref } from 'vue'

const count = ref(0)

function increment() {
 count.value++
}

function add(n) {
 count.value += n
}
</script>

<template>
 <!-- 方法处理器 -->
 <button @click="increment">点击 +1</button>
 
 <!-- 内联处理器 -->
 <button @click="count++">点击 +1</button>
 
 <!-- 传递参数 -->
 <button @click="add(5)">点击 +5</button>
 
 <!-- 访问事件对象 -->
 <button @click="(e) => console.log(e.target)">
 打印事件对象
 </button>
</template>
```

### 事件修饰符

```vue
<template>
 <!-- 阻止默认行为 -->
 <form @submit.prevent="onSubmit">
 <button type="submit">提交</button>
 </form>
 
 <!-- 阻止事件冒泡 -->
 <div @click="onDivClick">
 <button @click.stop="onButtonClick">点击</button>
 </div>
 
 <!-- 事件只触发一次 -->
 <button @click.once="onOnceClick">只触发一次</button>
 
 <!-- 捕获模式 -->
 <div @click.capture="onCapture">捕获模式</div>
 
 <!-- 只当事件在该元素本身触发时触发 -->
 <div @click.self="onSelf">只响应自身点击</div>
 
 <!-- 链式修饰符 -->
 <div @click.stop.prevent="doThat">链式修饰符</div>
</template>
```

### 按键修饰符

```vue
<template>
 <!-- 按键修饰符 -->
 <input @keyup.enter="onEnter" />
 <input @keyup.tab="onTab" />
 <input @keyup.esc="onEsc" />
 
 <!-- 系统修饰键 -->
 <input @keyup.ctrl="onCtrl" />
 <input @keyup.alt="onAlt" />
 <input @keyup.shift="onShift" />
 
 <!-- 组合使用 -->
 <input @keyup.ctrl.enter="onCtrlEnter" />
 <input @click.ctrl="onCtrlClick" />
</template>
```

## 表单输入绑定

### v-model 基础

```vue
<script setup>
import { ref } from 'vue'

const text = ref('')
const message = ref('')
const checked = ref(false)
const checkedNames = ref([])
const picked = ref('')
const selected = ref('')
const selectedMultiple = ref([])
</script>

<template>
 <!-- 文本输入 -->
 <input v-model="text" placeholder="输入文字" />
 <p>输入内容: {{ text }}</p>
 
 <!-- 多行文本 -->
 <textarea v-model="message"></textarea>
 
 <!-- 复选框 -->
 <input type="checkbox" v-model="checked" />
 <label>{{ checked ? '已选中' : '未选中' }}</label>
 
 <!-- 多个复选框 -->
 <input type="checkbox" v-model="checkedNames" value="张三" />
 <input type="checkbox" v-model="checkedNames" value="李四" />
 <input type="checkbox" v-model="checkedNames" value="王五" />
 
 <!-- 单选框 -->
 <input type="radio" v-model="picked" value="one" />
 <input type="radio" v-model="picked" value="two" />
 
 <!-- 下拉选择 -->
 <select v-model="selected">
 <option value="">请选择</option>
 <option value="a">A</option>
 <option value="b">B</option>
 </select>
 
 <!-- 多选 -->
 <select v-model="selectedMultiple" multiple>
 <option value="a">A</option>
 <option value="b">B</option>
 </select>
</template>
```

### v-model 修饰符

```vue
<script setup>
import { ref } from 'vue'

const text = ref('')
const number = ref(0)
const trimmed = ref('')
</script>

<template>
 <!-- .lazy：在 change 事件后同步 -->
 <input v-model.lazy="text" />
 
 <!-- .number：转换为数字 -->
 <input v-model.number="number" type="number" />
 
 <!-- .trim：去除首尾空格 -->
 <input v-model.trim="trimmed" />
</template>
```

## 总结

| 语法 | 说明 |
|------|------|
| `{{ }}` | 文本插值 |
| `v-html` | 输出原始 HTML |
| `v-bind` / `:` | 属性绑定 |
| `v-if` / `v-show` | 条件渲染 |
| `v-for` | 列表渲染 |
| `v-on` / `@` | 事件绑定 |
| `v-model` | 双向数据绑定 |
