# Vue.js 完整教程

## 📖 教程简介

Vue.js 是一个渐进式 JavaScript 框架，用于构建用户界面。它的核心库专注于视图层，易于上手，同时也便于与第三方库或既有项目整合。本教程从零开始，带你全面掌握 Vue.js 3 开发的方方面面。

## 🎯 学习目标

- 理解 Vue.js 的核心概念和响应式原理
- 掌握组件化开发思想
- 学会使用 Vue Router 进行路由管理
- 掌握 Pinia 状态管理
- 了解 Vue 3 Composition API 的新特性

## 学习建议

1. **循序渐进**：按照章节顺序学习，每章都有示例代码
2. **动手实践**：边学边写代码，加深理解
3. **阅读源码**：遇到问题时，Vue 源码是最好的老师
4. **项目驱动**：尝试用 Vue 做一个小项目巩固知识
