# 2.2 响应式数据

## 响应式系统概述

Vue 的响应式系统是框架的核心特性，当数据变化时，视图会自动更新。Vue 3 提供了两种创建响应式数据的方式：`ref` 和 `reactive`。

## ref

### 基础用法

`ref` 用于创建响应式的基本类型数据：

```vue
<script setup>
import { ref } from 'vue'

// 创建响应式数据
const count = ref(0)
const message = ref('Hello')
const isActive = ref(false)

// 访问和修改需要使用 .value
console.log(count.value) // 0
count.value++ // 修改
console.log(count.value) // 1
</script>

<template>
 <!-- 模板中自动解包，不需要 .value -->
 <p>{{ count }}</p>
 <p>{{ message }}</p>
</template>
```

### ref 与对象

```vue
<script setup>
import { ref } from 'vue'

// ref 也可以包装对象
const user = ref({
 name: '张三',
 age: 25
})

// 修改对象属性
user.value.name = '李四'

// 替换整个对象
user.value = { name: '王五', age: 30 }
</script>
```

### ref 解包

```vue
<script setup>
import { ref } from 'vue'

const count = ref(0)
const objectWithRef = {
 count // 等同于 count: ref(0)
}
</script>

<template>
 <!-- 模板中自动解包 -->
 <p>{{ count }}</p>
 
 <!-- 作为顶层属性自动解包 -->
 <p>{{ objectWithRef.count }}</p>
</template>
```

## reactive

### 基础用法

`reactive` 用于创建响应式对象：

```vue
<script setup>
import { reactive } from 'vue'

// 创建响应式对象
const state = reactive({
 count: 0,
 user: {
 name: '张三',
 age: 25
 }
})

// 直接访问，不需要 .value
console.log(state.count) // 0
state.count++ // 修改
console.log(state.count) // 1

// 嵌套对象也是响应式的
state.user.name = '李四'
</script>

<template>
 <p>{{ state.count }}</p>
 <p>{{ state.user.name }}</p>
</template>
```

### reactive 的局限性

```vue
<script setup>
import { reactive } from 'vue'

const state = reactive({
 count: 0
})

// 不能直接替换整个对象
// state = reactive({ count: 1 }) // 响应式丢失

// 不能解构
// const { count } = state // 响应式丢失

// 使用 toRefs 解构
import { toRefs } from 'vue'
const { count } = toRefs(state) // 保持响应式
</script>
```

## ref vs reactive 对比

| 特性 | ref | reactive |
|------|-----|----------|
| 适用类型 | 基本类型 + 对象 | 仅对象 |
| 访问方式 | `.value` | 直接访问 |
| 替换整个值 | 支持 | 会丢失响应式 |
| 解构 | 直接解包 | 需用 toRefs |
| 模板使用 | 自动解包 | 直接使用 |

### 选择建议

```vue
<script setup>
import { ref, reactive } from 'vue'

// 使用 ref：基本类型
const count = ref(0)
const message = ref('Hello')

// 使用 ref：需要替换整个对象
const user = ref({ name: '张三' })
user.value = { name: '李四' } // 保持响应式

// 使用 reactive：复杂对象，不需要替换
const form = reactive({
 username: '',
 password: '',
 remember: false
})
</script>
```

## 响应式工具函数

### toRef 和 toRefs

```vue
<script setup>
import { reactive, toRef, toRefs } from 'vue'

const state = reactive({
 count: 0,
 name: 'Vue'
})

// toRef：为单个属性创建 ref
const countRef = toRef(state, 'count')
countRef.value++ // 同时更新 state.count

// toRefs：为所有属性创建 ref
const { count, name } = toRefs(state)
count.value++ // 同时更新 state.count
</script>
```

### isRef 和 isReactive

```vue
<script setup>
import { ref, reactive, isRef, isReactive, isProxy } from 'vue'

const count = ref(0)
const state = reactive({ count: 0 })

console.log(isRef(count)) // true
console.log(isRef(state)) // false
console.log(isReactive(state)) // true
console.log(isReactive(count)) // false
console.log(isProxy(state)) // true
console.log(isProxy(count.value)) // false
</script>
```

### unref

```vue
<script setup>
import { ref, unref } from 'vue'

const count = ref(0)
const num = 1

// 如果参数是 ref，返回 .value；否则返回参数本身
console.log(unref(count)) // 0
console.log(unref(num)) // 1
</script>
```

## 响应式原理

### Proxy 代理

Vue 3 使用 Proxy 实现响应式：

```javascript
// 简化版响应式原理
function reactive(target) {
 return new Proxy(target, {
 get(target, key, receiver) {
 // 收集依赖
 track(target, key)
 return Reflect.get(target, key, receiver)
 },
 set(target, key, value, receiver) {
 const result = Reflect.set(target, key, value, receiver)
 // 触发更新
 trigger(target, key)
 return result
 }
 })
}
```

### ref 的实现原理

```javascript
// 简化版 ref 原理
function ref(value) {
 return {
 _isRef: true,
 _value: value,
 get value() {
 track(this, 'value')
 return this._value
 },
 set value(newValue) {
 this._value = newValue
 trigger(this, 'value')
 }
 }
}
```

## 实际应用示例

### 表单状态管理

```vue
<script setup>
import { reactive, toRefs } from 'vue'

// 使用 reactive 管理表单
const form = reactive({
 username: '',
 email: '',
 password: '',
 confirmPassword: ''
})

// 验证函数
function validate() {
 if (!form.username) {
 alert('请输入用户名')
 return false
 }
 if (form.password !== form.confirmPassword) {
 alert('两次密码不一致')
 return false
 }
 return true
}

// 提交函数
function onSubmit() {
 if (validate()) {
 console.log('提交数据:', { ...form })
 }
}

// 重置函数
function reset() {
 Object.assign(form, {
 username: '',
 email: '',
 password: '',
 confirmPassword: ''
 })
}
</script>

<template>
 <form @submit.prevent="onSubmit">
 <div>
 <label>用户名</label>
 <input v-model="form.username" />
 </div>
 <div>
 <label>邮箱</label>
 <input v-model="form.email" type="email" />
 </div>
 <div>
 <label>密码</label>
 <input v-model="form.password" type="password" />
 </div>
 <div>
 <label>确认密码</label>
 <input v-model="form.confirmPassword" type="password" />
 </div>
 <button type="submit">提交</button>
 <button type="button" @click="reset">重置</button>
 </form>
</template>
```

### 购物车示例

```vue
<script setup>
import { ref, computed } from 'vue'

// 使用 ref 管理购物车
const cart = ref([])

// 添加商品
function addToCart(product) {
 const existing = cart.value.find(item => item.id === product.id)
 if (existing) {
 existing.quantity++
 } else {
 cart.value.push({ ...product, quantity: 1 })
 }
}

// 移除商品
function removeFromCart(productId) {
 const index = cart.value.findIndex(item => item.id === productId)
 if (index > -1) {
 cart.value.splice(index, 1)
 }
}

// 计算总价
const total = computed(() => {
 return cart.value.reduce((sum, item) => {
 return sum + item.price * item.quantity
 }, 0)
})

// 商品列表
const products = [
 { id: 1, name: '苹果', price: 5 },
 { id: 2, name: '香蕉', price: 3 },
 { id: 3, name: '橙子', price: 4 }
]
</script>

<template>
 <div class="shopping-cart">
 <!-- 商品列表 -->
 <div class="products">
 <h2>商品列表</h2>
 <div v-for="product in products" :key="product.id" class="product">
 <span>{{ product.name }} - ¥{{ product.price }}</span>
 <button @click="addToCart(product)">加入购物车</button>
 </div>
 </div>

 <!-- 购物车 -->
 <div class="cart">
 <h2>购物车</h2>
 <div v-if="cart.length === 0">购物车为空</div>
 <div v-for="item in cart" :key="item.id" class="cart-item">
 <span>{{ item.name }} x {{ item.quantity }}</span>
 <span>¥{{ item.price * item.quantity }}</span>
 <button @click="removeFromCart(item.id)">删除</button>
 </div>
 <div v-if="cart.length > 0" class="total">
 总计: ¥{{ total }}
 </div>
 </div>
 </div>
</template>
```

## 总结

| API | 用途 | 特点 |
|-----|------|------|
| `ref` | 创建响应式数据 | 支持 `.value` 访问，可替换整个值 |
| `reactive` | 创建响应式对象 | 直接访问，不能替换整个对象 |
| `toRef` | 为属性创建 ref | 保持与原对象的连接 |
| `toRefs` | 解构响应式对象 | 保持响应式 |
| `isRef` | 判断是否为 ref | 类型检查 |
| `unref` | 获取 ref 的值 | 自动解包 |
