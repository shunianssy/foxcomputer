# 4.2 参数传递

参数传递是函数与调用者之间数据交换的方式。本节介绍值传递、引用传递和指针传递。

## 值传递

```cpp
#include <iostream>

// 值传递：复制参数值
void doubleValue(int x) {
 x = x * 2;
 std::cout << "函数内 x = " << x << std::endl;
}

int main() {
 int a = 5;
 std::cout << "调用前 a = " << a << std::endl;
 
 doubleValue(a);
 
 std::cout << "调用后 a = " << a << std::endl; // a 仍然是 5
 
 return 0;
}
```

## 引用传递

```cpp
#include <iostream>

// 引用传递：传递变量的引用
void doubleValue(int& x) {
 x = x * 2;
 std::cout << "函数内 x = " << x << std::endl;
}

// 交换两个变量
void swap(int& a, int& b) {
 int temp = a;
 a = b;
 b = temp;
}

int main() {
 int a = 5;
 std::cout << "调用前 a = " << a << std::endl;
 
 doubleValue(a);
 
 std::cout << "调用后 a = " << a << std::endl; // a 变为 10
 
 // 交换
 int x = 10, y = 20;
 std::cout << "交换前: x = " << x << ", y = " << y << std::endl;
 swap(x, y);
 std::cout << "交换后: x = " << x << ", y = " << y << std::endl;
 
 return 0;
}
```

## const 引用

```cpp
#include <iostream>
#include <string>

// const 引用：避免拷贝，同时防止修改
void printString(const std::string& str) {
 std::cout << str << std::endl;
 // str = "new value"; // 错误：不能修改 const 引用
}

// 计算字符串长度（不修改）
size_t getStringLength(const std::string& str) {
 return str.length();
}

int main() {
 std::string message = "Hello, C++!";
 
 printString(message);
 printString("临时字符串"); // const 引用可以绑定临时对象
 
 std::cout << "长度: " << getStringLength(message) << std::endl;
 
 return 0;
}
```

## 指针传递

```cpp
#include <iostream>

// 指针传递：传递变量的地址
void doubleValue(int* x) {
 *x = (*x) * 2;
}

// 交换两个变量
void swap(int* a, int* b) {
 int temp = *a;
 *a = *b;
 *b = temp;
}

// 可选参数（指针可以为空）
void process(int* data) {
 if (data == nullptr) {
 std::cout << "空指针" << std::endl;
 return;
 }
 std::cout << "数据: " << *data << std::endl;
}

int main() {
 int a = 5;
 doubleValue(&a);
 std::cout << "a = " << a << std::endl;
 
 int x = 10, y = 20;
 swap(&x, &y);
 std::cout << "x = " << x << ", y = " << y << std::endl;
 
 // 可选参数
 int value = 42;
 process(&value);
 process(nullptr);
 
 return 0;
}
```

## 数组参数

```cpp
#include <iostream>

// 数组参数（退化为指针）
void printArray(int arr[], int size) {
 for (int i = 0; i < size; ++i) {
 std::cout << arr[i] << " ";
 }
 std::cout << std::endl;
}

// 使用指针
void printArray2(int* arr, int size) {
 for (int i = 0; i < size; ++i) {
 std::cout << arr[i] << " ";
 }
 std::cout << std::endl;
}

// 使用模板保留数组大小
template<size_t N>
void printArray3(int (&arr)[N]) {
 for (int i = 0; i < N; ++i) {
 std::cout << arr[i] << " ";
 }
 std::cout << std::endl;
}

int main() {
 int arr[] = {1, 2, 3, 4, 5};
 int size = sizeof(arr) / sizeof(arr[0]);
 
 printArray(arr, size);
 printArray2(arr, size);
 printArray3(arr);
 
 return 0;
}
```

## 小结

参数传递要点：

1. **值传递**：复制参数，不影响原变量
2. **引用传递**：传递引用，可以修改原变量
3. **const 引用**：避免拷贝，防止修改
4. **指针传递**：传递地址，可以为空

> **提示**：优先使用 const 引用传递大对象，使用引用传递需要修改的参数。
