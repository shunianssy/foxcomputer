# 3.1 条件语句

条件语句用于根据条件执行不同的代码块。本节介绍 C++ 中的 if-else 分支结构。

## if 语句

```cpp
#include <iostream>

int main() {
 int score = 85;
 
 // 基本 if 语句
 if (score >= 60) {
 std::cout << "及格了！" << std::endl;
 }
 
 // if-else 语句
 if (score >= 90) {
 std::cout << "优秀！" << std::endl;
 } else {
 std::cout << "继续努力！" << std::endl;
 }
 
 // if-else if-else 语句
 if (score >= 90) {
 std::cout << "等级: A" << std::endl;
 } else if (score >= 80) {
 std::cout << "等级: B" << std::endl;
 } else if (score >= 70) {
 std::cout << "等级: C" << std::endl;
 } else if (score >= 60) {
 std::cout << "等级: D" << std::endl;
 } else {
 std::cout << "等级: F" << std::endl;
 }
 
 return 0;
}
```

## 嵌套 if 语句

```cpp
#include <iostream>

int main() {
 int age = 25;
 bool hasLicense = true;
 
 // 嵌套 if 语句
 if (age >= 18) {
 std::cout << "年龄符合要求" << std::endl;
 
 if (hasLicense) {
 std::cout << "可以驾驶" << std::endl;
 } else {
 std::cout << "需要先考取驾照" << std::endl;
 }
 } else {
 std::cout << "年龄不符合要求" << std::endl;
 }
 
 return 0;
}
```

## 逻辑运算符组合条件

```cpp
#include <iostream>

int main() {
 int age = 25;
 int income = 5000;
 
 // 使用 && (与)
 if (age >= 18 && income >= 3000) {
 std::cout << "符合贷款条件" << std::endl;
 }
 
 // 使用 || (或)
 if (age < 18 || age > 65) {
 std::cout << "不在工作年龄范围" << std::endl;
 }
 
 // 使用 ! (非)
 bool isStudent = false;
 if (!isStudent) {
 std::cout << "不是学生" << std::endl;
 }
 
 // 组合使用
 if ((age >= 18 && age <= 60) && (income >= 3000 || income == 0)) {
 std::cout << "复杂条件满足" << std::endl;
 }
 
 return 0;
}
```

## 三元运算符

```cpp
#include <iostream>

int main() {
 int a = 10, b = 20;
 
 // 三元运算符
 int max = (a > b) ? a : b;
 std::cout << "最大值: " << max << std::endl;
 
 // 在输出中使用
 int score = 75;
 std::cout << "考试" << (score >= 60 ? "通过" : "未通过") << std::endl;
 
 return 0;
}
```

## 实用示例

```cpp
#include <iostream>

int main() {
 // 判断闰年
 int year = 2024;
 
 if ((year % 4 == 0 && year % 100 != 0) || (year % 400 == 0)) {
 std::cout << year << " 是闰年" << std::endl;
 } else {
 std::cout << year << " 不是闰年" << std::endl;
 }
 
 // 判断季节
 int month = 7;
 
 if (month >= 3 && month <= 5) {
 std::cout << "春季" << std::endl;
 } else if (month >= 6 && month <= 8) {
 std::cout << "夏季" << std::endl;
 } else if (month >= 9 && month <= 11) {
 std::cout << "秋季" << std::endl;
 } else {
 std::cout << "冬季" << std::endl;
 }
 
 return 0;
}
```

## 小结

条件语句要点：

1. **if**：单条件判断
2. **if-else**：二选一
3. **if-else if-else**：多选一
4. **嵌套 if**：多层条件判断
5. **三元运算符**：简化简单的 if-else

> **提示**：条件语句中，即使只有一行代码，也建议使用大括号，避免潜在的错误。
