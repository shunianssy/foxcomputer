# 2.1 变量与常量

变量和常量是程序中最基本的存储单元。本节介绍 C++ 中变量和常量的定义与使用。

## 变量

### 变量定义

```cpp
#include <iostream>

int main() {
 // 基本变量定义
 int age; // 定义一个整型变量
 double price; // 定义一个双精度浮点变量
 char grade; // 定义一个字符变量
 
 // 定义时初始化
 int count = 0;
 double pi = 3.14159;
 char letter = 'A';
 
 // C++11 列表初始化（推荐）
 int value{42};
 double rate{0.05};
 char symbol{'$'};
 
 // 定义多个同类型变量
 int x = 1, y = 2, z = 3;
 
 return 0;
}
```

### 变量初始化方式

```cpp
#include <iostream>
#include <string>

int main() {
 // 方式一：拷贝初始化
 int a = 10;
 double b = 3.14;
 std::string s1 = "Hello";
 
 // 方式二：直接初始化
 int c(20);
 double d(2.71);
 std::string s2("World");
 
 // 方式三：列表初始化（C++11，推荐）
 int e{30};
 double f{1.41};
 std::string s3{"C++"};
 
 // 方式四：值初始化
 int g{}; // 初始化为 0
 double h{}; // 初始化为 0.0
 std::string s4{}; // 初始化为空字符串
 
 return 0;
}
```

## 常量

### const 关键字

```cpp
#include <iostream>

int main() {
 // const 常量：必须在定义时初始化
 const int MAX_SIZE = 100;
 const double PI = 3.14159;
 const char NEWLINE = '\n';
 
 // const 常量不能修改
 // MAX_SIZE = 200; // 编译错误
 
 std::cout << "PI = " << PI << NEWLINE;
 
 return 0;
}
```

### constexpr 关键字（C++11）

```cpp
#include <iostream>

// constexpr 函数：编译时计算
constexpr int square(int x) {
 return x * x;
}

int main() {
 // 编译时计算
 constexpr int result = square(5); // 编译时计算为 25
 
 // 用于数组大小（需要编译时常量）
 int arr[square(3)]; // 大小为 9 的数组
 
 std::cout << "square(5) = " << result << std::endl;
 
 return 0;
}
```

### 枚举常量

```cpp
#include <iostream>

// 传统枚举
enum Color {
 RED, // 默认 0
 GREEN, // 默认 1
 BLUE // 默认 2
};

// 强类型枚举（C++11，推荐）
enum class Status {
 OK,
 ERROR,
 PENDING
};

int main() {
 Color c = RED;
 std::cout << "RED = " << RED << std::endl;
 
 Status s = Status::OK;
 std::cout << "Status::OK = " << static_cast<int>(s) << std::endl;
 
 return 0;
}
```

## auto 关键字（C++11）

```cpp
#include <iostream>
#include <vector>
#include <string>

int main() {
 // 自动类型推导
 auto a = 10; // int
 auto b = 3.14; // double
 auto c = 'A'; // char
 auto d = std::string("Hello"); // std::string
 
 // 简化复杂类型
 std::vector<int> nums = {1, 2, 3};
 for (const auto& n : nums) {
 std::cout << n << " ";
 }
 std::cout << std::endl;
 
 return 0;
}
```

## 小结

变量与常量要点：

1. **变量定义**：使用类型名 + 变量名，推荐列表初始化
2. **const 常量**：运行时常量，不可修改
3. **constexpr 常量**：编译时常量，性能更好
4. **枚举**：定义一组相关常量，推荐使用 enum class
5. **auto**：自动类型推导，简化代码

> **提示**：优先使用 constexpr 定义编译时常量，使用 const 定义运行时常量。
