# 3.4 跳转语句

跳转语句用于改变程序的执行流程。本节介绍 break、continue 和 goto 语句。

## break 语句

```cpp
#include <iostream>

int main() {
    // 在循环中使用 break
    for (int i = 0; i < 10; ++i) {
        if (i == 5) {
            std::cout << "遇到 5，退出循环" << std::endl;
            break;
        }
        std::cout << "i = " << i << std::endl;
    }
    
    // 在 switch 中使用 break
    int choice = 2;
    switch (choice) {
        case 1:
            std::cout << "选项 1" << std::endl;
            break;
        case 2:
            std::cout << "选项 2" << std::endl;
            break;
        default:
            std::cout << "其他" << std::endl;
    }
    
    // 查找元素
    int arr[] = {3, 7, 2, 9, 5};
    int target = 9;
    bool found = false;
    
    for (int i = 0; i < 5; ++i) {
        if (arr[i] == target) {
            std::cout << "找到 " << target << " 在位置 " << i << std::endl;
            found = true;
            break;
        }
    }
    
    if (!found) {
        std::cout << "未找到 " << target << std::endl;
    }
    
    return 0;
}
```

## continue 语句

```cpp
#include <iostream>

int main() {
    // 跳过偶数
    for (int i = 1; i <= 10; ++i) {
        if (i % 2 == 0) {
            continue;  // 跳过偶数
        }
        std::cout << i << " ";
    }
    std::cout << std::endl;
    
    // 过滤特定值
    int scores[] = {85, -1, 90, 72, -1, 88};
    int sum = 0;
    int count = 0;
    
    for (int score : scores) {
        if (score < 0) {
            continue;  // 跳过无效分数
        }
        sum += score;
        ++count;
    }
    
    std::cout << "有效分数平均: " << (double)sum / count << std::endl;
    
    return 0;
}
```

## goto 语句

```cpp
#include <iostream>

int main() {
    // goto 语句（不推荐使用）
    int i = 0;
    
start:
    std::cout << "i = " << i << std::endl;
    ++i;
    
    if (i < 5) {
        goto start;
    }
    
    std::cout << "循环结束" << std::endl;
    
    // goto 的合理使用：跳出嵌套循环
    int matrix[3][3] = {
        {1, 2, 3},
        {4, 5, 6},
        {7, 8, 9}
    };
    int target = 5;
    bool found = false;
    int row = -1, col = -1;
    
    for (int i = 0; i < 3; ++i) {
        for (int j = 0; j < 3; ++j) {
            if (matrix[i][j] == target) {
                found = true;
                row = i;
                col = j;
                goto found_target;  // 跳出嵌套循环
            }
        }
    }
    
found_target:
    if (found) {
        std::cout << "找到 " << target << " 在 [" << row << "][" << col << "]" << std::endl;
    } else {
        std::cout << "未找到 " << target << std::endl;
    }
    
    return 0;
}
```

## return 语句

```cpp
#include <iostream>

// 提前返回
bool isPrime(int n) {
    if (n <= 1) {
        return false;
    }
    if (n == 2) {
        return true;
    }
    if (n % 2 == 0) {
        return false;
    }
    
    for (int i = 3; i * i <= n; i += 2) {
        if (n % i == 0) {
            return false;
        }
    }
    
    return true;
}

int main() {
    // 测试素数
    for (int i = 1; i <= 20; ++i) {
        if (isPrime(i)) {
            std::cout << i << " 是素数" << std::endl;
        }
    }
    
    return 0;
}
```

## 对比总结

```cpp
#include <iostream>

int main() {
    // break: 完全退出循环
    std::cout << "break 示例:" << std::endl;
    for (int i = 0; i < 5; ++i) {
        if (i == 3) break;
        std::cout << i << " ";
    }
    std::cout << std::endl;
    
    // continue: 跳过本次迭代
    std::cout << "continue 示例:" << std::endl;
    for (int i = 0; i < 5; ++i) {
        if (i == 3) continue;
        std::cout << i << " ";
    }
    std::cout << std::endl;
    
    return 0;
}
```

## 小结

跳转语句要点：

1. **break**：退出循环或 switch
2. **continue**：跳过本次迭代，继续下次
3. **goto**：跳转到标签（不推荐使用）
4. **return**：从函数返回

> 💡 **提示**：优先使用 break 和 continue，避免使用 goto。goto 会破坏程序结构，增加代码复杂度。
