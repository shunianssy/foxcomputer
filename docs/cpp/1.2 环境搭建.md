# 1.2 环境搭建

本节将介绍如何在 Windows、macOS 和 Linux 系统上搭建 C++ 开发环境。

## 编译器选择

### 主流 C++ 编译器

| 编译器 | 平台 | 特点 |
|--------|------|------|
| GCC (GNU Compiler Collection) | Linux/macOS/Windows | 开源免费，标准支持好 |
| Clang | macOS/Linux/Windows | 编译速度快，错误提示友好 |
| MSVC (Microsoft Visual C++) | Windows | 微软官方，Windows 集成好 |
| MinGW | Windows | GCC 的 Windows 移植版 |

## Windows 环境配置

### 方式一：安装 Visual Studio（推荐初学者）

1. **下载 Visual Studio**
 - 访问 [Visual Studio 官网](https://visualstudio.microsoft.com/)
 - 下载 Community 版本（免费）

2. **安装时选择组件**
 - 勾选"使用 C++ 的桌面开发"
 - 点击"安装"等待完成

3. **创建第一个项目**
 - 打开 Visual Studio
 - 选择"创建新项目"
 - 选择"控制台应用"
 - 编写并运行代码

### 方式二：安装 MinGW-w64（轻量级）

```powershell
# 使用 winget 安装（Windows 10/11）
winget install -e --id GnuWin32.Make

# 或使用 scoop 安装
scoop install mingw

# 或使用 chocolatey 安装
choco install mingw -y
```

### 验证安装

```powershell
# 打开命令提示符或 PowerShell，输入：
g++ --version

# 输出示例：
# g++ (MinGW-W64) 13.1.0
# Copyright (C) 2023 Free Software Foundation, Inc.
```

## macOS 环境配置

### 安装 Xcode Command Line Tools

```bash
# 打开终端，执行以下命令：
xcode-select --install

# 会弹出安装对话框，点击"安装"
```

### 安装 Homebrew 包管理器（可选但推荐）

```bash
# 安装 Homebrew
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 使用 Homebrew 安装 GCC
brew install gcc

# 验证安装
g++ --version
```

## Linux 环境配置

### Ubuntu/Debian

```bash
# 更新包列表
sudo apt update

# 安装编译工具链
sudo apt install build-essential gdb

# 验证安装
g++ --version
```

### CentOS/RHEL/Fedora

```bash
# Fedora
sudo dnf install gcc-c++ make

# CentOS/RHEL
sudo yum groupinstall "Development Tools"

# 验证安装
g++ --version
```

## 开发工具推荐

### IDE（集成开发环境）

| IDE | 平台 | 特点 |
|-----|------|------|
| Visual Studio | Windows | 功能强大，调试方便 |
| CLion | 跨平台 | JetBrains 出品，智能提示 |
| VS Code | 跨平台 | 轻量级，插件丰富 |
| Code::Blocks | 跨平台 | 开源免费，适合初学者 |

### VS Code 配置（推荐）

1. **安装 VS Code**
 - 访问 [VS Code 官网](https://code.visualstudio.com/) 下载安装

2. **安装必要扩展**
 - C/C++（Microsoft 官方）
 - C/C++ Extension Pack
 - Code Runner（一键运行）

3. **配置编译任务**

创建 `.vscode/tasks.json`：

```json
{
 "version": "2.0.0",
 "tasks": [
 {
 "type": "cppbuild",
 "label": "C/C++: g++ 编译活动文件",
 "command": "/usr/bin/g++",
 "args": [
 "-fdiagnostics-color=always",
 "-g",
 "${file}",
 "-o",
 "${fileDirname}/${fileBasenameNoExtension}"
 ],
 "options": {
 "cwd": "${fileDirname}"
 },
 "problemMatcher": ["$gcc"],
 "group": {
 "kind": "build",
 "isDefault": true
 },
 "detail": "编译器: /usr/bin/g++"
 }
 ]
}
```

4. **配置调试**

创建 `.vscode/launch.json`：

```json
{
 "version": "0.2.0",
 "configurations": [
 {
 "name": "g++ 调试",
 "type": "cppdbg",
 "request": "launch",
 "program": "${fileDirname}/${fileBasenameNoExtension}",
 "args": [],
 "stopAtEntry": false,
 "cwd": "${fileDirname}",
 "environment": [],
 "externalConsole": false,
 "MIMode": "gdb",
 "setupCommands": [
 {
 "description": "为 gdb 启用整齐打印",
 "text": "-enable-pretty-printing",
 "ignoreFailures": true
 }
 ],
 "preLaunchTask": "C/C++: g++ 编译活动文件",
 "miDebuggerPath": "/usr/bin/gdb"
 }
 ]
}
```

## 编译与运行

### 命令行编译

```bash
# 编译单个文件
g++ main.cpp -o main

# 运行程序
./main # Linux/macOS
main.exe # Windows

# 启用 C++17 标准
g++ -std=c++17 main.cpp -o main

# 启用调试信息
g++ -g main.cpp -o main

# 开启警告
g++ -Wall -Wextra main.cpp -o main
```

### 常用编译选项

| 选项 | 说明 |
|------|------|
| `-o <name>` | 指定输出文件名 |
| `-std=c++17` | 使用 C++17 标准 |
| `-g` | 生成调试信息 |
| `-Wall` | 开启所有警告 |
| `-O2` | 优化级别 2 |
| `-I<path>` | 添加头文件搜索路径 |
| `-L<path>` | 添加库文件搜索路径 |
| `-l<lib>` | 链接库文件 |

### Makefile 示例

```makefile
# Makefile 示例
CXX = g++
CXXFLAGS = -std=c++17 -Wall -Wextra -g

# 目标文件
TARGET = myprogram

# 源文件
SRCS = main.cpp utils.cpp

# 目标文件
OBJS = $(SRCS:.cpp=.o)

# 默认目标
all: $(TARGET)

# 链接
$(TARGET): $(OBJS)
	$(CXX) $(CXXFLAGS) -o $@ $^

# 编译
%.o: %.cpp
	$(CXX) $(CXXFLAGS) -c $< -o $@

# 清理
clean:
	rm -f $(OBJS) $(TARGET)

# 伪目标
.PHONY: all clean
```

## 验证环境

创建测试文件 `test_env.cpp`：

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>

int main() {
 // 测试基本输出
 std::cout << "C++ 环境配置成功！" << std::endl;
 
 // 测试 C++ 版本
 std::cout << "C++ 标准: " << __cplusplus << std::endl;
 
 // 测试 STL
 std::vector<int> nums = {3, 1, 4, 1, 5, 9};
 std::sort(nums.begin(), nums.end());
 
 std::cout << "排序结果: ";
 for (int n : nums) {
 std::cout << n << " ";
 }
 std::cout << std::endl;
 
 // 测试字符串
 std::string msg = "Hello, C++!";
 std::cout << msg << std::endl;
 
 return 0;
}
```

编译并运行：

```bash
g++ -std=c++17 test_env.cpp -o test_env
./test_env
```

预期输出：

```
C++ 环境配置成功！
C++ 标准: 201703
排序结果: 1 1 3 4 5 9 
Hello, C++!
```

## 常见问题

### 1. 找不到编译器

```bash
# 检查编译器是否在 PATH 中
where g++ # Windows
which g++ # Linux/macOS

# 如果找不到，需要添加到环境变量
```

### 2. 中文乱码

```cpp
// Windows 下设置控制台编码
#include <windows.h>
SetConsoleOutputCP(65001); // UTF-8

// 或使用
system("chcp 65001");
```

### 3. 头文件找不到

```bash
# 使用 -I 指定头文件路径
g++ -I./include main.cpp -o main
```

## 小结

环境搭建要点：

1. **选择编译器**：Windows 推荐 MSVC 或 MinGW，macOS 用 Clang，Linux 用 GCC
2. **选择 IDE**：初学者推荐 VS Code + 插件，或 Visual Studio
3. **配置调试**：配置好 tasks.json 和 launch.json
4. **验证安装**：运行测试代码确认环境正确

> **提示**：环境配置是学习编程的第一步，遇到问题时多搜索、多尝试。一个好的开发环境能大大提高学习效率。
