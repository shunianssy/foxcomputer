# 2.2 基本数据类型

C++ 提供了丰富的数据类型，本节详细介绍各种基本数据类型及其使用方法。

## 整型

```cpp
#include <iostream>
#include <climits> // 整型范围

int main() {
 // 基本整型
 short s = 100; // 短整型，至少 16 位
 int i = 100000; // 整型，至少 16 位（通常 32 位）
 long l = 1000000L; // 长整型，至少 32 位
 long long ll = 1000000000000LL; // 长长整型，至少 64 位
 
 // 无符号整型
 unsigned int ui = 100000U;
 unsigned long ul = 1000000UL;
 
 // 输出类型大小
 std::cout << "int 大小: " << sizeof(int) << " 字节" << std::endl;
 std::cout << "int 范围: " << INT_MIN << " 到 " << INT_MAX << std::endl;
 
 return 0;
}
```

## 浮点型

```cpp
#include <iostream>
#include <cfloat> // 浮点型范围
#include <iomanip> // 格式化输出

int main() {
 // 浮点类型
 float f = 3.14f; // 单精度，至少 6 位有效数字
 double d = 3.14159265; // 双精度，至少 10 位有效数字
 long double ld = 3.14159265358979L; // 扩展精度
 
 // 输出类型大小
 std::cout << "float 大小: " << sizeof(float) << " 字节" << std::endl;
 std::cout << "double 大小: " << sizeof(double) << " 字节" << std::endl;
 
 // 精度演示
 std::cout << std::setprecision(15);
 std::cout << "float: " << 3.14159265358979f << std::endl;
 std::cout << "double: " << 3.14159265358979 << std::endl;
 
 return 0;
}
```

## 字符型

```cpp
#include <iostream>

int main() {
 // 字符类型
 char c1 = 'A'; // 普通 char
 unsigned char c3 = 255; // 无符号 char
 
 // 字符字面量
 char letter = 'A';
 char digit = '7';
 char symbol = '$';
 
 // 字符与整数转换
 char c = 'A';
 int ascii = c; // ASCII 码值：65
 std::cout << "字符: " << c << ", ASCII: " << ascii << std::endl;
 
 // 大小写转换
 char upper = 'A';
 char lower = upper + 32; // 或使用 tolower()
 std::cout << "大写: " << upper << ", 小写: " << lower << std::endl;
 
 return 0;
}
```

## 布尔型

```cpp
#include <iostream>
#include <iomanip>

int main() {
 // 布尔类型
 bool isTrue = true;
 bool isFalse = false;
 
 // 输出布尔值
 std::cout << "true: " << isTrue << std::endl; // 输出 1
 
 // 使用 boolalpha 输出 true/false
 std::cout << std::boolalpha;
 std::cout << "true: " << isTrue << std::endl; // 输出 true
 
 // 布尔运算
 bool a = true;
 bool b = false;
 std::cout << "a && b: " << (a && b) << std::endl; // false
 std::cout << "a || b: " << (a || b) << std::endl; // true
 
 return 0;
}
```

## 类型大小

```cpp
#include <iostream>
#include <climits>
#include <cfloat>

int main() {
 std::cout << "=== 数据类型大小 ===" << std::endl;
 std::cout << "bool: " << sizeof(bool) << " 字节" << std::endl;
 std::cout << "char: " << sizeof(char) << " 字节" << std::endl;
 std::cout << "short: " << sizeof(short) << " 字节" << std::endl;
 std::cout << "int: " << sizeof(int) << " 字节" << std::endl;
 std::cout << "long: " << sizeof(long) << " 字节" << std::endl;
 std::cout << "long long: " << sizeof(long long) << " 字节" << std::endl;
 std::cout << "float: " << sizeof(float) << " 字节" << std::endl;
 std::cout << "double: " << sizeof(double) << " 字节" << std::endl;
 
 return 0;
}
```

## 小结

基本数据类型要点：

1. **整型**：short、int、long、long long，有符号和无符号版本
2. **浮点型**：float、double、long double，注意精度问题
3. **字符型**：char、wchar_t、char16_t、char32_t
4. **布尔型**：bool，只有 true 和 false
5. **类型大小**：使用 sizeof 获取

> **提示**：选择数据类型时，优先使用 int 和 double。需要精确大整数时使用 long long。
