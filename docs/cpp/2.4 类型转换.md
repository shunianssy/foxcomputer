# 2.4 类型转换

类型转换是将一种数据类型的值转换为另一种数据类型的过程。本节介绍 C++ 中的各种类型转换方式。

## 隐式类型转换

```cpp
#include <iostream>

int main() {
 // 整数提升
 short s = 100;
 int i = s; // short → int
 
 // 算术转换
 int a = 5;
 double b = 2.5;
 auto result = a + b; // int → double，结果是 double
 std::cout << "int + double = " << result << std::endl;
 
 // 赋值转换
 double d = 3.14;
 int n = d; // double → int，丢失小数部分
 std::cout << "double → int: " << n << std::endl; // 3
 
 // 布尔转换
 int zero = 0;
 bool b1 = zero; // false
 bool b2 = 42; // true
 std::cout << std::boolalpha;
 std::cout << "0 → bool: " << b1 << std::endl;
 std::cout << "42 → bool: " << b2 << std::endl;
 
 return 0;
}
```

## C 风格类型转换

```cpp
#include <iostream>

int main() {
 double d = 3.14159;
 
 // C 风格类型转换（不推荐）
 int i1 = (int)d; // C 风格转换
 int i2 = int(d); // 函数风格转换
 
 std::cout << "原值: " << d << std::endl;
 std::cout << "转换后: " << i1 << std::endl;
 
 return 0;
}
```

## C++ 风格类型转换

### static_cast

```cpp
#include <iostream>

int main() {
 // static_cast：最常用的类型转换
 double d = 3.14159;
 int i = static_cast<int>(d);
 std::cout << "double → int: " << i << std::endl;
 
 // 整型之间的转换
 long l = 1000000L;
 short s = static_cast<short>(l);
 std::cout << "long → short: " << s << std::endl;
 
 return 0;
}
```

### dynamic_cast

```cpp
#include <iostream>
#include <stdexcept>

class Animal {
public:
 virtual void speak() const { std::cout << "动物" << std::endl; }
 virtual ~Animal() = default;
};

class Dog : public Animal {
public:
 void speak() const override { std::cout << "汪汪！" << std::endl; }
 void fetch() const { std::cout << "捡球" << std::endl; }
};

int main() {
 Animal* animal = new Dog();
 
 // 安全的向下转型
 Dog* dog = dynamic_cast<Dog*>(animal);
 if (dog) {
 dog->fetch();
 }
 
 delete animal;
 return 0;
}
```

### const_cast

```cpp
#include <iostream>

int main() {
 // const_cast：移除或添加 const 属性
 const int ci = 10;
 int* pi = const_cast<int*>(&ci);
 *pi = 20; // 危险操作
 
 std::cout << "ci = " << ci << std::endl;
 
 return 0;
}
```

### reinterpret_cast

```cpp
#include <iostream>
#include <cstdint>

int main() {
 // reinterpret_cast：底层重新解释（最危险）
 int value = 42;
 uintptr_t addr = reinterpret_cast<uintptr_t>(&value);
 std::cout << "地址值: " << addr << std::endl;
 
 int* ptr = reinterpret_cast<int*>(addr);
 std::cout << "从地址恢复的值: " << *ptr << std::endl;
 
 return 0;
}
```

## 类型转换总结

| 转换类型 | 用途 | 安全性 |
|----------|------|--------|
| `static_cast` | 相关类型转换 | 较安全 |
| `dynamic_cast` | 多态类型转换 | 安全（运行时检查） |
| `const_cast` | 移除/添加 const | 需谨慎 |
| `reinterpret_cast` | 底层重新解释 | 危险 |

## 小结

类型转换要点：

1. **隐式转换**：编译器自动进行，注意精度丢失
2. **显式转换**：推荐使用 C++ 风格（`static_cast` 等）
3. **static_cast**：最常用的类型转换
4. **dynamic_cast**：多态类型的安全转换
5. **const_cast**：移除 const 属性，需谨慎使用

> **提示**：优先使用 `static_cast`，避免使用 C 风格的类型转换。尽量减少类型转换，保持类型安全。
