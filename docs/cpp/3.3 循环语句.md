# 3.3 循环语句

循环语句用于重复执行代码块。本节介绍 for、while 和 do-while 循环。

## for 循环

```cpp
#include <iostream>

int main() {
    // 基本 for 循环
    for (int i = 0; i < 5; ++i) {
        std::cout << "i = " << i << std::endl;
    }
    
    // 输出: 0, 1, 2, 3, 4
    
    // 计算 1 到 100 的和
    int sum = 0;
    for (int i = 1; i <= 100; ++i) {
        sum += i;
    }
    std::cout << "1+2+...+100 = " << sum << std::endl;
    
    // 倒序循环
    for (int i = 5; i > 0; --i) {
        std::cout << i << " ";
    }
    std::cout << "发射！" << std::endl;
    
    return 0;
}
```

### 范围 for 循环（C++11）

```cpp
#include <iostream>
#include <vector>
#include <string>

int main() {
    // 遍历数组
    int arr[] = {1, 2, 3, 4, 5};
    for (int x : arr) {
        std::cout << x << " ";
    }
    std::cout << std::endl;
    
    // 遍历 vector
    std::vector<std::string> names = {"Alice", "Bob", "Charlie"};
    for (const auto& name : names) {
        std::cout << name << " ";
    }
    std::cout << std::endl;
    
    // 修改元素
    std::vector<int> nums = {1, 2, 3};
    for (int& n : nums) {
        n *= 2;  // 每个元素乘以 2
    }
    for (int n : nums) {
        std::cout << n << " ";
    }
    std::cout << std::endl;
    
    return 0;
}
```

## while 循环

```cpp
#include <iostream>

int main() {
    // 基本 while 循环
    int i = 0;
    while (i < 5) {
        std::cout << "i = " << i << std::endl;
        ++i;
    }
    
    // 计算 1 到 100 的和
    int sum = 0;
    int n = 1;
    while (n <= 100) {
        sum += n;
        ++n;
    }
    std::cout << "和: " << sum << std::endl;
    
    // 猜数字游戏
    int target = 42;
    int guess = 0;
    
    while (guess != target) {
        std::cout << "请输入猜测的数字: ";
        std::cin >> guess;
        
        if (guess < target) {
            std::cout << "太小了！" << std::endl;
        } else if (guess > target) {
            std::cout << "太大了！" << std::endl;
        }
    }
    std::cout << "恭喜，猜对了！" << std::endl;
    
    return 0;
}
```

## do-while 循环

```cpp
#include <iostream>

int main() {
    // do-while 至少执行一次
    int i = 0;
    do {
        std::cout << "i = " << i << std::endl;
        ++i;
    } while (i < 5);
    
    // 菜单选择
    int choice;
    do {
        std::cout << "\n=== 菜单 ===" << std::endl;
        std::cout << "1. 新游戏" << std::endl;
        std::cout << "2. 继续游戏" << std::endl;
        std::cout << "3. 设置" << std::endl;
        std::cout << "0. 退出" << std::endl;
        std::cout << "请选择: ";
        std::cin >> choice;
        
        switch (choice) {
            case 1:
                std::cout << "开始新游戏..." << std::endl;
                break;
            case 2:
                std::cout << "继续游戏..." << std::endl;
                break;
            case 3:
                std::cout << "打开设置..." << std::endl;
                break;
            case 0:
                std::cout << "再见！" << std::endl;
                break;
            default:
                std::cout << "无效选择！" << std::endl;
        }
    } while (choice != 0);
    
    return 0;
}
```

## 嵌套循环

```cpp
#include <iostream>
#include <iomanip>

int main() {
    // 打印乘法表
    for (int i = 1; i <= 9; ++i) {
        for (int j = 1; j <= i; ++j) {
            std::cout << j << "×" << i << "=" << std::setw(2) << i * j << " ";
        }
        std::cout << std::endl;
    }
    
    // 打印图形
    int rows = 5;
    for (int i = 1; i <= rows; ++i) {
        for (int j = 1; j <= i; ++j) {
            std::cout << "* ";
        }
        std::cout << std::endl;
    }
    
    return 0;
}
```

## 小结

循环语句要点：

1. **for**：已知循环次数时使用
2. **范围 for**：遍历容器时使用
3. **while**：条件循环，可能一次都不执行
4. **do-while**：至少执行一次的循环
5. **嵌套循环**：多层循环结构

> 💡 **提示**：选择合适的循环类型。for 适合已知次数，while 适合条件循环，do-while 适合至少执行一次的情况。
