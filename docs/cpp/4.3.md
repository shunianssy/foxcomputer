# 4.3 函数重载与默认参数

函数重载允许同名函数有不同的参数列表，默认参数简化函数调用。

## 函数重载

```cpp
#include <iostream>
#include <string>

// 重载：同名函数，不同参数
int add(int a, int b) {
    return a + b;
}

double add(double a, double b) {
    return a + b;
}

int add(int a, int b, int c) {
    return a + b + c;
}

std::string add(const std::string& a, const std::string& b) {
    return a + b;
}

int main() {
    std::cout << "int + int: " << add(1, 2) << std::endl;
    std::cout << "double + double: " << add(1.5, 2.5) << std::endl;
    std::cout << "三个 int: " << add(1, 2, 3) << std::endl;
    std::cout << "string + string: " << add("Hello, ", "World!") << std::endl;
    
    return 0;
}
```

## 重载解析规则

```cpp
#include <iostream>

void print(int x) {
    std::cout << "int: " << x << std::endl;
}

void print(double x) {
    std::cout << "double: " << x << std::endl;
}

void print(const char* x) {
    std::cout << "string: " << x << std::endl;
}

int main() {
    print(42);           // 调用 print(int)
    print(3.14);         // 调用 print(double)
    print("Hello");      // 调用 print(const char*)
    
    // print(42L);       // 歧义：long 可以转为 int 或 double
    
    return 0;
}
```

## 默认参数

```cpp
#include <iostream>
#include <string>

// 默认参数：从右向左
void printInfo(const std::string& name, int age = 18, const std::string& city = "北京") {
    std::cout << "姓名: " << name << std::endl;
    std::cout << "年龄: " << age << std::endl;
    std::cout << "城市: " << city << std::endl;
    std::cout << "---" << std::endl;
}

// 计算幂
double power(double base, int exp = 2) {
    double result = 1;
    for (int i = 0; i < exp; ++i) {
        result *= base;
    }
    return result;
}

int main() {
    // 使用默认参数
    printInfo("张三");
    
    // 部分使用默认参数
    printInfo("李四", 25);
    
    // 不使用默认参数
    printInfo("王五", 30, "上海");
    
    // 幂运算
    std::cout << "2^2 = " << power(2) << std::endl;
    std::cout << "2^3 = " << power(2, 3) << std::endl;
    
    return 0;
}
```

## 默认参数与重载冲突

```cpp
#include <iostream>

// 注意：默认参数可能导致歧义
void func(int x) {
    std::cout << "func(int)" << std::endl;
}

// void func(int x, int y = 0) {
//     std::cout << "func(int, int)" << std::endl;
// }
// 如果同时定义这两个函数，func(5) 会有歧义

int main() {
    func(5);
    
    return 0;
}
```

## 小结

函数重载与默认参数要点：

1. **函数重载**：同名函数，不同参数列表
2. **重载解析**：编译器选择最佳匹配
3. **默认参数**：从右向左提供默认值
4. **避免歧义**：注意重载与默认参数的冲突

> 💡 **提示**：合理使用函数重载可以提高代码可读性，但避免过度重载导致歧义。
