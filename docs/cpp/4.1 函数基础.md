# 4.1 函数基础

函数是组织好的、可重复使用的代码块。本节介绍 C++ 函数的定义与调用。

## 函数定义

```cpp
#include <iostream>

// 无返回值函数
void sayHello() {
    std::cout << "Hello, World!" << std::endl;
}

// 有返回值函数
int add(int a, int b) {
    return a + b;
}

// 返回布尔值
bool isEven(int n) {
    return n % 2 == 0;
}

int main() {
    // 调用函数
    sayHello();
    
    int result = add(3, 5);
    std::cout << "3 + 5 = " << result << std::endl;
    
    int num = 4;
    if (isEven(num)) {
        std::cout << num << " 是偶数" << std::endl;
    }
    
    return 0;
}
```

## 函数声明与定义

```cpp
#include <iostream>

// 函数声明（原型）
int multiply(int a, int b);
void printResult(int value);

int main() {
    int result = multiply(4, 5);
    printResult(result);
    
    return 0;
}

// 函数定义
int multiply(int a, int b) {
    return a * b;
}

void printResult(int value) {
    std::cout << "结果是: " << value << std::endl;
}
```

## 返回值

```cpp
#include <iostream>
#include <string>

// 返回基本类型
int getMax(int a, int b) {
    return (a > b) ? a : b;
}

// 返回字符串
std::string getGrade(int score) {
    if (score >= 90) return "A";
    if (score >= 80) return "B";
    if (score >= 70) return "C";
    if (score >= 60) return "D";
    return "F";
}

// 提前返回
bool isPositive(int n) {
    if (n > 0) {
        return true;
    }
    return false;
}

int main() {
    std::cout << "最大值: " << getMax(10, 20) << std::endl;
    std::cout << "等级: " << getGrade(85) << std::endl;
    std::cout << "是否正数: " << std::boolalpha << isPositive(5) << std::endl;
    
    return 0;
}
```

## 多文件组织

```cpp
// math_utils.h
#ifndef MATH_UTILS_H
#define MATH_UTILS_H

int add(int a, int b);
int subtract(int a, int b);
int multiply(int a, int b);
double divide(double a, double b);

#endif

// math_utils.cpp
#include "math_utils.h"

int add(int a, int b) {
    return a + b;
}

int subtract(int a, int b) {
    return a - b;
}

int multiply(int a, int b) {
    return a * b;
}

double divide(double a, double b) {
    if (b == 0) {
        return 0;  // 简单处理
    }
    return a / b;
}

// main.cpp
#include <iostream>
#include "math_utils.h"

int main() {
    std::cout << "5 + 3 = " << add(5, 3) << std::endl;
    std::cout << "5 - 3 = " << subtract(5, 3) << std::endl;
    std::cout << "5 * 3 = " << multiply(5, 3) << std::endl;
    std::cout << "5 / 3 = " << divide(5, 3) << std::endl;
    
    return 0;
}
```

## 小结

函数基础要点：

1. **函数定义**：返回类型 + 函数名 + 参数列表 + 函数体
2. **函数声明**：提前声明函数原型
3. **返回值**：使用 return 返回结果
4. **多文件**：头文件声明，源文件定义

> 💡 **提示**：函数应该只做一件事，并且做好。保持函数简短、职责单一。
