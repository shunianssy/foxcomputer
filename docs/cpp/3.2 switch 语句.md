# 3.2 switch 语句

switch 语句用于多分支选择，比多个 if-else 更清晰。本节介绍 switch 语句的使用方法。

## 基本 switch 语句

```cpp
#include <iostream>

int main() {
    int day = 3;
    
    switch (day) {
        case 1:
            std::cout << "星期一" << std::endl;
            break;
        case 2:
            std::cout << "星期二" << std::endl;
            break;
        case 3:
            std::cout << "星期三" << std::endl;
            break;
        case 4:
            std::cout << "星期四" << std::endl;
            break;
        case 5:
            std::cout << "星期五" << std::endl;
            break;
        case 6:
            std::cout << "星期六" << std::endl;
            break;
        case 7:
            std::cout << "星期日" << std::endl;
            break;
        default:
            std::cout << "无效的日期" << std::endl;
    }
    
    return 0;
}
```

## break 和 default

```cpp
#include <iostream>

int main() {
    char grade = 'B';
    
    switch (grade) {
        case 'A':
            std::cout << "优秀" << std::endl;
            break;
        case 'B':
            std::cout << "良好" << std::endl;
            break;
        case 'C':
            std::cout << "及格" << std::endl;
            break;
        case 'D':
            std::cout << "不及格" << std::endl;
            break;
        default:
            std::cout << "无效的等级" << std::endl;
    }
    
    return 0;
}
```

## 穿透特性

```cpp
#include <iostream>

int main() {
    int month = 2;
    
    // 利用穿透特性
    switch (month) {
        case 1:
        case 3:
        case 5:
        case 7:
        case 8:
        case 10:
        case 12:
            std::cout << "31 天" << std::endl;
            break;
        case 4:
        case 6:
        case 9:
        case 11:
            std::cout << "30 天" << std::endl;
            break;
        case 2:
            std::cout << "28 或 29 天" << std::endl;
            break;
        default:
            std::cout << "无效的月份" << std::endl;
    }
    
    return 0;
}
```

## C++17 初始化语句

```cpp
#include <iostream>

int main() {
    // C++17: switch 中的初始化语句
    switch (int x = getValue(); x) {
        case 1:
            std::cout << "值为 1" << std::endl;
            break;
        case 2:
            std::cout << "值为 2" << std::endl;
            break;
        default:
            std::cout << "其他值: " << x << std::endl;
    }
    
    return 0;
}

int getValue() {
    return 2;
}
```

## switch vs if-else

```cpp
#include <iostream>

int main() {
    int choice = 1;
    
    // switch 适合离散值判断
    switch (choice) {
        case 1:
            std::cout << "选项 1" << std::endl;
            break;
        case 2:
            std::cout << "选项 2" << std::endl;
            break;
        default:
            std::cout << "其他选项" << std::endl;
    }
    
    // if-else 适合范围判断
    int score = 85;
    
    if (score >= 90) {
        std::cout << "A" << std::endl;
    } else if (score >= 80) {
        std::cout << "B" << std::endl;
    } else {
        std::cout << "C" << std::endl;
    }
    
    return 0;
}
```

## 小结

switch 语句要点：

1. **case**：匹配具体值
2. **break**：跳出 switch，防止穿透
3. **default**：默认分支
4. **穿透**：没有 break 时继续执行下一个 case
5. **适用场景**：离散值判断

> 💡 **提示**：每个 case 后记得加 break，除非故意使用穿透特性。
