# 1.4 代码规范

良好的代码规范是编写高质量 C++ 程序的基础。本节介绍 C++ 编码规范和最佳实践。

## 命名规范

### 标识符命名规则

```cpp
// 正确的命名
int studentAge; // 小驼峰命名法
int student_age; // 下划线命名法
int StudentAge; // 大驼峰命名法（类名）
int MAX_SIZE; // 全大写（常量）

// 错误的命名
// int 1student; // 不能以数字开头
// int my-var; // 不能包含连字符
// int class; // 不能使用关键字
```

### 命名约定

```cpp
// 变量和函数：小驼峰或下划线
int studentCount;
int student_count;

void calculateTotal();
void calculate_total();

// 类名：大驼峰
class StudentManager {
 // ...
};

// 常量：全大写下划线或 k 前缀
const int MAX_BUFFER_SIZE = 1024;
const int kMaxBufferSize = 1024;

// 成员变量：下划线后缀或 m_ 前缀
class Student {
private:
 std::string name_; // 下划线后缀
 int m_age; // m_ 前缀
};
```

## 代码格式

### 缩进和空格

```cpp
// 使用 4 个空格缩进（推荐）
class Example {
public:
 void method() {
 if (condition) {
 // 4 个空格缩进
 doSomething();
 }
 }
};

// 运算符两侧加空格
int result = a + b * c - d;

// 逗号后加空格
void function(int a, int b, int c);
```

### 大括号风格

```cpp
// K&R 风格（推荐）
if (condition) {
 // 代码
} else {
 // 代码
}

// 单行语句也使用大括号（推荐）
if (condition) {
 return true;
}
```

## 注释规范

### 文件头注释

```cpp
/**
 * @file student_manager.cpp
 * @brief 学生管理器实现文件
 * @author Your Name
 * @date 2024-01-01
 * @version 1.0
 */
```

### 函数注释

```cpp
/**
 * @brief 计算学生的平均成绩
 * * @param scores 成绩数组
 * @param count 成绩数量
 * @return double 平均成绩
 */
double calculateAverage(const double* scores, int count);
```

### 行内注释

```cpp
// 单行注释：解释下方代码
int result = a + b;

int value = 42; // 行尾注释：简短说明

// TODO: 待实现的功能
// FIXME: 需要修复的问题
// NOTE: 重要说明
```

## 头文件规范

### 头文件保护

```cpp
// 方式一：传统宏保护（推荐）
#ifndef STUDENT_MANAGER_H
#define STUDENT_MANAGER_H

// 头文件内容

#endif // STUDENT_MANAGER_H

// 方式二：#pragma once（简单但不标准）
#pragma once

// 头文件内容
```

## 最佳实践

### 使用 const

```cpp
// const 变量
const int kMaxSize = 100;

// const 引用参数（避免拷贝）
void printString(const std::string& str);

// const 成员函数
class Counter {
public:
 int getValue() const { return value_; }
 
private:
 int value_;
};
```

### 使用 auto

```cpp
// 简化复杂类型
auto iter = myMap.find(key);

// 范围 for 循环中使用 auto&
std::vector<std::string> names = {"Alice", "Bob"};
for (const auto& name : names) {
 std::cout << name << std::endl;
}
```

### 资源管理

```cpp
// 推荐：智能指针
auto ptr = std::make_unique<int>(42);
// 自动释放，无需手动 delete

// 推荐：使用容器
std::vector<int> numbers = {1, 2, 3, 4, 5};
// 自动管理内存
```

### 错误处理

```cpp
// 使用异常处理错误
#include <stdexcept>

void setAge(int age) {
 if (age < 0 || age > 150) {
 throw std::invalid_argument("年龄必须在 0-150 之间");
 }
 age_ = age;
}

// 使用 try-catch
try {
 student.setAge(-5);
} catch (const std::invalid_argument& e) {
 std::cerr << "参数错误: " << e.what() << std::endl;
}
```

## 小结

代码规范要点：

1. **命名清晰**：使用有意义的名称，遵循命名约定
2. **格式统一**：一致的缩进、空格和大括号风格
3. **注释充分**：解释复杂逻辑，文档化公共接口
4. **头文件规范**：使用保护宏，正确组织包含顺序
5. **最佳实践**：使用 const、auto、智能指针等现代特性

> **提示**：好的代码规范不仅让代码更易读，还能减少错误。养成良好习惯，从第一行代码开始。
