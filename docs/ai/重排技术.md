# 重排技术 (Reranking)

## 概述

重排技术（Reranking）是信息检索系统中的关键步骤，用于对初步检索结果进行精细化排序。在 RAG（检索增强生成）、搜索引擎、推荐系统等场景中，重排可以显著提升检索结果的相关性和准确性。

## 为什么需要重排？

### 两阶段检索架构

```
查询 Query
    │
    ▼
┌─────────────────────────────────┐
│   第一阶段：粗排 (Retrieval)     │
│   - 使用向量相似度快速检索       │
│   - 从海量文档中筛选候选集       │
│   - 返回 Top-K 候选文档         │
└─────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────┐
│   第二阶段：精排 (Reranking)     │
│   - 使用重排模型精细评分         │
│   - 综合考虑语义、关键词等       │
│   - 返回重新排序的结果           │
└─────────────────────────────────┘
    │
    ▼
  最终结果
```

### 粗排 vs 精排对比

| 特性 | 粗排 (Retrieval) | 精排 (Reranking) |
|------|------------------|------------------|
| 目标 | 快速召回候选文档 | 精确排序候选文档 |
| 方法 | 向量相似度搜索 | 交叉编码器/LLM |
| 速度 | 极快（毫秒级） | 较慢（秒级） |
| 处理量 | 百万级文档 | 百级候选文档 |
| 准确性 | 一般 | 高 |

## 重排模型类型

### 1. 交叉编码器 (Cross-Encoder)

交叉编码器将查询和文档作为一对输入，直接输出相关性分数：

```python
"""
交叉编码器重排实现
"""
from sentence_transformers import CrossEncoder
from typing import List, Tuple
import numpy as np

class CrossEncoderReranker:
    """
    基于交叉编码器的重排器
    """
    def __init__(self, model_name: str = 'cross-encoder/ms-marco-MiniLM-L-6-v2'):
        """
        初始化重排模型
        
        Args:
            model_name: 模型名称，常用选项:
                - 'cross-encoder/ms-marco-MiniLM-L-6-v2': 快速，适合通用场景
                - 'cross-encoder/ms-marco-MiniLM-L-12-v2': 更高质量
                - 'cross-encoder/ms-marco-MiniLM-L-4-v2': 更快速度
                - 'BAAI/bge-reranker-base': 中文优化
                - 'BAAI/bge-reranker-large': 中文高质量
        """
        self.model = CrossEncoder(model_name)
        self.model_name = model_name
        
    def rerank(self, query: str, documents: List[str], 
               top_k: int = None) -> List[Tuple[int, float, str]]:
        """
        对文档进行重排
        
        Args:
            query: 查询文本
            documents: 候选文档列表
            top_k: 返回前 k 个结果，None 表示返回全部
            
        Returns:
            [(原始索引, 相关性分数, 文档内容), ...] 按分数降序排列
        """
        # 构建查询-文档对
        pairs = [(query, doc) for doc in documents]
        
        # 计算相关性分数
        scores = self.model.predict(pairs)
        
        # 排序
        ranked_indices = np.argsort(scores)[::-1]
        
        if top_k:
            ranked_indices = ranked_indices[:top_k]
            
        # 整理结果
        results = [
            (int(idx), float(scores[idx]), documents[idx])
            for idx in ranked_indices
        ]
        
        return results
    
    def score_pairs(self, pairs: List[Tuple[str, str]]) -> np.ndarray:
        """
        直接对查询-文档对进行评分
        
        Args:
            pairs: [(query, document), ...] 列表
            
        Returns:
            相关性分数数组
        """
        return self.model.predict(pairs)


# 使用示例
if __name__ == "__main__":
    # 创建重排器
    reranker = CrossEncoderReranker('cross-encoder/ms-marco-MiniLM-L-6-v2')
    
    # 查询和候选文档
    query = "什么是机器学习？"
    documents = [
        "机器学习是人工智能的一个分支，它使计算机能够从数据中学习。",
        "深度学习是机器学习的一个子领域，使用神经网络进行学习。",
        "今天天气很好，适合户外运动。",
        "机器学习算法可以分为监督学习、无监督学习和强化学习。",
        "Python 是一种流行的编程语言。"
    ]
    
    # 重排
    results = reranker.rerank(query, documents, top_k=3)
    
    print(f"查询: {query}\n")
    print("重排结果:")
    for rank, (idx, score, doc) in enumerate(results, 1):
        print(f"{rank}. [分数: {score:.4f}] {doc[:50]}...")
```

### 2. LLM 重排

使用大语言模型进行重排，可以获得更高的准确性：

```python
"""
LLM 重排实现
"""
from openai import OpenAI
import os
import json
from typing import List, Tuple

class LLMReranker:
    """
    基于 LLM 的重排器
    """
    def __init__(self, model: str = "gpt-3.5-turbo"):
        """
        初始化 LLM 重排器
        
        Args:
            model: OpenAI 模型名称
        """
        self.client = OpenAI(api_key=os.getenv("OPENAI_API_KEY"))
        self.model = model
        
    def rerank(self, query: str, documents: List[str], 
               top_k: int = None) -> List[Tuple[int, float, str]]:
        """
        使用 LLM 进行重排
        
        Args:
            query: 查询文本
            documents: 候选文档列表
            top_k: 返回前 k 个结果
            
        Returns:
            [(原始索引, 相关性分数, 文档内容), ...]
        """
        # 构建 prompt
        doc_list = "\n".join([f"[{i}] {doc}" for i, doc in enumerate(documents)])
        
        prompt = f"""你是一个搜索结果重排专家。请根据查询对以下文档进行相关性评分和排序。

查询: {query}

文档列表:
{doc_list}

请对每个文档进行相关性评分（0-100分），并按相关性从高到低排序。
返回 JSON 格式：
{{"results": [{{"index": 文档索引, "score": 分数, "reason": "评分理由"}}]}}

只返回 JSON，不要其他内容。"""

        # 调用 LLM
        response = self.client.chat.completions.create(
            model=self.model,
            messages=[
                {"role": "system", "content": "你是一个搜索结果重排专家，擅长评估文档相关性。"},
                {"role": "user", "content": prompt}
            ],
            temperature=0
        )
        
        # 解析结果
        try:
            content = response.choices[0].message.content
            result = json.loads(content)
            
            results = []
            for item in result["results"]:
                idx = item["index"]
                score = item["score"] / 100.0  # 归一化到 0-1
                results.append((idx, score, documents[idx]))
                
            if top_k:
                results = results[:top_k]
                
            return results
            
        except (json.JSONDecodeError, KeyError) as e:
            print(f"解析错误: {e}")
            # 返回原始顺序
            return [(i, 0.5, doc) for i, doc in enumerate(documents[:top_k])]
    
    def rerank_with_reasoning(self, query: str, documents: List[str]) -> List[dict]:
        """
        带详细推理的重排
        
        Returns:
            包含详细推理信息的结果列表
        """
        doc_list = "\n".join([f"[{i}] {doc}" for i, doc in enumerate(documents)])
        
        prompt = f"""分析以下文档与查询的相关性，给出详细评估。

查询: {query}

文档列表:
{doc_list}

请返回 JSON 格式：
{{
    "analysis": [
        {{
            "index": 文档索引,
            "relevance": "high/medium/low",
            "score": 0-100,
            "key_matches": ["匹配的关键词或概念"],
            "reasoning": "详细的相关性分析"
        }}
    ],
    "ranking": [按相关性排序的索引列表]
}}"""

        response = self.client.chat.completions.create(
            model=self.model,
            messages=[
                {"role": "system", "content": "你是搜索相关性分析专家。"},
                {"role": "user", "content": prompt}
            ],
            temperature=0
        )
        
        return json.loads(response.choices[0].message.content)
```

### 3. 多特征融合重排

```python
"""
多特征融合重排实现
"""
import numpy as np
from typing import List, Dict, Tuple
from dataclasses import dataclass

@dataclass
class DocumentFeatures:
    """文档特征"""
    doc_id: str
    content: str
    semantic_score: float      # 语义相似度分数
    keyword_score: float       # 关键词匹配分数
    bm25_score: float          # BM25 分数
    recency_score: float       # 时效性分数
    authority_score: float     # 权威性分数


class MultiFeatureReranker:
    """
    多特征融合重排器
    """
    def __init__(self, weights: Dict[str, float] = None):
        """
        初始化重排器
        
        Args:
            weights: 各特征的权重配置
        """
        self.weights = weights or {
            'semantic': 0.4,
            'keyword': 0.2,
            'bm25': 0.2,
            'recency': 0.1,
            'authority': 0.1
        }
        
    def compute_final_score(self, features: DocumentFeatures) -> float:
        """
        计算最终融合分数
        
        Args:
            features: 文档特征
            
        Returns:
            融合后的分数
        """
        score = (
            self.weights['semantic'] * features.semantic_score +
            self.weights['keyword'] * features.keyword_score +
            self.weights['bm25'] * features.bm25_score +
            self.weights['recency'] * features.recency_score +
            self.weights['authority'] * features.authority_score
        )
        return score
    
    def rerank(self, documents: List[DocumentFeatures], 
               top_k: int = None) -> List[Tuple[str, float, DocumentFeatures]]:
        """
        多特征融合重排
        
        Args:
            documents: 带特征的文档列表
            top_k: 返回前 k 个结果
            
        Returns:
            [(文档ID, 最终分数, 文档特征), ...]
        """
        # 计算每个文档的最终分数
        scored_docs = []
        for doc in documents:
            final_score = self.compute_final_score(doc)
            scored_docs.append((doc.doc_id, final_score, doc))
            
        # 按分数排序
        scored_docs.sort(key=lambda x: x[1], reverse=True)
        
        if top_k:
            scored_docs = scored_docs[:top_k]
            
        return scored_docs
    
    def normalize_scores(self, documents: List[DocumentFeatures]) -> List[DocumentFeatures]:
        """
        归一化各特征分数到 [0, 1] 区间
        """
        if not documents:
            return documents
            
        # 提取各特征
        semantic_scores = np.array([d.semantic_score for d in documents])
        keyword_scores = np.array([d.keyword_score for d in documents])
        bm25_scores = np.array([d.bm25_score for d in documents])
        recency_scores = np.array([d.recency_score for d in documents])
        authority_scores = np.array([d.authority_score for d in documents])
        
        # Min-Max 归一化
        def normalize(arr):
            min_val, max_val = arr.min(), arr.max()
            if max_val == min_val:
                return np.ones_like(arr) * 0.5
            return (arr - min_val) / (max_val - min_val)
        
        semantic_norm = normalize(semantic_scores)
        keyword_norm = normalize(keyword_scores)
        bm25_norm = normalize(bm25_scores)
        recency_norm = normalize(recency_scores)
        authority_norm = normalize(authority_scores)
        
        # 更新特征
        for i, doc in enumerate(documents):
            doc.semantic_score = semantic_norm[i]
            doc.keyword_score = keyword_norm[i]
            doc.bm25_score = bm25_norm[i]
            doc.recency_score = recency_norm[i]
            doc.authority_score = authority_norm[i]
            
        return documents


# 使用示例
if __name__ == "__main__":
    # 创建模拟数据
    documents = [
        DocumentFeatures(
            doc_id="doc1",
            content="机器学习是人工智能的核心技术...",
            semantic_score=0.85,
            keyword_score=0.9,
            bm25_score=3.5,
            recency_score=0.8,
            authority_score=0.9
        ),
        DocumentFeatures(
            doc_id="doc2",
            content="深度学习使用神经网络...",
            semantic_score=0.75,
            keyword_score=0.7,
            bm25_score=2.8,
            recency_score=0.95,
            authority_score=0.85
        ),
        DocumentFeatures(
            doc_id="doc3",
            content="Python 编程入门...",
            semantic_score=0.3,
            keyword_score=0.2,
            bm25_score=1.2,
            recency_score=0.5,
            authority_score=0.7
        )
    ]
    
    # 创建重排器
    reranker = MultiFeatureReranker()
    
    # 归一化分数
    documents = reranker.normalize_scores(documents)
    
    # 重排
    results = reranker.rerank(documents, top_k=3)
    
    print("多特征融合重排结果:")
    for doc_id, score, features in results:
        print(f"\n文档ID: {doc_id}")
        print(f"最终分数: {score:.4f}")
        print(f"内容: {features.content[:30]}...")
```

## 完整的 RAG 重排流程

```python
"""
完整的 RAG 重排流程实现
"""
from typing import List, Tuple, Optional
from dataclasses import dataclass
import numpy as np

# 假设已有以下模块
# from embedding import SentenceEmbedding
# from vector_store import VectorStore
# from reranker import CrossEncoderReranker

@dataclass
class SearchResult:
    """搜索结果"""
    doc_id: str
    content: str
    retrieval_score: float
    rerank_score: Optional[float] = None
    final_rank: Optional[int] = None


class RAGPipeline:
    """
    完整的 RAG 管道，包含重排步骤
    """
    def __init__(self, embedder, vector_store, reranker, 
                 retrieval_top_k: int = 50, rerank_top_k: int = 5):
        """
        初始化 RAG 管道
        
        Args:
            embedder: 嵌入模型
            vector_store: 向量存储
            reranker: 重排模型
            retrieval_top_k: 检索阶段返回的文档数
            rerank_top_k: 重排后返回的文档数
        """
        self.embedder = embedder
        self.vector_store = vector_store
        self.reranker = reranker
        self.retrieval_top_k = retrieval_top_k
        self.rerank_top_k = rerank_top_k
        
    def retrieve(self, query: str) -> List[SearchResult]:
        """
        第一阶段：向量检索
        
        Args:
            query: 查询文本
            
        Returns:
            检索结果列表
        """
        # 生成查询向量
        query_embedding = self.embedder.encode(query)
        
        # 向量搜索
        raw_results = self.vector_store.search(query_embedding, k=self.retrieval_top_k)
        
        # 封装结果
        results = [
            SearchResult(
                doc_id=doc_id,
                content=self._get_document_content(doc_id),
                retrieval_score=score
            )
            for doc_id, score in raw_results
        ]
        
        return results
    
    def rerank(self, query: str, results: List[SearchResult]) -> List[SearchResult]:
        """
        第二阶段：重排
        
        Args:
            query: 查询文本
            results: 检索结果
            
        Returns:
            重排后的结果
        """
        if not results:
            return results
            
        # 提取文档内容
        documents = [r.content for r in results]
        
        # 重排
        reranked = self.reranker.rerank(query, documents, top_k=self.rerank_top_k)
        
        # 更新结果
        final_results = []
        for rank, (orig_idx, score, _) in enumerate(reranked, 1):
            result = results[orig_idx]
            result.rerank_score = score
            result.final_rank = rank
            final_results.append(result)
            
        return final_results
    
    def search(self, query: str) -> List[SearchResult]:
        """
        完整搜索流程：检索 + 重排
        
        Args:
            query: 查询文本
            
        Returns:
            最终搜索结果
        """
        # 第一阶段：检索
        retrieval_results = self.retrieve(query)
        
        # 第二阶段：重排
        final_results = self.rerank(query, retrieval_results)
        
        return final_results
    
    def _get_document_content(self, doc_id: str) -> str:
        """根据 ID 获取文档内容（实际实现需要连接文档存储）"""
        # 这里是模拟实现
        return f"文档 {doc_id} 的内容..."
```

## 重排技术的应用场景

### 1. 语义搜索

用户搜"手机续航差"，能匹配到"电池不耐用"相关内容

### 2. RAG（检索增强生成）

将知识库文档向量化，为大模型提供精准上下文

### 3. 推荐系统

计算用户/商品嵌入的相似度，实现个性化推荐

### 4. 聚类与分类

将相似文档自动分组，或用于训练分类模型

### 5. 去重与相似检测

快速识别重复或高度相似的内容

### 6. 跨语言检索

多语言嵌入模型支持不同语言间的语义匹配

## 性能优化建议

### 1. 批量处理

```python
def batch_rerank(reranker, query: str, documents: List[str], 
                 batch_size: int = 32) -> List[Tuple[int, float]]:
    """批量重排，避免内存溢出"""
    all_results = []
    
    for i in range(0, len(documents), batch_size):
        batch = documents[i:i + batch_size]
        results = reranker.rerank(query, batch)
        all_results.extend(results)
        
    # 全局排序
    all_results.sort(key=lambda x: x[1], reverse=True)
    return all_results
```

### 2. 缓存机制

```python
from functools import lru_cache
import hashlib

class CachedReranker:
    """带缓存的重排器"""
    
    def __init__(self, reranker, cache_size: int = 1000):
        self.reranker = reranker
        self.cache = {}
        self.cache_size = cache_size
        
    def _get_cache_key(self, query: str, doc: str) -> str:
        """生成缓存键"""
        combined = f"{query}|||{doc}"
        return hashlib.md5(combined.encode()).hexdigest()
    
    def score_single(self, query: str, doc: str) -> float:
        """对单个文档评分（带缓存）"""
        key = self._get_cache_key(query, doc)
        
        if key in self.cache:
            return self.cache[key]
            
        score = self.reranker.score_pairs([(query, doc)])[0]
        
        # 更新缓存
        if len(self.cache) >= self.cache_size:
            # 简单的 FIFO 淘汰
            oldest_key = next(iter(self.cache))
            del self.cache[oldest_key]
            
        self.cache[key] = score
        return score
```

### 3. 异步处理

```python
import asyncio
from typing import List, Tuple

async def async_rerank(reranker, query: str, 
                       documents: List[str]) -> List[Tuple[int, float]]:
    """异步重排"""
    loop = asyncio.get_event_loop()
    
    # 在线程池中执行重排
    results = await loop.run_in_executor(
        None,
        reranker.rerank,
        query,
        documents
    )
    
    return results
```

## 最佳实践

1. **检索数量**：检索阶段返回 20-100 个候选文档
2. **重排数量**：重排后返回 3-10 个最终结果
3. **模型选择**：根据语言和精度需求选择合适的重排模型
4. **特征融合**：结合多种特征提升排序质量
