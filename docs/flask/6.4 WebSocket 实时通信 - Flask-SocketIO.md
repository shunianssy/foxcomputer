# 6.4 WebSocket 实时通信：Flask-SocketIO

WebSocket 允许服务器主动向客户端推送消息，实现实时通信功能。

## 安装

```bash
pip install flask-socketio
```

## 基本配置

```python
from flask import Flask, render_template
from flask_socketio import SocketIO, emit, join_room, leave_room

app = Flask(__name__)
app.config['SECRET_KEY'] = 'your-secret-key'
socketio = SocketIO(app)

# 客户端连接
@socketio.on('connect')
def handle_connect():
    print('客户端已连接')
    emit('message', {'data': '欢迎连接！'})

# 客户端断开
@socketio.on('disconnect')
def handle_disconnect():
    print('客户端已断开')

# 接收消息
@socketio.on('send_message')
def handle_message(data):
    print(f'收到消息: {data}')
    # 广播给所有客户端
    emit('receive_message', {'data': data['message']}, broadcast=True)
```

## 聊天室功能

```python
from flask_socketio import rooms

# 加入房间
@socketio.on('join')
def on_join(data):
    room = data['room']
    join_room(room)
    emit('status', {'msg': f'用户加入了房间 {room}'}, room=room)

# 离开房间
@socketio.on('leave')
def on_leave(data):
    room = data['room']
    leave_room(room)
    emit('status', {'msg': f'用户离开了房间 {room}'}, room=room)

# 房间内发送消息
@socketio.on('room_message')
def handle_room_message(data):
    room = data['room']
    emit('message', {'msg': data['msg']}, room=room)
```

## 前端 JavaScript 客户端

```html
<script src="https://cdn.socket.io/4.5.4/socket.io.min.js"></script>
<script>
const socket = io();

// 连接成功
socket.on('connect', function() {
    console.log('已连接到服务器');
});

// 接收消息
socket.on('receive_message', function(data) {
    console.log('收到消息:', data.data);
});

// 发送消息
socket.emit('send_message', {message: '你好！'});
</script>
```

## 运行 SocketIO 应用

```python
if __name__ == '__main__':
    socketio.run(app, host='0.0.0.0', port=5000, debug=True)
```
