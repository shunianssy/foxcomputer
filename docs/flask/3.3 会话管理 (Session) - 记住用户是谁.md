# 3.3 会话管理 (Session)：记住用户是谁

HTTP 协议本身是"无记忆"的（无状态）。为了让服务器知道"这个请求和上个请求是同一个人"，我们需要 Session

## Flask Session 原理

Flask 的 Session 是加密存储在浏览器 Cookie 中的：

1. 服务器将数据序列化后加密
2. 加密后的数据存储在 Cookie 中
3. 客户端每次请求都会带上这个 Cookie
4. 服务器解密并读取 Session 数据

## 基本配置

### 设置密钥（必须）

```python
app = Flask(__name__)

# 方式一：直接设置
app.secret_key = 'your-secret-key-here'

# 方式二：从环境变量读取
import os
app.secret_key = os.environ.get('SECRET_KEY') or 'dev-key'

# 方式三：使用配置文件
app.config['SECRET_KEY'] = 'your-secret-key-here'
```

> **重要**：密钥应该是一个足够复杂的随机字符串

### 生成安全密钥

```python
import secrets

# 生成安全的随机密钥
secret_key = secrets.token_hex(32)
print(secret_key) # 例如: 'a1b2c3d4e5f6...'
```

## Session 基本操作

### 存储数据

```python
from flask import session

@app.route('/set_user/<name>')
def set_user(name):
 session['user'] = name # 存入数据
 session['logged_in'] = True
 return '已记录身份'
```

### 读取数据

```python
@app.route('/get_user')
def get_user():
 user = session.get('user', '游客') # 读取数据，带默认值
 logged_in = session.get('logged_in', False)
 return f'当前用户：{user}, 登录状态：{logged_in}'
```

### 删除数据

```python
@app.route('/clear_user')
def clear_user():
 # 删除单个键
 session.pop('user', None)
 return '已清除用户信息'

@app.route('/logout')
def logout():
 # 清除所有 Session
 session.clear()
 return '已退出登录'
```

### 检查键是否存在

```python
@app.route('/check_login')
def check_login():
 if 'user' in session:
 return f"已登录: {session['user']}"
 return '未登录'
```

## Session 配置选项

```python
app.config.update(
 # Session 密钥
 SECRET_KEY='your-secret-key',
 
 # Session Cookie 名称（默认 'session'）
 SESSION_COOKIE_NAME='my_session',
 
 # Session 有效期（秒），None 表示关闭浏览器失效
 PERMANENT_SESSION_LIFETIME=3600, # 1小时
 
 # Cookie 安全设置
 SESSION_COOKIE_SECURE=True, # 仅 HTTPS
 SESSION_COOKIE_HTTPONLY=True, # 防止 JS 访问
 SESSION_COOKIE_SAMESITE='Lax', # CSRF 防护
 
 # Session 类型（默认使用 Cookie）
 SESSION_TYPE='filesystem', # 可选: redis, memcached, filesystem
)
```

## 持久化 Session

默认情况下，Session 在关闭浏览器后失效。设置持久化可以让 Session 在指定时间内有效：

```python
from datetime import timedelta

# 设置全局 Session 有效期
app.permanent_session_lifetime = timedelta(days=7)

@app.route('/login', methods=['POST'])
def login():
 username = request.form.get('username')
 session['user'] = username
 session.permanent = True # 启用持久化
 return '登录成功'
```

## 完整登录示例

```python
from flask import Flask, session, redirect, url_for, request, render_template
from functools import wraps

app = Flask(__name__)
app.secret_key = 'your-secret-key'

# 模拟用户数据库
USERS = {
 'admin': 'admin123',
 'user': 'user123'
}

# 登录验证装饰器
def login_required(f):
 @wraps(f)
 def decorated_function(*args, **kwargs):
 if 'user' not in session:
 return redirect(url_for('login', next=request.url))
 return f(*args, **kwargs)
 return decorated_function

# 登录页面
@app.route('/login', methods=['GET', 'POST'])
def login():
 if request.method == 'POST':
 username = request.form.get('username')
 password = request.form.get('password')
 
 if username in USERS and USERS[username] == password:
 session['user'] = username
 session.permanent = True
 next_page = request.args.get('next', url_for('index'))
 return redirect(next_page)
 
 return '用户名或密码错误'
 
 return '''
 <form method="post">
 <input name="username" placeholder="用户名">
 <input name="password" type="password" placeholder="密码">
 <button type="submit">登录</button>
 </form>
 '''

# 登出
@app.route('/logout')
def logout():
 session.clear()
 return redirect(url_for('index'))

# 首页
@app.route('/')
def index():
 if 'user' in session:
 return f'欢迎, {session["user"]}! <a href="/logout">退出</a>'
 return '<a href="/login">登录</a>'

# 需要登录才能访问的页面
@app.route('/dashboard')
@login_required
def dashboard():
 return f'仪表盘 - 当前用户: {session["user"]}'
```

## 服务端 Session

默认的 Cookie Session 有大小限制（约 4KB）。对于大量数据，应使用服务端 Session：

### 使用 Flask-Session

```bash
pip install Flask-Session
```

```python
from flask_session import Session

app = Flask(__name__)
app.config['SESSION_TYPE'] = 'redis' # 使用 Redis 存储
app.config['SESSION_REDIS'] = redis.from_url('redis://localhost:6379')

Session(app)
```

### 支持的存储类型

| 类型 | 配置值 | 说明 |
|------|--------|------|
| Redis | `redis` | 推荐，高性能 |
| Memcached | `memcached` | 高性能缓存 |
| 文件系统 | `filesystem` | 简单，适合开发 |
| 数据库 | `sqlalchemy` | 持久化存储 |
| MongoDB | `mongodb` | NoSQL 存储 |

## Session 安全建议

### 1. 使用强密钥

```python
# 不要使用简单密钥
app.secret_key = '123' # 不安全

# 使用强随机密钥
import secrets
app.secret_key = secrets.token_hex(32) # 安全
```

### 2. 设置安全 Cookie 属性

```python
app.config.update(
 SESSION_COOKIE_SECURE=True, # 仅 HTTPS
 SESSION_COOKIE_HTTPONLY=True, # 防止 XSS
 SESSION_COOKIE_SAMESITE='Lax', # 防止 CSRF
)
```

### 3. 不要存储敏感信息

```python
# 不要存储密码
session['password'] = password

# 存储用户 ID
session['user_id'] = user.id
```

### 4. 设置合理的过期时间

```python
from datetime import timedelta

# 短期 Session（敏感操作）
app.permanent_session_lifetime = timedelta(minutes=30)

# 长期 Session（普通网站）
app.permanent_session_lifetime = timedelta(days=7)
```

## 小结

| 操作 | 代码 |
|------|------|
| 设置值 | `session['key'] = value` |
| 获取值 | `session.get('key', default)` |
| 删除值 | `session.pop('key', None)` |
| 清空 | `session.clear()` |
| 检查存在 | `'key' in session` |
| 持久化 | `session.permanent = True` |

> **提示**：Session 数据存储在客户端 Cookie 中
