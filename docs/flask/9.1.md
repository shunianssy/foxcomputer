# 9.1 Flask-Mail：邮件发送

Flask-Mail 提供了简单的邮件发送功能，支持 SMTP 服务器配置。

## 安装

```bash
pip install flask-mail
```

## 基本配置

```python
from flask import Flask
from flask_mail import Mail, Message

app = Flask(__name__)

# 邮件服务器配置
app.config['MAIL_SERVER'] = 'smtp.gmail.com'
app.config['MAIL_PORT'] = 587
app.config['MAIL_USE_TLS'] = True
app.config['MAIL_USERNAME'] = 'your-email@gmail.com'
app.config['MAIL_PASSWORD'] = 'your-app-password'  # 使用应用专用密码
app.config['MAIL_DEFAULT_SENDER'] = 'your-email@gmail.com'

mail = Mail(app)
```

## 发送简单邮件

```python
@app.route('/send-mail')
def send_mail():
    msg = Message(
        subject='欢迎加入',
        recipients=['user@example.com'],
        body='感谢您注册我们的服务！'
    )
    mail.send(msg)
    return '邮件已发送'
```

## 发送 HTML 邮件

```python
@app.route('/send-html-mail')
def send_html_mail():
    msg = Message(
        subject='邮件确认',
        recipients=['user@example.com'],
        html='''
        <h1>欢迎！</h1>
        <p>感谢您注册我们的服务。</p>
        <a href="http://example.com/confirm">点击确认</a>
        '''
    )
    mail.send(msg)
    return 'HTML 邮件已发送'
```

## 使用模板发送邮件

```python
from flask import render_template

def send_welcome_email(user):
    """发送欢迎邮件"""
    msg = Message(
        subject='欢迎加入',
        recipients=[user.email]
    )
    
    # 使用模板渲染邮件内容
    msg.html = render_template('emails/welcome.html', user=user)
    mail.send(msg)
```

## 异步发送邮件

```python
from threading import Thread

def send_async_email(app, msg):
    """异步发送邮件"""
    with app.app_context():
        mail.send(msg)

def send_email_async(subject, recipients, html_body):
    """异步发送邮件接口"""
    msg = Message(subject, recipients=recipients, html=html_body)
    Thread(target=send_async_email, args=(app, msg)).start()
```

## 添加附件

```python
@app.route('/send-attachment')
def send_attachment():
    msg = Message(
        subject='带附件的邮件',
        recipients=['user@example.com']
    )
    
    # 添加附件
    with app.open_resource('report.pdf') as fp:
        msg.attach('report.pdf', 'application/pdf', fp.read())
    
    mail.send(msg)
    return '带附件的邮件已发送'
```
