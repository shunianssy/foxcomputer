# 2.1 路由与变量规则（Routing）

路由是 Web 应用的指路牌。除了固定路径，我们经常需要处理动态内容，比如"用户个人主页"。

## 基本路由

```python
from flask import Flask

app = Flask(__name__)

# 基本路由
@app.route('/')
def index():
    return '这是首页'

@app.route('/about')
def about():
    return '关于我们'
```

## 动态路由

使用 `<变量名>` 来捕捉 URL 中的一部分。

```python
@app.route('/user/<username>')
def show_user_profile(username):
    return f'用户: {username}'

@app.route('/post/<int:post_id>')
def show_post(post_id):
    return f'正在阅读文章 ID: {post_id}'
```

## 类型转换器

你可以指定参数类型，防止非法输入。

| 转换器类型 | 说明 | 示例 |
|------------|------|------|
| `string` | 默认类型，接受任何不带斜杠的文本 | `/user/<name>` |
| `int` | 接受正整数 | `/post/<int:post_id>` |
| `float` | 接受正浮点数 | `/price/<float:val>` |
| `path` | 类似 string，但可以包含斜杠 | `/file/<path:subpath>` |
| `uuid` | 接受 UUID 字符串 | `/item/<uuid:id>` |

### 类型转换示例

```python
@app.route('/user/<username>')
def user_profile(username):
    # string 类型（默认）
    return f'用户名: {username}'

@app.route('/post/<int:post_id>')
def show_post(post_id):
    # int 类型
    return f'文章编号: {post_id}'

@app.route('/price/<float:amount>')
def show_price(amount):
    # float 类型
    return f'价格: ¥{amount:.2f}'

@app.route('/path/<path:subpath>')
def show_subpath(subpath):
    # path 类型，可以包含斜杠
    return f'子路径: {subpath}'

@app.route('/item/<uuid:item_id>')
def show_item(item_id):
    # uuid 类型
    return f'商品 ID: {item_id}'
```

## URL 尾部斜杠处理

Flask 对 URL 尾部斜杠有特殊处理：

```python
# 访问 /project 和 /project/ 都可以
@app.route('/project/')
def project():
    return '项目页面'

# 只能访问 /about，访问 /about/ 会 404
@app.route('/about')
def about():
    return '关于页面'
```

**建议**：保持一致性，要么都加斜杠，要么都不加。

## URL 构建：url_for

使用 `url_for()` 函数根据视图函数名生成 URL，比硬编码更安全。

```python
from flask import Flask, url_for

app = Flask(__name__)

@app.route('/')
def index():
    return '首页'

@app.route('/login')
def login():
    return '登录页面'

@app.route('/user/<username>')
def profile(username):
    return f'{username} 的个人主页'

# 在 Python 代码中生成 URL
with app.test_request_context():
    print(url_for('index'))           # /
    print(url_for('login'))           # /login
    print(url_for('login', next='/')) # /login?next=/
    print(url_for('profile', username='john'))  # /user/john
```

### 在模板中使用 url_for

```html
<a href="{{ url_for('index') }}">首页</a>
<a href="{{ url_for('profile', username='john') }}">John 的主页</a>
<link rel="stylesheet" href="{{ url_for('static', filename='css/style.css') }}">
```

## HTTP 方法

路由可以指定接受的 HTTP 方法：

```python
from flask import request

@app.route('/login', methods=['GET', 'POST'])
def login():
    if request.method == 'POST':
        return '处理登录表单'
    return '显示登录页面'
```

### 常用 HTTP 方法

| 方法 | 用途 |
|------|------|
| GET | 获取资源 |
| POST | 创建资源 |
| PUT | 更新资源（完整替换） |
| PATCH | 更新资源（部分更新） |
| DELETE | 删除资源 |

### 不同方法分开定义

```python
@app.route('/api/users', methods=['GET'])
def get_users():
    return '获取用户列表'

@app.route('/api/users', methods=['POST'])
def create_user():
    return '创建新用户'

@app.route('/api/users/<int:id>', methods=['PUT'])
def update_user(id):
    return f'更新用户 {id}'

@app.route('/api/users/<int:id>', methods=['DELETE'])
def delete_user(id):
    return f'删除用户 {id}'
```

## 路由装饰器进阶

### 自定义路由规则

```python
from werkzeug.routing import Rule

app.add_url_rule('/', 'index', index)
app.add_url_rule('/about', 'about', about)
```

### 路由别名

```python
@app.route('/old-page')
@app.route('/new-page', alias=True)
def page():
    return '页面内容'
```

### 重定向到其他路由

```python
from flask import redirect, url_for

@app.route('/admin')
def admin():
    return redirect(url_for('login'))
```

## 路由最佳实践

### 1. RESTful 风格

```python
# 获取文章列表
@app.route('/api/posts', methods=['GET'])
def get_posts():
    pass

# 创建文章
@app.route('/api/posts', methods=['POST'])
def create_post():
    pass

# 获取单篇文章
@app.route('/api/posts/<int:id>', methods=['GET'])
def get_post(id):
    pass

# 更新文章
@app.route('/api/posts/<int:id>', methods=['PUT'])
def update_post(id):
    pass

# 删除文章
@app.route('/api/posts/<int:id>', methods=['DELETE'])
def delete_post(id):
    pass
```

### 2. 路由命名规范

```python
# 推荐：使用有意义的函数名
@app.route('/user/profile')
def user_profile():
    pass

# 不推荐：函数名与路由无关
@app.route('/user/profile')
def page1():
    pass
```

### 3. 避免过深的嵌套

```python
# 不推荐
@app.route('/api/v1/user/profile/settings/privacy')
def privacy():
    pass

# 推荐：扁平化设计
@app.route('/api/v1/user/privacy-settings')
def privacy_settings():
    pass
```

## 小结

| 功能 | 语法 |
|------|------|
| 基本路由 | `@app.route('/path')` |
| 动态参数 | `@app.route('/user/<name>')` |
| 类型转换 | `@app.route('/post/<int:id>')` |
| 多方法 | `methods=['GET', 'POST']` |
| URL 生成 | `url_for('view_name')` |

> 💡 **提示**：使用 `url_for()` 生成 URL，而不是硬编码路径。这样当你修改路由时，不需要修改所有链接。
