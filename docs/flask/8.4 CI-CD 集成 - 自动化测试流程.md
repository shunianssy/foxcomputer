# 8.4 CI/CD 集成：自动化测试流程

持续集成/持续部署（CI/CD）确保每次代码变更都经过自动测试验证。

## GitHub Actions 配置

```yaml
# .github/workflows/ci.yml
name: CI/CD Pipeline

on:
  push:
    branches: [main, develop]
  pull_request:
    branches: [main]

jobs:
  test:
    runs-on: ubuntu-latest
    
    strategy:
      matrix:
        python-version: ['3.9', '3.10', '3.11']
    
    services:
      postgres:
        image: postgres:14
        env:
          POSTGRES_USER: test
          POSTGRES_PASSWORD: test
          POSTGRES_DB: test_db
        ports:
          - 5432:5432
        options: >-
          --health-cmd pg_isready
          --health-interval 10s
          --health-timeout 5s
          --health-retries 5
    
    steps:
      - name: Checkout code
        uses: actions/checkout@v3
      
      - name: Set up Python
        uses: actions/setup-python@v4
        with:
          python-version: ${{ matrix.python-version }}
      
      - name: Install dependencies
        run: |
          python -m pip install --upgrade pip
          pip install -r requirements.txt
          pip install pytest pytest-cov flake8
      
      - name: Lint with flake8
        run: |
          flake8 app --count --select=E9,F63,F7,F82 --show-source
          flake8 app --count --exit-zero --max-complexity=10 --max-line-length=127
      
      - name: Run tests
        env:
          DATABASE_URL: postgresql://test:test@localhost:5432/test_db
          SECRET_KEY: test-secret-key
        run: |
          pytest --cov=app --cov-report=xml tests/
      
      - name: Upload coverage
        uses: codecov/codecov-action@v3
        with:
          file: ./coverage.xml
```

## GitLab CI 配置

```yaml
# .gitlab-ci.yml
stages:
  - test
  - deploy

test:
  stage: test
  image: python:3.11
  services:
    - postgres:14
  variables:
    POSTGRES_DB: test_db
    POSTGRES_USER: test
    POSTGRES_PASSWORD: test
    DATABASE_URL: postgresql://test:test@postgres:5432/test_db
  script:
    - pip install -r requirements.txt
    - pip install pytest pytest-cov
    - pytest --cov=app tests/
  coverage: '/TOTAL.*\s+(\d+%)/'

deploy:
  stage: deploy
  image: python:3.11
  script:
    - pip install fabric
    - fab deploy
  only:
    - main
```

## 自动化部署脚本

```python
# fabfile.py
from fabric import Connection, task

@task
def deploy(c):
    """部署到生产服务器"""
    c = Connection('user@your-server.com')
    
    with c.cd('/var/www/myapp'):
        # 拉取最新代码
        c.run('git pull origin main')
        
        # 更新依赖
        c.run('source venv/bin/activate && pip install -r requirements.txt')
        
        # 运行数据库迁移
        c.run('source venv/bin/activate && flask db upgrade')
        
        # 重启服务
        c.sudo('systemctl restart myapp')
        
        print("部署完成！")
```

## 通知配置

```yaml
# 在 CI 配置中添加通知
jobs:
  test:
    # ... 其他配置
    steps:
      # ... 测试步骤
      
      - name: Notify on failure
        if: failure()
        uses: 8398a7/action-slack@v3
        with:
          status: failure
          fields: repo,message,commit,author
        env:
          SLACK_WEBHOOK_URL: ${{ secrets.SLACK_WEBHOOK }}
```

## CI/CD 最佳实践

| 实践 | 说明 |
|------|------|
| 快速反馈 | 测试应在 10 分钟内完成 |
| 并行测试 | 使用矩阵策略并行运行 |
| 缓存依赖 | 加速构建过程 |
| 环境隔离 | 每次构建使用干净环境 |
| 自动回滚 | 部署失败时自动回滚 |
