# 3.2 Response 对象：反馈与跳转

服务器处理完数据后，需要给用户一个结果

## 基本响应

### 字符串响应

```python
@app.route('/')
def index():
    return 'Hello, World!'
```

### HTML 响应

```python
@app.route('/html')
def html():
    return '<h1>Hello</h1><p>这是 HTML 内容</p>'
```

### 模板响应

```python
from flask import render_template

@app.route('/page')
def page():
    return render_template('page.html', title='页面标题')
```

## JSON 响应

### 使用 jsonify

```python
from flask import jsonify

@app.route('/api/data')
def get_data():
    return jsonify({
        'status': 'success',
        'data': [1, 2, 3]
    })
```

### 直接返回字典（Flask 1.1+）

```python
@app.route('/api/user')
def get_user():
    return {'id': 1, 'name': 'Alice'}
```

### 返回 JSON 列表

```python
@app.route('/api/users')
def get_users():
    users = [
        {'id': 1, 'name': 'Alice'},
        {'id': 2, 'name': 'Bob'}
    ]
    return jsonify(users)
```

## 自定义状态码

### 方式一：返回元组

```python
@app.route('/not-found')
def not_found():
    return '页面不存在', 404

@app.route('/created')
def created():
    return {'id': 1}, 201

@app.route('/no-content')
def no_content():
    return '', 204
```

### 方式二：返回元组（含请求头）

```python
@app.route('/custom')
def custom():
    return '自定义响应', 200, {'X-Custom-Header': 'Value'}
```

## 重定向 (Redirect)

### 基本重定向

```python
from flask import redirect, url_for

@app.route('/old-page')
def old_page():
    return redirect('/new-page')

@app.route('/new-page')
def new_page():
    return '这是新页面'
```

### 使用 url_for 重定向

```python
@app.route('/admin')
def admin():
    # 如果没登录，跳转到登录页
    return redirect(url_for('login'))

@app.route('/login')
def login():
    return '登录页面'
```

### 带参数重定向

```python
@app.route('/go-to-user/<username>')
def go_to_user(username):
    return redirect(url_for('user_profile', username=username))

@app.route('/user/<username>')
def user_profile(username):
    return f'用户: {username}'
```

### 永久重定向

```python
@app.route('/old-url')
def old_url():
    return redirect(url_for('new_url'), code=301)
```

### 重定向状态码

| 状态码 | 说明 |
|--------|------|
| 301 | 永久重定向 |
| 302 | 临时重定向（默认） |
| 303 | 临时重定向（POST 后推荐） |
| 307 | 临时重定向（保持请求方法） |
| 308 | 永久重定向（保持请求方法） |

## Response 对象

### 创建 Response 对象

```python
from flask import Response

@app.route('/response')
def custom_response():
    resp = Response('自定义响应内容')
    resp.headers['X-Custom'] = 'Custom Value'
    resp.status_code = 200
    return resp
```

### 使用 make_response

```python
from flask import make_response

@app.route('/cookie')
def set_cookie():
    resp = make_response('Cookie 已设置')
    resp.set_cookie('username', 'john')
    return resp

@app.route('/headers')
def custom_headers():
    resp = make_response('带自定义头的响应')
    resp.headers['X-API-Version'] = '1.0'
    resp.headers['Cache-Control'] = 'no-cache'
    return resp
```

## 文件下载

### 发送文件

```python
from flask import send_file, send_from_directory

@app.route('/download/<filename>')
def download(filename):
    return send_file(f'uploads/{filename}', 
                     as_attachment=True)

@app.route('/files/<filename>')
def get_file(filename):
    return send_from_directory('uploads', filename)
```

### 自定义下载文件名

```python
@app.route('/download/report')
def download_report():
    return send_file('reports/report.pdf',
                     as_attachment=True,
                     download_name='月度报告.pdf')
```

## 流式响应

### 生成器响应

```python
def generate():
    for i in range(100):
        yield f'数据 {i}\n'

@app.route('/stream')
def stream():
    return Response(generate(), 
                    mimetype='text/plain')
```

### SSE (Server-Sent Events)

```python
import time
import json

@app.route('/events')
def events():
    def event_stream():
        for i in range(10):
            yield f"data: {json.dumps({'count': i})}\n\n"
            time.sleep(1)
    
    return Response(event_stream(),
                    mimetype='text/event-stream')
```

## 设置响应头

### CORS 头

```python
@app.route('/api/data')
def api_data():
    resp = jsonify({'data': 'value'})
    resp.headers['Access-Control-Allow-Origin'] = '*'
    resp.headers['Access-Control-Allow-Methods'] = 'GET, POST'
    return resp
```

### 缓存控制

```python
@app.route('/cached')
def cached():
    resp = make_response('可缓存的内容')
    resp.headers['Cache-Control'] = 'public, max-age=3600'
    return resp
```

### 安全头

```python
@app.route('/secure')
def secure():
    resp = make_response('安全响应')
    resp.headers['X-Content-Type-Options'] = 'nosniff'
    resp.headers['X-Frame-Options'] = 'DENY'
    resp.headers['X-XSS-Protection'] = '1; mode=block'
    return resp
```

## 错误响应

### abort 函数

```python
from flask import abort

@app.route('/user/<int:id>')
def get_user(id):
    if id > 100:
        abort(404)  # 返回 404 错误
    return f'用户 {id}'

@app.route('/admin')
def admin():
    if not is_admin():
        abort(403)  # 返回 403 禁止访问
    return '管理后台'
```

### 自定义错误消息

```python
@app.route('/api/user/<int:id>')
def api_user(id):
    user = get_user_from_db(id)
    if not user:
        abort(Response(
            json.dumps({'error': '用户不存在'}),
            status=404,
            mimetype='application/json'
        ))
    return jsonify(user)
```

## 小结

| 功能 | 代码 |
|------|------|
| 字符串响应 | `return 'text'` |
| JSON 响应 | `jsonify(data)` 或 `return dict` |
| 状态码 | `return data, 404` |
| 重定向 | `redirect(url_for('view'))` |
| 设置 Cookie | `resp.set_cookie('key', 'value')` |
| 文件下载 | `send_file(path)` |
| 流式响应 | `Response(generator())` |
| 中止请求 | `abort(404)` |

> **提示**：使用 `url_for()` 生成 URL 进行重定向
