# 6.1 中间件与钩子：请求生命周期控制

Flask 提供了多种方式在请求处理过程中插入自定义逻辑，这就是中间件和钩子的作用。

## 请求生命周期

```
请求 → before_request → 视图函数 → after_request → 响应
 ↓
 teardown_request
```

## 请求钩子

### before_request

在每个请求处理之前执行：

```python
@app.before_request
def before_request():
 """在每个请求前执行"""
 # 记录请求开始时间
 g.start_time = time.time()
 
 # 检查维护模式
 if app.config.get('MAINTENANCE_MODE'):
 return '系统维护中', 503
 
 # 检查用户登录状态
 if not current_user.is_authenticated and request.endpoint not in ['login', 'static']:
 return redirect(url_for('login'))
```

### before_first_request

只在第一个请求前执行一次：

```python
@app.before_first_request
def initialize():
 """应用启动后的初始化"""
 app.logger.info('应用已启动')
 # 初始化数据库连接池
 # 预加载配置等
```

### after_request

在每个请求处理后执行，可以修改响应：

```python
@app.after_request
def after_request(response):
 """在每个请求后执行"""
 # 添加安全头
 response.headers['X-Content-Type-Options'] = 'nosniff'
 response.headers['X-Frame-Options'] = 'SAMEORIGIN'
 
 # 记录响应时间
 if hasattr(g, 'start_time'):
 elapsed = time.time() - g.start_time
 response.headers['X-Response-Time'] = f'{elapsed:.3f}s'
 
 return response
```

### teardown_request

在请求结束后执行，即使发生异常也会执行：

```python
@app.teardown_request
def teardown_request(exception=None):
 """请求结束时清理资源"""
 # 关闭数据库连接
 db = getattr(g, 'db', None)
 if db is not None:
 db.close()
 
 # 记录异常
 if exception:
 app.logger.error(f'请求异常: {exception}')
```

### teardown_appcontext

在应用上下文销毁时执行：

```python
@app.teardown_appcontext
def shutdown_session(exception=None):
 """关闭数据库会话"""
 db.session.remove()
```

## 钩子执行顺序

```python
@app.before_request
def before_1():
 print('before_request 1')

@app.before_request
def before_2():
 print('before_request 2')

@app.after_request
def after_1(response):
 print('after_request 1')
 return response

@app.after_request
def after_2(response):
 print('after_request 2')
 return response

# 执行顺序：
# before_request 1
# before_request 2
# 视图函数
# after_request 2 (反向执行)
# after_request 1
# teardown_request
```

## 蓝图级别的钩子

```python
from flask import Blueprint

api_bp = Blueprint('api', __name__)

@api_bp.before_request
def api_before_request():
 """只对 API 蓝图生效"""
 if not request.headers.get('X-API-Key'):
 return jsonify({'error': '缺少 API Key'}), 401

@api_bp.after_request
def api_after_request(response):
 """API 响应处理"""
 response.headers['X-API-Version'] = '1.0'
 return response
```

## 自定义中间件

### WSGI 中间件

```python
class TimingMiddleware:
 """计时中间件"""
 
 def __init__(self, app):
 self.app = app
 
 def __call__(self, environ, start_response):
 start_time = time.time()
 
 def custom_start_response(status, headers, exc_info=None):
 elapsed = time.time() - start_time
 headers.append(('X-Response-Time', f'{elapsed:.3f}s'))
 return start_response(status, headers, exc_info)
 
 return self.app(environ, custom_start_response)

# 使用中间件
app.wsgi_app = TimingMiddleware(app.wsgi_app)
```

### 代理中间件

```python
class ProxyFix:
 """代理修复中间件"""
 
 def __init__(self, app, num_proxies=1):
 self.app = app
 self.num_proxies = num_proxies
 
 def __call__(self, environ, start_response):
 # 从 X-Forwarded-For 获取真实 IP
 forwarded_for = environ.get('HTTP_X_FORWARDED_FOR')
 if forwarded_for:
 proxies = forwarded_for.split(',')
 if len(proxies) >= self.num_proxies:
 environ['REMOTE_ADDR'] = proxies[-self.num_proxies].strip()
 
 return self.app(environ, start_response)

# 使用 Werkzeug 提供的 ProxyFix
from werkzeug.middleware.proxy_fix import ProxyFix
app.wsgi_app = ProxyFix(app.wsgi_app, x_for=1, x_proto=1)
```

## 实用钩子示例

### 请求日志

```python
import time
from flask import g, request

@app.before_request
def start_timer():
 g.start_time = time.time()

@app.after_request
def log_request(response):
 if request.path.startswith('/static'):
 return response
 
 elapsed = time.time() - g.start_time
 app.logger.info(
 f'{request.method} {request.path} '
 f'{response.status_code} {elapsed:.3f}s'
 )
 return response
```

### 异常处理

```python
@app.teardown_request
def log_exception(exception=None):
 if exception:
 app.logger.error(
 f'请求异常: {request.path}\n'
 f'用户: {current_user.id if current_user.is_authenticated else "匿名"}\n'
 f'异常: {str(exception)}'
 )
```

### 数据库事务

```python
@app.before_request
def begin_transaction():
 g.db_session = db.create_session()

@app.teardown_request
def end_transaction(exception=None):
 session = getattr(g, 'db_session', None)
 if session:
 if exception:
 session.rollback()
 else:
 session.commit()
 session.close()
```

## 小结

| 钩子 | 执行时机 | 用途 |
|------|----------|------|
| `before_request` | 请求处理前 | 认证、日志、预处理 |
| `before_first_request` | 首次请求前 | 初始化 |
| `after_request` | 请求处理后 | 修改响应、添加头 |
| `teardown_request` | 请求结束后 | 清理资源 |
| `teardown_appcontext` | 上下文销毁时 | 关闭连接 |

> **提示**：`after_request` 必须返回响应对象，而 `teardown_request` 不接收也不返回响应。
