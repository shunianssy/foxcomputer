# 9.2 Flask-Caching：缓存优化

缓存可以显著提高应用性能，减少数据库查询和计算开销。

## 安装

```bash
pip install flask-caching
```

## 基本配置

```python
from flask import Flask
from flask_caching import Cache

app = Flask(__name__)

# 缓存配置
app.config['CACHE_TYPE'] = 'SimpleCache'  # 开发环境使用简单缓存
app.config['CACHE_DEFAULT_TIMEOUT'] = 300  # 默认缓存 5 分钟

cache = Cache(app)
```

## 缓存类型配置

```python
# Redis 缓存（推荐生产环境）
app.config['CACHE_TYPE'] = 'RedisCache'
app.config['CACHE_REDIS_URL'] = 'redis://localhost:6379/0'

# Memcached 缓存
app.config['CACHE_TYPE'] = 'MemcachedCache'
app.config['CACHE_MEMCACHED_SERVERS'] = ['127.0.0.1:11211']

# 文件系统缓存
app.config['CACHE_TYPE'] = 'FileSystemCache'
app.config['CACHE_DIR'] = '/tmp/cache'
```

## 缓存视图函数

```python
# 缓存整个视图函数的响应
@app.route('/expensive-page')
@cache.cached(timeout=60)  # 缓存 60 秒
def expensive_page():
    # 耗时操作
    result = complex_calculation()
    return render_template('page.html', result=result)

# 带键前缀的缓存
@app.route('/user/<int:user_id>')
@cache.cached(timeout=300, key_prefix='user_view')
def user_profile(user_id):
    user = User.query.get_or_404(user_id)
    return render_template('profile.html', user=user)
```

## 缓存函数结果

```python
@cache.memoize(timeout=60)
def get_user_stats(user_id):
    """缓存函数结果，参数不同则缓存不同"""
    # 复杂计算
    stats = calculate_user_statistics(user_id)
    return stats

# 调用时自动使用缓存
stats = get_user_stats(1)  # 第一次计算并缓存
stats = get_user_stats(1)  # 从缓存获取
stats = get_user_stats(2)  # 新参数，重新计算
```

## 手动缓存操作

```python
# 设置缓存
cache.set('my_key', 'my_value', timeout=60)

# 获取缓存
value = cache.get('my_key')

# 删除缓存
cache.delete('my_key')

# 清空所有缓存
cache.clear()

# 检查缓存是否存在
if cache.has('my_key'):
    print('缓存存在')
```

## 缓存模板片段

```python
from flask import render_template_string

@app.route('/cached-fragment')
def cached_fragment():
    # 缓存模板片段
    cached_content = cache.get('fragment_key')
    if cached_content is None:
        cached_content = render_template_string('''
            {% for item in items %}
                <div>{{ item.name }}</div>
            {% endfor %}
        ''', items=Item.query.all())
        cache.set('fragment_key', cached_content, timeout=300)
    
    return render_template('page.html', fragment=cached_content)
```

## 缓存最佳实践

| 场景 | 建议超时时间 | 说明 |
|------|-------------|------|
| 静态数据 | 1 小时+ | 配置、字典数据 |
| 用户数据 | 5-15 分钟 | 需要及时更新 |
| 计算结果 | 10-60 分钟 | 复杂计算结果 |
| API 响应 | 1-5 分钟 | 频繁变化的数据 |
