# 7.2 CSRF 与 XSS 防护：常见攻击防御

## CSRF（跨站请求伪造）防护

### 使用 Flask-WTF

```python
from flask_wtf.csrf import CSRFProtect

app = Flask(__name__)
app.config['SECRET_KEY'] = 'your-secret-key'

# 启用 CSRF 保护
csrf = CSRFProtect(app)

# 在表单中使用
from flask_wtf import FlaskForm
from wtforms import StringField, SubmitField

class MyForm(FlaskForm):
    name = StringField('名称')
    submit = SubmitField('提交')
    # Flask-WTF 自动添加 CSRF token
```

### 在模板中渲染 CSRF Token

```jinja2
<form method="POST">
    <input type="hidden" name="csrf_token" value="{{ csrf_token() }}">
    <!-- 或使用 Flask-WTF 表单 -->
    {{ form.csrf_token }}
    <input type="text" name="name">
    <button type="submit">提交</button>
</form>
```

### AJAX 请求 CSRF 保护

```javascript
// 在请求头中发送 CSRF token
fetch('/api/data', {
    method: 'POST',
    headers: {
        'X-CSRFToken': document.querySelector('meta[name="csrf-token"]').content
    },
    body: JSON.stringify(data)
});
```

```jinja2
<!-- 在 head 中添加 meta 标签 -->
<meta name="csrf-token" content="{{ csrf_token() }}">
```

## XSS（跨站脚本攻击）防护

### Jinja2 自动转义

```python
# Flask 默认启用自动转义
@app.route('/search')
def search():
    query = request.args.get('q', '')
    # 自动转义 HTML 特殊字符
    return f'搜索结果: {query}'  # 安全
```

### 危险操作：手动关闭转义

```jinja2
<!-- 危险！仅在信任内容时使用 -->
{{ user_input|safe }}

<!-- 安全的方式 -->
{{ user_input }}  <!-- 自动转义 -->
```

### 内容安全策略（CSP）

```python
@app.after_request
def set_csp(response):
    response.headers['Content-Security-Policy'] = (
        "default-src 'self'; "
        "script-src 'self' 'unsafe-inline'; "
        "style-src 'self' 'unsafe-inline'"
    )
    return response
```

## 安全检查清单

| 攻击类型 | 防护措施 |
|---------|---------|
| CSRF | 使用 CSRF Token、验证 Referer 头 |
| XSS | 自动转义、CSP 策略、输入验证 |
| 点击劫持 | X-Frame-Options 头 |
| 中间人攻击 | 强制 HTTPS、HSTS |
