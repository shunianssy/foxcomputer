# 6.2 信号机制：事件驱动编程

Flask 信号允许你在特定事件发生时执行自定义代码，实现松耦合的事件驱动架构。

## 安装 Blinker

Flask 信号基于 Blinker 库：

```bash
pip install blinker
```

## 内置信号

Flask 提供了以下内置信号：

| 信号 | 触发时机 |
|------|----------|
| `request_started` | 请求开始时 |
| `request_finished` | 请求结束时 |
| `before_render_template` | 模板渲染前 |
| `template_rendered` | 模板渲染后 |
| `got_request_exception` | 请求发生异常时 |
| `appcontext_pushed` | 应用上下文推入时 |
| `appcontext_popped` | 应用上下文弹出时 |
| `appcontext_tearing_down` | 应用上下文销毁时 |
| `message_flashed` | flash 消息发送时 |

## 订阅信号

### 基本用法

```python
from flask import template_rendered
from flask.signals import request_started, request_finished

def log_template_render(sender, template, context, **extra):
 """记录模板渲染"""
 app.logger.info(f'渲染模板: {template.name}')

template_rendered.connect(log_template_render, app)

def log_request_start(sender, **extra):
 """记录请求开始"""
 app.logger.info(f'请求开始: {sender.request.path}')

request_started.connect(log_request_start, app)
```

### 使用装饰器

```python
from flask.signals import request_finished

@request_finished.connect_via(app)
def log_request_end(sender, response, **extra):
 """记录请求结束"""
 app.logger.info(f'请求结束: {response.status_code}')
```

## 自定义信号

### 定义信号

```python
from blinker import Namespace

# 创建命名空间
my_signals = Namespace()

# 定义信号
user_registered = my_signals.signal('user-registered')
user_logged_in = my_signals.signal('user-logged-in')
order_completed = my_signals.signal('order-completed')
```

### 发送信号

```python
@app.route('/register', methods=['POST'])
def register():
 user = User(username=form.username.data)
 db.session.add(user)
 db.session.commit()
 
 # 发送用户注册信号
 user_registered.send(
 app,
 user=user,
 timestamp=datetime.utcnow()
 )
 
 return '注册成功'

@app.route('/login', methods=['POST'])
def login():
 # ... 登录逻辑
 
 # 发送登录信号
 user_logged_in.send(
 app,
 user=user,
 ip=request.remote_addr
 )
 
 return redirect(url_for('index'))
```

### 订阅自定义信号

```python
@user_registered.connect
def on_user_registered(sender, user, **kwargs):
 """用户注册后的处理"""
 # 发送欢迎邮件
 send_welcome_email(user)
 
 # 记录日志
 app.logger.info(f'新用户注册: {user.username}')

@user_logged_in.connect
def on_user_logged_in(sender, user, ip, **kwargs):
 """用户登录后的处理"""
 # 记录登录日志
 LoginLog.create(user_id=user.id, ip=ip)
 
 # 检查异常登录
 if is_suspicious_ip(ip):
 send_security_alert(user, ip)
```

## 实际应用示例

### 邮件通知系统

```python
from blinker import Namespace

signals = Namespace()

# 定义信号
comment_added = signals.signal('comment-added')
post_published = signals.signal('post-published')

# 订阅者：发送通知邮件
@comment_added.connect
def notify_author(sender, comment, **kwargs):
 """通知文章作者有新评论"""
 post = comment.post
 if comment.author != post.author:
 send_email(
 to=post.author.email,
 subject=f'您的文章有新评论',
 body=f'{comment.author.username} 评论了您的文章: {post.title}'
 )

@comment_added.connect
def notify_mentioned_users(sender, comment, **kwargs):
 """通知被 @ 的用户"""
 mentioned = extract_mentions(comment.content)
 for username in mentioned:
 user = User.query.filter_by(username=username).first()
 if user:
 send_email(
 to=user.email,
 subject='有人提到了你',
 body=f'{comment.author.username} 在评论中提到了你'
 )

# 视图中发送信号
@app.route('/post/<int:id>/comment', methods=['POST'])
def add_comment(id):
 post = Post.query.get_or_404(id)
 comment = Comment(
 content=form.content.data,
 post=post,
 author=current_user
 )
 db.session.add(comment)
 db.session.commit()
 
 # 发送信号
 comment_added.send(app, comment=comment)
 
 return redirect(url_for('post', id=id))
```

### 活动日志

```python
from blinker import Namespace

signals = Namespace()
user_action = signals.signal('user-action')

@user_action.connect
def log_user_action(sender, user, action, target=None, **kwargs):
 """记录用户活动"""
 log = ActivityLog(
 user_id=user.id if user else None,
 action=action,
 target_type=target.__class__.__name__ if target else None,
 target_id=target.id if target else None,
 ip=request.remote_addr,
 user_agent=request.user_agent.string
 )
 db.session.add(log)
 db.session.commit()

# 使用装饰器简化
def log_action(action):
 def decorator(f):
 @wraps(f)
 def decorated(*args, **kwargs):
 result = f(*args, **kwargs)
 user_action.send(
 app,
 user=current_user if current_user.is_authenticated else None,
 action=action
 )
 return result
 return decorated
 return decorator

@app.route('/post/<int:id>/like')
@login_required
@log_action('like_post')
def like_post(id):
 # ... 点赞逻辑
 pass
```

### 缓存失效

```python
from blinker import Namespace

signals = Namespace()
cache_invalidate = signals.signal('cache-invalidate')

@cache_invalidate.connect
def clear_cache(sender, keys, **kwargs):
 """清除缓存"""
 cache = get_cache()
 for key in keys:
 cache.delete(key)

# 在模型中发送信号
class Post(db.Model):
 # ...
 
 def save(self):
 db.session.add(self)
 db.session.commit()
 
 # 清除相关缓存
 cache_invalidate.send(
 app,
 keys=[f'post:{self.id}', 'posts:latest', f'user:{self.author_id}:posts']
 )
```

## 信号的优缺点

### 优点

1. **松耦合**：发送者和接收者不需要相互了解
2. **可扩展**：可以随时添加新的订阅者
3. **可维护**：业务逻辑分离，代码更清晰

### 缺点

1. **调试困难**：信号处理分散，难以追踪执行流程
2. **性能影响**：每个信号都会遍历所有订阅者
3. **顺序不确定**：订阅者执行顺序不保证

## 最佳实践

```python
# 1. 使用命名空间组织信号
blog_signals = Namespace()
user_signals = Namespace()

# 2. 信号处理要轻量
@user_registered.connect
def on_user_registered(sender, user, **kwargs):
 # 使用异步任务处理耗时操作
 send_welcome_email.delay(user.id) # Celery 异步任务

# 3. 处理异常，避免影响主流程
@user_registered.connect
def on_user_registered(sender, user, **kwargs):
 try:
 send_welcome_email(user)
 except Exception as e:
 app.logger.error(f'发送欢迎邮件失败: {e}')

# 4. 使用弱引用避免内存泄漏
user_registered.connect(handler, weak=False)
```

## 小结

| 功能 | 代码 |
|------|------|
| 定义信号 | `signal = Namespace().signal('name')` |
| 发送信号 | `signal.send(sender, **kwargs)` |
| 订阅信号 | `signal.connect(handler)` |
| 装饰器订阅 | `@signal.connect` |

> **提示**：信号适用于松耦合的场景，如日志、通知、缓存等。对于核心业务逻辑，建议直接调用，以便于理解和调试。
