# 1.3 Hello World：你的第一行 Flask 代码

在项目文件夹下新建一个文件 `app.py`，填入以下内容：

```python
from flask import Flask

# 1. 初始化：创建一个 Flask 实例
app = Flask(__name__)

# 2. 路由：告诉 Flask 哪个 URL 触发哪个函数
@app.route('/')
def hello_world():
    # 3. 响应：返回给浏览器显示的内容
    return '<h1>Hello, Flask!</h1><p>这是我的第一个 Web 页面。</p>'

if __name__ == '__main__':
    app.run()
```

## 代码拆解

### `Flask(__name__)`

这是 Flask 的核心。它让程序知道在哪里寻找模板和静态文件。

- `__name__` 是 Python 的内置变量，表示当前模块的名称
- 如果直接运行此文件，`__name__` 的值是 `'__main__'`
- 如果作为模块导入，`__name__` 就是模块的实际名称

### `@app.route('/')`

这是一个装饰器。它把根路径（`/`）和 `hello_world` 函数绑定在一起。当用户访问网站首页时，Flask 就会调用这个函数。

路由装饰器的工作原理：

```python
# 这两行代码等价
@app.route('/')
def hello():
    return 'Hello'

# 等价于
def hello():
    return 'Hello'
hello = app.route('/')(hello)
```

### `app.run()`

启动内置的开发服务器。默认配置：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| host | '127.0.0.1' | 监听地址 |
| port | 5000 | 监听端口 |
| debug | False | 调试模式 |

## 更多路由示例

### 返回不同类型的内容

```python
from flask import Flask, jsonify

app = Flask(__name__)

# 返回 HTML
@app.route('/')
def index():
    return '<h1>首页</h1>'

# 返回 JSON
@app.route('/api/info')
def api_info():
    return jsonify({
        'name': 'Flask App',
        'version': '1.0.0'
    })

# 返回纯文本
@app.route('/text')
def text():
    return '这是一段纯文本', 200, {'Content-Type': 'text/plain; charset=utf-8'}

# 返回带状态码的响应
@app.route('/not-found')
def not_found():
    return '页面不存在', 404
```

### 多个路由指向同一函数

```python
@app.route('/')
@app.route('/home')
@app.route('/index')
def index():
    return '欢迎来到首页！'
```

## 运行应用

### 方式一：直接运行 Python 文件

```bash
python app.py
```

### 方式二：使用 Flask 命令行工具（推荐）

```bash
# 设置应用入口
# Windows
set FLASK_APP=app.py

# macOS / Linux
export FLASK_APP=app.py

# 运行
flask run
```

### 方式三：使用 python-dotenv（最推荐）

创建 `.env` 文件：

```env
FLASK_APP=app.py
FLASK_DEBUG=1
```

然后直接运行：

```bash
flask run
```

## 访问应用

启动成功后，你会看到类似输出：

```
 * Serving Flask app 'app.py'
 * Debug mode: off
 * Running on http://127.0.0.1:5000
```

打开浏览器访问 `http://127.0.0.1:5000`，你就能看到你的页面了！

### 常用访问地址

| 地址 | 说明 |
|------|------|
| `http://127.0.0.1:5000` | 本地回环地址 |
| `http://localhost:5000` | localhost 别名 |
| `http://0.0.0.0:5000` | 允许局域网访问 |

## 让局域网内其他设备访问

```python
if __name__ == '__main__':
    app.run(host='0.0.0.0', port=5000)
```

或者使用命令行：

```bash
flask run --host=0.0.0.0
```

> ⚠️ **注意**：确保防火墙允许该端口访问。

## 小结

一个最简单的 Flask 应用只需要：

1. 导入 Flask 类
2. 创建应用实例
3. 定义路由和视图函数
4. 运行应用

```python
from flask import Flask
app = Flask(__name__)

@app.route('/')
def hello():
    return 'Hello, World!'

if __name__ == '__main__':
    app.run()
```

> 💡 **提示**：`127.0.0.1` 是本地回环地址，只能在本机访问。`0.0.0.0` 表示监听所有网络接口，允许局域网访问。
