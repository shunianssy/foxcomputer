# 7.1 安全配置：密钥管理与安全头

安全是 Web 应用的基石，正确的安全配置能有效防止多种攻击。

## 密钥管理

```python
import os
from flask import Flask

app = Flask(__name__)

# 方式一：从环境变量读取（推荐）
app.config['SECRET_KEY'] = os.environ.get('SECRET_KEY')

# 方式二：从配置文件读取
app.config.from_pyfile('config.py')

# 方式三：生成随机密钥
import secrets
app.config['SECRET_KEY'] = secrets.token_hex(32)
```

## 安全响应头配置

```python
from flask_talisman import Talisman

app = Flask(__name__)

# 启用安全头
Talisman(app, 
    force_https=True,                    # 强制 HTTPS
    strict_transport_security=True,      # HSTS 头
    content_security_policy={            # CSP 策略
        'default-src': "'self'",
        'script-src': ["'self'", "https://cdn.jsdelivr.net"],
        'style-src': ["'self'", "https://fonts.googleapis.com"],
    },
    referrer_policy='strict-origin-when-cross-origin'  # Referrer 策略
)
```

## 手动设置安全头

```python
@app.after_request
def add_security_headers(response):
    # 防止点击劫持
    response.headers['X-Frame-Options'] = 'DENY'
    
    # 防止 MIME 类型嗅探
    response.headers['X-Content-Type-Options'] = 'nosniff'
    
    # XSS 保护
    response.headers['X-XSS-Protection'] = '1; mode=block'
    
    # 内容安全策略
    response.headers['Content-Security-Policy'] = "default-src 'self'"
    
    return response
```

## 敏感配置最佳实践

```python
# config.py - 不要提交到版本控制
class Config:
    SECRET_KEY = os.environ.get('SECRET_KEY') or 'dev-key-only'
    DATABASE_URL = os.environ.get('DATABASE_URL')
    
class ProductionConfig(Config):
    DEBUG = False
    # 生产环境必须设置环境变量
    SECRET_KEY = os.environ.get('SECRET_KEY')
    if not SECRET_KEY:
        raise ValueError("生产环境必须设置 SECRET_KEY 环境变量")

# .env 文件（不要提交）
SECRET_KEY=your-super-secret-key-here
DATABASE_URL=postgresql://user:pass@localhost/db
```

## 使用 python-dotenv 管理环境变量

```python
from dotenv import load_dotenv

load_dotenv()  # 加载 .env 文件

app.config['SECRET_KEY'] = os.environ.get('SECRET_KEY')
```
