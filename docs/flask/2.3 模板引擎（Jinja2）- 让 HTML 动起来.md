# 2.3 模板引擎（Jinja2）：让 HTML 动起来

在 Python 代码里写 HTML 字符串简直是噩梦。Flask 默认集成了 Jinja2 模板引擎，让你能把逻辑和页面分开。

## 1. 创建模板文件夹

在项目根目录下创建一个 `templates` 文件夹。

## 2. 创建 HTML 模板

新建 `templates/index.html`：

```jinja2
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>{{ title }}</title>
</head>
<body>
    <h1>你好, {{ name }}!</h1>
    
    <ul>
    {% for item in items %}
        <li>{{ item }}</li>
    {% endfor %}
    </ul>
</body>
</html>
```

## 3. 在 Flask 中渲染模板

在 `app.py` 中渲染它：

```python
from flask import Flask, render_template

app = Flask(__name__)

@app.route('/')
def index():
    my_items = ['Python', 'Flask', 'Jinja2']
    return render_template('index.html', 
                          title='首页',
                          name='开发者', 
                          items=my_items)
```

## 4. Jinja2 语法要点

::: v-pre
| 语法 | 说明 | 示例 |
|------|------|------|
| `{{ ... }}` | 变量占位（打印输出） | `{{ name }}` |
| `{% ... %}` | 控制流（if、for 等） | `{% for item in items %}` |
| `{# ... #}` | 模板注释 | `{# 这是注释 #}` |
:::

## 5. 变量与表达式

### 基本变量

```jinja2
<p>用户名: {{ user.name }}</p>
<p>邮箱: {{ user['email'] }}</p>
<p>年龄: {{ user.age or '未设置' }}</p>
```

### 数学运算

```jinja2
<p>价格: {{ price * 1.1 }}</p>
<p>总数: {{ items|length }}</p>
<p>求和: {{ 1 + 2 + 3 }}</p>
```

### 字符串操作

```jinja2
<p>拼接: {{ 'Hello ' ~ name }}</p>
<p>包含: {{ 'flask' in tags }}</p>
```

## 6. 控制结构

### 条件判断

```html
{% if user %}
    <p>欢迎, {{ user.name }}!</p>
{% elif guest %}
    <p>欢迎, 游客!</p>
{% else %}
    <p>请先登录</p>
{% endif %}
```

### 循环

```html
<ul>
{% for item in items %}
    <li>{{ loop.index }}. {{ item }}</li>
{% endfor %}
</ul>
```

### 循环变量

| 变量 | 说明 |
|------|------|
| `loop.index` | 当前迭代索引（从 1 开始） |
| `loop.index0` | 当前迭代索引（从 0 开始） |
| `loop.first` | 是否为第一次迭代 |
| `loop.last` | 是否为最后一次迭代 |
| `loop.length` | 序列长度 |
| `loop.cycle` | 在值之间循环 |

```jinja2
{% for item in items %}
    <li class="{{ loop.cycle('odd', 'even') }}">
        {{ loop.index }}. {{ item }}
    </li>
{% endfor %}
```

### 循环与条件结合

```jinja2
{% for user in users %}
    {% if loop.first %}
        <li class="first">{{ user.name }}</li>
    {% elif loop.last %}
        <li class="last">{{ user.name }}</li>
    {% else %}
        <li>{{ user.name }}</li>
    {% endif %}
{% else %}
    <li>没有用户数据</li>
{% endfor %}
```

## 7. 过滤器

过滤器用于修改变量的显示方式。

### 常用过滤器

```jinja2
<!-- 字符串处理 -->
<p>大写: {{ name|upper }}</p>
<p>小写: {{ name|lower }}</p>
<p>首字母大写: {{ name|capitalize }}</p>
<p>标题格式: {{ title|title }}</p>
<p>去除空白: {{ text|trim }}</p>

<!-- 截取 -->
<p>截取前 10 字符: {{ text|truncate(10) }}</p>
<p>截取单词: {{ text|wordwrap(5) }}</p>

<!-- 默认值 -->
<p>默认值: {{ value|default('未设置') }}</p>

<!-- 类型转换 -->
<p>转整数: {{ num|int }}</p>
<p>转浮点: {{ num|float }}</p>
<p>转字符串: {{ num|string }}</p>

<!-- 列表操作 -->
<p>长度: {{ items|length }}</p>
<p>第一个: {{ items|first }}</p>
<p>最后一个: {{ items|last }}</p>
<p>排序: {{ items|sort }}</p>
<p>反转: {{ items|reverse }}</p>
<p>连接: {{ items|join(', ') }}</p>

<!-- 安全输出 -->
<p>不转义: {{ html|safe }}</p>
<p>转义: {{ html|e }}</p>
```

### 链式过滤器

```jinja2
<p>{{ items|sort|reverse|join(' | ') }}</p>
<p>{{ name|trim|capitalize }}</p>
```

### 自定义过滤器

```python
@app.template_filter('reverse')
def reverse_filter(s):
    return s[::-1]

# 在模板中使用
# {{ name|reverse }}
```

## 8. 模板继承

### 基础模板 `base.html`

```jinja2
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>{% block title %}默认标题{% endblock %}</title>
    {% block head %}{% endblock %}
</head>
<body>
    <header>
        {% block header %}
        <nav>
            <a href="/">首页</a>
            <a href="/about">关于</a>
        </nav>
        {% endblock %}
    </header>
    
    <main>
        {% block content %}{% endblock %}
    </main>
    
    <footer>
        {% block footer %}
        <p>&copy; 2024 我的网站</p>
        {% endblock %}
    </footer>
    
    {% block scripts %}{% endblock %}
</body>
</html>
```

### 子模板 `index.html`

```jinja2
{% extends "base.html" %}

{% block title %}首页{% endblock %}

{% block head %}
    <link rel="stylesheet" href="{{ url_for('static', filename='css/index.css') }}">
{% endblock %}

{% block content %}
    <h1>欢迎来到首页</h1>
    <p>这是首页的特有内容。</p>
{% endblock %}

{% block scripts %}
    <script src="{{ url_for('static', filename='js/index.js') }}"></script>
{% endblock %}
```

### super() 函数

保留父模板的内容：

```jinja2
{% block head %}
    {{ super() }}
    <link rel="stylesheet" href="{{ url_for('static', filename='css/custom.css') }}">
{% endblock %}
```

## 9. 宏（Macros）

宏类似于函数，可以复用模板代码。

### 定义宏

```jinja2
<!-- macros.html -->
{% macro input(name, value='', type='text', placeholder='') %}
    <input type="{{ type }}" 
           name="{{ name }}" 
           value="{{ value }}" 
           placeholder="{{ placeholder }}">
{% endmacro %}

{% macro form_field(label, name, value='', type='text') %}
    <div class="form-group">
        <label>{{ label }}</label>
        {{ input(name, value, type) }}
    </div>
{% endmacro %}
```

### 使用宏

```jinja2
{% from "macros.html" import input, form_field %}

<form>
    {{ form_field('用户名', 'username', placeholder='请输入用户名') }}
    {{ form_field('密码', 'password', type='password') }}
    {{ input('remember', type='checkbox') }}
</form>
```

## 10. 包含（Include）

将其他模板包含到当前模板：

```jinja2
<!-- templates/components/navbar.html -->
<nav>
    <a href="/">首页</a>
    <a href="/about">关于</a>
</nav>

<!-- 在其他模板中包含 -->
<body>
    {% include 'components/navbar.html' %}
    
    <main>
        {% block content %}{% endblock %}
    </main>
</body>
```

### 忽略包含错误

```jinja2
{% include 'missing.html' ignore missing %}
```

## 11. 全局变量与上下文

### 传递全局变量

```python
@app.context_processor
def inject_user():
    return dict(user=current_user)
```

所有模板都可以访问 `user` 变量。

### 自定义全局函数

```python
@app.context_processor
def utility_processor():
    def format_price(amount):
        return f"¥{amount:.2f}"
    return dict(format_price=format_price)
```

在模板中使用：

```jinja2
<p>价格: {{ format_price(99.9) }}</p>
```

## 小结

| 功能 | 语法 |
|------|------|
| 变量输出 | `{{ variable }}` |
| 条件判断 | `{% if %}...{% endif %}` |
| 循环 | `{% for %}...{% endfor %}` |
| 过滤器 | `{{ variable\|filter }}` |
| 模板继承 | `{% extends "base.html" %}` |
| 定义块 | `{% block name %}...{% endblock %}` |
| 包含模板 | `{% include "file.html" %}` |
| 宏定义 | `{% macro name() %}...{% endmacro %}` |

> **提示**：将重复使用的模板代码抽取为宏或组件
