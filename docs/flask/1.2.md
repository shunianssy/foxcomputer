# 1.2 环境准备：搭建你的实验室

为了不让不同项目的依赖包打架，我们必须使用虚拟环境（Virtual Environment）

## 1. 创建项目文件夹

在终端（Terminal/PowerShell）执行：

```bash
mkdir my_flask_app
cd my_flask_app
```

## 2. 创建并激活虚拟环境

### Windows:

```bash
python -m venv venv
venv\Scripts\activate
```

### macOS / Linux:

```bash
python3 -m venv venv
source venv/bin/activate
```

激活成功后，终端前面会显示 `(venv)` 标识。

## 3. 安装 Flask

```bash
pip install flask
```

### 验证安装

```bash
# 查看 Flask 版本
python -c "import flask; print(flask.__version__)"

# 或者使用 flask 命令
flask --version
```

输出示例：
```
Python 3.11.0
Flask 3.0.0
Werkzeug 3.0.0
```

## 4. 项目结构初始化

一个标准的 Flask 项目结构如下：

```bash
my_flask_app/
├── venv/                 # 虚拟环境（不要修改）
├── app.py               # 主应用入口
├── templates/           # HTML 模板文件夹
│   └── index.html
├── static/              # 静态资源文件夹
│   ├── css/
│   ├── js/
│   └── img/
├── requirements.txt     # 依赖清单
└── .env                 # 环境变量配置（可选）
```

### 创建基础目录

```bash
# Windows
mkdir templates
mkdir static\css static\js static\img

# macOS / Linux
mkdir -p templates static/{css,js,img}
```

### 创建 requirements.txt

```bash
pip freeze > requirements.txt
```

这样其他人只需要运行 `pip install -r requirements.txt` 就能安装所有依赖。

## 5. 环境变量配置（推荐）

使用 `python-dotenv` 管理环境变量：

```bash
pip install python-dotenv
```

创建 `.env` 文件：

```env
FLASK_APP=app.py
FLASK_DEBUG=1
SECRET_KEY=your-secret-key-here
```

## 6. 常见问题排查

### 问题 1：`python` 命令找不到

**解决方案**：
- Windows：确保 Python 已添加到 PATH 环境变量
- macOS/Linux：使用 `python3` 代替 `python`

### 问题 2：虚拟环境激活失败

**Windows PowerShell 执行策略限制**：

```powershell
# 临时允许运行脚本
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process
```

### 问题 3：pip 安装速度慢

**使用国内镜像源**：

```bash
# 临时使用
pip install flask -i https://pypi.tuna.tsinghua.edu.cn/simple

# 永久配置
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
```

### 问题 4：依赖冲突

**解决方案**：确保在虚拟环境中操作，退出后重新激活：

```bash
# 退出虚拟环境
deactivate

# 重新激活
venv\Scripts\activate  # Windows
source venv/bin/activate  # macOS/Linux
```

## 7. IDE 配置建议

### VS Code 推荐扩展

- **Python**：Microsoft 官方 Python 扩展
- **Pylance**：类型检查和智能提示
- **Flask-Snippets**：Flask 代码片段
- **Jinja2**：模板语法高亮

### PyCharm 配置

1. 打开 `Settings` → `Project` → `Python Interpreter`
2. 添加虚拟环境中的 Python 解释器
3. 路径：`项目目录/venv/Scripts/python.exe`（Windows）

## 小结

环境准备完成后，你应该有：

- ✅ Python 环境（建议 3.8+）
- ✅ 虚拟环境已激活
- ✅ Flask 已安装
- ✅ 项目目录结构已创建
- ✅ requirements.txt 已生成

> ⚠️ **注意**：永远不要把 `venv/` 文件夹提交到版本控制系统。确保 `.gitignore` 包含 `venv/` 或 `.venv/`。
