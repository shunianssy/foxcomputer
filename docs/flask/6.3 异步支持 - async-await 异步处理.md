# 6.3 异步支持：async/await 异步处理

Flask 2.0+ 原生支持异步视图函数，让你可以使用 Python 的 async/await 语法处理异步操作。

## 基本用法

### 异步视图函数

```python
from flask import Flask

app = Flask(__name__)

@app.route('/async')
async def async_view():
 # 异步操作
 result = await fetch_data()
 return {'result': result}

async def fetch_data():
 # 模拟异步操作
 import asyncio
 await asyncio.sleep(1)
 return 'data'
```

### 异步数据库查询

```python
from sqlalchemy.ext.asyncio import create_async_engine, AsyncSession
from sqlalchemy.orm import sessionmaker

# 异步数据库引擎
engine = create_async_engine('postgresql+asyncpg://user:pass@localhost/db')
async_session = sessionmaker(engine, class_=AsyncSession)

@app.route('/users/<int:id>')
async def get_user(id):
 async with async_session() as session:
 result = await session.get(User, id)
 return result.to_dict()
```

### 异步 HTTP 请求

```python
import httpx

@app.route('/api/proxy')
async def proxy_request():
 async with httpx.AsyncClient() as client:
 response = await client.get('https://api.example.com/data')
 return response.json()
```

## 并发执行

### asyncio.gather

```python
import asyncio
import httpx

@app.route('/api/aggregated')
async def aggregated_data():
 async with httpx.AsyncClient() as client:
 # 并发请求多个 API
 results = await asyncio.gather(
 client.get('https://api.example.com/users'),
 client.get('https://api.example.com/posts'),
 client.get('https://api.example.com/comments')
 )
 
 return {
 'users': results[0].json(),
 'posts': results[1].json(),
 'comments': results[2].json()
 }
```

### asyncio.create_task

```python
@app.route('/send-notification')
async def send_notification():
 # 创建后台任务（不等待完成）
 asyncio.create_task(send_email_async())
 
 return {'status': 'notification queued'}

async def send_email_async():
 # 异步发送邮件
 await asyncio.sleep(2)
 # 发送邮件逻辑
```

## 异步后台任务

### 使用 BackgroundTasks

```python
from starlette.background import BackgroundTasks

@app.route('/process')
async def process():
 tasks = BackgroundTasks()
 tasks.add_task(send_email, 'user@example.com', '处理完成')
 
 return {'status': 'processing'}, background=tasks
```

### 异步 Celery 任务

```python
from celery import Celery

celery = Celery('tasks', broker='redis://localhost:6379/0')

@celery.task
def process_data(data_id):
 # 耗时处理
 pass

@app.route('/process/<int:id>')
async def start_process(id):
 # 异步启动 Celery 任务
 process_data.delay(id)
 return {'status': 'started'}
```

@app.before_request
async def async_before_request():

## 性能对比

```python
import time
import asyncio
import httpx

# 同步版本
@app.route('/sync-fetch')
def sync_fetch():
 start = time.time()
 
 with httpx.Client() as client:
 results = [
 client.get(f'https://api.example.com/item/{i}').json()
 for i in range(10)
 ]
 
 return {
 'count': len(results),
 'time': time.time() - start
 }

# 异步版本
@app.route('/async-fetch')
async def async_fetch():
 start = time.time()
 
 async with httpx.AsyncClient() as client:
 tasks = [
 client.get(f'https://api.example.com/item/{i}')
 for i in range(10)
 ]
 responses = await asyncio.gather(*tasks)
 results = [r.json() for r in responses]
 
 return {
 'count': len(results),
 'time': time.time() - start
 }
```

## 注意事项

### WSGI vs ASGI

Flask 默认使用 WSGI 服务器，异步视图会在线程池中执行。要获得真正的异步性能，需要使用 ASGI 服务器：

```bash
# 使用 Hypercorn（ASGI 服务器）
pip install hypercorn
hypercorn app:app

# 使用 Uvicorn
pip install uvicorn
uvicorn app:app
```

### 避免混用

```python
# 不要在同步函数中直接调用异步函数
def sync_view():
 result = await async_function() # 错误！

# 正确做法
async def async_view():
 result = await async_function() # 正确

# 或者在同步函数中运行事件循环
def sync_view():
 import asyncio
 result = asyncio.run(async_function())
```

## 小结

| 功能 | 代码 |
|------|------|
| 异步视图 | `async def view():` |
| 等待异步操作 | `await async_function()` |
| 并发执行 | `await asyncio.gather(*tasks)` |
| 后台任务 | `asyncio.create_task(task())` |

> **提示**：异步编程适合 I/O 密集型操作（如 HTTP 请求、数据库查询）。对于 CPU 密集型任务，应使用进程池或消息队列。
