# Flask 完整教程

## 📖 教程简介

Flask 是一个轻量级的 Python Web 框架，以其简洁、灵活而著称。本教程从零开始，带你全面掌握 Flask 开发的方方面面。

## 🎯 学习目标

- 理解 Flask 的核心概念和设计哲学
- 掌握路由、模板、数据库等基础功能
- 学会使用蓝图组织大型项目
- 了解 RESTful API 开发
- 掌握部署和安全最佳实践

## 💡 学习建议

1. **循序渐进**：按照章节顺序学习，每章都有示例代码
2. **动手实践**：边学边写代码，加深理解
3. **阅读源码**：遇到问题时，Flask 源码是最好的老师
4. **项目驱动**：尝试用 Flask 做一个小项目巩固知识
