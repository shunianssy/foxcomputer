# 9.4 Flask-Migrate：数据库迁移

Flask-Migrate 是 SQLAlchemy 的数据库迁移工具，帮助你管理数据库模式的变更。

## 安装

```bash
pip install flask-migrate
```

## 基本配置

```python
from flask import Flask
from flask_sqlalchemy import SQLAlchemy
from flask_migrate import Migrate

app = Flask(__name__)
app.config['SQLALCHEMY_DATABASE_URI'] = 'sqlite:///app.db'

db = SQLAlchemy(app)
migrate = Migrate(app, db)

# 定义模型
class User(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    username = db.Column(db.String(80), unique=True)
    email = db.Column(db.String(120), unique=True)

class Post(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    title = db.Column(db.String(100))
    content = db.Column(db.Text)
    user_id = db.Column(db.Integer, db.ForeignKey('user.id'))
```

## 初始化迁移

```bash
# 初始化迁移目录
flask db init

# 这会创建 migrations 目录：
# migrations/
# ├── versions/        # 存放迁移脚本
# ├── alembic.ini      # Alembic 配置
# ├── env.py           # 迁移环境配置
# └── script.py.mako   # 迁移脚本模板
```

## 创建迁移

```bash
# 自动生成迁移脚本（检测模型变更）
flask db migrate -m "添加用户表"

# 这会在 migrations/versions/ 下生成迁移文件
# 如：20240101_123456_添加用户表.py
```

## 应用迁移

```bash
# 应用最新迁移
flask db upgrade

# 迁移到指定版本
flask db upgrade <revision>

# 回滚到上一版本
flask db downgrade

# 回滚到指定版本
flask db downgrade <revision>
```

## 查看迁移状态

```bash
# 查看当前迁移版本
flask db current

# 查看迁移历史
flask db history
```

## 迁移脚本示例

```python
# migrations/versions/20240101_add_user_table.py
"""添加用户表

Revision ID: abc123
Revises: 
Create Date: 2024-01-01 10:00:00
"""
from alembic import op
import sqlalchemy as sa

# revision identifiers
revision = 'abc123'
down_revision = None
branch_labels = None
depends_on = None

def upgrade():
    # 创建用户表
    op.create_table(
        'user',
        sa.Column('id', sa.Integer(), nullable=False),
        sa.Column('username', sa.String(length=80), nullable=True),
        sa.Column('email', sa.String(length=120), nullable=True),
        sa.PrimaryKeyConstraint('id'),
        sa.UniqueConstraint('username'),
        sa.UniqueConstraint('email')
    )

def downgrade():
    # 删除用户表
    op.drop_table('user')
```

## 常见迁移操作

```python
def upgrade():
    # 添加列
    op.add_column('user', sa.Column('age', sa.Integer()))
    
    # 删除列
    op.drop_column('user', 'age')
    
    # 修改列
    op.alter_column('user', 'username',
        existing_type=sa.String(80),
        type_=sa.String(100),
        existing_nullable=True
    )
    
    # 创建索引
    op.create_index('idx_user_email', 'user', ['email'])
    
    # 删除索引
    op.drop_index('idx_user_email', 'user')
    
    # 添加外键
    op.create_foreign_key('fk_post_user', 'post', 'user', ['user_id'], ['id'])
```

## 生产环境迁移流程

```bash
# 1. 开发环境测试迁移
flask db migrate -m "添加新字段"
flask db upgrade

# 2. 检查生成的迁移脚本
cat migrations/versions/xxx_添加新字段.py

# 3. 提交迁移脚本到版本控制
git add migrations/
git commit -m "添加数据库迁移"

# 4. 生产环境执行迁移
flask db upgrade
```

## 迁移最佳实践

| 实践 | 说明 |
|------|------|
| 每次变更都迁移 | 不要手动修改数据库 |
| 检查迁移脚本 | 自动生成可能不完美 |
| 备份数据库 | 迁移前先备份 |
| 测试回滚 | 确保 downgrade 正确 |
| 版本控制 | 迁移脚本纳入 Git |
