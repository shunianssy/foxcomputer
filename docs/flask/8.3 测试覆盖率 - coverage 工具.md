# 8.3 测试覆盖率：coverage 工具

测试覆盖率衡量代码被测试覆盖的程度，帮助发现未测试的代码路径。

## 安装 coverage

```bash
pip install coverage pytest-cov
```

## 使用 pytest-cov

```bash
# 运行测试并显示覆盖率
pytest --cov=app tests/

# 显示缺失覆盖的行号
pytest --cov=app --cov-report=term-missing tests/

# 生成 HTML 报告
pytest --cov=app --cov-report=html tests/

# 同时生成多种报告
pytest --cov=app --cov-report=term --cov-report=html tests/
```

## 配置覆盖率

在 `pyproject.toml` 或 `.coveragerc` 中配置：

```toml
# pyproject.toml
[tool.coverage.run]
source = ["app"]
omit = [
    "app/__init__.py",
    "app/config.py",
    "*/tests/*",
]

[tool.coverage.report]
exclude_lines = [
    "pragma: no cover",
    "def __repr__",
    "raise NotImplementedError",
    "if __name__ == .__main__.:",
]
fail_under = 80  # 覆盖率低于 80% 则失败
```

## 使用 coverage 命令行

```bash
# 收集覆盖率数据
coverage run -m pytest

# 生成报告
coverage report

# 生成 HTML 报告
coverage html

# 查看特定文件的覆盖情况
coverage report -m app/routes.py
```

## 跳过特定代码覆盖

```python
def debug_function():
    if False:  # pragma: no cover
        # 这段代码不会被覆盖检查
        print("调试信息")

def get_platform():
    if sys.platform == 'win32':  # pragma: no cover
        return "Windows"
    elif sys.platform == 'darwin':  # pragma: no cover
        return "macOS"
    else:
        return "Linux"
```

## CI/CD 集成覆盖率检查

```yaml
# .github/workflows/test.yml
name: Tests

on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: actions/setup-python@v4
        with:
          python-version: '3.11'
      - run: pip install -r requirements.txt
      - run: pip install pytest pytest-cov
      - name: Run tests with coverage
        run: pytest --cov=app --cov-fail-under=80 tests/
```

## 覆盖率目标

| 项目类型 | 建议覆盖率 |
|---------|-----------|
| 关键业务逻辑 | 90%+ |
| 一般应用 | 80%+ |
| 工具脚本 | 70%+ |

> 注意：高覆盖率不等于高质量测试，确保测试覆盖边界情况和异常路径。
