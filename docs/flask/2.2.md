# 2.2 HTTP 方法：处理 GET 和 POST

默认情况下，路由只响应 GET 请求。如果你要处理表单提交，就需要开启 POST。

## GET 与 POST 的区别

| 特性 | GET | POST |
|------|-----|------|
| 数据位置 | URL 参数 | 请求体 |
| 数据长度 | 有限制 | 无限制 |
| 安全性 | 参数可见 | 参数不可见 |
| 缓存 | 可被缓存 | 不缓存 |
| 用途 | 获取数据 | 提交数据 |

## 处理 GET 和 POST

```python
from flask import Flask, request

app = Flask(__name__)

@app.route('/login', methods=['GET', 'POST'])
def login():
    if request.method == 'POST':
        # 处理登录表单提交
        username = request.form.get('username')
        password = request.form.get('password')
        return f'正在登录: {username}'
    # 显示登录页面
    return '''
        <form method="post">
            <input name="username" placeholder="用户名">
            <input name="password" type="password" placeholder="密码">
            <button type="submit">登录</button>
        </form>
    '''
```

## 获取请求数据

### GET 参数（查询字符串）

```python
@app.route('/search')
def search():
    # 获取单个参数
    keyword = request.args.get('q')
    # 获取参数，带默认值
    page = request.args.get('page', '1', type=int)
    # 获取所有参数
    all_args = request.args.to_dict()
    
    return f'搜索关键词: {keyword}, 页码: {page}'
```

访问 `http://localhost:5000/search?q=flask&page=2`

```python
from flask import jsonify
```

### 文件上传

```python
import os
from werkzeug.utils import secure_filename

UPLOAD_FOLDER = 'uploads'
ALLOWED_EXTENSIONS = {'txt', 'pdf', 'png', 'jpg', 'jpeg', 'gif'}

app.config['UPLOAD_FOLDER'] = UPLOAD_FOLDER

def allowed_file(filename):
    return '.' in filename and \
           filename.rsplit('.', 1)[1].lower() in ALLOWED_EXTENSIONS

@app.route('/upload', methods=['POST'])
def upload_file():
    if 'file' not in request.files:
        return '没有选择文件'
    
    file = request.files['file']
    
    if file.filename == '':
        return '没有选择文件'
    
    if file and allowed_file(file.filename):
        # 安全地获取文件名
        filename = secure_filename(file.filename)
        # 保存文件
        file.save(os.path.join(app.config['UPLOAD_FOLDER'], filename))
        return '文件上传成功'
    
    return '不支持的文件类型'
```

## RESTful API 示例

```python
from flask import Flask, request, jsonify

app = Flask(__name__)

# 模拟数据库
users = {
    1: {'id': 1, 'name': 'Alice', 'email': 'alice@example.com'},
    2: {'id': 2, 'name': 'Bob', 'email': 'bob@example.com'},
}

# 获取用户列表
@app.route('/api/users', methods=['GET'])
def get_users():
    return jsonify(list(users.values()))

# 获取单个用户
@app.route('/api/users/<int:user_id>', methods=['GET'])
def get_user(user_id):
    user = users.get(user_id)
    if user:
        return jsonify(user)
    return jsonify({'error': '用户不存在'}), 404

# 创建用户
@app.route('/api/users', methods=['POST'])
def create_user():
    data = request.get_json()
    user_id = max(users.keys()) + 1
    user = {
        'id': user_id,
        'name': data['name'],
        'email': data['email']
    }
    users[user_id] = user
    return jsonify(user), 201

# 更新用户
@app.route('/api/users/<int:user_id>', methods=['PUT'])
def update_user(user_id):
    if user_id not in users:
        return jsonify({'error': '用户不存在'}), 404
    
    data = request.get_json()
    users[user_id].update(data)
    return jsonify(users[user_id])

# 删除用户
@app.route('/api/users/<int:user_id>', methods=['DELETE'])
def delete_user(user_id):
    if user_id not in users:
        return jsonify({'error': '用户不存在'}), 404
    
    del users[user_id]
    return '', 204
```

## HTTP 状态码

| 状态码 | 说明 | 使用场景 |
|--------|------|----------|
| 200 | OK | 请求成功 |
| 201 | Created | 资源创建成功 |
| 204 | No Content | 删除成功（无返回内容） |
| 400 | Bad Request | 请求参数错误 |
| 401 | Unauthorized | 未认证 |
| 403 | Forbidden | 无权限 |
| 404 | Not Found | 资源不存在 |
| 500 | Internal Server Error | 服务器错误 |

## 小结

| 功能 | 代码 |
|------|------|
| 获取 GET 参数 | `request.args.get('key')` |
| 获取 POST 表单 | `request.form.get('key')` |
| 获取 JSON | `request.get_json()` |
| 获取文件 | `request.files['file']` |
| 返回 JSON | `jsonify(data)` |
| 返回状态码 | `return data, 404` |

> 💡 **提示**：对于 API 开发，建议统一使用 JSON 格式进行数据交互，并遵循 RESTful 设计规范。
