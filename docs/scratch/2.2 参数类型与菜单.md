# 2.2 参数类型与菜单

Scratch 扩展支持多种参数类型，可以为积木块添加丰富的输入选项。

## 参数类型概览

| 类型 | 英文名 | 用途 | 示例 |
|-----|-------|-----|-----|
| 数字 | NUMBER | 数值输入 | 移动 10 步 |
| 字符串 | STRING | 文本输入 | 说 "你好" |
| 布尔 | BOOLEAN | 布尔值输入 | 如果 <条件> |
| 角度 | ANGLE | 角度选择 | 旋转 90 度 |
| 颜色 | COLOR | 颜色选择 | 设置颜色 |
| 矩阵 | MATRIX | LED 矩阵 | 显示图案 |
| 笔记 | NOTE | 音符选择 | 演奏音符 |

## 基本参数类型

### 数字类型 (NUMBER)

```javascript
{
    opcode: 'moveSteps',
    blockType: Scratch.BlockType.COMMAND,
    text: '移动 [STEPS] 步',
    arguments: {
        STEPS: {
            type: Scratch.ArgumentType.NUMBER,
            defaultValue: 10
        }
    }
}

// 实现方法
moveSteps(args) {
    // 转换为数字，处理非法输入
    const steps = Number(args.STEPS) || 0;
    console.log(`移动 ${steps} 步`);
}
```

### 字符串类型 (STRING)

```javascript
{
    opcode: 'sayText',
    blockType: Scratch.BlockType.COMMAND,
    text: '说 [TEXT]',
    arguments: {
        TEXT: {
            type: Scratch.ArgumentType.STRING,
            defaultValue: '你好！'
        }
    }
}

// 实现方法
sayText(args) {
    // 转换为字符串
    const text = String(args.TEXT);
    console.log(`说: ${text}`);
}
```

### 布尔类型 (BOOLEAN)

```javascript
{
    opcode: 'ifCondition',
    blockType: Scratch.BlockType.CONDITIONAL,
    text: '如果 [CONDITION]',
    arguments: {
        CONDITION: {
            type: Scratch.ArgumentType.BOOLEAN
        }
    }
}

// 实现方法
ifCondition(args) {
    // 转换为布尔值
    return Boolean(args.CONDITION);
}
```

## 特殊参数类型

### 角度类型 (ANGLE)

```javascript
{
    opcode: 'turnAngle',
    blockType: Scratch.BlockType.COMMAND,
    text: '旋转 [ANGLE] 度',
    arguments: {
        ANGLE: {
            type: Scratch.ArgumentType.ANGLE,
            defaultValue: 90
        }
    }
}

// 实现方法
turnAngle(args) {
    // 规范化角度到 0-360 范围
    let angle = Number(args.ANGLE) || 0;
    angle = ((angle % 360) + 360) % 360;
    console.log(`旋转 ${angle} 度`);
}
```

### 颜色类型 (COLOR)

```javascript
{
    opcode: 'setColor',
    blockType: Scratch.BlockType.COMMAND,
    text: '设置颜色为 [COLOR]',
    arguments: {
        COLOR: {
            type: Scratch.ArgumentType.COLOR,
            defaultValue: '#ff0000'
        }
    }
}

// 实现方法
setColor(args) {
    // 颜色值为十六进制字符串
    const color = args.COLOR || '#000000';
    console.log(`设置颜色: ${color}`);
    
    // 解析颜色值
    const r = parseInt(color.slice(1, 3), 16);
    const g = parseInt(color.slice(3, 5), 16);
    const b = parseInt(color.slice(5, 7), 16);
    console.log(`RGB: (${r}, ${g}, ${b})`);
}
```

### 矩阵类型 (MATRIX)

```javascript
{
    opcode: 'displayPattern',
    blockType: Scratch.BlockType.COMMAND,
    text: '显示图案 [PATTERN]',
    arguments: {
        PATTERN: {
            type: Scratch.ArgumentType.MATRIX,
            defaultValue: '01010101011000101010001010101010'
        }
    }
}

// 实现方法
displayPattern(args) {
    // 矩阵值为二进制字符串
    const pattern = args.PATTERN || '0'.repeat(25);
    
    // 解析 5x5 矩阵
    for (let y = 0; y < 5; y++) {
        let row = '';
        for (let x = 0; x < 5; x++) {
            const index = y * 5 + x;
            row += pattern[index] === '1' ? '■' : '□';
        }
        console.log(row);
    }
}
```

### 音符类型 (NOTE)

```javascript
{
    opcode: 'playNote',
    blockType: Scratch.BlockType.COMMAND,
    text: '演奏音符 [NOTE] 持续 [DURATION] 拍',
    arguments: {
        NOTE: {
            type: Scratch.ArgumentType.NOTE,
            defaultValue: 60  // MIDI 音符编号 (中央 C)
        },
        DURATION: {
            type: Scratch.ArgumentType.NUMBER,
            defaultValue: 0.5
        }
    }
}

// 实现方法
playNote(args) {
    // 音符值为 MIDI 音符编号 (0-127)
    const note = Math.max(0, Math.min(127, Number(args.NOTE) || 60));
    const duration = Number(args.DURATION) || 0.5;
    
    // MIDI 音符转频率
    const frequency = 440 * Math.pow(2, (note - 69) / 12);
    console.log(`演奏音符 ${note} (${frequency.toFixed(2)} Hz)`);
}
```

## 下拉菜单

### 静态菜单

```javascript
class MenuExtension {
    getInfo() {
        return {
            id: 'menuExt',
            name: '菜单示例',
            color1: '#4C97FF',
            blocks: [
                {
                    opcode: 'setDirection',
                    blockType: Scratch.BlockType.COMMAND,
                    text: '朝向 [DIRECTION]',
                    arguments: {
                        DIRECTION: {
                            type: Scratch.ArgumentType.STRING,
                            menu: 'directions',  // 菜单 ID
                            defaultValue: 'right'
                        }
                    }
                },
                {
                    opcode: 'selectColor',
                    blockType: Scratch.BlockType.COMMAND,
                    text: '选择颜色 [COLOR]',
                    arguments: {
                        COLOR: {
                            type: Scratch.ArgumentType.STRING,
                            menu: 'colors',
                            defaultValue: 'red'
                        }
                    }
                }
            ],
            // 菜单定义
            menus: {
                // 方向菜单
                directions: [
                    { text: '右', value: 'right' },
                    { text: '左', value: 'left' },
                    { text: '上', value: 'up' },
                    { text: '下', value: 'down' }
                ],
                // 颜色菜单
                colors: [
                    { text: '红色', value: 'red' },
                    { text: '绿色', value: 'green' },
                    { text: '蓝色', value: 'blue' },
                    { text: '黄色', value: 'yellow' }
                ]
            }
        };
    }

    setDirection(args) {
        const direction = args.DIRECTION;
        console.log(`朝向: ${direction}`);
    }

    selectColor(args) {
        const color = args.COLOR;
        console.log(`选择颜色: ${color}`);
    }
}
```

### 动态菜单

```javascript
class DynamicMenuExtension {
    constructor() {
        this.items = ['项目1', '项目2', '项目3'];
    }

    getInfo() {
        return {
            id: 'dynamicMenuExt',
            name: '动态菜单',
            color1: '#4C97FF',
            blocks: [
                {
                    opcode: 'selectItem',
                    blockType: Scratch.BlockType.COMMAND,
                    text: '选择 [ITEM]',
                    arguments: {
                        ITEM: {
                            type: Scratch.ArgumentType.STRING,
                            menu: 'dynamicItems',
                            defaultValue: this.items[0]
                        }
                    }
                },
                {
                    opcode: 'addItem',
                    blockType: Scratch.BlockType.COMMAND,
                    text: '添加项目 [NAME]'
                }
            ],
            menus: {
                // 动态菜单 - 返回函数
                dynamicItems: {
                    acceptReporters: true,  // 是否接受报告块输入
                    items: this.getItems.bind(this)
                }
            }
        };
    }

    /**
     * 获取菜单项（动态）
     * @returns {Array} 菜单项数组
     */
    getItems() {
        return this.items.map(item => ({
            text: item,
            value: item
        }));
    }

    selectItem(args) {
        console.log(`选择: ${args.ITEM}`);
    }

    addItem(args) {
        const name = String(args.NAME);
        if (name && !this.items.includes(name)) {
            this.items.push(name);
            console.log(`添加项目: ${name}`);
        }
    }
}
```

## 参数验证与处理

### 安全的类型转换

```javascript
class SafeExtension {
    getInfo() {
        return {
            id: 'safeExt',
            name: '安全扩展',
            color1: '#4C97FF',
            blocks: [
                {
                    opcode: 'calculate',
                    blockType: Scratch.BlockType.REPORTER,
                    text: '[A] 和 [B] 的和',
                    arguments: {
                        A: { type: Scratch.ArgumentType.NUMBER, defaultValue: 0 },
                        B: { type: Scratch.ArgumentType.NUMBER, defaultValue: 0 }
                    }
                }
            ]
        };
    }

    /**
     * 安全的计算方法
     * @param {object} args
     * @returns {number}
     */
    calculate(args) {
        // 安全转换为数字
        const a = this.toNumber(args.A);
        const b = this.toNumber(args.B);
        
        // 检查是否为有限数字
        if (!Number.isFinite(a) || !Number.isFinite(b)) {
            return 0;  // 返回安全默认值
        }
        
        return a + b;
    }

    /**
     * 安全转换为数字
     * @param {*} value
     * @returns {number}
     */
    toNumber(value) {
        const num = Number(value);
        return Number.isFinite(num) ? num : 0;
    }

    /**
     * 安全转换为字符串
     * @param {*} value
     * @returns {string}
     */
    toString(value) {
        if (value === null || value === undefined) {
            return '';
        }
        return String(value);
    }

    /**
     * 安全转换为布尔值
     * @param {*} value
     * @returns {boolean}
     */
    toBoolean(value) {
        // 处理字符串 "false"
        if (typeof value === 'string') {
            return value.toLowerCase() !== 'false' && value !== '0';
        }
        return Boolean(value);
    }

    /**
     * 限制数字范围
     * @param {number} value
     * @param {number} min
     * @param {number} max
     * @returns {number}
     */
    clamp(value, min, max) {
        return Math.max(min, Math.min(max, value));
    }
}
```

## 复合参数示例

### 多参数组合

```javascript
{
    opcode: 'drawRectangle',
    blockType: Scratch.BlockType.COMMAND,
    text: '绘制矩形 宽:[WIDTH] 高:[HEIGHT] 颜色:[COLOR] 填充:[FILLED]',
    arguments: {
        WIDTH: {
            type: Scratch.ArgumentType.NUMBER,
            defaultValue: 100
        },
        HEIGHT: {
            type: Scratch.ArgumentType.NUMBER,
            defaultValue: 50
        },
        COLOR: {
            type: Scratch.ArgumentType.COLOR,
            defaultValue: '#4C97FF'
        },
        FILLED: {
            type: Scratch.ArgumentType.STRING,
            menu: 'filledOptions',
            defaultValue: 'yes'
        }
    }
}

drawRectangle(args) {
    const width = Math.max(1, Number(args.WIDTH) || 100);
    const height = Math.max(1, Number(args.HEIGHT) || 50);
    const color = args.COLOR || '#000000';
    const filled = args.FILLED === 'yes';
    
    console.log(`绘制矩形: ${width}x${height}, 颜色: ${color}, 填充: ${filled}`);
}
```

### 参数默认值策略

```javascript
class DefaultValueExtension {
    constructor() {
        this.lastValue = 0;
    }

    getInfo() {
        return {
            id: 'defaultExt',
            name: '默认值示例',
            color1: '#4C97FF',
            blocks: [
                {
                    opcode: 'remember',
                    blockType: Scratch.BlockType.COMMAND,
                    text: '记住值 [VALUE]',
                    arguments: {
                        VALUE: {
                            type: Scratch.ArgumentType.NUMBER,
                            defaultValue: 0
                        }
                    }
                },
                {
                    opcode: 'recall',
                    blockType: Scratch.BlockType.REPORTER,
                    text: '回忆的值'
                }
            ]
        };
    }

    remember(args) {
        // 使用上次值作为默认值
        this.lastValue = Number(args.VALUE) || this.lastValue;
    }

    recall() {
        return this.lastValue;
    }
}
```

## 小结

本章要点：

1. **基本类型**：NUMBER、STRING、BOOLEAN
2. **特殊类型**：ANGLE、COLOR、MATRIX、NOTE
3. **静态菜单**：预定义的选项列表
4. **动态菜单**：运行时生成的选项
5. **参数验证**：安全的类型转换和边界检查

> 💡 **提示**：合理的参数设计能让扩展更易用、更安全。
