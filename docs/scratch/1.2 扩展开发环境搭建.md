# 1.2 扩展开发环境搭建

本节详细介绍如何搭建 Scratch 扩展开发环境，包括多种开发方式的选择和配置。

## 开发方式选择

### 方式对比

| 开发方式 | 难度 | 适用场景 | 推荐指数 |
|---------|-----|---------|---------|
| TurboWarp | | 快速原型开发、学习 | |
| scratch-vm 本地 | | 深度开发、调试 | |
| scratch-gui 本地 | | 完整开发环境 | |

## 方式一：TurboWarp 开发（推荐）

TurboWarp 提供了最简单的扩展开发方式。

### 1. 在线开发

```javascript
// 1. 打开 TurboWarp 网站
// https://turbowarp.org/editor

// 2. 点击左下角 "添加扩展"
// 3. 选择 "自定义扩展"
// 4. 粘贴以下测试代码

class TestExtension {
 getInfo() {
 return {
 id: 'test',
 name: '测试扩展',
 color1: '#FF6680',
 blocks: [
 {
 opcode: 'hello',
 blockType: Scratch.BlockType.REPORTER,
 text: '你好，[NAME]！',
 arguments: {
 NAME: {
 type: Scratch.ArgumentType.STRING,
 defaultValue: '世界'
 }
 }
 }
 ]
 };
 }

 hello(args) {
 return `你好，${args.NAME}！`;
 }
}

// 注册扩展
Scratch.extensions.register(new TestExtension());
```

### 2. 本地文件开发

```bash
# 1. 创建项目目录
mkdir my-scratch-extension
cd my-scratch-extension

# 2. 创建扩展文件
# 新建 extension.js 文件
```

```javascript
// extension.js

/**
 * 我的第一个 Scratch 扩展
 */
class MyExtension {
 constructor() {
 // 初始化扩展状态
 this.counter = 0;
 }

 getInfo() {
 return {
 id: 'myExtension',
 name: '我的扩展',
 color1: '#4C97FF',
 color2: '#4280D7',
 color3: '#3373CC',
 
 // 扩展图标（可选）
 blockIconURI: 'data:image/svg+xml,' + encodeURIComponent(`
 <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 40 40">
 <circle cx="20" cy="20" r="18" fill="#4C97FF"/>
 <text x="20" y="26" text-anchor="middle" fill="white" font-size="16">M</text>
 </svg>
 `),
 
 blocks: [
 // 积木块定义
 {
 opcode: 'increment',
 blockType: Scratch.BlockType.REPORTER,
 text: '计数器加 [NUM]',
 arguments: {
 NUM: {
 type: Scratch.ArgumentType.NUMBER,
 defaultValue: 1
 }
 }
 },
 {
 opcode: 'getCounter',
 blockType: Scratch.BlockType.REPORTER,
 text: '获取计数器值'
 },
 {
 opcode: 'resetCounter',
 blockType: Scratch.BlockType.COMMAND,
 text: '重置计数器'
 }
 ]
 };
 }

 /**
 * 计数器增加
 * @param {object} args - 参数对象
 * @returns {number} - 新的计数值
 */
 increment(args) {
 const num = Number(args.NUM) || 0;
 this.counter += num;
 return this.counter;
 }

 /**
 * 获取计数器值
 * @returns {number}
 */
 getCounter() {
 return this.counter;
 }

 /**
 * 重置计数器
 */
 resetCounter() {
 this.counter = 0;
 }
}

// 注册扩展
Scratch.extensions.register(new MyExtension());
```

### 3. 加载本地扩展

```bash
# 方法一：使用本地服务器
# 安装 Python 后，在扩展目录运行
python -m http.server 8000

# 然后在 TurboWarp 中加载
# http://localhost:8000/extension.js
```

```bash
# 方法二：使用 Node.js 服务器
npx serve .

# 或使用 http-server
npx http-server -p 8000
```

## 方式二：scratch-vm 本地开发

适合需要深度调试的开发者。

### 1. 克隆仓库

```bash
# 克隆 scratch-vm
git clone https://github.com/LLK/scratch-vm.git
cd scratch-vm

# 安装依赖
npm install
```

### 2. 添加扩展

```bash
# 在 src/extensions/ 目录创建扩展文件
# 文件命名格式：index_扩展名.js
```

```javascript
// src/extensions/index_myextension.js

const ArgumentType = require('../extension-support/argument-type');
const BlockType = require('../extension-support/block-type');
const Cast = require('../util/cast');
const log = require('../util/log');

/**
 * 我的扩展
 */
class MyExtension {
 /**
 * 构造函数
 * @param {Runtime} runtime - Scratch 运行时
 */
 constructor(runtime) {
 this.runtime = runtime;
 }

 /**
 * 获取扩展信息
 * @returns {object} 扩展信息
 */
 getInfo() {
 return {
 id: 'myextension',
 name: '我的扩展',
 color1: '#FF6680',
 color2: '#FF4D6A',
 color3: '#FF3355',
 
 blocks: [
 {
 opcode: 'saySomething',
 blockType: BlockType.REPORTER,
 text: '说 [TEXT]',
 arguments: {
 TEXT: {
 type: ArgumentType.STRING,
 defaultValue: '你好'
 }
 }
 }
 ],
 
 menus: {}
 };
 }

 /**
 * 说些什么
 * @param {object} args - 参数
 * @returns {string} - 文本
 */
 saySomething(args) {
 return Cast.toString(args.TEXT);
 }
}

module.exports = MyExtension;
```

### 3. 注册扩展

```javascript
// 在 src/extension-support/extension-manager.js 中添加

const builtInExtensions = {
 // ... 其他扩展
 myextension: require('../extensions/index_myextension')
};
```

### 4. 启动开发服务器

```bash
# 启动开发服务器
npm start

# 或运行测试
npm test
```

## 方式三：完整 Scratch GUI 开发

适合需要完整开发环境的场景。

### 1. 克隆并配置

```bash
# 克隆 scratch-gui
git clone https://github.com/LLK/scratch-gui.git
cd scratch-gui

# 安装依赖
npm install

# 克隆 scratch-vm 到同一父目录
cd ..
git clone https://github.com/LLK/scratch-vm.git
cd scratch-vm
npm install
npm link

# 链接 scratch-vm 到 scratch-gui
cd ../scratch-gui
npm link scratch-vm
```

### 2. 开发扩展

按照方式二的方法在 scratch-vm 中开发扩展。

### 3. 启动 GUI

```bash
# 在 scratch-gui 目录
npm start

# 浏览器访问
# http://localhost:8601
```

## 调试技巧

### 1. 控制台调试

```javascript
// 在扩展中添加调试日志
class MyExtension {
 getInfo() {
 console.log('[MyExtension] getInfo called');
 // ...
 }

 someBlock(args) {
 console.log('[MyExtension] someBlock called with:', args);
 // ...
 }
}
```

### 2. 断点调试

```javascript
// 使用 debugger 语句
someBlock(args) {
 debugger; // 执行会在此暂停
 return args.value;
}
```

### 3. 错误捕获

```javascript
someBlock(args) {
 try {
 // 可能出错的代码
 return this.processData(args);
 } catch (error) {
 console.error('[MyExtension] Error:', error);
 return null; // 返回安全默认值
 }
}
```

## 常见问题解决

### 问题 1：扩展无法加载

```javascript
// 检查扩展是否正确注册
if (typeof Scratch !== 'undefined' && Scratch.extensions) {
 Scratch.extensions.register(new MyExtension());
} else {
 console.error('Scratch 环境未就绪');
}
```

### 问题 2：跨域问题

```bash
# 使用 CORS 代理启动服务器
npx http-server --cors

# 或在 Python 服务器中添加 CORS 头
python -c "
from http.server import HTTPServer, SimpleHTTPRequestHandler
class CORSRequestHandler(SimpleHTTPRequestHandler):
 def end_headers(self):
 self.send_header('Access-Control-Allow-Origin', '*')
 super().end_headers()
HTTPServer(('', 8000), CORSRequestHandler).serve_forever()
"
```

### 问题 3：热重载

```javascript
// 开发时支持热重载
if (module.hot) {
 module.hot.accept();
}
```
