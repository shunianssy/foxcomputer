# 1.2 环境准备

在开始 FastAPI 开发之前，我们需要搭建一个完整的开发环境。本章将介绍如何安装和配置 FastAPI。

## Python 版本要求

FastAPI 需要较新的 Python 版本：

| Python 版本 | 支持情况 |
|-------------|----------|
| Python 3.6 | 不支持 |
| Python 3.7 | 最低要求 |
| Python 3.8+ | 推荐 |
| Python 3.10+ | 最佳体验 |

> **建议**：使用 Python 3.10 或更高版本，可以获得更好的类型提示支持和性能优化。

## 创建虚拟环境

虚拟环境可以隔离项目依赖，避免版本冲突。

### 使用 venv（推荐）

```bash
# 创建虚拟环境
python -m venv venv

# Windows 激活
venv\Scripts\activate

# Linux/macOS 激活
source venv/bin/activate
```

### 使用 conda

```bash
# 创建虚拟环境
conda create -n fastapi-env python=3.10

# 激活环境
conda activate fastapi-env
```

### 使用 poetry（现代化方式）

```bash
# 安装 poetry
pip install poetry

# 创建项目
poetry new my-fastapi-project
cd my-fastapi-project

# 安装依赖
poetry add fastapi uvicorn
```

## 安装 FastAPI

### 核心依赖

FastAPI 本身非常轻量，核心安装只需要：

```bash
pip install fastapi
```

### ASGI 服务器

FastAPI 需要 ASGI 服务器来运行，推荐使用 Uvicorn：

```bash
pip install uvicorn[standard]
```

`[standard]` 选项会安装额外的依赖，提供更好的性能和功能。

### 开发依赖

推荐安装以下开发工具：

```bash
# 代码格式化
pip install black isort

# 类型检查
pip install mypy

# 测试工具
pip install pytest httpx

# 一起安装
pip install fastapi uvicorn[standard] black isort mypy pytest httpx
```

## 项目结构

一个基本的 FastAPI 项目结构：

```
my-fastapi-project/
├── app/
│ ├── __init__.py
│ ├── main.py # 应用入口
│ ├── routers/ # 路由模块
│ │ └── __init__.py
│ ├── models/ # 数据模型
│ │ └── __init__.py
│ ├── schemas/ # Pydantic 模型
│ │ └── __init__.py
│ └── services/ # 业务逻辑
│ └── __init__.py
├── tests/ # 测试文件
│ └── __init__.py
├── requirements.txt # 依赖列表
└── README.md
```

## requirements.txt

创建 `requirements.txt` 文件：

```txt
fastapi>=0.100.0
uvicorn[standard]>=0.23.0
pydantic>=2.0.0

# 开发依赖
black>=23.0.0
isort>=5.12.0
mypy>=1.0.0
pytest>=7.0.0
httpx>=0.24.0
```

安装所有依赖：

```bash
pip install -r requirements.txt
```

## IDE 配置

### VS Code 推荐配置

创建 `.vscode/settings.json`：

```json
{
 "python.linting.enabled": true,
 "python.linting.mypyEnabled": true,
 "python.formatting.provider": "black",
 "editor.formatOnSave": true,
 "editor.codeActionsOnSave": {
 "source.organizeImports": true
 }
}
```

### PyCharm 配置

1. 设置 Python 解释器为虚拟环境
2. 启用 MyPy 类型检查
3. 配置 Black 作为代码格式化工具

## 验证安装

创建一个简单的测试文件验证安装是否成功：

```python
# test_install.py
import fastapi
import uvicorn
import pydantic

print(f"FastAPI 版本: {fastapi.__version__}")
print(f"Uvicorn 版本: {uvicorn.__version__}")
print(f"Pydantic 版本: {pydantic.__version__}")
```

运行测试：

```bash
python test_install.py
```

如果看到版本信息输出，说明安装成功！

## 常见问题

### 问题 1：pip 安装速度慢

使用国内镜像源：

```bash
pip install fastapi -i https://pypi.tuna.tsinghua.edu.cn/simple
```

或配置永久使用：

```bash
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
```

### 问题 2：虚拟环境激活失败

Windows PowerShell 可能需要修改执行策略：

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

### 问题 3：类型检查报错

确保安装了 mypy 和相关类型包：

```bash
pip install mypy types-requests
```

## 小结

环境准备步骤总结：

1. **选择 Python 版本**：推荐 3.10+
2. **创建虚拟环境**：使用 venv、conda 或 poetry
3. **安装 FastAPI**：`pip install fastapi uvicorn[standard]`
4. **配置开发工具**：black、isort、mypy、pytest
5. **验证安装**：运行测试脚本确认安装成功
