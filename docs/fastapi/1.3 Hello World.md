# 1.3 Hello World

让我们创建第一个 FastAPI 应用，体验 FastAPI 的简洁和强大。

## 最简单的 FastAPI 应用

创建 `main.py` 文件：

```python
from fastapi import FastAPI

# 创建 FastAPI 实例
app = FastAPI()

# 定义路由
@app.get("/")
async def root():
    """根路径处理函数"""
    return {"message": "Hello World"}

@app.get("/hello/{name}")
async def say_hello(name: str):
    """带路径参数的路由"""
    return {"message": f"Hello, {name}!"}
```

## 运行应用

### 使用 uvicorn 命令

```bash
uvicorn main:app --reload
```

参数说明：

- `main:app`：`main.py` 文件中的 `app` 对象
- `--reload`：开发模式下自动重载（代码修改后自动重启）

### 在代码中运行

```python
import uvicorn
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
async def root():
    return {"message": "Hello World"}

if __name__ == "__main__":
    uvicorn.run("main:app", host="0.0.0.0", port=8000, reload=True)
```

## HTTP 方法

FastAPI 支持所有标准 HTTP 方法：

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
async def read_root():
    """GET 请求 - 获取资源"""
    return {"method": "GET"}

@app.post("/")
async def create_item():
    """POST 请求 - 创建资源"""
    return {"method": "POST"}

@app.put("/")
async def update_item():
    """PUT 请求 - 更新资源（完整更新）"""
    return {"method": "PUT"}

@app.patch("/")
async def partial_update_item():
    """PATCH 请求 - 部分更新"""
    return {"method": "PATCH"}

@app.delete("/")
async def delete_item():
    """DELETE 请求 - 删除资源"""
    return {"method": "DELETE"}
```

## 路由参数

### 路径参数

```python
@app.get("/items/{item_id}")
async def read_item(item_id: int):
    """
    路径参数会被自动转换为指定类型
    
    - item_id: int 类型，FastAPI 会自动验证
    """
    return {"item_id": item_id}
```

访问 `/items/42` 返回：

```json
{"item_id": 42}
```

### 查询参数

```python
from typing import Optional

@app.get("/items/")
async def read_items(
    skip: int = 0,           # 默认值
    limit: int = 10,         # 默认值
    q: Optional[str] = None  # 可选参数
):
    """
    查询参数从 URL 的 ? 后获取
    
    示例: /items/?skip=0&limit=10&q=search
    """
    return {"skip": skip, "limit": limit, "q": q}
```

## 请求体

使用 Pydantic 模型定义请求体：

```python
from pydantic import BaseModel
from typing import Optional

class Item(BaseModel):
    """定义数据模型"""
    name: str
    price: float
    description: Optional[str] = None
    tax: Optional[float] = None

@app.post("/items/")
async def create_item(item: Item):
    """
    请求体会自动解析为 Item 对象
    
    请求示例:
    {
        "name": "商品名称",
        "price": 99.9,
        "description": "商品描述",
        "tax": 10.5
    }
    """
    return item
```

## 响应模型

定义响应格式：

```python
from pydantic import BaseModel

class User(BaseModel):
    id: int
    name: str
    email: str

class UserResponse(BaseModel):
    id: int
    name: str
    # 不返回 email，保护隐私

@app.get("/users/{user_id}", response_model=UserResponse)
async def read_user(user_id: int):
    """
    response_model 会自动过滤不需要的字段
    """
    # 模拟数据库查询
    user_data = {
        "id": user_id,
        "name": "张三",
        "email": "zhangsan@example.com"
    }
    return user_data
```

## 完整示例

一个更完整的示例：

```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel
from typing import Optional, List

app = FastAPI(
    title="My API",
    description="一个简单的 FastAPI 示例",
    version="1.0.0"
)

# 数据模型
class Item(BaseModel):
    id: int
    name: str
    price: float
    description: Optional[str] = None

# 模拟数据库
items_db: List[Item] = []

# 路由
@app.get("/")
async def root():
    """根路径"""
    return {"message": "Welcome to My API"}

@app.get("/items", response_model=List[Item])
async def get_items():
    """获取所有商品"""
    return items_db

@app.get("/items/{item_id}", response_model=Item)
async def get_item(item_id: int):
    """获取单个商品"""
    for item in items_db:
        if item.id == item_id:
            return item
    raise HTTPException(status_code=404, detail="Item not found")

@app.post("/items", response_model=Item, status_code=201)
async def create_item(item: Item):
    """创建商品"""
    items_db.append(item)
    return item

@app.delete("/items/{item_id}")
async def delete_item(item_id: int):
    """删除商品"""
    for i, item in enumerate(items_db):
        if item.id == item_id:
            items_db.pop(i)
            return {"message": "Item deleted"}
    raise HTTPException(status_code=404, detail="Item not found")
```

## 小结

FastAPI Hello World 要点：

1. **创建应用**：`app = FastAPI()`
2. **定义路由**：使用装饰器 `@app.get()`、`@app.post()` 等
3. **运行服务**：`uvicorn main:app --reload`
4. **自动文档**：访问 `/docs` 和 `/redoc`
5. **类型提示**：FastAPI 利用类型提示进行数据验证
