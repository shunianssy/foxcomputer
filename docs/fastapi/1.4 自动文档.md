# 1.4 自动文档

FastAPI 最令人惊艳的特性之一是自动生成 API 文档。本章将详细介绍如何使用和自定义这些文档。

## 自动文档概述

FastAPI 基于 OpenAPI 规范（原名 Swagger）自动生成 API 文档，包括：

- **Swagger UI**：交互式 API 测试界面
- **ReDoc**：美观的 API 文档展示
- **OpenAPI JSON**：机器可读的 API 规范

## 访问文档

默认情况下，FastAPI 提供三个文档端点：

| 端点 | 说明 |
|------|------|
| `/docs` | Swagger UI 交互式文档 |
| `/redoc` | ReDoc 美观文档 |
| `/openapi.json` | OpenAPI 规范 JSON |

## 配置应用信息

创建 FastAPI 实例时可以配置元数据：

```python
from fastapi import FastAPI

app = FastAPI(
 # 基本信息
 title="My Awesome API",
 description="""
## 简介

这是一个示例 API，展示了 FastAPI 的强大功能。

## 功能特性

- 用户管理
- 商品管理 
- 订单处理

## 联系方式

- 作者：张三
- 邮箱：zhangsan@example.com
 """,
 version="1.0.0",
 
 # 服务信息
 terms_of_service="https://example.com/terms/",
 contact={
 "name": "API Support",
 "url": "https://example.com/support",
 "email": "support@example.com",
 },
 license_info={
 "name": "MIT License",
 "url": "https://opensource.org/licenses/MIT",
 },
 
 # 文档配置
 docs_url="/docs", # Swagger UI 路径
 redoc_url="/redoc", # ReDoc 路径
 openapi_url="/openapi.json" # OpenAPI JSON 路径
)
```

## 路由文档

### 基本描述

使用文档字符串添加路由描述：

```python
@app.get("/items/{item_id}")
async def read_item(item_id: int):
 """
 获取商品详情
 
 根据商品 ID 获取商品的详细信息。
 """
 return {"item_id": item_id}
```

### 详细配置

使用 `summary`、`description` 等参数：

```python
from fastapi import FastAPI

app = FastAPI()

@app.get(
 "/items/{item_id}",
 summary="获取单个商品",
 description="""
 获取商品的详细信息。
 
 参数说明：
 - **item_id**: 商品的唯一标识符
 
 返回商品的完整信息，包括名称、价格、描述等。
 """,
 response_description="商品详细信息",
 tags=["商品管理"],
 deprecated=False
)
async def read_item(item_id: int):
 return {"item_id": item_id, "name": "示例商品"}
```

### 使用 docstring 作为 description

```python
@app.post("/items/", response_model=Item, tags=["商品管理"])
async def create_item(item: Item):
 """
 创建新商品
 
 Args:
 item: 商品信息，包括名称、价格等
 
 Returns:
 创建成功的商品信息
 
 Raises:
 HTTPException: 当商品已存在时返回 400 错误
 
 Examples:
 创建一个新商品：
 ```json
 {
 "name": "新商品",
 "price": 99.9
 }
 ```
 """
 return item
```

## 标签分组

使用标签组织 API：

```python
from fastapi import FastAPI

app = FastAPI()

# 定义标签元数据
tags_metadata = [
 {
 "name": "users",
 "description": "用户管理相关操作",
 },
 {
 "name": "items",
 "description": "商品管理相关操作",
 "externalDocs": {
 "description": "更多文档",
 "url": "https://example.com/docs",
 },
 },
]

app = FastAPI(openapi_tags=tags_metadata)

@app.get("/users/", tags=["users"])
async def get_users():
 """获取用户列表"""
 return [{"name": "张三"}, {"name": "李四"}]

@app.get("/items/", tags=["items"])
async def get_items():
 """获取商品列表"""
 return [{"name": "商品A"}, {"name": "商品B"}]
```

## 响应模型文档

### 基本响应模型

```python
from pydantic import BaseModel
from typing import Optional

class Item(BaseModel):
 """商品模型"""
 id: int
 name: str
 price: float
 description: Optional[str] = None

@app.post("/items/", response_model=Item)
async def create_item(item: Item):
 """
 创建商品
 
 响应模型会自动显示在文档中
 """
 return item
```

### 多种响应

定义不同状态码的响应：

```python
from fastapi import FastAPI, HTTPException
from fastapi.responses import JSONResponse
from pydantic import BaseModel

app = FastAPI()

class Item(BaseModel):
 id: int
 name: str

class Error(BaseModel):
 code: int
 message: str

@app.get(
 "/items/{item_id}",
 response_model=Item,
 responses={
 200: {
 "description": "成功返回商品信息",
 "model": Item
 },
 404: {
 "description": "商品不存在",
 "model": Error
 },
 400: {
 "description": "无效的商品 ID",
 "model": Error
 }
 }
)
async def read_item(item_id: int):
 if item_id < 0:
 return JSONResponse(
 status_code=400,
 content={"code": 400, "message": "无效的商品 ID"}
 )
 if item_id > 100:
 return JSONResponse(
 status_code=404,
 content={"code": 404, "message": "商品不存在"}
 )
 return {"id": item_id, "name": "示例商品"}
```

## 禁用文档

在生产环境中，可能需要禁用文档：

```python
# 完全禁用文档
app = FastAPI(
 docs_url=None,
 redoc_url=None,
 openapi_url=None
)

# 或者根据环境变量控制
import os

app = FastAPI(
 docs_url="/docs" if os.getenv("ENV") != "production" else None,
 redoc_url="/redoc" if os.getenv("ENV") != "production" else None
)
```

## 自定义 OpenAPI

### 添加安全方案

```python
from fastapi import FastAPI, Security
from fastapi.security import HTTPBearer

app = FastAPI()

security = HTTPBearer()

# 配置安全方案
app.openapi_schema = None # 重置 schema

def custom_openapi():
 if app.openapi_schema:
 return app.openapi_schema
 
 from fastapi.openapi.utils import get_openapi
 
 openapi_schema = get_openapi(
 title="My API",
 version="1.0.0",
 description="API 描述",
 routes=app.routes,
 )
 
 # 添加安全方案
 openapi_schema["components"]["securitySchemes"] = {
 "bearerAuth": {
 "type": "http",
 "scheme": "bearer",
 "bearerFormat": "JWT",
 }
 }
 openapi_schema["security"] = [{"bearerAuth": []}]
 
 app.openapi_schema = openapi_schema
 return app.openapi_schema

app.openapi = custom_openapi
```

## Swagger UI 配置

自定义 Swagger UI 行为：

```python
from fastapi import FastAPI
from fastapi.openapi.docs import get_swagger_ui_html

app = FastAPI(docs_url=None) # 禁用默认的 docs

@app.get("/docs", include_in_schema=False)
async def custom_swagger_ui_html():
 return get_swagger_ui_html(
 openapi_url=app.openapi_url,
 title=app.title + " - Swagger UI",
 oauth2_redirect_url=app.swagger_ui_oauth2_redirect_url,
 swagger_js_url="https://cdn.jsdelivr.net/npm/swagger-ui-dist@5/swagger-ui-bundle.js",
 swagger_css_url="https://cdn.jsdelivr.net/npm/swagger-ui-dist@5/swagger-ui.css",
 )
```

## 实用技巧

### 添加示例数据

```python
from pydantic import BaseModel, Field

class Item(BaseModel):
 name: str = Field(
 ...,
 description="商品名称",
 json_schema_extra={"example": "iPhone 15"}
 )
 price: float = Field(
 ...,
 description="商品价格",
 json_schema_extra={"example": 5999.0}
 )

# 或使用 model_config
class User(BaseModel):
 name: str
 email: str
 
 model_config = {
 "json_schema_extra": {
 "examples": [
 {
 "name": "张三",
 "email": "zhangsan@example.com"
 }
 ]
 }
 }
```

### 隐藏路由

不在文档中显示某些路由：

```python
@app.get("/internal/stats", include_in_schema=False)
async def internal_stats():
 """内部统计接口，不在文档中显示"""
 return {"stats": "internal"}
```

## 小结

FastAPI 自动文档要点：

1. **开箱即用**：无需额外配置即可生成完整文档
2. **交互测试**：Swagger UI 支持直接测试 API
3. **丰富配置**：可自定义标题、描述、标签等
4. **多种响应**：支持定义不同状态码的响应模型
5. **安全可控**：生产环境可禁用或限制访问

> **提示**：好的 API 文档是项目成功的关键。利用 FastAPI 的自动文档功能，你可以专注于编写代码，文档会自动保持同步更新。
