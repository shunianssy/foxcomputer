# 3.1 JavaScript 简介

JavaScript 是 Web 开发的三大核心技术之一，它让网页"动起来"，实现交互功能。

## 什么是 JavaScript？

JavaScript 是一种**脚本语言**，可以在浏览器中运行，用于：

- **操作网页内容**：修改 HTML 元素、样式
- **响应用户操作**：点击、输入、滚动等事件
- **与服务器通信**：发送请求、获取数据
- **实现复杂功能**：动画、游戏、图表等

### JavaScript vs Java

> ⚠️ **注意**：JavaScript 和 Java 是两种完全不同的语言，只是名字相似而已。

| 特性 | JavaScript | Java |
|------|------------|------|
| 类型 | 脚本语言 | 编程语言 |
| 运行环境 | 浏览器/Node.js | JVM |
| 类型系统 | 动态类型 | 静态类型 |
| 用途 | Web 前端/后端 | 企业应用/Android |

## JavaScript 引入方式

### 1. 行内脚本

直接在 HTML 元素上使用事件属性：

```html
<button onclick="alert('你好！')">点击我</button>
```

> ⚠️ **注意**：这种方式不推荐，代码难以维护。

### 2. 内部脚本

在 HTML 文档中使用 `<script>` 标签：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>内部脚本示例</title>
    <script>
        // JavaScript 代码
        console.log('页面加载中...');
        
        function sayHello() {
            alert('你好！');
        }
    </script>
</head>
<body>
    <button onclick="sayHello()">点击我</button>
    
    <!-- 脚本也可以放在 body 末尾 -->
    <script>
        console.log('页面加载完成');
    </script>
</body>
</html>
```

### 3. 外部脚本（推荐）

创建独立的 `.js` 文件，然后在 HTML 中引入：

**script.js：**
```javascript
// JavaScript 代码
console.log('外部脚本加载');

function sayHello(name) {
    alert('你好，' + name + '！');
}
```

**index.html：**
```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>外部脚本示例</title>
    <!-- 引入外部脚本 -->
    <script src="script.js"></script>
</head>
<body>
    <button onclick="sayHello('小明')">点击我</button>
    
    <!-- 推荐放在 body 末尾 -->
    <script src="script.js"></script>
</body>
</html>
```

### script 标签属性

```html
<!-- 普通引入 -->
<script src="script.js"></script>

<!-- 异步加载（不阻塞页面渲染） -->
<script src="script.js" async></script>

<!-- 延迟执行（DOM 加载完成后执行） -->
<script src="script.js" defer></script>

<!-- 模块化 -->
<script type="module" src="script.js"></script>
```

| 属性 | 说明 |
|------|------|
| `async` | 异步加载，加载完立即执行 |
| `defer` | 异步加载，DOM 解析完成后执行 |
| `type="module"` | 作为 ES 模块加载 |

## 控制台

浏览器控制台是调试 JavaScript 的重要工具。

### 打开控制台

- **Chrome/Edge**：`F12` 或 `Ctrl+Shift+J`
- **Firefox**：`F12` 或 `Ctrl+Shift+K`
- **Safari**：`Cmd+Option+C`

### console 方法

```javascript
// 输出信息
console.log('普通信息');
console.info('提示信息');
console.warn('警告信息');
console.error('错误信息');

// 输出对象
console.log({ name: '张三', age: 25 });

// 输出表格
console.table([
    { name: '张三', age: 25 },
    { name: '李四', age: 30 }
]);

// 分组输出
console.group('用户信息');
console.log('姓名：张三');
console.log('年龄：25');
console.groupEnd();

// 计时
console.time('循环耗时');
for (let i = 0; i < 1000000; i++) {}
console.timeEnd('循环耗时');

// 清空控制台
console.clear();
```

## 第一个 JavaScript 程序

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>第一个 JavaScript 程序</title>
</head>
<body>
    <h1 id="title">欢迎</h1>
    <p id="message">请点击按钮</p>
    <button id="btn">点击我</button>
    
    <script>
        // 获取元素
        const btn = document.getElementById('btn');
        const message = document.getElementById('message');
        
        // 添加点击事件
        btn.addEventListener('click', function() {
            // 修改内容
            message.textContent = '你点击了按钮！';
            message.style.color = 'green';
            
            // 输出到控制台
            console.log('按钮被点击了');
        });
        
        // 页面加载完成
        console.log('JavaScript 加载成功！');
    </script>
</body>
</html>
```

## JavaScript 语法基础

### 语句

每条语句以分号结尾（可选，但推荐使用）：

```javascript
let name = '张三';
console.log(name);
```

### 注释

```javascript
// 单行注释

/*
 * 多行注释
 * 可以跨越多行
 */

/**
 * 文档注释
 * @param {string} name - 用户名
 * @returns {string} 问候语
 */
function greet(name) {
    return '你好，' + name;
}
```

### 标识符命名规则

```javascript
// 合法命名
let userName = '张三';
let user_name = '张三';
let userName1 = '张三';
let $name = '张三';
let _name = '张三';

// 非法命名
// let 1name = '张三';    // 不能以数字开头
// let user-name = '张三'; // 不能使用连字符
// let let = '张三';       // 不能使用保留字
```

### 保留字

JavaScript 保留了一些关键字，不能用作变量名：

```javascript
// 保留字示例
// let, const, var, function, class, if, else, for, while, return, true, false, null, undefined...
```

## JavaScript 特点

### 1. 解释型语言

JavaScript 代码不需要编译，由浏览器直接解释执行：

```javascript
// 直接运行
console.log('Hello, World!');
```

### 2. 动态类型

变量类型在运行时确定，可以改变：

```javascript
let x = 10;        // 数字
x = 'hello';       // 字符串
x = true;          // 布尔值
x = [1, 2, 3];     // 数组
```

### 3. 弱类型

自动进行类型转换：

```javascript
console.log('1' + 2);     // '12'（字符串拼接）
console.log('1' - 1);     // 0（数字相减）
console.log(true + 1);    // 2（true 转为 1）
console.log(false + 1);   // 1（false 转为 0）
```

### 4. 基于原型的面向对象

```javascript
// 创建对象
const person = {
    name: '张三',
    age: 25,
    sayHello: function() {
        console.log('你好，我是' + this.name);
    }
};

person.sayHello();  // 你好，我是张三
```

## JavaScript 能做什么？

### 1. 操作网页内容

```javascript
// 修改文本
document.getElementById('title').textContent = '新标题';

// 修改样式
document.getElementById('box').style.backgroundColor = 'red';

// 添加/删除元素
const div = document.createElement('div');
div.textContent = '新元素';
document.body.appendChild(div);
```

### 2. 响应用户操作

```javascript
// 点击事件
document.getElementById('btn').addEventListener('click', function() {
    alert('按钮被点击');
});

// 键盘事件
document.addEventListener('keydown', function(e) {
    console.log('按下键：' + e.key);
});
```

### 3. 定时器

```javascript
// 延迟执行
setTimeout(function() {
    console.log('3秒后执行');
}, 3000);

// 定时执行
let count = 0;
const timer = setInterval(function() {
    console.log('执行次数：' + ++count);
    if (count >= 5) {
        clearInterval(timer);  // 停止定时器
    }
}, 1000);
```

### 4. 网络请求

```javascript
// 使用 fetch 获取数据
fetch('https://api.example.com/data')
    .then(response => response.json())
    .then(data => {
        console.log(data);
    })
    .catch(error => {
        console.error('请求失败：', error);
    });
```
