# 2.2 CSS 选择器

选择器是 CSS 的核心概念，它决定了样式应用到哪些元素上。掌握选择器是编写高效 CSS 的关键。

## 基础选择器

### 1. 通配符选择器

匹配页面上的所有元素：

```css
/* 重置所有元素的默认边距 */
* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}
```

### 2. 元素选择器

根据 HTML 标签名选择元素：

```css
/* 所有段落 */
p {
    color: #333;
    line-height: 1.6;
}

/* 所有链接 */
a {
    color: #0066cc;
    text-decoration: none;
}

/* 所有图片 */
img {
    max-width: 100%;
    height: auto;
}
```

### 3. 类选择器

使用 `.` 加类名选择元素：

```css
/* 单个类 */
.highlight {
    background-color: yellow;
}

/* 多个类（元素同时具有多个类） */
.card.featured {
    border: 2px solid gold;
}
```

**HTML 使用：**

```html
<p class="highlight">高亮文字</p>
<div class="card featured">特色卡片</div>
```

### 4. ID 选择器

使用 `#` 加 ID 名选择元素：

```css
#header {
    background-color: #333;
    color: white;
}

#main-content {
    padding: 20px;
}
```

**HTML 使用：**

```html
<header id="header">
    <!-- 页眉内容 -->
</header>
```

> ⚠️ **注意**：ID 在页面中应该是唯一的，不要重复使用。

### 选择器对比

| 选择器 | 语法 | 示例 | 特点 |
|--------|------|------|------|
| 通配符 | `*` | `* {}` | 匹配所有元素 |
| 元素 | `标签名` | `p {}` | 匹配所有该标签 |
| 类 | `.类名` | `.text {}` | 可重复使用 |
| ID | `#ID名` | `#header {}` | 页面唯一 |

## 组合选择器

### 1. 后代选择器（空格）

选择某元素内部的所有后代元素：

```css
/* article 内的所有段落 */
article p {
    color: #666;
}

/* nav 内的所有链接 */
nav a {
    color: white;
}
```

### 2. 子选择器（>）

只选择直接子元素：

```css
/* nav 的直接子元素 a */
nav > a {
    padding: 10px 20px;
}

/* 列表的直接子项 */
ul > li {
    list-style: none;
}
```

**区别示例：**

```html
<nav>
    <a href="#">直接子元素</a>  <!-- 被选中 -->
    <div>
        <a href="#">后代元素</a>  <!-- 不被选中 -->
    </div>
</nav>
```

### 3. 相邻兄弟选择器（+）

选择紧邻在后面的兄弟元素：

```css
/* 紧跟在 h1 后面的 p */
h1 + p {
    font-size: 1.2em;
    color: #666;
}
```

### 4. 通用兄弟选择器（~）

选择后面的所有兄弟元素：

```css
/* h2 后面的所有 p */
h2 ~ p {
    margin-left: 20px;
}
```

### 组合选择器对比

```html
<div class="container">
    <h2>标题</h2>
    <p>段落1</p>
    <p>段落2</p>
    <div>
        <p>段落3</p>
    </div>
</div>
```

```css
/* 后代选择器：选中所有 p */
.container p { }  /* 段落1, 2, 3 */

/* 子选择器：只选中直接子元素 p */
.container > p { }  /* 段落1, 2 */

/* 相邻兄弟：选中 h2 后的第一个 p */
h2 + p { }  /* 段落1 */

/* 通用兄弟：选中 h2 后的所有 p 兄弟 */
h2 ~ p { }  /* 段落1, 2 */
```

## 属性选择器

根据元素的属性选择：

```css
/* 有 title 属性的元素 */
[title] {
    cursor: help;
}

/* type="text" 的输入框 */
input[type="text"] {
    border: 1px solid #ccc;
}

/* href 以 https 开头的链接 */
a[href^="https"] {
    color: green;
}

/* href 以 .pdf 结尾的链接 */
a[href$=".pdf"] {
    background: url('pdf-icon.png') no-repeat;
}

/* href 包含 example 的链接 */
a[href*="example"] {
    font-weight: bold;
}

/* class 包含完整单词 btn */
[class~="btn"] {
    padding: 10px 20px;
}
```

### 属性选择器语法

| 选择器 | 说明 | 示例 |
|--------|------|------|
| `[attr]` | 有该属性 | `[disabled]` |
| `[attr="val"]` | 属性值等于 | `[type="text"]` |
| `[attr^="val"]` | 属性值开头 | `[href^="https"]` |
| `[attr$="val"]` | 属性值结尾 | `[href$=".pdf"]` |
| `[attr*="val"]` | 属性值包含 | `[class*="btn"]` |
| `[attr~="val"]` | 包含完整单词 | `[class~="active"]` |

## 伪类选择器

伪类用于选择元素的特定状态。

### 链接伪类

```css
/* 未访问的链接 */
a:link {
    color: blue;
}

/* 已访问的链接 */
a:visited {
    color: purple;
}

/* 鼠标悬停 */
a:hover {
    color: red;
}

/* 激活状态（点击瞬间） */
a:active {
    color: orange;
}
```

> ⚠️ **注意**：链接伪类的顺序很重要，遵循 **LVHA** 原则：`:link` → `:visited` → `:hover` → `:active`

### 表单伪类

```css
/* 获得焦点 */
input:focus {
    border-color: blue;
    outline: none;
}

/* 禁用状态 */
input:disabled {
    background-color: #eee;
    cursor: not-allowed;
}

/* 选中状态（复选框、单选框） */
input:checked {
    accent-color: blue;
}

/* 必填字段 */
input:required {
    border-left: 3px solid red;
}

/* 可选字段 */
input:optional {
    border-left: 3px solid gray;
}

/* 验证通过 */
input:valid {
    border-color: green;
}

/* 验证失败 */
input:invalid {
    border-color: red;
}
```

### 结构伪类

```css
/* 第一个子元素 */
li:first-child {
    font-weight: bold;
}

/* 最后一个子元素 */
li:last-child {
    border-bottom: none;
}

/* 第 n 个子元素 */
li:nth-child(2) { }      /* 第 2 个 */
li:nth-child(odd) { }    /* 奇数个 */
li:nth-child(even) { }   /* 偶数个 */
li:nth-child(3n) { }     /* 3 的倍数 */
li:nth-child(3n+1) { }   /* 1, 4, 7, ... */

/* 倒数第 n 个子元素 */
li:nth-last-child(2) { }

/* 唯一子元素 */
p:only-child { }

/* 第一个该类型子元素 */
p:first-of-type { }

/* 最后一个该类型子元素 */
p:last-of-type { }

/* 第 n 个该类型子元素 */
p:nth-of-type(2) { }

/* 空元素 */
div:empty {
    display: none;
}

/* 非... */
p:not(.special) {
    color: gray;
}
```

### 否定伪类

```css
/* 不是 .active 类的按钮 */
button:not(.active) {
    opacity: 0.5;
}

/* 不是第一个子元素 */
li:not(:first-child) {
    border-top: 1px solid #eee;
}

/* 不是禁用的输入框 */
input:not(:disabled) {
    background: white;
}
```

## 伪元素选择器

伪元素用于创建或选择元素的特定部分。

### 常用伪元素

```css
/* 元素内容之前插入 */
.quote::before {
    content: '"';
    color: gray;
}

/* 元素内容之后插入 */
.quote::after {
    content: '"';
    color: gray;
}

/* 首行 */
p::first-line {
    font-weight: bold;
}

/* 首字母 */
p::first-letter {
    font-size: 2em;
    float: left;
}

/* 选中文本 */
::selection {
    background-color: yellow;
    color: black;
}

/* 占位符文本 */
input::placeholder {
    color: #999;
}
```

### 实用示例

**清除浮动：**

```css
.clearfix::after {
    content: "";
    display: table;
    clear: both;
}
```

**自定义列表标记：**

```css
ul.custom li::before {
    content: "✓";
    color: green;
    margin-right: 8px;
}
```

**装饰性元素：**

```css
.card::before {
    content: "";
    position: absolute;
    top: 0;
    left: 0;
    width: 4px;
    height: 100%;
    background: linear-gradient(to bottom, #ff6b6b, #4ecdc4);
}
```

## 选择器优先级计算

### 权重值

| 选择器 | 权重 |
|--------|------|
| `!important` | 最高（覆盖一切） |
| 行内样式 `style=""` | 1000 |
| ID 选择器 `#id` | 100 |
| 类选择器 `.class` | 10 |
| 属性选择器 `[attr]` | 10 |
| 伪类 `:hover` | 10 |
| 元素选择器 `div` | 1 |
| 伪元素 `::before` | 1 |
| 通配符 `*` | 0 |

### 计算示例

```css
/* 权重：1 */
p { color: black; }

/* 权重：10 */
.text { color: blue; }

/* 权重：11 (10+1) */
p.text { color: green; }

/* 权重：100 */
#intro { color: red; }

/* 权重：111 (100+10+1) */
#intro p.text { color: purple; }

/* 权重：21 (10+10+1) */
.text.highlight p { color: orange; }
```

### 优先级规则

1. 权重相同时，后写的生效
2. `!important` 强制最高优先级（慎用）
3. 行内样式优先级高于外部样式

## 选择器最佳实践

### ✅ 推荐做法

```css
/* 使用语义化的类名 */
.nav-link { }
.btn-primary { }
.card-title { }

/* 保持选择器简洁 */
.nav a { }  /* 好 */

/* 使用 BEM 命名规范 */
.block__element--modifier { }
.card__title--large { }
```

### ❌ 避免做法

```css
/* 过长的选择器 */
body div.wrapper section.main article p span.text { }

/* 过度使用 ID */
#header #nav #menu li a { }

/* 滥用 !important */
.text { color: red !important; }

/* 无语义的类名 */
.red { }
.big { }
.style1 { }
```

本章我们学习了：

| 选择器类型 | 示例 |
|------------|------|
| 基础选择器 | `*`, `div`, `.class`, `#id` |

| 伪元素选择器 | `::before`, `::after`, `::first-letter` |
