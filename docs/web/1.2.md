# 1.2 HTML 基础标签

本章介绍 HTML 中最常用的基础标签，包括文本、链接、图片和列表。这些标签是构建网页的基石。

## 文本标签

### 标题标签

HTML 提供了 6 级标题，从 `<h1>` 到 `<h6>`：

```html
<h1>一级标题 - 最大</h1>
<h2>二级标题</h2>
<h3>三级标题</h3>
<h4>四级标题</h4>
<h5>五级标题</h5>
<h6>六级标题 - 最小</h6>
```

> ⚠️ **注意**：每个页面通常只有一个 `<h1>` 标签，用于主标题。标题标签对于 SEO（搜索引擎优化）很重要。

### 段落和换行

```html
<p>这是第一个段落。段落之间会自动产生间距。</p>
<p>这是第二个段落。</p>

<p>这是一段文字，<br>这里换行了。</p>
```

| 标签 | 作用 |
|------|------|
| `<p>` | 段落，自动产生上下间距 |
| `<br>` | 换行，单标签 |

### 文本格式化

```html
<strong>重要文本，加粗显示</strong>
<b>粗体文本</b>
<em>强调文本，斜体显示</em>
<i>斜体文本</i>
<u>下划线文本</u>
<s>删除线文本</s>
<mark>高亮标记文本</mark>
<sub>下标</sub>
<sup>上标</sup>
```

**显示效果：**

- **重要文本**（strong）
- *强调文本*（em）
- <u>下划线文本</u>
- ~~删除线文本~~（s）
- ==高亮标记==（mark）
- H<sub>2</sub>O（下标）
- E=mc<sup>2</sup>（上标）

### 语义化文本标签

```html
<blockquote>这是一段引用文字</blockquote>
<code>console.log('代码')</code>
<pre>预格式化文本，保留空格和换行</pre>
<abbr title="HyperText Markup Language">HTML</abbr>
<time datetime="2024-01-01">2024年元旦</time>
```

## 链接标签

### 基本链接

```html
<a href="https://www.baidu.com">访问百度</a>
```

### 链接属性

```html
<!-- 在新窗口打开 -->
<a href="https://www.baidu.com" target="_blank">新窗口打开</a>

<!-- 当前窗口打开（默认） -->
<a href="https://www.baidu.com" target="_self">当前窗口打开</a>

<!-- 链接到页面内锚点 -->
<a href="#section1">跳转到章节1</a>

<!-- 页面内的锚点 -->
<h2 id="section1">章节1</h2>

<!-- 邮件链接 -->
<a href="mailto:example@email.com">发送邮件</a>

<!-- 电话链接 -->
<a href="tel:+8613800138000">拨打电话</a>
```

### 链接 target 属性值

| 值 | 说明 |
|------|------|
| `_self` | 默认值，在当前窗口打开 |
| `_blank` | 在新窗口/标签页打开 |
| `_parent` | 在父框架中打开 |
| `_top` | 在顶层窗口打开 |

### 相对路径与绝对路径

```html
<!-- 绝对路径 -->
<a href="https://example.com/page.html">绝对路径</a>

<!-- 相对路径 -->
<a href="page.html">同目录下的文件</a>
<a href="./page.html">同目录下的文件（明确写法）</a>
<a href="../page.html">上级目录的文件</a>
<a href="folder/page.html">子目录下的文件</a>
```

## 图片标签

### 基本用法

```html
<img src="image.jpg" alt="图片描述">
```

### 图片属性

```html
<img 
    src="photo.jpg" 
    alt="风景照片"
    width="300"
    height="200"
    title="鼠标悬停显示的文字"
>
```

| 属性 | 说明 | 是否必须 |
|------|------|----------|
| `src` | 图片路径 | ✅ 必须 |
| `alt` | 替代文本（图片无法显示时） | ✅ 推荐 |
| `width` | 宽度（像素或百分比） | 可选 |
| `height` | 高度（像素或百分比） | 可选 |
| `title` | 鼠标悬停提示 | 可选 |

### 图片格式选择

| 格式 | 特点 | 适用场景 |
|------|------|----------|
| JPEG/JPG | 有损压缩，文件小 | 照片、复杂图像 |
| PNG | 无损压缩，支持透明 | 图标、logo、截图 |
| GIF | 支持动画 | 动态图片 |
| WebP | 新格式，压缩率高 | 现代浏览器 |
| SVG | 矢量图，无限缩放 | 图标、logo |

### 图片加载优化

```html
<!-- 懒加载：图片进入视口才加载 -->
<img src="image.jpg" alt="描述" loading="lazy">

<!-- 响应式图片 -->
<picture>
    <source media="(min-width: 800px)" srcset="large.jpg">
    <source media="(min-width: 400px)" srcset="medium.jpg">
    <img src="small.jpg" alt="响应式图片">
</picture>
```

## 列表标签

### 无序列表

```html
<ul>
    <li>苹果</li>
    <li>香蕉</li>
    <li>橙子</li>
</ul>
```

**显示效果：**
- 苹果
- 香蕉
- 橙子

### 有序列表

```html
<ol>
    <li>第一步：准备材料</li>
    <li>第二步：开始制作</li>
    <li>第三步：完成</li>
</ol>
```

**显示效果：**
1. 第一步：准备材料
2. 第二步：开始制作
3. 第三步：完成

### 有序列表属性

```html
<!-- 从 3 开始编号 -->
<ol start="3">
    <li>项目</li>
</ol>

<!-- 倒序排列 -->
<ol reversed>
    <li>项目</li>
</ol>

<!-- 使用字母编号 -->
<ol type="a">
    <li>项目A</li>
    <li>项目B</li>
</ol>
```

| type 值 | 编号样式 |
|---------|----------|
| `1` | 数字（默认） |
| `a` | 小写字母 |
| `A` | 大写字母 |
| `i` | 小写罗马数字 |
| `I` | 大写罗马数字 |

### 定义列表

```html
<dl>
    <dt>HTML</dt>
    <dd>超文本标记语言，用于构建网页结构</dd>
    
    <dt>CSS</dt>
    <dd>层叠样式表，用于美化网页</dd>
    
    <dt>JavaScript</dt>
    <dd>脚本语言，用于实现网页交互</dd>
</dl>
```

### 嵌套列表

```html
<ul>
    <li>水果
        <ul>
            <li>苹果</li>
            <li>香蕉</li>
        </ul>
    </li>
    <li>蔬菜
        <ul>
            <li>西红柿</li>
            <li>黄瓜</li>
        </ul>
    </li>
</ul>
```

## div 和 span

### div（块级元素）

`<div>` 是一个通用的容器，用于组合其他元素：

```html
<div class="header">
    <h1>网站标题</h1>
    <nav>导航栏</nav>
</div>

<div class="content">
    <p>主要内容区域</p>
</div>

<div class="footer">
    <p>版权信息</p>
</div>
```

### span（行内元素）

`<span>` 用于标记文本的一部分：

```html
<p>价格：<span class="price">¥99.00</span></p>
<p>状态：<span class="status">已发货</span></p>
```

### 块级元素 vs 行内元素

| 特性 | 块级元素 | 行内元素 |
|------|----------|----------|
| 独占一行 | ✅ 是 | ❌ 否 |
| 可设置宽高 | ✅ 可以 | ❌ 不可以 |
| 示例 | div, p, h1-h6, ul, li | span, a, img, strong |

创建一个个人介绍页面：

```html

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>个人介绍</title>

<body>
    <h1>关于我</h1>
    
    <img src="avatar.jpg" alt="我的头像" width="150">
    
    <h2>基本信息</h2>
    <p>大家好，我是<strong>小明</strong>，一名<em>前端开发学习者</em>。</p>
    
    <h2>我的爱好</h2>
    <ul>
        <li>编程</li>
        <li>阅读</li>
        <li>运动</li>
    </ul>
    
    <h2>学习计划</h2>
    <ol>
        <li>学习 HTML 基础</li>
        <li>学习 CSS 样式</li>
        <li>学习 JavaScript</li>
    </ol>
    
    <h2>联系方式</h2>
    <p>
        邮箱：<a href="mailto:xiaoming@example.com">xiaoming@example.com</a><br>
        博客：<a href="https://blog.example.com" target="_blank">访问我的博客</a>
    </p>
</body>
</html>
```
