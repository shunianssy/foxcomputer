# 1.4 HTML 语义化标签

语义化标签是 HTML5 的重要特性，它们让网页结构更加清晰，对搜索引擎和辅助技术更加友好。

## 什么是语义化？

**语义化**是指使用恰当的 HTML 标签来标记内容，让标签本身就能表达内容的含义。

### 为什么需要语义化？

| 好处 | 说明 |
|------|------|
| **SEO 优化** | 搜索引擎更容易理解页面内容 |
| **无障碍访问** | 屏幕阅读器能更好地解析页面 |
| **代码可读性** | 开发者更容易理解和维护代码 |
| **团队协作** | 统一的标签规范便于协作开发 |

### 对比示例

**❌ 非语义化写法：**

```html
<div class="header">
    <div class="nav">
        <div class="link">首页</div>
    </div>
</div>
<div class="main">
    <div class="article">
        <div class="title">文章标题</div>
        <div class="content">文章内容</div>
    </div>
</div>
<div class="footer">版权信息</div>
```

**✅ 语义化写法：**

```html
<header>
    <nav>
        <a href="/">首页</a>
    </nav>
</header>
<main>
    <article>
        <h1>文章标题</h1>
        <p>文章内容</p>
    </article>
</main>
<footer>版权信息</footer>
```

## 页面结构标签

### header - 页眉

用于页面或区块的头部区域：

```html
<header>
    <h1>网站标题</h1>
    <nav>
        <a href="/">首页</a>
        <a href="/about">关于</a>
        <a href="/contact">联系</a>
    </nav>
</header>
```

### nav - 导航

用于导航链接区域：

```html
<nav>
    <ul>
        <li><a href="/">首页</a></li>
        <li><a href="/products">产品</a></li>
        <li><a href="/about">关于我们</a></li>
        <li><a href="/contact">联系方式</a></li>
    </ul>
</nav>
```

> 💡 **提示**：一个页面可以有多个 `<nav>`，如主导航、侧边导航、页脚导航等。

### main - 主要内容

页面的主要内容区域，每个页面只能有一个：

```html
<main>
    <h1>欢迎访问</h1>
    <p>这是页面的主要内容...</p>
</main>
```

### article - 文章

独立的、完整的内容单元：

```html
<article>
    <header>
        <h1>文章标题</h1>
        <time datetime="2024-01-15">2024年1月15日</time>
    </header>
    <p>文章正文内容...</p>
    <footer>
        <p>作者：张三</p>
    </footer>
</article>
```

### section - 区块

文档中的一个主题性区块：

```html
<section>
    <h2>产品特点</h2>
    <p>介绍产品的特点...</p>
</section>

<section>
    <h2>用户评价</h2>
    <p>用户的评价内容...</p>
</section>
```

> ⚠️ **注意**：`<section>` 通常包含标题，如果只是为了样式分组，应该使用 `<div>`。

### aside - 侧边栏

与主要内容相关但独立的内容：

```html
<aside>
    <h3>相关文章</h3>
    <ul>
        <li><a href="#">文章1</a></li>
        <li><a href="#">文章2</a></li>
    </ul>
</aside>
```

### footer - 页脚

页面或区块的底部区域：

```html
<footer>
    <p>&copy; 2024 我的网站. 保留所有权利.</p>
    <nav>
        <a href="/privacy">隐私政策</a>
        <a href="/terms">使用条款</a>
    </nav>
</footer>
```

## 内容标签

### figure 和 figcaption

用于图片、图表等及其说明：

```html
<figure>
    <img src="landscape.jpg" alt="风景照片">
    <figcaption>图1：美丽的自然风景</figcaption>
</figure>
```

### details 和 summary

可折叠的内容区域：

```html
<details>
    <summary>点击查看更多</summary>
    <p>这里是隐藏的详细内容...</p>
</details>

<!-- 默认展开 -->
<details open>
    <summary>常见问题</summary>
    <p>这里是问题的答案...</p>
</details>
```

### mark - 标记

高亮显示文本：

```html
<p>搜索结果中，<mark>关键词</mark>会被高亮显示。</p>
```

### time - 时间

标记日期或时间：

```html
<p>发布于 <time datetime="2024-01-15">2024年1月15日</time></p>
<p>活动时间：<time datetime="2024-02-20T14:00">2月20日下午2点</time></p>
```

### address - 地址

联系信息：

```html
<address>
    作者：张三<br>
    邮箱：<a href="mailto:zhangsan@example.com">zhangsan@example.com</a><br>
    地址：北京市朝阳区xxx街道
</address>
```

## 媒体标签

### audio - 音频

```html
<audio controls>
    <source src="music.mp3" type="audio/mpeg">
    <source src="music.ogg" type="audio/ogg">
    您的浏览器不支持音频播放。
</audio>
```

### video - 视频

```html
<video controls width="640" height="360" poster="poster.jpg">
    <source src="video.mp4" type="video/mp4">
    <source src="video.webm" type="video/webm">
    您的浏览器不支持视频播放。
</video>
```

**视频属性：**

| 属性 | 说明 |
|------|------|
| `controls` | 显示控制面板 |
| `autoplay` | 自动播放 |
| `muted` | 静音 |
| `loop` | 循环播放 |
| `poster` | 封面图片 |
| `preload` | 预加载策略 |

### source - 媒体源

为 `<audio>` 和 `<video>` 提供多个格式：

```html
<video controls>
    <source src="video.mp4" type="video/mp4">
    <source src="video.webm" type="video/webm">
    <source src="video.ogg" type="video/ogg">
</video>
```

## 其他语义标签

### progress - 进度条

```html
<!-- 确定进度 -->
<progress value="70" max="100">70%</progress>

<!-- 不确定进度 -->
<progress>加载中...</progress>
```

### meter - 度量

```html
<meter value="0.6" min="0" max="1">60%</meter>

<!-- 磁盘使用量 -->
<meter value="60" min="0" max="100" low="30" high="70" optimum="50">
    60GB 已使用
</meter>
```

### dialog - 对话框

```html
<dialog id="myModal">
    <h2>提示</h2>
    <p>这是一个对话框。</p>
    <button onclick="document.getElementById('myModal').close()">关闭</button>
</dialog>

<button onclick="document.getElementById('myModal').showModal()">
    打开对话框
</button>
```

## 完整页面结构示例

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">

<body>
    <!-- 页眉 -->
    <header>
        <h1>我的博客</h1>
        <nav aria-label="主导航">
            <ul>
                <li><a href="/">首页</a></li>
                <li><a href="/articles">文章</a></li>
                <li><a href="/about">关于</a></li>
            </ul>
        </nav>
    </header>

    <!-- 主要内容 -->
    <main>
        <!-- 文章列表 -->
        <section>
            <h2>最新文章</h2>
            
            <article>
                <header>
                    <h3><a href="/article/1">HTML 语义化标签详解</a></h3>
                    <time datetime="2024-01-15">2024年1月15日</time>
                </header>
                <p>本文介绍 HTML5 中的语义化标签...</p>
                <footer>
                    <p>分类：<a href="/category/html">HTML</a></p>
                </footer>
            </article>

            <article>
                <header>
                    <h3><a href="/article/2">CSS Flexbox 布局指南</a></h3>
                    <time datetime="2024-01-10">2024年1月10日</time>
                </header>
                <p>Flexbox 是一种强大的 CSS 布局方式...</p>
                <footer>
                    <p>分类：<a href="/category/css">CSS</a></p>
                </footer>
            </article>
        </section>
    </main>

    <!-- 侧边栏 -->
    <aside>
        <section>
            <h3>关于我</h3>
            <p>一名前端开发者，热爱分享技术知识。</p>
        </section>
        
        <section>
            <h3>热门标签</h3>
            <ul>
                <li><a href="/tag/html">HTML</a></li>
                <li><a href="/tag/css">CSS</a></li>
                <li><a href="/tag/javascript">JavaScript</a></li>
            </ul>
        </section>
    </aside>

    <!-- 页脚 -->
    <footer>
        <p>&copy; 2024 我的博客. 保留所有权利.</p>
        <nav aria-label="页脚导航">
            <a href="/privacy">隐私政策</a>
            <a href="/terms">使用条款</a>
        </nav>
        <address>
            联系邮箱：<a href="mailto:contact@example.com">contact@example.com</a>
        </address>
    </footer>
</body>
</html>
```

## 语义化标签总结

| 标签 | 用途 | 使用场景 |
|------|------|----------|
| `<header>` | 页眉/区块头部 | 网站顶部、文章标题区 |
| `<nav>` | 导航 | 主导航、面包屑、页脚导航 |
| `<main>` | 主要内容 | 页面核心内容（唯一） |
| `<article>` | 独立文章 | 博客文章、新闻、评论 |
| `<section>` | 主题区块 | 内容分组、章节 |
| `<aside>` | 侧边栏 | 相关链接、广告、推荐 |
| `<footer>` | 页脚/区块底部 | 版权信息、联系方式 |
| `<figure>` | 媒体容器 | 图片、图表、代码块 |
| `<figcaption>` | 媒体说明 | 图片说明、图表标题 |
| `<time>` | 时间 | 发布日期、活动时间 |
| `<mark>` | 高亮标记 | 搜索结果高亮 |
| `<address>` | 联系信息 | 作者信息、公司地址 |
