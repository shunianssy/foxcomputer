# 1.3 HTML 表单与表格

表单和表格是网页中重要的交互和数据展示元素。表单用于收集用户输入，表格用于展示结构化数据。

## 表单基础

### 表单结构

```html
<form action="/submit" method="post">
    <!-- 表单元素 -->
</form>
```

| 属性 | 说明 |
|------|------|
| `action` | 表单提交的 URL 地址 |
| `method` | 提交方式：`get` 或 `post` |
| `enctype` | 编码类型，文件上传时需要 `multipart/form-data` |

### input 输入框

`<input>` 是最常用的表单元素：

```html
<!-- 文本输入 -->
<input type="text" name="username" placeholder="请输入用户名">

<!-- 密码输入 -->
<input type="password" name="password" placeholder="请输入密码">

<!-- 邮箱输入 -->
<input type="email" name="email" placeholder="请输入邮箱">

<!-- 数字输入 -->
<input type="number" name="age" min="0" max="150">

<!-- 电话输入 -->
<input type="tel" name="phone" placeholder="请输入手机号">

<!-- 搜索框 -->
<input type="search" name="keyword" placeholder="搜索...">

<!-- URL 输入 -->
<input type="url" name="website" placeholder="请输入网址">
```

### input 类型

| type 值 | 用途 | 示例 |
|---------|------|------|
| `text` | 单行文本 | 用户名 |
| `password` | 密码（显示为圆点） | 密码 |
| `email` | 邮箱（有格式验证） | 邮箱地址 |
| `number` | 数字（可设置范围） | 年龄、数量 |
| `tel` | 电话号码 | 手机号 |
| `url` | 网址 | 个人网站 |
| `search` | 搜索框 | 搜索关键词 |
| `date` | 日期选择 | 出生日期 |
| `time` | 时间选择 | 预约时间 |
| `datetime-local` | 日期时间 | 完整时间 |
| `month` | 月份选择 | 有效期 |
| `week` | 周选择 | 周报 |
| `color` | 颜色选择器 | 主题颜色 |
| `range` | 滑块 | 音量调节 |
| `file` | 文件上传 | 头像上传 |
| `hidden` | 隐藏字段 | 用户ID |
| `submit` | 提交按钮 | 提交表单 |
| `reset` | 重置按钮 | 清空表单 |
| `button` | 普通按钮 | 自定义操作 |

### input 常用属性

```html
<input 
    type="text" 
    name="username"           <!-- 字段名称 -->
    value="默认值"            <!-- 默认值 -->
    placeholder="请输入..."   <!-- 占位提示 -->
    maxlength="20"            <!-- 最大字符数 -->
    minlength="3"             <!-- 最小字符数 -->
    required                  <!-- 必填 -->
    readonly                  <!-- 只读 -->
    disabled                  <!-- 禁用 -->
    autofocus                 <!-- 自动聚焦 -->
    autocomplete="off"        <!-- 关闭自动完成 -->
    pattern="[A-Za-z]{3,}"    <!-- 正则验证 -->
>
```

### label 标签

`<label>` 用于关联表单元素的说明文字：

```html
<!-- 方式一：使用 for 属性 -->
<label for="username">用户名：</label>
<input type="text" id="username" name="username">

<!-- 方式二：包裹表单元素 -->
<label>
    用户名：
    <input type="text" name="username">
</label>
```

> 💡 **提示**：使用 `<label>` 可以提升用户体验，点击标签文字时，对应的输入框会自动获得焦点。

### 文本域 textarea

```html
<textarea 
    name="content" 
    rows="5" 
    cols="30"
    placeholder="请输入内容..."
></textarea>
```

### 选择框

**单选按钮（radio）：**

```html
<fieldset>
    <legend>性别</legend>
    <label>
        <input type="radio" name="gender" value="male" checked> 男
    </label>
    <label>
        <input type="radio" name="gender" value="female"> 女
    </label>
</fieldset>
```

> ⚠️ **注意**：同一组单选按钮必须有相同的 `name` 属性值。

**复选框（checkbox）：**

```html
<fieldset>
    <legend>兴趣爱好</legend>
    <label>
        <input type="checkbox" name="hobby" value="reading"> 阅读
    </label>
    <label>
        <input type="checkbox" name="hobby" value="coding" checked> 编程
    </label>
    <label>
        <input type="checkbox" name="hobby" value="gaming"> 游戏
    </label>
</fieldset>
```

### 下拉选择框

```html
<label for="city">选择城市：</label>
<select name="city" id="city">
    <option value="">请选择</option>
    <optgroup label="一线城市">
        <option value="beijing">北京</option>
        <option value="shanghai" selected>上海</option>
        <option value="guangzhou">广州</option>
        <option value="shenzhen">深圳</option>
    </optgroup>
    <optgroup label="二线城市">
        <option value="hangzhou">杭州</option>
        <option value="nanjing">南京</option>
    </optgroup>
</select>
```

**多选下拉框：**

```html
<select name="skills" multiple size="4">
    <option value="html">HTML</option>
    <option value="css">CSS</option>
    <option value="js">JavaScript</option>
    <option value="vue">Vue</option>
</select>
```

### 按钮

```html
<!-- 提交按钮 -->
<button type="submit">提交</button>
<input type="submit" value="提交">

<!-- 重置按钮 -->
<button type="reset">重置</button>
<input type="reset" value="重置">

<!-- 普通按钮 -->
<button type="button">点击</button>
<input type="button" value="点击">
```

### 完整表单示例

```html
<form action="/register" method="post">
    <h2>用户注册</h2>
    
    <div>
        <label for="username">用户名：</label>
        <input type="text" id="username" name="username" required>
    </div>
    
    <div>
        <label for="email">邮箱：</label>
        <input type="email" id="email" name="email" required>
    </div>
    
    <div>
        <label for="password">密码：</label>
        <input type="password" id="password" name="password" 
               minlength="6" required>
    </div>
    
    <div>
        <label for="birthday">出生日期：</label>
        <input type="date" id="birthday" name="birthday">
    </div>
    
    <fieldset>
        <legend>性别</legend>
        <label>
            <input type="radio" name="gender" value="male"> 男
        </label>
        <label>
            <input type="radio" name="gender" value="female"> 女
        </label>
    </fieldset>
    
    <div>
        <label for="avatar">头像：</label>
        <input type="file" id="avatar" name="avatar" accept="image/*">
    </div>
    
    <div>
        <label>
            <input type="checkbox" name="agree" required> 
            我同意用户协议
        </label>
    </div>
    
    <button type="submit">注册</button>
    <button type="reset">重置</button>
</form>
```

## 表格基础

### 表格结构

```html
<table>
    <caption>学生成绩表</caption>
    <thead>
        <tr>
            <th>姓名</th>
            <th>语文</th>
            <th>数学</th>
            <th>英语</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>张三</td>
            <td>90</td>
            <td>85</td>
            <td>88</td>
        </tr>
        <tr>
            <td>李四</td>
            <td>78</td>
            <td>92</td>
            <td>80</td>
        </tr>
    </tbody>
    <tfoot>
        <tr>
            <td>平均分</td>
            <td>84</td>
            <td>88.5</td>
            <td>84</td>
        </tr>
    </tfoot>
</table>
```

### 表格标签说明

| 标签 | 说明 |
|------|------|
| `<table>` | 表格容器 |
| `<caption>` | 表格标题 |
| `<thead>` | 表头区域 |
| `<tbody>` | 表体区域 |
| `<tfoot>` | 表尾区域 |
| `<tr>` | 表格行 |
| `<th>` | 表头单元格（加粗居中） |
| `<td>` | 数据单元格 |

### 单元格合并

**跨列合并（colspan）：**

```html
<table border="1">
    <tr>
        <th colspan="3">学生信息</th>
    </tr>
    <tr>
        <td>姓名</td>
        <td>年龄</td>
        <td>班级</td>
    </tr>
</table>
```

**跨行合并（rowspan）：**

```html
<table border="1">
    <tr>
        <td rowspan="2">张三</td>
        <td>语文：90</td>
    </tr>
    <tr>
        <td>数学：85</td>
    </tr>
</table>
```

### 表格属性

```html
<table 
    border="1"           <!-- 边框宽度 -->
    cellpadding="10"     <!-- 单元格内边距 -->
    cellspacing="0"      <!-- 单元格间距 -->
    width="100%"         <!-- 表格宽度 -->
>
```

> ⚠️ **注意**：表格样式建议使用 CSS 来设置，HTML 属性已逐渐被废弃。

## 表单验证

### HTML5 内置验证

```html
<form>
    <!-- 必填验证 -->
    <input type="text" required>
    
    <!-- 邮箱格式验证 -->
    <input type="email" required>
    
    <!-- 最小/最大长度 -->
    <input type="text" minlength="3" maxlength="10">
    
    <!-- 数字范围 -->
    <input type="number" min="0" max="100">
    
    <!-- 正则表达式验证 -->
    <input type="text" pattern="[A-Za-z]{3,}" 
           title="请输入至少3个字母">
    
    <button type="submit">提交</button>
</form>
```

### 自定义验证提示

```html
<input type="text" 
       required
       oninvalid="this.setCustomValidity('请填写此字段')"
       oninput="this.setCustomValidity('')">
```
