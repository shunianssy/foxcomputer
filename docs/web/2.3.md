# 2.3 CSS 盒模型

盒模型是 CSS 布局的基础概念。理解盒模型对于控制元素尺寸和间距至关重要。

## 什么是盒模型？

在 CSS 中，每个元素都被看作一个"盒子"，由以下部分组成：

```
+-------------------------------------------+
|                   margin                   |
|   +-----------------------------------+   |
|   |             border                 |   |
|   |   +---------------------------+   |   |
|   |   |         padding           |   |   |
|   |   |   +-------------------+   |   |   |
|   |   |   |                   |   |   |   |
|   |   |   |     content       |   |   |   |
|   |   |   |                   |   |   |   |
|   |   |   +-------------------+   |   |   |
|   |   |         padding           |   |   |
|   |   +---------------------------+   |   |
|   |             border                 |   |
|   +-----------------------------------+   |
|                   margin                   |
+-------------------------------------------+
```

### 盒模型组成部分

| 部分 | 说明 |
|------|------|
| **content** | 内容区域，显示文本、图片等 |
| **padding** | 内边距，内容与边框之间的空间 |
| **border** | 边框，包围内容和内边距 |
| **margin** | 外边距，元素与其他元素之间的空间 |

## content 内容区域

### 尺寸属性

```css
.box {
    /* 宽度 */
    width: 300px;
    
    /* 高度 */
    height: 200px;
    
    /* 最小/最大尺寸 */
    min-width: 200px;
    max-width: 1000px;
    min-height: 100px;
    max-height: 500px;
}
```

### 尺寸单位

```css
/* 绝对单位 */
width: 300px;

/* 相对单位 */
width: 50%;        /* 父元素的 50% */
width: 10em;       /* 当前字体大小的 10 倍 */
width: 20rem;      /* 根字体大小的 20 倍 */
width: 80vw;       /* 视口宽度的 80% */
width: 100vh;      /* 视口高度的 100% */

/* 关键字 */
width: auto;       /* 自动计算 */
width: max-content;  /* 内容最大宽度 */
width: min-content;  /* 内容最小宽度 */
width: fit-content;  /* 适应内容宽度 */
```

## padding 内边距

内边距是内容与边框之间的空间，背景色会延伸到内边距区域。

### 设置方式

```css
.box {
    /* 四边相同 */
    padding: 20px;
    
    /* 上下 | 左右 */
    padding: 10px 20px;
    
    /* 上 | 左右 | 下 */
    padding: 10px 20px 15px;
    
    /* 上 | 右 | 下 | 左（顺时针） */
    padding: 10px 20px 15px 25px;
    
    /* 单边设置 */
    padding-top: 10px;
    padding-right: 20px;
    padding-bottom: 15px;
    padding-left: 25px;
}
```

### 内边距示意图

```css
/* 四个值：上 右 下 左 */
padding: 10px 20px 15px 25px;
/*
    上：10px
    右：20px
    下：15px
    左：25px
*/

/* 三个值：上 左右 下 */
padding: 10px 20px 15px;
/*
    上：10px
    左右：20px
    下：15px
*/

/* 两个值：上下 左右 */
padding: 10px 20px;
/*
    上下：10px
    左右：20px
*/

/* 一个值：四边相同 */
padding: 10px;
/*
    四边都是 10px
*/
```

## border 边框

边框是包围内容和内边距的线条。

### 边框属性

```css
.box {
    /* 边框宽度 */
    border-width: 1px;
    
    /* 边框样式 */
    border-style: solid;  /* solid, dashed, dotted, double, none */
    
    /* 边框颜色 */
    border-color: #333;
    
    /* 简写属性 */
    border: 1px solid #333;
}
```

### 边框样式

| 值 | 效果 |
|----|------|
| `solid` | 实线 |
| `dashed` | 虚线 |
| `dotted` | 点线 |
| `double` | 双线 |
| `none` | 无边框 |
| `hidden` | 隐藏边框 |

### 单边边框

```css
.box {
    border-top: 1px solid #333;
    border-right: 2px dashed #666;
    border-bottom: 3px dotted #999;
    border-left: 4px double #ccc;
}
```

### 圆角边框

```css
.box {
    /* 四角相同 */
    border-radius: 10px;
    
    /* 水平/垂直半径 */
    border-radius: 10px 20px;
    
    /* 四角分别设置 */
    border-radius: 10px 20px 30px 40px;
    
    /* 单独设置 */
    border-top-left-radius: 10px;
    border-top-right-radius: 20px;
    border-bottom-right-radius: 30px;
    border-bottom-left-radius: 40px;
    
    /* 圆形 */
    border-radius: 50%;
    
    /* 椭圆 */
    border-radius: 50% / 30%;
}
```

## margin 外边距

外边距是元素与其他元素之间的空间，背景色不会延伸到外边距区域。

### 设置方式

```css
.box {
    /* 四边相同 */
    margin: 20px;
    
    /* 上下 | 左右 */
    margin: 10px auto;  /* 水平居中 */
    
    /* 上 | 左右 | 下 */
    margin: 10px 20px 15px;
    
    /* 上 | 右 | 下 | 左 */
    margin: 10px 20px 15px 25px;
    
    /* 单边设置 */
    margin-top: 10px;
    margin-right: 20px;
    margin-bottom: 15px;
    margin-left: 25px;
}
```

### 水平居中

```css
.container {
    width: 960px;
    margin: 0 auto;  /* 上下为0，左右自动 */
}
```

### 外边距合并

当两个垂直相邻的元素都有外边距时，它们的外边距会**合并**，取较大的值：

```css
.box1 {
    margin-bottom: 30px;
}

.box2 {
    margin-top: 20px;
}

/* 实际间距是 30px，不是 50px */
```

### 外边距塌陷

父子元素的外边距可能会发生塌陷：

```html
<div class="parent">
    <div class="child">内容</div>
</div>
```

```css
.parent {
    background: #eee;
}

.child {
    margin-top: 20px;  /* 可能会影响父元素 */
}
```

**解决方案：**

```css
.parent {
    background: #eee;
    /* 方案1：添加边框 */
    border: 1px solid transparent;
    /* 方案2：添加内边距 */
    padding-top: 1px;
    /* 方案3：创建 BFC */
    overflow: hidden;
}
```

## box-sizing 盒模型类型

CSS 有两种盒模型计算方式：

### 1. 标准盒模型（content-box）

默认模式，`width` 和 `height` 只包含内容区域：

```css
.box {
    box-sizing: content-box;  /* 默认值 */
    width: 300px;
    padding: 20px;
    border: 1px solid #333;
    /* 实际宽度 = 300 + 20*2 + 1*2 = 342px */
}
```

### 2. IE 盒模型（border-box）

`width` 和 `height` 包含内容、内边距和边框：

```css
.box {
    box-sizing: border-box;
    width: 300px;
    padding: 20px;
    border: 1px solid #333;
    /* 实际宽度 = 300px（固定不变） */
    /* 内容宽度 = 300 - 20*2 - 1*2 = 258px */
}
```

### 推荐全局设置

```css
/* 所有元素使用 border-box */
*,
*::before,
*::after {
    box-sizing: border-box;
}
```

## display 显示类型

`display` 属性决定元素的显示方式，影响盒模型的计算。

### 块级元素（block）

```css
.block {
    display: block;
    /* 特点：
       - 独占一行
       - 可设置宽高
       - 默认宽度为父元素100%
    */
}
```

常见块级元素：`div`, `p`, `h1-h6`, `ul`, `ol`, `li`, `table`, `form`

### 行内元素（inline）

```css
.inline {
    display: inline;
    /* 特点：
       - 不独占一行
       - 不能设置宽高
       - 宽度由内容决定
    */
}
```

常见行内元素：`span`, `a`, `strong`, `em`, `img`

### 行内块元素（inline-block）

```css
.inline-block {
    display: inline-block;
    /* 特点：
       - 不独占一行
       - 可以设置宽高
       - 基线对齐
    */
}
```

### 隐藏元素

```css
.hidden {
    display: none;     /* 完全隐藏，不占空间 */
}

.invisible {
    visibility: hidden;  /* 隐藏，但占空间 */
}

.transparent {
    opacity: 0;         /* 透明，但占空间 */
}
```

## 实战示例

### 卡片组件

```css
.card {
    /* 盒模型 */
    box-sizing: border-box;
    width: 300px;
    padding: 20px;
    border: 1px solid #e0e0e0;
    border-radius: 8px;
    margin: 10px;
    
    /* 阴影 */
    box-shadow: 0 2px 8px rgba(0, 0, 0, 0.1);
    
    /* 背景 */
    background-color: #fff;
}

.card-image {
    width: 100%;
    height: 200px;
    object-fit: cover;
    border-radius: 4px;
    margin-bottom: 15px;
}

.card-title {
    margin: 0 0 10px 0;
    font-size: 18px;
}

.card-text {
    margin: 0;
    color: #666;
    line-height: 1.6;
}
```

### 按钮组件

```css
.btn {
    /* 盒模型 */
    display: inline-block;
    box-sizing: border-box;
    padding: 10px 24px;
    border: none;
    border-radius: 4px;
    margin: 5px;
    
    /* 文字 */
    color: #fff;
    font-size: 16px;
    text-align: center;
    text-decoration: none;
    
    /* 背景 */
    background-color: #007bff;
    cursor: pointer;
    
    /* 过渡 */
    transition: background-color 0.3s;
}

.btn:hover {
    background-color: #0056b3;
}
```

## 小结

本章我们学习了：

| 内容 | 要点 |
|------|------|
| 盒模型组成 | content、padding、border、margin |
| 内边距 | `padding`，背景色会延伸 |
| 边框 | `border`，可设置样式、宽度、颜色、圆角 |
| 外边距 | `margin`，注意合并和塌陷问题 |
| 盒模型类型 | `content-box` vs `border-box` |
| 显示类型 | `block`、`inline`、`inline-block` |
