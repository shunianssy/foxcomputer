# 2.4 CSS 布局

CSS 布局是网页设计的核心技能。本章介绍现代 CSS 布局技术，包括 Flexbox 和 Grid，以及响应式设计。

## display 属性

`display` 属性决定元素的布局方式：

```css
/* 基础值 */
display: block; /* 块级元素 */
display: inline; /* 行内元素 */
display: inline-block; /* 行内块元素 */
display: none; /* 隐藏元素 */

/* Flexbox 布局 */
display: flex; /* 弹性容器 */
display: inline-flex; /* 行内弹性容器 */

/* Grid 布局 */
display: grid; /* 网格容器 */
display: inline-grid; /* 行内网格容器 */
```

## Flexbox 弹性布局

Flexbox 是一维布局系统，适合处理行或列的布局。

### 基本概念

```
+--------------------------------------------------+
| main-start main-end |
| +--------+ +--------+ +--------+ +--------+ |
| | item | | item | | item | | item | | ← 主轴 (main axis)
| +--------+ +--------+ +--------+ +--------+ |
| cross-start |
| ... |
| cross-end |
+--------------------------------------------------+
 ↑
 交叉轴 (cross axis)
```

### 容器属性

**1. flex-direction（主轴方向）**

```css
.container {
 display: flex;
 
 flex-direction: row; /* 水平方向，从左到右（默认） */
 flex-direction: row-reverse; /* 水平方向，从右到左 */
 flex-direction: column; /* 垂直方向，从上到下 */
 flex-direction: column-reverse; /* 垂直方向，从下到上 */
}
```

**2. flex-wrap（换行方式）**

```css
.container {
 display: flex;
 
 flex-wrap: nowrap; /* 不换行（默认） */
 flex-wrap: wrap; /* 换行 */
 flex-wrap: wrap-reverse; /* 反向换行 */
}
```

**3. flex-flow（简写）**

```css
.container {
 flex-flow: row wrap; /* direction + wrap */
}
```

**4. justify-content（主轴对齐）**

```css
.container {
 display: flex;
 
 justify-content: flex-start; /* 起点对齐（默认） */
 justify-content: flex-end; /* 终点对齐 */
 justify-content: center; /* 居中对齐 */
 justify-content: space-between; /* 两端对齐，中间平分 */
 justify-content: space-around; /* 环绕分布 */
 justify-content: space-evenly; /* 完全均分 */
}
```

**5. align-items（交叉轴对齐）**

```css
.container {
 display: flex;
 height: 200px;
 
 align-items: stretch; /* 拉伸填满（默认） */
 align-items: flex-start; /* 起点对齐 */
 align-items: flex-end; /* 终点对齐 */
 align-items: center; /* 居中对齐 */
 align-items: baseline; /* 基线对齐 */
}
```

**6. align-content（多行对齐）**

```css
.container {
 display: flex;
 flex-wrap: wrap;
 
 align-content: flex-start;
 align-content: flex-end;
 align-content: center;
 align-content: space-between;
 align-content: space-around;
 align-content: stretch;
}
```

### 项目属性

**1. flex-grow（放大比例）**

```css
.item {
 flex-grow: 0; /* 默认，不放大 */
 flex-grow: 1; /* 放大，填满剩余空间 */
}

/* 示例：三等分 */
.item:nth-child(1) { flex-grow: 1; }
.item:nth-child(2) { flex-grow: 1; }
.item:nth-child(3) { flex-grow: 1; }

/* 示例：1:2:1 比例 */
.item:nth-child(1) { flex-grow: 1; }
.item:nth-child(2) { flex-grow: 2; }
.item:nth-child(3) { flex-grow: 1; }
```

**2. flex-shrink（缩小比例）**

```css
.item {
 flex-shrink: 1; /* 默认，可缩小 */
 flex-shrink: 0; /* 不缩小 */
}
```

**3. flex-basis（初始大小）**

```css
.item {
 flex-basis: auto; /* 默认，使用元素本身大小 */
 flex-basis: 200px; /* 固定初始大小 */
 flex-basis: 25%; /* 百分比 */
}
```

**4. flex（简写）**

```css
.item {
 flex: 0 1 auto; /* 默认值：grow shrink basis */
 flex: 1; /* 等同于 flex: 1 1 0% */
 flex: auto; /* 等同于 flex: 1 1 auto */
 flex: none; /* 等同于 flex: 0 0 auto */
}
```

**5. align-self（单独对齐）**

```css
.item {
 align-self: auto; /* 继承父元素 */
 align-self: flex-start;
 align-self: flex-end;
 align-self: center;
 align-self: baseline;
 align-self: stretch;
}
```

**6. order（排序）**

```css
.item:nth-child(1) { order: 3; } /* 排在最后 */
.item:nth-child(2) { order: 1; } /* 排在最前 */
.item:nth-child(3) { order: 2; } /* 排在中间 */
```

### Flexbox 实用布局

**水平垂直居中：**

```css
.container {
 display: flex;
 justify-content: center;
 align-items: center;
 height: 100vh;
}
```

**等分布局：**

```css
.container {
 display: flex;
}

.item {
 flex: 1;
}
```

**圣杯布局：**

```css
.layout {
 display: flex;
 flex-direction: column;
 min-height: 100vh;
}

.header, .footer {
 height: 60px;
}

.main {
 display: flex;
 flex: 1;
}

.sidebar {
 width: 200px;
}

.content {
 flex: 1;
}
```

## Grid 网格布局

Grid 是二维布局系统，适合处理行和列同时存在的复杂布局。

### 基本概念

```
+-----+-----+-----+-----+
| 1 | 2 | 3 | 4 | ← 行轨道 (row track)
+-----+-----+-----+-----+
| 5 | 6 | 7 | 8 |
+-----+-----+-----+-----+
| 9 | 10 | 11 | 12 |
+-----+-----+-----+-----+
 ↑ ↑ ↑ ↑
 列轨道 (column track)
```

### 容器属性

**1. grid-template-columns / grid-template-rows**

```css
.container {
 display: grid;
 
 /* 固定宽度 */
 grid-template-columns: 200px 200px 200px;
 
 /* 使用 fr 单位（比例） */
 grid-template-columns: 1fr 2fr 1fr;
 
 /* 使用 repeat() 函数 */
 grid-template-columns: repeat(3, 1fr);
 
 /* 自动填充 */
 grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));
 
 /* 行高 */
 grid-template-rows: 100px 200px;
}
```

**2. grid-gap（间距）**

```css
.container {
 display: grid;
 
 gap: 20px; /* 行列间距相同 */
 gap: 20px 10px; /* 行间距 列间距 */
 row-gap: 20px; /* 行间距 */
 column-gap: 10px; /* 列间距 */
}
```

**3. grid-template-areas（区域命名）**

```css
.container {
 display: grid;
 grid-template-columns: 200px 1fr;
 grid-template-rows: 60px 1fr 60px;
 grid-template-areas:
 "header header"
 "sidebar main"
 "footer footer";
}

.header { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main { grid-area: main; }
.footer { grid-area: footer; }
```

**4. justify-items / align-items**

```css
.container {
 display: grid;
 
 justify-items: start | end | center | stretch;
 align-items: start | end | center | stretch;
 
 /* 简写 */
 place-items: center; /* align-items justify-items */
}
```

**5. justify-content / align-content**

```css
.container {
 display: grid;
 
 justify-content: start | end | center | space-between | space-around | space-evenly;
 align-content: start | end | center | space-between | space-around | space-evenly;
 
 /* 简写 */
 place-content: center;
}
```

### 项目属性

**1. grid-column / grid-row**

```css
.item {
 /* 跨列 */
 grid-column: 1 / 3; /* 从第1条线到第3条线 */
 grid-column: span 2; /* 跨2列 */
 
 /* 跨行 */
 grid-row: 1 / 3;
 grid-row: span 2;
}
```

**2. grid-area**

```css
.item {
 grid-area: header; /* 使用命名区域 */
 
 /* 或指定位置：row-start / column-start / row-end / column-end */
 grid-area: 1 / 1 / 3 / 4;
}
```

### Grid 实用布局

**响应式网格：**

```css
.container {
 display: grid;
 grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
 gap: 20px;
}
```

**经典布局：**

```css
.layout {
 display: grid;
 grid-template-columns: 250px 1fr;
 grid-template-rows: 60px 1fr 60px;
 grid-template-areas:
 "header header"
 "sidebar main"
 "footer footer";
 min-height: 100vh;
}
```

## position 定位

### 定位类型

```css
.element {
 position: static; /* 默认，正常文档流 */
 position: relative; /* 相对定位 */
 position: absolute; /* 绝对定位 */
 position: fixed; /* 固定定位 */
 position: sticky; /* 粘性定位 */
}
```

### 相对定位（relative）

相对于元素自身原位置偏移：

```css
.relative {
 position: relative;
 top: 10px;
 left: 20px;
 /* 原位置保留，不影响其他元素 */
}
```

### 绝对定位（absolute）

相对于最近的定位祖先元素：

```css
.parent {
 position: relative; /* 成为定位参考 */
}

.child {
 position: absolute;
 top: 0;
 right: 0;
}
```

### 固定定位（fixed）

相对于视口定位：

```css
.header {
 position: fixed;
 top: 0;
 left: 0;
 width: 100%;
 z-index: 1000;
}

.back-to-top {
 position: fixed;
 bottom: 20px;
 right: 20px;
}
```

### 粘性定位（sticky）

滚动时切换定位：

```css
.sticky-header {
 position: sticky;
 top: 0;
 background: white;
 z-index: 100;
}
```

### z-index 层级

```css
.modal {
 position: fixed;
 z-index: 9999; /* 数值越大越在上层 */
}
```

## 响应式设计

### 媒体查询

```css
/* 基本语法 */
@media (max-width: 768px) {
 .container {
 width: 100%;
 }
}

/* 常用断点 */
/* 手机 */
@media (max-width: 576px) { }

/* 平板 */
@media (min-width: 576px) and (max-width: 992px) { }

/* 桌面 */
@media (min-width: 992px) { }

/* 大屏 */
@media (min-width: 1200px) { }
```

### 响应式单位

```css
.responsive {
 /* 视口单位 */
 width: 100vw; /* 视口宽度 */
 height: 100vh; /* 视口高度 */
 
 /* 相对单位 */
 font-size: 1rem;
 padding: 2em;
 
 /* 计算函数 */
 width: calc(100% - 20px);
 font-size: clamp(14px, 2vw, 18px); /* 最小值, 首选值, 最大值 */
}
```

### 响应式图片

```css
img {
 max-width: 100%;
 height: auto;
}

/* 响应式背景图 */
.hero {
 background-image: url('small.jpg');
}

@media (min-width: 768px) {
 .hero {
 background-image: url('large.jpg');
 }
}
```

### 移动优先设计

```css
/* 默认样式（移动端） */
.container {
 width: 100%;
 padding: 10px;
}

/* 平板及以上 */
@media (min-width: 768px) {
 .container {
 width: 750px;
 margin: 0 auto;
 }
}

/* 桌面及以上 */
@media (min-width: 992px) {
 .container {
 width: 970px;
 }
}
```
