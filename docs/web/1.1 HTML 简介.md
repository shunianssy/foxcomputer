# 1.1 HTML 简介

HTML（HyperText Markup Language，超文本标记语言）是构建网页的基础。它是 Web 开发的第一步，也是每个前端开发者必须掌握的核心技能。

## 什么是 HTML？

HTML 是一种**标记语言**，不是编程语言。它使用"标签"来描述网页的结构和内容。

```html
<!DOCTYPE html>
<html>
<head>
    <title>我的第一个网页</title>
</head>
<body>
    <h1>你好，世界！</h1>
    <p>这是我的第一个网页。</p>
</body>
</html>
```

### HTML 的作用

- **结构化内容**：定义网页的标题、段落、列表等
- **语义化标记**：让浏览器和搜索引擎理解内容含义
- **嵌入资源**：引入图片、视频、音频等多媒体内容
- **创建链接**：实现页面之间的跳转

## HTML 发展历史

| 版本 | 年份 | 主要特点 |
|------|------|----------|
| HTML 1.0 | 1991 | 最初的 HTML，功能简单 |
| HTML 4.01 | 1999 | 成熟版本，广泛使用 |
| XHTML 1.0 | 2000 | 更严格的 HTML 规范 |
| **HTML5** | 2014 | 现代标准，支持多媒体、语义化 |

> 💡 **提示**：现在我们使用的都是 HTML5，它是最强大、最现代的 HTML 版本。

## HTML 文档结构

每个 HTML 文档都遵循相同的基本结构：

```html
<!DOCTYPE html>              <!-- 文档类型声明 -->
<html lang="zh-CN">          <!-- 根元素，lang 指定语言 -->
<head>                       <!-- 头部信息 -->
    <meta charset="UTF-8">   <!-- 字符编码 -->
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>页面标题</title>   <!-- 浏览器标签页标题 -->
</head>
<body>                       <!-- 页面主体内容 -->
    <!-- 这里写页面内容 -->
</body>
</html>
```

### 结构解析

| 部分 | 说明 |
|------|------|
| `<!DOCTYPE html>` | 告诉浏览器这是 HTML5 文档 |
| `<html>` | 根元素，包含整个页面 |
| `<head>` | 包含元数据，不显示在页面上 |
| `<body>` | 包含可见的页面内容 |

## 创建第一个 HTML 文件

1. 新建文件夹，命名为 `my-web`
2. 在文件夹中创建 `index.html` 文件
3. 输入以下内容：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>我的第一个网页</title>
</head>
<body>
    <h1>欢迎来到我的网页</h1>
    <p>这是我学习 HTML 的第一步！</p>
</body>
</html>
```

4. 使用 Live Server 打开，或直接双击文件在浏览器中查看

## HTML 语法规则

### 标签的基本形式

```html
<标签名>内容</标签名>
```

### 标签的分类

**1. 双标签（容器标签）**

```html
<p>这是一个段落</p>
<div>这是一个区块</div>
```

**2. 单标签（自闭合标签）**

```html
<br>        <!-- 换行 -->
<hr>        <!-- 水平线 -->
<img src="image.jpg">  <!-- 图片 -->
<input type="text">    <!-- 输入框 -->
```

### 标签的属性

属性为标签提供额外信息：

```html
<a href="https://example.com" target="_blank">点击跳转</a>
```

| 属性 | 值 | 说明 |
|------|-----|------|
| `href` | URL | 链接地址 |
| `target` | `_blank` | 在新窗口打开 |

### HTML 注释

```html
<!-- 这是注释，不会显示在页面上 -->
```

> ⚠️ **注意**：注释可以帮助你理解代码，但不要过度使用。

## 常见错误

| 错误 | 示例 | 正确写法 |
|------|------|----------|
| 标签未闭合 | `<p>内容` | `<p>内容</p>` |
| 标签嵌套错误 | `<b><i>内容</b></i>` | `<b><i>内容</i></b>` |
| 属性值无引号 | `<div class=name>` | `<div class="name">` |
