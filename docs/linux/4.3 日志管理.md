# 日志管理

## 日志概述

Linux 系统通过日志记录系统和应用程序的运行状态，日志对于故障排查和系统监控非常重要。

## 日志位置

### 常见日志文件

| 日志文件 | 说明 |
|----------|------|
| /var/log/syslog | 系统日志（Ubuntu/Debian） |
| /var/log/messages | 系统日志（CentOS/RHEL） |
| /var/log/auth.log | 认证日志 |
| /var/log/secure | 安全日志（CentOS/RHEL） |
| /var/log/kern.log | 内核日志 |
| /var/log/dmesg | 启动日志 |
| /var/log/cron | 定时任务日志 |
| /var/log/mail.log | 邮件服务日志 |
| /var/log/nginx/ | Nginx 日志目录 |
| /var/log/apache2/ | Apache 日志目录 |

## 查看日志

### cat 命令

```bash
# 查看日志内容
cat /var/log/syslog

# 查看多个日志
cat /var/log/syslog /var/log/auth.log
```

### tail 命令

```bash
# 查看最后 10 行
tail /var/log/syslog

# 查看最后 n 行
tail -n 50 /var/log/syslog

# 实时查看日志
tail -f /var/log/syslog

# 实时查看多个日志
tail -f /var/log/syslog /var/log/auth.log
```

### head 命令

```bash
# 查看前 10 行
head /var/log/syslog

# 查看前 n 行
head -n 50 /var/log/syslog
```

### less 命令

```bash
# 分页查看日志
less /var/log/syslog

# 操作方式：
# 空格键：向下翻页
# b：向上翻页
# /关键词：搜索
# n：下一个搜索结果
# G：跳到文件末尾
# g：跳到文件开头
# q：退出
```

## 日志搜索

### grep 命令

```bash
# 搜索关键词
grep "error" /var/log/syslog

# 忽略大小写
grep -i "error" /var/log/syslog

# 显示行号
grep -n "error" /var/log/syslog

# 显示上下文
grep -C 5 "error" /var/log/syslog

# 递归搜索
grep -r "error" /var/log/

# 统计匹配行数
grep -c "error" /var/log/syslog

# 搜索多个关键词
grep -E "error|warning" /var/log/syslog
```

### zgrep 命令

搜索压缩日志：

```bash
# 搜索压缩日志
zgrep "error" /var/log/syslog.1.gz

# 递归搜索
zgrep -r "error" /var/log/
```

## journalctl 命令

### 基本使用

```bash
# 查看所有日志
journalctl

# 查看最近的日志
journalctl -n 100

# 实时查看日志
journalctl -f

# 查看今天的日志
journalctl --since today

# 查看指定时间范围的日志
journalctl --since "2024-02-01" --until "2024-02-23"

# 查看最近一小时的日志
journalctl --since "1 hour ago"
```

### 按服务过滤

```bash
# 查看特定服务的日志
journalctl -u nginx

# 查看多个服务的日志
journalctl -u nginx -u mysql

# 查看服务启动日志
journalctl -u nginx -b
```

### 按优先级过滤

```bash
# 查看错误日志
journalctl -p err

# 查看警告及以上级别
journalctl -p warning

# 优先级：
# 0: emerg
# 1: alert
# 2: crit
# 3: err
# 4: warning
# 5: notice
# 6: info
# 7: debug
```

### 其他过滤

```bash
# 查看内核日志
journalctl -k

# 查看特定用户的日志
journalctl _UID=1000

# 查看特定进程的日志
journalctl _PID=1234

# 查看特定可执行文件的日志
journalctl /usr/bin/nginx

# 查看特定设备的日志
journalctl _SYSTEMD_UNIT=nginx.service
```

### 输出格式

```bash
# JSON 格式输出
journalctl -o json

# JSON 美化输出
journalctl -o json-pretty

# 导出格式
journalctl -o export

# 详细输出
journalctl -o verbose
```

## 日志轮转

### logrotate

日志轮转工具，自动压缩和删除旧日志。

#### 配置文件

主配置文件：/etc/logrotate.conf

```bash
# 查看配置
cat /etc/logrotate.conf
```

服务配置目录：/etc/logrotate.d/

```bash
# 查看服务配置
ls /etc/logrotate.d/
```

#### 自定义配置

创建配置文件：

```bash
# 创建配置文件
sudo vim /etc/logrotate.d/myapp
```

配置示例：

```
/var/log/myapp/*.log {
    daily                # 每天轮转
    rotate 7             # 保留7个备份
    compress             # 压缩旧日志
    delaycompress        # 延迟压缩
    missingok            # 日志文件不存在不报错
    notifempty           # 空文件不轮转
    create 0644 www-data www-data  # 创建新日志文件
    sharedscripts        # 共享脚本
    postrotate           # 轮转后执行
        systemctl reload myapp > /dev/null 2>&1 || true
    endscript
}
```

#### 手动执行

```bash
# 测试配置
sudo logrotate -d /etc/logrotate.conf

# 强制执行
sudo logrotate -f /etc/logrotate.conf

# 查看状态
cat /var/lib/logrotate/status
```

## 日志分析

### 统计分析

```bash
# 统计错误数量
grep -c "error" /var/log/syslog

# 统计各状态码数量
awk '{print $9}' /var/log/nginx/access.log | sort | uniq -c | sort -rn

# 统计 IP 访问量
awk '{print $1}' /var/log/nginx/access.log | sort | uniq -c | sort -rn | head -n 10

# 统计访问最多的 URL
awk '{print $7}' /var/log/nginx/access.log | sort | uniq -c | sort -rn | head -n 10
```

### 日志分析工具

#### goaccess

实时 Web 日志分析工具：

```bash
# 安装 goaccess
sudo apt install goaccess

# 分析日志
goaccess /var/log/nginx/access.log -o report.html --log-format=COMBINED

# 实时分析
goaccess /var/log/nginx/access.log -o report.html --log-format=COMBINED --real-time-html
```

#### logwatch

日志分析报告工具：

```bash
# 安装 logwatch
sudo apt install logwatch

# 生成报告
sudo logwatch --output stdout --detail high

# 发送邮件报告
sudo logwatch --mailto admin@example.com
```

## 日志监控

### 实时监控

```bash
# 实时监控日志
tail -f /var/log/syslog

# 监控多个日志
tail -f /var/log/syslog /var/log/auth.log

# 过滤监控
tail -f /var/log/syslog | grep --line-buffered "error"
```

### 日志告警

使用脚本监控日志：

```bash
#!/bin/bash
# 监控错误日志并发送告警

LOG_FILE="/var/log/syslog"
KEYWORDS="error|critical|failed"
ALERT_EMAIL="admin@example.com"

tail -fn0 $LOG_FILE | while read line; do
    if echo "$line" | grep -iE "$KEYWORDS" > /dev/null; then
        echo "$line" | mail -s "Log Alert" $ALERT_EMAIL
    fi
done
```
