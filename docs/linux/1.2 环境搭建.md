# 环境搭建

## 安装方式选择

学习 Linux 有多种方式，根据你的需求和经验选择合适的方式：

### 1. 虚拟机安装（推荐初学者）

虚拟机是在现有操作系统上运行 Linux 的安全方式，优点包括：

- 不影响原有系统
- 可以随时删除和重装
- 方便快照和备份
- 适合学习和实验

### 2. 双系统安装

在电脑上同时安装 Windows 和 Linux，特点：

- 性能更好
- 可以直接访问硬件
- 适合日常使用
- 需要分区操作

### 3. 云服务器

租用云服务器学习 Linux，优势：

- 随时随地访问
- 真实服务器环境
- 按需付费
- 适合远程学习

### 4. WSL（Windows Subsystem for Linux）

Windows 10/11 自带的 Linux 子系统：

- 与 Windows 无缝集成
- 性能接近原生
- 安装简单
- 适合开发环境

## 虚拟机安装教程

### 步骤一：下载虚拟机软件

#### VMware Workstation

1. 访问 VMware 官网下载页面
2. 下载 VMware Workstation Pro（个人使用免费）
3. 运行安装程序
4. 按照向导完成安装

#### VirtualBox（免费开源）

1. 访问 VirtualBox 官网
2. 下载适合你系统的版本
3. 运行安装程序
4. 完成安装并重启电脑

### 步骤二：下载 Linux 发行版

推荐初学者使用 Ubuntu：

1. 访问 Ubuntu 官网下载页面
2. 选择 LTS（长期支持）版本，如 Ubuntu 22.04 LTS
3. 下载 ISO 镜像文件（约 3GB）

其他可选发行版：

- Linux Mint：界面友好，适合 Windows 用户
- Manjaro：基于 Arch，易于使用
- Fedora：技术先进，适合开发者

### 步骤三：创建虚拟机

以 VMware 为例：

1. 打开 VMware Workstation
2. 点击"创建新的虚拟机"
3. 选择"典型"配置
4. 选择"稍后安装操作系统"
5. 选择客户机操作系统为"Linux"
6. 版本选择"Ubuntu 64 位"
7. 设置虚拟机名称和位置
8. 设置磁盘大小（建议 40GB 以上）
9. 完成创建

### 步骤四：配置虚拟机

1. 选择创建的虚拟机
2. 点击"编辑虚拟机设置"
3. 在"CD/DVD"驱动器中选择"使用 ISO 映像文件"
4. 浏览并选择下载的 Ubuntu ISO 文件
5. 调整内存大小（建议 4GB 以上）
6. 调整处理器数量（建议 2 核以上）
7. 点击确定保存设置

### 步骤五：安装 Linux

1. 启动虚拟机
2. 选择"Install Ubuntu"
3. 选择语言（中文）
4. 选择安装类型（正常安装）
5. 选择安装类型（清除整个磁盘并安装 Ubuntu）
6. 设置时区
7. 设置用户名和密码
8. 等待安装完成
9. 重启系统

## WSL 安装教程

### 前提条件

- Windows 10 版本 2004 或更高
- Windows 11 任意版本

### 安装步骤

1. 以管理员身份打开 PowerShell
2. 运行以下命令启用 WSL：

```bash
wsl --install
```

3. 重启电脑
4. 系统会自动安装 Ubuntu
5. 首次启动时设置用户名和密码

### 安装特定发行版

```bash
# 查看可用发行版
wsl --list --online

# 安装特定发行版
wsl --install -d Ubuntu-22.04
```

## 云服务器配置

### 选择云服务商

主流云服务商：

- 阿里云
- 腾讯云
- 华为云
- AWS
- Azure

### 购买服务器

1. 注册云服务商账号
2. 选择服务器类型（按量付费或包年包月）
3. 选择配置（建议 2核4GB 起步）

5. 设置密码或 SSH 密钥
6. 完成购买

### 连接服务器

使用 SSH 连接：

```bash
ssh root@服务器IP地址
```

## 基础配置

### 更新系统

安装完成后首先更新系统：

```bash
# Ubuntu/Debian
sudo apt update
sudo apt upgrade -y

# CentOS/Rocky Linux
sudo yum update -y
# 或
sudo dnf update -y
```

### 安装常用软件

```bash
# 安装文本编辑器
sudo apt install vim -y

# 安装网络工具
sudo apt install net-tools -y

# 安装 Git
sudo apt install git -y

# 安装 htop（进程监控）
sudo apt install htop -y
```

### 配置用户

```bash
# 创建新用户
sudo adduser username

# 将用户添加到 sudo 组
sudo usermod -aG sudo username

# 切换到新用户
su - username
```

### 配置 SSH（仅服务器）

```bash
# 编辑 SSH 配置文件
sudo vim /etc/ssh/sshd_config

# 禁用 root 登录
PermitRootLogin no

# 修改默认端口
Port 2222

# 重启 SSH 服务
sudo systemctl restart sshd
```

## 常见问题

### 1. 虚拟机启动慢

- 增加虚拟机内存
- 启用虚拟化技术（VT-x/AMD-V）
- 使用 SSD 存储

### 2. 网络连接问题

- 检查虚拟机网络模式（NAT/桥接）
- 确认防火墙设置
- 重启网络服务

### 3. 安装失败

- 检查 ISO 文件完整性
- 确认虚拟机配置
- 尝试重新下载 ISO

### 4. WSL 问题

```bash
# 重启 WSL
wsl --shutdown

# 更新 WSL
wsl --update
```
