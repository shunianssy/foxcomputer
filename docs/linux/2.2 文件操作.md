# 文件操作

## 创建文件

### touch 命令

创建空文件或更新文件时间戳：

```bash
# 创建空文件
touch newfile.txt

# 创建多个文件
touch file1.txt file2.txt file3.txt

# 更新文件时间戳
touch -a file.txt    # 更新访问时间
touch -m file.txt    # 更新修改时间
```

### 使用重定向创建文件

```bash
# 创建空文件
> newfile.txt

# 创建文件并写入内容
echo "Hello, Linux" > file.txt

# 追加内容
echo "New line" >> file.txt
```

## 查看文件内容

### cat 命令

查看文件全部内容：

```bash
# 查看文件内容
cat file.txt

# 显示行号
cat -n file.txt

# 显示多个文件
cat file1.txt file2.txt

# 合并文件
cat file1.txt file2.txt > merged.txt
```

### less 命令

分页查看文件：

```bash
# 分页查看文件
less file.txt

# 操作方式：
# 空格键：向下翻页
# b：向上翻页
# /关键词：搜索
# n：下一个搜索结果
# q：退出
```

### more 命令

简单的分页查看：

```bash
# 分页查看
more file.txt

# 操作方式：
# 空格键：向下翻页
# Enter：向下滚动一行
# q：退出
```

### head 命令

查看文件开头部分：

```bash
# 查看前 10 行
head file.txt

# 查看前 n 行
head -n 20 file.txt

# 查看前 n 个字节
head -c 100 file.txt
```

### tail 命令

查看文件末尾部分：

```bash
# 查看后 10 行
tail file.txt

# 查看后 n 行
tail -n 20 file.txt

# 实时查看文件更新（常用于日志）
tail -f /var/log/syslog

# 从第 n 行开始显示
tail -n +10 file.txt
```

## 复制文件

### cp 命令

复制文件和目录：

```bash
# 复制文件
cp source.txt destination.txt

# 复制到目录
cp file.txt /path/to/directory/

# 复制多个文件到目录
cp file1.txt file2.txt /path/to/directory/

# 递归复制目录
cp -r source_dir/ destination_dir/

# 显示复制过程
cp -v source.txt destination.txt

# 保留文件属性
cp -p source.txt destination.txt

# 强制覆盖
cp -f source.txt destination.txt

# 交互式复制（覆盖前确认）
cp -i source.txt destination.txt
```

## 移动和重命名文件

### mv 命令

移动文件或重命名：

```bash
# 重命名文件
mv oldname.txt newname.txt

# 移动文件到目录
mv file.txt /path/to/directory/

# 移动多个文件
mv file1.txt file2.txt /path/to/directory/

# 移动目录
mv old_dir/ new_dir/

# 强制覆盖
mv -f source.txt destination.txt

# 交互式移动
mv -i source.txt destination.txt

# 显示移动过程
mv -v source.txt destination.txt
```

## 删除文件

### rm 命令

删除文件和目录：

```bash
# 删除文件
rm file.txt

# 删除多个文件
rm file1.txt file2.txt

# 交互式删除
rm -i file.txt

# 强制删除
rm -f file.txt

# 删除目录
rm -r directory/

# 删除目录（不提示）
rm -rf directory/

# 显示删除过程
rm -v file.txt
```

### 安全删除

```bash
# 使用 shred 安全删除（覆盖文件内容）
shred -u file.txt

# 覆盖 3 次
shred -n 3 file.txt
```

## 文件编辑

### nano 编辑器

简单易用的文本编辑器：

```bash
# 打开文件
nano file.txt

# 快捷键：
# Ctrl + O：保存
# Ctrl + X：退出
# Ctrl + K：剪切
# Ctrl + U：粘贴
# Ctrl + W：搜索
# Ctrl + G：帮助
```

### vim 编辑器

功能强大的文本编辑器：

```bash
# 打开文件
vim file.txt

# 模式：
# 普通模式：导航和操作
# 插入模式：编辑文本（按 i 进入）
# 命令模式：执行命令（按 : 进入）

# 常用命令：
# i：进入插入模式
# Esc：返回普通模式
# :w：保存
# :q：退出
# :wq：保存并退出
# :q!：强制退出不保存
# dd：删除一行
# yy：复制一行
# p：粘贴
# /关键词：搜索
# :%s/old/new/g：全局替换
```

## 文件搜索

### grep 命令

在文件中搜索文本：

```bash
# 搜索文本
grep "pattern" file.txt

# 递归搜索目录
grep -r "pattern" /path/to/directory/

# 忽略大小写
grep -i "pattern" file.txt

# 显示行号
grep -n "pattern" file.txt

# 显示匹配数量
grep -c "pattern" file.txt

# 显示不匹配的行
grep -v "pattern" file.txt

# 使用正则表达式
grep -E "pattern1|pattern2" file.txt

# 只显示文件名
grep -l "pattern" *.txt
```

### 常用正则表达式

```bash
# 以 pattern 开头
grep "^pattern" file.txt

# 以 pattern 结尾
grep "pattern$" file.txt

# 匹配任意字符
grep "pat.ern" file.txt

# 匹配零次或多次
grep "pat*ern" file.txt

# 匹配一次或多次
grep "pat+ern" file.txt

# 匹配字符集
grep "[abc]" file.txt

# 匹配数字
grep "[0-9]" file.txt
```

## 文件比较

### diff 命令

比较文件差异：

```bash
# 比较两个文件
diff file1.txt file2.txt

# 并排显示
diff -y file1.txt file2.txt

# 显示上下文
diff -c file1.txt file2.txt

# 生成补丁文件
diff -u file1.txt file2.txt > patch.diff
```

### cmp 命令

逐字节比较文件：

```bash
# 比较文件
cmp file1.txt file2.txt

# 显示所有差异
cmp -l file1.txt file2.txt
```

## 文件统计

### wc 命令

统计文件行数、字数、字节数：

```bash
# 统计行数、字数、字节数
wc file.txt

# 只统计行数
wc -l file.txt

# 只统计字数
wc -w file.txt

# 只统计字节数
wc -c file.txt

# 统计多个文件
wc file1.txt file2.txt
```

## 文件排序

### sort 命令

排序文件内容：

```bash
# 排序文件
sort file.txt

# 逆序排序
sort -r file.txt

# 按数字排序
sort -n file.txt

# 按月份排序
sort -M file.txt

# 去除重复行
sort -u file.txt

# 按指定字段排序
sort -k 2 file.txt

# 保存排序结果
sort file.txt > sorted.txt
```

### uniq 命令

去除重复行：

```bash
# 去除重复行（需要先排序）
sort file.txt | uniq

# 显示重复次数
sort file.txt | uniq -c

# 只显示重复行
sort file.txt | uniq -d

# 只显示不重复的行
sort file.txt | uniq -u
```

## 文件分割与合并

### split 命令

分割文件：

```bash
# 按行数分割
split -l 1000 largefile.txt smallfile_

# 按大小分割
split -b 10M largefile.txt smallfile_

# 指定后缀长度
split -l 1000 -d -a 3 largefile.txt smallfile_
```

### 合并文件

```bash
# 合并文件
cat smallfile_* > largefile.txt
```

## 实践练习

### 练习 1：文件创建与查看

```bash
# 1. 创建文件
touch test.txt

# 2. 写入内容
echo "Hello, Linux" > test.txt
echo "Second line" >> test.txt

# 3. 查看文件
cat test.txt

# 4. 查看文件信息
wc test.txt
```

### 练习 2：文件复制与移动

```bash
# 1. 创建目录
mkdir backup

# 2. 复制文件
cp test.txt backup/

# 3. 重命名文件
mv test.txt renamed.txt

# 4. 移动文件
mv renamed.txt backup/
```

### 练习 3：文件搜索

```bash
# 1. 创建测试文件
echo -e "apple\nbanana\napple\ncherry\nbanana" > fruits.txt

# 2. 搜索特定内容
grep "apple" fruits.txt

# 3. 统计出现次数
grep -c "apple" fruits.txt

# 4. 去除重复行
sort fruits.txt | uniq
```
