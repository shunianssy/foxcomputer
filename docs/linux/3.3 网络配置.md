# 网络配置

## 网络基础

### 网络接口

Linux 系统中的网络接口通常命名为：

- eth0、eth1：以太网接口
- wlan0、wlan1：无线网卡接口
- lo：本地回环接口
- enp0s3、ens33：新的命名规则

### IP 地址

IP 地址是网络中设备的标识符，分为 IPv4 和 IPv6：

- IPv4：192.168.1.100
- IPv6：2001:db8::1

### 子网掩码

子网掩码用于划分网络和主机部分：

- 255.255.255.0（/24）
- 255.255.0.0（/16）

### 网关

网关是连接不同网络的设备，用于转发数据包。

### DNS

域名系统（DNS）将域名解析为 IP 地址。

## 查看网络信息

### ip 命令

查看和配置网络：

```bash
# 查看所有网络接口
ip addr

# 查看特定接口
ip addr show eth0

# 查看路由表
ip route

# 查看 ARP 表
ip neigh

# 查看网络统计
ip -s link
```

### ifconfig 命令

传统网络配置命令（需要安装 net-tools）：

```bash
# 安装 net-tools
sudo apt install net-tools

# 查看所有网络接口
ifconfig

# 查看特定接口
ifconfig eth0

# 启用接口
sudo ifconfig eth0 up

# 禁用接口
sudo ifconfig eth0 down
```

### 查看网络连接

```bash
# 查看所有网络连接
netstat -an

# 查看监听端口
netstat -tuln

# 查看 TCP 连接
netstat -tn

# 查看 UDP 连接
netstat -un

# 查看进程和端口
sudo netstat -tlnp

# 使用 ss 命令（推荐）
ss -tuln

# 查看所有连接
ss -a

# 查看进程信息
ss -tlnp
```

## 配置网络

### 静态 IP 配置

#### Ubuntu/Debian（Netplan）

编辑 Netplan 配置文件：

```bash
# 编辑配置文件
sudo vim /etc/netplan/00-installer-config.yaml
```

配置示例：

```yaml
network:
  version: 2
  renderer: networkd
  ethernets:
    eth0:
      addresses:
        - 192.168.1.100/24
      routes:
        - to: default
          via: 192.168.1.1
      nameservers:
        addresses:
          - 8.8.8.8
          - 8.8.4.4
```

应用配置：

```bash
# 应用配置
sudo netplan apply

# 测试配置
sudo netplan try
```

#### CentOS/RHEL

编辑网络配置文件：

```bash
# 编辑配置文件
sudo vim /etc/sysconfig/network-scripts/ifcfg-eth0
```

配置示例：

```
TYPE=Ethernet
BOOTPROTO=static
NAME=eth0
DEVICE=eth0
ONBOOT=yes
IPADDR=192.168.1.100
NETMASK=255.255.255.0
GATEWAY=192.168.1.1
DNS1=8.8.8.8
DNS2=8.8.4.4
```

重启网络服务：

```bash
# 重启网络
sudo systemctl restart network
```

### DHCP 配置

#### Ubuntu/Debian

```yaml
network:
  version: 2
  renderer: networkd
  ethernets:
    eth0:
      dhcp4: yes
```

#### CentOS/RHEL

```
TYPE=Ethernet
BOOTPROTO=dhcp
NAME=eth0
DEVICE=eth0
ONBOOT=yes
```

### 使用 ip 命令临时配置

```bash
# 添加 IP 地址
sudo ip addr add 192.168.1.100/24 dev eth0

# 删除 IP 地址
sudo ip addr del 192.168.1.100/24 dev eth0

# 添加默认网关
sudo ip route add default via 192.168.1.1

# 删除默认网关
sudo ip route del default via 192.168.1.1

# 启用接口
sudo ip link set eth0 up

# 禁用接口
sudo ip link set eth0 down
```

## DNS 配置

### /etc/resolv.conf

配置 DNS 服务器：

```bash
# 编辑 DNS 配置
sudo vim /etc/resolv.conf
```

配置示例：

```
nameserver 8.8.8.8
nameserver 8.8.4.4
search example.com
```

### systemd-resolved

使用 systemd-resolved 管理 DNS：

```bash
# 查看 DNS 配置
resolvectl status

# 设置 DNS 服务器
sudo resolvectl dns eth0 8.8.8.8 8.8.4.4

# 重启服务
sudo systemctl restart systemd-resolved
```

## 主机名配置

### 设置主机名

```bash
# 查看主机名
hostname

# 设置主机名（临时）
sudo hostname new-hostname

# 设置主机名（永久）
sudo hostnamectl set-hostname new-hostname

# 编辑 hosts 文件
sudo vim /etc/hosts
```

### /etc/hosts 文件

本地域名解析：

```
127.0.0.1       localhost
127.0.1.1       hostname
192.168.1.100   server.example.com server
```

## 网络工具

### ping 命令

测试网络连通性：

```bash
# 测试连通性
ping 8.8.8.8

# 测试域名
ping google.com

# 指定次数
ping -c 4 8.8.8.8

# 指定间隔
ping -i 2 8.8.8.8
```

### traceroute 命令

追踪数据包路由：

```bash
# 安装 traceroute
sudo apt install traceroute

# 追踪路由
traceroute google.com

# 使用 ICMP
traceroute -I google.com

# 使用 TCP
traceroute -T google.com
```

### curl 命令

HTTP 客户端工具：

```bash
# 发送 GET 请求
curl http://example.com

# 发送 POST 请求
curl -X POST -d "data=value" http://example.com

# 下载文件
curl -O http://example.com/file.txt

# 显示响应头
curl -I http://example.com

# 指定超时
curl --connect-timeout 10 http://example.com

# 使用代理
curl -x http://proxy:8080 http://example.com
```

### wget 命令

下载文件：

```bash
# 下载文件
wget http://example.com/file.txt

# 指定保存文件名
wget -O newname.txt http://example.com/file.txt

# 断点续传
wget -c http://example.com/file.txt

# 后台下载
wget -b http://example.com/file.txt

# 递归下载网站
wget -r http://example.com/
```

### ssh 命令

远程登录：

```bash
# 远程登录
ssh user@hostname

# 指定端口
ssh -p 2222 user@hostname

# 使用密钥
ssh -i ~/.ssh/id_rsa user@hostname

# 执行远程命令
ssh user@hostname 'command'

# 端口转发
ssh -L 8080:localhost:80 user@hostname

# 反向端口转发
ssh -R 80:localhost:8080 user@hostname
```

### scp 命令

远程复制文件：

```bash
# 复制文件到远程
scp file.txt user@hostname:/path/

# 从远程复制文件
scp user@hostname:/path/file.txt ./

# 复制目录
scp -r directory/ user@hostname:/path/

# 指定端口
scp -P 2222 file.txt user@hostname:/path/
```

## 防火墙配置

### ufw（Ubuntu）

```bash
# 安装 ufw
sudo apt install ufw

# 启用防火墙
sudo ufw enable

# 禁用防火墙
sudo ufw disable

# 查看状态
sudo ufw status

# 允许端口
sudo ufw allow 22
sudo ufw allow 80/tcp

# 拒绝端口
sudo ufw deny 80

# 允许特定 IP
sudo ufw allow from 192.168.1.100

# 删除规则
sudo ufw delete allow 22

# 重置规则
sudo ufw reset
```

### firewalld（CentOS/RHEL）

```bash
# 安装 firewalld
sudo yum install firewalld

# 启动服务
sudo systemctl start firewalld

# 查看状态
sudo firewall-cmd --state

# 查看所有规则
sudo firewall-cmd --list-all

# 开放端口
sudo firewall-cmd --add-port=80/tcp --permanent

# 移除端口
sudo firewall-cmd --remove-port=80/tcp --permanent

# 重载配置
sudo firewall-cmd --reload

# 开放服务
sudo firewall-cmd --add-service=http --permanent
```

### iptables

```bash
# 查看规则
sudo iptables -L

# 允许入站 SSH
sudo iptables -A INPUT -p tcp --dport 22 -j ACCEPT

# 允许入站 HTTP
sudo iptables -A INPUT -p tcp --dport 80 -j ACCEPT

# 拒绝所有入站
sudo iptables -A INPUT -j DROP

# 删除规则
sudo iptables -D INPUT 1

# 保存规则
sudo iptables-save > /etc/iptables/rules.v4

# 恢复规则
sudo iptables-restore < /etc/iptables/rules.v4
```

## 网络故障排查

### 常用诊断命令

```bash
# 检查网络接口
ip addr

# 检查路由
ip route

# 检查 DNS 解析
nslookup google.com
dig google.com

# 检查端口
netstat -tuln
ss -tuln

# 检查网络连接
ping 8.8.8.8

# 追踪路由
traceroute google.com

# 检查防火墙
sudo ufw status
sudo firewall-cmd --list-all
```

### 常见问题

#### 1. 无法连接网络

```bash
# 检查网络接口
ip addr

# 检查 IP 地址
ip addr show eth0

# 检查网关
ip route

# 检查 DNS
cat /etc/resolv.conf

# 测试 DNS 解析
nslookup google.com
```

#### 2. DNS 解析失败

```bash
# 检查 DNS 配置
cat /etc/resolv.conf

# 修改 DNS
sudo vim /etc/resolv.conf

# 测试 DNS
nslookup google.com
dig google.com
```

#### 3. 端口被占用

```bash
# 查看端口占用
sudo lsof -i :80
sudo netstat -tlnp | grep :80

# 终止占用进程
sudo kill -9 PID
```
