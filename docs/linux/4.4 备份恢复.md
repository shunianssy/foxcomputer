# 备份恢复

## 备份概述

数据备份是系统管理的重要任务，可以防止数据丢失。备份策略包括：

- 完全备份：备份所有数据
- 增量备份：只备份变化的数据
- 差异备份：备份自上次完全备份以来的变化

## tar 命令

### 创建备份

```bash
# 创建 tar 归档
tar -cvf backup.tar /path/to/directory

# 创建压缩归档（gzip）
tar -czvf backup.tar.gz /path/to/directory

# 创建压缩归档（bzip2）
tar -cjvf backup.tar.bz2 /path/to/directory

# 创建压缩归档（xz）
tar -cJvf backup.tar.xz /path/to/directory

# 排除特定文件
tar -czvf backup.tar.gz --exclude='*.log' /path/to/directory

# 排除多个目录
tar -czvf backup.tar.gz --exclude={'dir1','dir2'} /path/to/directory

# 查看归档内容
tar -tvf backup.tar.gz
```

### 恢复备份

```bash
# 解压 tar 归档
tar -xvf backup.tar

# 解压 gzip 归档
tar -xzvf backup.tar.gz

# 解压到指定目录
tar -xzvf backup.tar.gz -C /path/to/directory

# 解压特定文件
tar -xzvf backup.tar.gz path/to/file

# 保留原权限
tar -xzvpf backup.tar.gz
```

## rsync 命令

### 基本使用

```bash
# 同步目录
rsync -av source/ destination/

# 显示进度
rsync -av --progress source/ destination/

# 删除目标中源没有的文件
rsync -av --delete source/ destination/

# 排除特定文件
rsync -av --exclude='*.log' source/ destination/

# 排除多个模式
rsync -av --exclude={'*.log','*.tmp'} source/ destination/

# 显示传输统计
rsync -av --stats source/ destination/
```

### 远程同步

```bash
# 推送到远程
rsync -avz source/ user@remote:/path/to/destination/

# 从远程拉取
rsync -avz user@remote:/path/to/source/ destination/

# 使用 SSH 指定端口
rsync -avz -e "ssh -p 2222" source/ user@remote:/path/

# 显示进度
rsync -avz --progress source/ user@remote:/path/

# 限速传输（KB/s）
rsync -avz --bwlimit=1000 source/ user@remote:/path/
```

### 增量备份

```bash
# 使用 --link-dest 创建增量备份
rsync -av --link-dest=/backup/previous /source/ /backup/current

# 创建硬链接备份
rsync -av --link-dest=../backup-2024-02-22 /data/ /backup/backup-2024-02-23
```

## dd 命令

### 磁盘克隆

```bash
# 克隆整个磁盘
sudo dd if=/dev/sda of=/dev/sdb bs=4M status=progress

# 创建磁盘镜像
sudo dd if=/dev/sda of=disk.img bs=4M status=progress

# 从镜像恢复
sudo dd if=disk.img of=/dev/sda bs=4M status=progress

# 压缩镜像
sudo dd if=/dev/sda | gzip > disk.img.gz

# 从压缩镜像恢复
gunzip -c disk.img.gz | sudo dd of=/dev/sda
```

### 分区备份

```bash
# 备份分区
sudo dd if=/dev/sda1 of=partition.img bs=4M status=progress

# 恢复分区
sudo dd if=partition.img of=/dev/sda1 bs=4M status=progress
```

## 数据库备份

### MySQL/MariaDB

```bash
# 备份所有数据库
mysqldump -u root -p --all-databases > all_databases.sql

# 备份特定数据库
mysqldump -u root -p database_name > database.sql

# 备份特定表
mysqldump -u root -p database_name table_name > table.sql

# 备份结构（不含数据）
mysqldump -u root -p --no-data database_name > structure.sql

# 压缩备份
mysqldump -u root -p database_name | gzip > database.sql.gz

# 恢复数据库
mysql -u root -p database_name < database.sql

# 恢复压缩备份
gunzip < database.sql.gz | mysql -u root -p database_name
```

### PostgreSQL

```bash
# 备份数据库
pg_dump -U username database_name > database.sql

# 备份所有数据库
pg_dumpall -U username > all_databases.sql

# 压缩备份
pg_dump -U username database_name | gzip > database.sql.gz

# 自定义格式备份
pg_dump -U username -F c database_name > database.dump

# 恢复数据库
psql -U username database_name < database.sql

# 恢复自定义格式
pg_restore -U username -d database_name database.dump
```

## 自动备份脚本

### 简单备份脚本

```bash
#!/bin/bash
# 简单备份脚本

# 配置
SOURCE="/data"
DEST="/backup"
DATE=$(date +%Y%m%d)
BACKUP_FILE="backup-${DATE}.tar.gz"

# 创建备份
tar -czvf ${DEST}/${BACKUP_FILE} ${SOURCE}

# 删除 7 天前的备份
find ${DEST} -name "backup-*.tar.gz" -mtime +7 -delete

# 记录日志
echo "Backup completed: ${BACKUP_FILE}" >> ${DEST}/backup.log
```

### 完整备份脚本

```bash
#!/bin/bash
# 完整备份脚本

# 配置
SOURCE_DIR="/data"
BACKUP_DIR="/backup"
REMOTE_USER="backup"
REMOTE_HOST="backup.example.com"
REMOTE_DIR="/backup/server"
DATE=$(date +%Y%m%d)
LOG_FILE="/var/log/backup.log"

# 日志函数
log() {
    echo "$(date '+%Y-%m-%d %H:%M:%S') - $1" >> ${LOG_FILE}
}

# 创建备份目录
mkdir -p ${BACKUP_DIR}

# 本地备份
log "Starting local backup..."
tar -czvf ${BACKUP_DIR}/backup-${DATE}.tar.gz ${SOURCE_DIR} 2>> ${LOG_FILE}

if [ $? -eq 0 ]; then
    log "Local backup completed successfully"
else
    log "Local backup failed"
    exit 1
fi

# 远程同步
log "Starting remote sync..."
rsync -avz --delete ${BACKUP_DIR}/ ${REMOTE_USER}@${REMOTE_HOST}:${REMOTE_DIR}/ >> ${LOG_FILE} 2>&1

if [ $? -eq 0 ]; then
    log "Remote sync completed successfully"
else
    log "Remote sync failed"
    exit 1
fi

# 清理旧备份
log "Cleaning old backups..."
find ${BACKUP_DIR} -name "backup-*.tar.gz" -mtime +30 -delete >> ${LOG_FILE} 2>&1

log "Backup process completed"
```

### 数据库备份脚本

```bash
#!/bin/bash
# MySQL 数据库备份脚本

# 配置
DB_USER="root"
DB_PASS="password"
BACKUP_DIR="/backup/mysql"
DATE=$(date +%Y%m%d)
LOG_FILE="/var/log/mysql-backup.log"

# 创建备份目录
mkdir -p ${BACKUP_DIR}

# 获取数据库列表
DATABASES=$(mysql -u ${DB_USER} -p${DB_PASS} -e "SHOW DATABASES;" | grep -Ev "(Database|information_schema|performance_schema)")

# 备份每个数据库
for DB in ${DATABASES}; do
    log "Backing up database: ${DB}"
    mysqldump -u ${DB_USER} -p${DB_PASS} ${DB} | gzip > ${BACKUP_DIR}/${DB}-${DATE}.sql.gz
done

# 清理旧备份
find ${BACKUP_DIR} -name "*.sql.gz" -mtime +7 -delete

log "Database backup completed"
```

## 备份策略

### 3-2-1 备份原则

- 3：保留至少 3 份数据副本
- 2：使用至少 2 种不同的存储介质
- 1：至少 1 份异地备份

### 备份计划

```bash
# 每日增量备份
0 2 * * * /usr/local/bin/incremental-backup.sh

# 每周完全备份
0 3 * * 0 /usr/local/bin/full-backup.sh

# 每月归档备份
0 4 1 * * /usr/local/bin/archive-backup.sh
```

## 验证备份

### 检查备份完整性

```bash
# 验证 tar 归档
tar -tzvf backup.tar.gz > /dev/null && echo "OK" || echo "FAILED"

# 验证压缩文件
gzip -t backup.tar.gz && echo "OK" || echo "FAILED"

# 比较文件差异
diff -r source/ destination/
```

### 测试恢复

```bash
# 创建测试目录
mkdir -p /tmp/restore_test

# 恢复到测试目录
tar -xzvf backup.tar.gz -C /tmp/restore_test

# 验证文件
ls -la /tmp/restore_test

# 清理测试目录
rm -rf /tmp/restore_test
```

