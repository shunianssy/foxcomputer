# 第一个命令

## 终端简介

终端是 Linux 系统中与系统交互的主要方式，通过命令行界面（CLI）执行各种操作。相比图形界面，终端具有以下优势：

- 执行效率高
- 资源占用少
- 适合远程操作
- 便于自动化脚本

## 第一个命令：echo

echo 是最简单的命令，用于在终端输出文本：

```bash
echo "Hello, Linux!"
```

输出结果：
```
Hello, Linux!
```

## 常用基础命令

### 1. pwd - 显示当前目录

pwd（Print Working Directory）显示当前所在的工作目录：

```bash
pwd
```

输出示例：
```
/home/username
```

### 2. ls - 列出目录内容

ls（List）命令用于列出目录中的文件和子目录：

```bash
# 列出当前目录内容
ls

# 列出详细信息（包括权限、大小、时间等）
ls -l

# 显示隐藏文件（以点开头的文件）
ls -a

# 以人类可读格式显示文件大小
ls -lh

# 组合使用
ls -lah
```

常用选项：
- -l：长格式显示
- -a：显示所有文件，包括隐藏文件
- -h：以人类可读格式显示大小
- -t：按修改时间排序
- -r：反向排序

### 3. cd - 切换目录

cd（Change Directory）用于切换当前工作目录：

```bash
# 切换到指定目录
cd /home/username

# 切换到上一级目录
cd ..

# 切换到用户主目录
cd ~

# 切换到上一次所在的目录
cd -

# 切换到根目录
cd /
```

### 4. clear - 清屏

clear 命令用于清除终端屏幕内容：

```bash
clear
```

快捷键：Ctrl + L

### 5. date - 显示日期时间

date 命令显示或设置系统日期和时间：

```bash
# 显示当前日期时间
date

# 按指定格式显示
date "+%Y-%m-%d %H:%M:%S"

# 设置日期时间（需要 root 权限）
sudo date -s "2024-02-23 12:00:00"
```

### 6. cal - 显示日历

cal 命令显示日历：

```bash
# 显示当前月份的日历
cal

# 显示指定年份的日历
cal 2024

# 显示指定月份的日历
cal 2 2024
```

### 7. whoami - 显示当前用户

whoami 命令显示当前登录的用户名：

```bash
whoami
```

### 8. hostname - 显示主机名

hostname 命令显示或设置系统主机名：

```bash
# 显示主机名
hostname

# 设置主机名（需要 root 权限）
sudo hostname new-hostname
```

## 命令的基本格式

Linux 命令的基本格式为：

```
命令 [选项] [参数]
```

- 命令：要执行的程序名称
- 选项：修改命令行为的标志，通常以 - 开头
- 参数：命令操作的对象

示例：
```bash
ls -l /home/username
```

- ls：命令
- -l：选项
- /home/username：参数

## 命令帮助

### 1. man - 查看手册

man（Manual）命令显示命令的详细手册：

```bash
man ls
```

操作方式：
- 空格键：向下翻页
- Enter：向下滚动一行
- q：退出手册
- /关键词：搜索关键词

### 2. --help 选项

大多数命令支持 --help 选项显示简要帮助：

```bash
ls --help
```

### 3. info 命令

info 命令提供更详细的信息：

```bash
info ls
```

## 命令自动补全

在终端中输入命令或文件名时，可以按 Tab 键自动补全：

```bash
# 输入部分命令后按 Tab
cd Doc[Tab]  # 自动补全为 cd Documents

# 如果有多个匹配，按两次 Tab 显示所有选项
```

## 命令历史

### 1. 查看历史命令

使用 history 命令查看之前执行的命令：

```bash
history
```

### 2. 执行历史命令

```bash
# 执行第 n 条历史命令
!n

# 执行上一条命令
!!

# 执行上一条以指定字符串开头的命令
!ls
```

### 3. 快捷键

- 上箭头：显示上一条命令
- 下箭头：显示下一条命令
- Ctrl + R：搜索历史命令

## 命令组合与管道

### 1. 命令分隔符

使用分号（;）分隔多个命令，按顺序执行：

```bash
pwd; ls; date
```

### 2. 管道符

管道符（|）将一个命令的输出作为另一个命令的输入：

```bash
# 将 ls 的输出通过管道传给 less 分页显示
ls -l | less

# 查找文件
ls -l | grep ".txt"
```

### 3. 输出重定向

将命令输出重定向到文件：

```bash
# 覆盖写入文件
ls -l > filelist.txt

# 追加到文件
ls -l >> filelist.txt

# 错误输出重定向
command 2> error.log

# 同时重定向标准输出和错误输出
command > output.log 2>&1
```

## 常见错误

### 1. 命令未找到

```
command not found
```

解决方法：
- 检查命令拼写
- 确认命令已安装
- 使用 which 查找命令位置

### 2. 权限不足

```
Permission denied
```

解决方法：
- 使用 sudo 提升权限
- 检查文件权限

### 3. 目录不存在

```
No such file or directory
```

解决方法：
- 检查路径拼写
- 使用 ls 确认目录存在
