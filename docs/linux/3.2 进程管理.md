# 进程管理

## 进程概述

进程是正在运行的程序实例，每个进程都有唯一的进程 ID（PID）。Linux 是多任务操作系统，可以同时运行多个进程。

## 进程类型

### 1. 前台进程

需要用户交互的进程，占用终端。

### 2. 后台进程

在后台运行的进程，不占用终端。

### 3. 守护进程

在后台运行的服务进程，通常在系统启动时启动。

## 进程信息文件

### /proc/[pid]

每个进程都有一个 /proc/[pid] 目录，包含进程信息：

```bash
# 查看进程信息
ls /proc/1/

# 查看进程命令行
cat /proc/1/cmdline

# 查看进程环境变量
cat /proc/1/environ

# 查看进程状态
cat /proc/1/status

# 查看进程打开的文件
ls /proc/1/fd/
```

## 查看进程

### ps 命令

查看进程信息：

```bash
# 查看当前用户的进程
ps

# 查看所有进程
ps aux

# 查看所有进程的详细信息
ps -ef

# 查看特定进程
ps -p PID

# 查看特定用户的进程
ps -u username

# 按资源使用排序
ps aux --sort=-%cpu
ps aux --sort=-%mem

# 查看进程树
ps -ejH

# 查看进程线程
ps -eLf
```

ps 输出说明：

```
USER       PID %CPU %MEM    VSZ   RSS TTY      STAT START   TIME COMMAND
│          │   │    │      │     │   │        │     │    │
│          │   │    │      │     │   │        │     │    └─ 命令
│          │   │    │      │     │   │        │     └─────── CPU 时间
│          │   │    │      │     │   │        └─────────── 启动时间
│          │   │    │      │     │   └──────────────────── 状态
│          │   │    │      │     └──────────────────────── 终端
│          │   │    │      └───────────────────────────── 物理内存
│          │   │    └───────────────────────────────────── 虚拟内存
│          │   └───────────────────────────────────────── 内存使用率
│          └───────────────────────────────────────────── CPU 使用率
└───────────────────────────────────────────────────────── 用户名
```

### top 命令

实时查看进程：

```bash
# 启动 top
top

# 交互命令：
# P：按 CPU 使用率排序
# M：按内存使用率排序
# N：按 PID 排序
# k：杀死进程
# r：重新设置进程优先级
# q：退出
# h：显示帮助
```

### htop 命令

增强版的 top（需要安装）：

```bash
# 安装 htop
sudo apt install htop

# 启动 htop
htop

# 特点：
# - 彩色显示
# - 鼠标操作
# - 更好的界面
# - 支持树形显示
```

### pgrep 命令

按名称查找进程：

```bash
# 查找进程
pgrep process_name

# 显示完整命令行
pgrep -a process_name

# 显示 PID
pgrep -l process_name

# 查找特定用户的进程
pgrep -u username process_name
```

### pidof 命令

查找进程的 PID：

```bash
# 查找进程 PID
pidof process_name

# 查找多个进程的 PID
pidof process1 process2
```

## 进程控制

### kill 命令

终止进程：

```bash
# 终止进程（默认 SIGTERM）
kill PID

# 强制终止进程（SIGKILL）
kill -9 PID

# 发送特定信号
kill -SIGNAL PID

# 按名称终止进程
killall process_name

# 强制终止同名进程
killall -9 process_name

# 终止特定用户的进程
pkill -u username process_name
```

常用信号：

| 信号 | 编号 | 说明 |
|------|------|------|
| SIGHUP | 1 | 挂起信号，重新加载配置 |
| SIGINT | 2 | 中断信号（Ctrl + C） |
| SIGQUIT | 3 | 退出信号（Ctrl + \） |
| SIGKILL | 9 | 强制终止 |
| SIGTERM | 15 | 终止信号（默认） |
| SIGCONT | 18 | 继续执行 |
| SIGSTOP | 19 | 暂停执行 |

### pkill 命令

按名称终止进程：

```bash
# 终止进程
pkill process_name

# 终止特定用户的进程
pkill -u username

# 终止特定终端的进程
pkill -t tty1

# 显示将要终止的进程
pkill -l process_name
```

### killall 命令

终止所有同名进程：

```bash
# 终止所有同名进程
killall process_name

# 强制终止
killall -9 process_name

# 终止特定用户的进程
killall -u username process_name

# 交互式终止
killall -i process_name
```

## 后台进程

### 后台运行

```bash
# 在后台运行命令
command &

# 将前台进程放到后台
Ctrl + Z
bg

# 查看后台任务
jobs

# 将后台任务调到前台
fg %1

# 继续后台运行
bg %1
```

### nohup 命令

不挂断地运行命令：

```bash
# 不挂断地运行命令
nohup command &

# 输出到文件
nohup command > output.log 2>&1 &

# 查看输出
tail -f nohup.out
```

### disown 命令

从当前 Shell 移除任务：

```bash
# 后台运行
command &

# 从当前 Shell 移除
disown

# 移除特定任务
disown %1

# 移除所有任务
disown -a
```

## 进程优先级

### nice 命令

以指定优先级启动进程：

```bash
# 以默认优先级启动
nice command

# 指定优先级（-20 到 19）
nice -n 10 command

# 高优先级
nice -n -5 command

# 低优先级
nice -n 15 command
```

### renice 命令

修改运行中进程的优先级：

```bash
# 修改进程优先级
renice -n 10 -p PID

# 修改用户所有进程的优先级
renice -n 5 -u username

# 修改用户组所有进程的优先级
renice -n 5 -g groupname
```

## 进程监控

### vmstat 命令

查看虚拟内存统计：

```bash
# 查看系统统计
vmstat

# 每秒更新一次
vmstat 1

# 显示 10 次统计
vmstat 1 10

# 显示详细信息
vmstat -s
```

### iostat 命令

查看 I/O 统计：

```bash
# 查看 I/O 统计
iostat

# 每秒更新
iostat 1

# 显示详细信息
iostat -x
```

### mpstat 命令

查看 CPU 统计：

```bash
# 查看 CPU 统计
mpstat

# 每秒更新
mpstat 1

# 显示每个 CPU 的统计
mpstat -P ALL
```

## 进程树

### pstree 命令

显示进程树：

```bash
# 显示进程树
pstree

# 显示 PID
pstree -p

# 显示用户
pstree -u

# 显示完整命令行
pstree -a

# 高亮显示当前进程
pstree -h
```

## 实践练习

### 练习 1：查看和管理进程

```bash
# 1. 查看所有进程
ps aux

# 2. 查找特定进程
ps aux | grep nginx

# 3. 使用 pgrep 查找进程
pgrep nginx

# 4. 查看进程详细信息
ps -p PID -o pid,ppid,cmd,%cpu,%mem
```

```bash
sleep 100 &

# 2. 查看后台任务
jobs

ps aux | grep sleep

# 4. 终止进程
kill %1
```

```bash

top

# 2. 按 CPU 排序
P

# 3. 按内存排序
M

# 4. 退出
q
```

## 故障排查

### 僵尸进程

```bash
# 查找僵尸进程
ps aux | grep Z

# 查找僵尸进程的父进程
ps -eo pid,ppid,stat,cmd | grep Z

# 终止父进程
kill -9 PPID
```

### 高 CPU 使用

```bash
# 查找高 CPU 使用进程
top

# 或
ps aux --sort=-%cpu | head -n 10
```

### 高内存使用

```bash
# 查找高内存使用进程
ps aux --sort=-%mem | head -n 10
```
