# 文件系统

## Linux 文件系统概述

Linux 文件系统采用树形结构，从根目录（/）开始，所有文件和目录都挂载在这个树形结构上。

### 文件系统层次结构标准（FHS）

Linux 遵循文件系统层次结构标准（Filesystem Hierarchy Standard），定义了各目录的用途。

## 目录结构详解

### 根目录（/）

根目录是整个文件系统的起点，所有文件和目录都位于根目录下。

```bash
# 查看根目录内容
ls /
```

### 主要目录说明

| 目录 | 说明 |
|------|------|
| /bin | 基本命令二进制文件（所有用户可用） |
| /sbin | 系统管理命令二进制文件（通常需要 root 权限） |
| /boot | 启动加载器文件和内核 |
| /dev | 设备文件 |
| /etc | 系统配置文件 |
| /home | 普通用户主目录 |
| /lib | 共享库文件 |
| /lib64 | 64位共享库文件 |
| /media | 可移动设备挂载点 |
| /mnt | 临时挂载点 |
| /opt | 可选软件包 |
| /proc | 进程和内核信息（虚拟文件系统） |
| /root | root 用户主目录 |
| /run | 运行时数据 |
| /srv | 服务数据 |
| /sys | 系统设备信息（虚拟文件系统） |
| /tmp | 临时文件 |
| /usr | 用户程序和数据 |
| /var | 可变数据文件 |

### 重要目录详解

#### /etc - 配置文件目录

存放系统和应用程序的配置文件：

```bash
# 常见配置文件
/etc/passwd          # 用户信息
/etc/shadow          # 用户密码信息
/etc/group           # 用户组信息
/etc/hosts           # 主机名解析
/etc/fstab           # 文件系统挂载配置
/etc/hostname        # 主机名
/etc/ssh/            # SSH 配置
/etc/apt/            # APT 配置
```

#### /home - 用户主目录

普通用户的主目录，每个用户都有一个子目录：

```bash
# 用户主目录
/home/username/      # 用户主目录
/home/username/Documents/  # 文档目录
/home/username/Downloads/  # 下载目录
```

#### /var - 可变数据目录

存放经常变化的数据：

```bash
# 常见目录
/var/log/            # 日志文件
/var/cache/          # 缓存数据
/var/spool/          # 队列数据
/var/lib/            # 应用程序数据
/var/www/            # Web 服务器文件
```

#### /usr - 用户程序目录

存放用户程序和数据：

```bash
# 常见目录
/usr/bin/            # 用户命令
/usr/sbin/           # 系统管理命令
/usr/lib/            # 库文件
/usr/local/          # 本地安装的软件
/usr/share/          # 共享数据
```

#### /proc - 进程信息目录

虚拟文件系统，提供内核和进程信息：

```bash
# 常见文件
/proc/cpuinfo        # CPU 信息
/proc/meminfo        # 内存信息
/proc/version        # 内核版本
/proc/uptime         # 系统运行时间
/proc/[pid]/         # 进程信息
```

#### /dev - 设备文件目录

存放设备文件：

```bash
# 常见设备文件
/dev/null            # 空设备
/dev/zero            # 零设备
/dev/random          # 随机数设备
/dev/sda             # SATA 硬盘
/dev/tty             # 终端设备
```

## 文件类型

Linux 中一切皆文件，常见的文件类型：

| 类型 | 标识 | 说明 |
|------|------|------|
| 普通文件 | - | 文本文件、二进制文件等 |
| 目录 | d | 目录文件 |
| 链接文件 | l | 符号链接 |
| 块设备 | b | 硬盘、U盘等 |
| 字符设备 | c | 键盘、鼠标等 |
| 管道文件 | p | 命名管道 |
| 套接字 | s | 网络套接字 |

### 查看文件类型

```bash
# 使用 ls -l 查看文件类型
ls -l

# 使用 file 命令
file filename

# 使用 stat 命令
stat filename
```

## 文件路径

### 绝对路径

从根目录开始的完整路径：

```bash
/home/username/Documents/file.txt
/etc/passwd
/var/log/syslog
```

### 相对路径

相对于当前目录的路径：

```bash
./file.txt           # 当前目录的文件
../file.txt          # 上级目录的文件
Documents/file.txt   # 子目录中的文件
```

### 特殊目录符号

| 符号 | 说明 |
|------|------|
| . | 当前目录 |
| .. | 上级目录 |
| ~ | 用户主目录 |
| - | 上一次所在目录 |

## 文件系统操作

### 查看磁盘使用情况

```bash
# 查看磁盘空间使用
df -h

# 查看目录大小
du -sh /path/to/directory

# 查看当前目录下各子目录大小
du -h --max-depth=1
```

### 挂载文件系统

```bash
# 挂载设备
mount /dev/sdb1 /mnt/usb

# 卸载设备
umount /mnt/usb

# 查看挂载信息
mount
```

### 文件系统检查

```bash
# 检查文件系统（需要卸载）
fsck /dev/sda1

# 检查 ext4 文件系统
e2fsck /dev/sda1
```

## 文件链接

### 硬链接

硬链接指向文件的物理数据：

```bash
# 创建硬链接
ln source.txt hardlink.txt

# 特点：
# - 指向相同的 inode
# - 删除原文件不影响硬链接
# - 不能跨文件系统
# - 不能链接目录
```

### 符号链接（软链接）

符号链接是指向另一个文件的路径：

```bash
# 创建符号链接
ln -s source.txt symlink.txt

# 特点：
# - 指向文件路径
# - 删除原文件后链接失效
# - 可以跨文件系统
# - 可以链接目录
```

### 查看链接

```bash
# 查看链接信息
ls -l symlink.txt

# 查看链接目标
readlink symlink.txt
```

## 文件查找

### find 命令

强大的文件查找工具：

```bash
# 按名称查找
find /path -name "*.txt"

# 按类型查找
find /path -type f    # 文件
find /path -type d    # 目录
find /path -type l    # 链接

# 按大小查找
find /path -size +100M  # 大于 100MB
find /path -size -10k   # 小于 10KB

# 按时间查找
find /path -mtime -7    # 7天内修改过
find /path -atime +30   # 30天前访问过

# 按权限查找
find /path -perm 755

# 组合条件
find /path -name "*.txt" -size +1M

# 执行操作
find /path -name "*.log" -delete
find /path -name "*.txt" -exec chmod 644 {} \;
```

### locate 命令

快速查找文件（使用数据库）：

```bash
# 更新数据库
sudo updatedb

# 查找文件
locate filename

# 忽略大小写
locate -i filename
```

### which 命令

查找命令的位置：

```bash
# 查找命令路径
which python3
```

### whereis 命令

查找命令、源码和手册：

```bash
# 查找命令相关文件
whereis ls
```

## 实践练习

### 练习 1：探索文件系统

```bash
# 1. 查看根目录结构
ls /

# 2. 查看 /etc 目录内容
ls /etc

# 3. 查看 CPU 信息
cat /proc/cpuinfo

# 4. 查看内存信息
cat /proc/meminfo
```

### 练习 2：文件查找

```bash
# 1. 查找所有 .txt 文件
find ~ -name "*.txt"

# 2. 查找大于 100MB 的文件
find ~ -size +100M

# 3. 查找最近 7 天修改的文件
find ~ -mtime -7

# 4. 使用 locate 查找文件
locate bash
```

### 练习 3：文件链接

```bash
# 1. 创建测试文件
echo "Hello" > original.txt

# 2. 创建硬链接
ln original.txt hardlink.txt

# 3. 创建符号链接
ln -s original.txt symlink.txt

# 4. 查看链接信息
ls -l *.txt

# 5. 删除原文件，观察链接变化
rm original.txt
cat hardlink.txt    # 仍然可读
cat symlink.txt     # 链接失效
```
