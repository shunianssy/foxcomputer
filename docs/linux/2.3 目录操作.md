# 目录操作

## 创建目录

### mkdir 命令

创建目录：

```bash
# 创建单个目录
mkdir newdir

# 创建多个目录
mkdir dir1 dir2 dir3

# 创建多级目录
mkdir -p parent/child/grandchild

# 显示创建过程
mkdir -v newdir

# 创建目录并设置权限
mkdir -m 755 newdir
```

## 切换目录

### cd 命令

切换工作目录：

```bash
# 切换到指定目录
cd /path/to/directory

# 切换到用户主目录
cd ~
# 或
cd

# 切换到上一级目录
cd ..

# 切换到上一次所在目录
cd -

# 切换到根目录
cd /

# 使用相对路径
cd Documents/Projects
```

## 列出目录内容

### ls 命令

列出目录内容：

```bash
# 列出当前目录
ls

# 列出指定目录
ls /path/to/directory

# 详细信息
ls -l

# 显示隐藏文件
ls -a

# 人类可读格式
ls -lh

# 按时间排序
ls -lt

# 按大小排序
ls -lS

# 反向排序
ls -lr

# 组合选项
ls -lah

# 递归列出
ls -R
```

### ls 输出说明

```
-rw-r--r-- 1 user group 1234 Feb 23 12:00 file.txt
│ │ │ │  │   │    │      │    │    │
│ │ │ │  │   │    │      │    │    └─ 文件名
│ │ │ │  │   │    │      │    └───── 修改时间
│ │ │ │  │   │    │      └────────── 文件大小
│ │ │ │  │   │    └───────────────── 用户组
│ │ │ │  │   └────────────────────── 用户名
│ │ │ │  └────────────────────────── 链接数
│ │ │ └───────────────────────────── 权限
│ │ └──────────────────────────────── 文件类型
│ └────────────────────────────────── 用户权限
└─────────────────────────────────── 组权限
```

## 删除目录

### rmdir 命令

删除空目录：

```bash
# 删除空目录
rmdir emptydir

# 删除多个空目录
rmdir dir1 dir2

# 删除多级空目录
rmdir -p parent/child/grandchild

# 显示删除过程
rmdir -v emptydir
```

### rm 命令

删除目录（包括非空目录）：

```bash
# 删除目录及其内容
rm -r directory/

# 强制删除（不提示）
rm -rf directory/

# 交互式删除
rm -ri directory/

# 显示删除过程
rm -rv directory/
```

## 移动目录

### mv 命令

移动或重命名目录：

```bash
# 重命名目录
mv olddir newdir

# 移动目录
mv dir1 /path/to/destination/

# 移动多个目录
mv dir1 dir2 /path/to/destination/

# 覆盖前确认
mv -i dir1 /path/to/destination/

# 显示移动过程
mv -v dir1 /path/to/destination/
```

## 复制目录

### cp 命令

复制目录：

```bash
# 复制目录及其内容
cp -r sourcedir/ destdir/

# 保留文件属性
cp -rp sourcedir/ destdir/

# 显示复制过程
cp -rv sourcedir/ destdir/

# 交互式复制
cp -ri sourcedir/ destdir/

# 仅复制目录结构
cp -r --parents dir1/dir2 destdir/
```

## 查看目录树

### tree 命令

以树形结构显示目录：

```bash
# 安装 tree
sudo apt install tree

# 显示当前目录树
tree

# 显示指定目录
tree /path/to/directory

# 只显示目录
tree -d

# 显示文件大小
tree -h

# 限制深度
tree -L 2

# 显示隐藏文件
tree -a

# 输出到文件
tree > tree.txt
```

## 目录导航技巧

### pushd 和 popd

目录栈操作：

```bash
# 将目录压入栈并切换
pushd /path/to/directory

# 查看目录栈
dirs

# 切换到栈顶目录
popd

# 切换到栈中指定目录
pushd +2

# 交换栈顶两个目录
pushd
```

### 快速导航

```bash
# 使用 Tab 自动补全
cd Doc[Tab]

# 使用历史目录
cd -

# 使用环境变量
cd $HOME
cd $OLDPWD

# 使用通配符
cd D*
```

## 目录权限

### 查看目录权限

```bash
# 查看目录权限
ls -ld directory/

# 详细查看
stat directory/
```

### 修改目录权限

```bash
# 修改权限
chmod 755 directory/

# 递归修改权限
chmod -R 755 directory/

# 添加执行权限
chmod +x directory/

# 移除写权限
chmod -w directory/
```

### 修改目录所有者

```bash
# 修改所有者
chown user directory/

# 修改所有者和组
chown user:group directory/

# 递归修改
chown -R user:group directory/
```

## 目录大小

### du 命令

查看目录大小：

```bash
# 查看目录大小
du -sh directory/

# 查看当前目录下各子目录大小
du -h --max-depth=1

# 查看所有文件大小
du -ah directory/

# 按大小排序
du -h --max-depth=1 | sort -hr

# 查看总大小
du -csh directory/
```

## 目录查找

### find 命令

查找目录：

```bash
# 查找目录
find /path -type d

# 按名称查找目录
find /path -type d -name "dirname"

# 查找空目录
find /path -type d -empty

# 查找特定权限的目录
find /path -type d -perm 755

# 查找最近修改的目录
find /path -type d -mtime -7
```

## 目录链接

### 符号链接目录

```bash
# 创建目录符号链接
ln -s /path/to/original linkdir

# 查看链接
ls -l linkdir

# 查看链接目标
readlink linkdir
```

## 目录比较

### diff 命令

比较目录：

```bash
# 比较两个目录
diff -r dir1/ dir2/

# 只显示文件差异
diff -rq dir1/ dir2/

# 生成补丁
diff -Naur dir1/ dir2/ > patch.diff
```

## 目录备份

### tar 命令

打包目录：

```bash
# 打包目录
tar -cvf archive.tar directory/

# 压缩打包
tar -czvf archive.tar.gz directory/

# 解包
tar -xvf archive.tar

# 解压缩
tar -xzvf archive.tar.gz

# 查看内容
tar -tvf archive.tar
```

### rsync 命令

同步目录：

```bash
# 同步目录
rsync -av source/ destination/

# 删除目标中源没有的文件
rsync -av --delete source/ destination/

# 显示传输进度
rsync -av --progress source/ destination/

# 通过 SSH 同步远程目录
rsync -avz -e ssh source/ user@remote:/path/
```

## 实践练习

### 练习 1：目录创建与管理

```bash
# 1. 创建多级目录
mkdir -p project/{src,docs,tests}

# 2. 查看目录结构
tree project/

# 3. 切换目录
cd project/src

# 4. 返回上级目录
cd ../..

# 5. 查看目录大小
du -sh project/
```

### 练习 2：目录复制与移动

```bash
# 1. 创建测试目录
mkdir testdir
echo "test" > testdir/file.txt

# 2. 复制目录
cp -r testdir testdir_copy

# 3. 重命名目录
mv testdir newdir

# 4. 移动目录
mv newdir backup/
```

### 练习 3：目录查找

```bash
# 1. 查找所有目录
find ~ -type d

# 2. 查找空目录
find ~ -type d -empty

# 3. 查找最近修改的目录
find ~ -type d -mtime -7

# 4. 查找特定名称的目录
find ~ -type d -name "*test*"
```
