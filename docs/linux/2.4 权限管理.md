# 权限管理

## 权限概述

Linux 是多用户操作系统，通过权限机制控制用户对文件和目录的访问。权限分为三类：

- 读（Read，r）：查看文件内容或列出目录内容
- 写（Write，w）：修改文件内容或在目录中创建/删除文件
- 执行（Execute，x）：执行文件或进入目录

## 权限表示

### 字符表示法

```
-rwxr-xr--
│└┬┘└┬┘└┬┘
│ │  │  └── 其他用户权限（r--）
│ │  └───── 用户组权限（r-x）
│ └──────── 文件所有者权限（rwx）
└────────── 文件类型（- 普通文件）
```

### 数字表示法

每种权限对应一个数字：

| 权限 | 数字 |
|------|------|
| r（读） | 4 |
| w（写） | 2 |
| x（执行） | 1 |

组合权限：

| 权限 | 数字 | 说明 |
|------|------|------|
| --- | 0 | 无权限 |
| --x | 1 | 仅执行 |
| -w- | 2 | 仅写 |
| -wx | 3 | 写和执行 |
| r-- | 4 | 仅读 |
| r-x | 5 | 读和执行 |
| rw- | 6 | 读和写 |
| rwx | 7 | 读、写、执行 |

示例：
- 755 = rwxr-xr-x
- 644 = rw-r--r--
- 700 = rwx------

## 查看权限

### ls 命令

```bash
# 查看文件权限
ls -l file.txt

# 查看目录权限
ls -ld directory/

# 查看所有文件权限
ls -la
```

### stat 命令

```bash
# 查看详细权限信息
stat file.txt

# 只显示权限
stat -c "%a %n" file.txt
```

## 修改权限

### chmod 命令

修改文件权限：

#### 数字方式

```bash
# 设置权限为 755
chmod 755 file.txt

# 设置权限为 644
chmod 644 file.txt

# 递归修改目录权限
chmod -R 755 directory/
```

#### 符号方式

```bash
# 给所有者添加执行权限
chmod u+x file.txt

# 给用户组添加写权限
chmod g+w file.txt

# 给其他用户移除读权限
chmod o-r file.txt

# 给所有用户添加执行权限
chmod a+x file.txt

# 同时设置多个权限
chmod u=rwx,g=rx,o=r file.txt

# 递归修改
chmod -R u+rwx directory/
```

符号说明：

| 符号 | 含义 |
|------|------|
| u | 用户（所有者） |
| g | 用户组 |
| o | 其他用户 |
| a | 所有用户 |
| + | 添加权限 |
| - | 移除权限 |
| = | 设置权限 |

## 修改所有者

### chown 命令

修改文件所有者：

```bash
# 修改所有者
chown user file.txt

# 修改所有者和用户组
chown user:group file.txt

# 只修改用户组
chown :group file.txt

# 递归修改
chown -R user:group directory/

# 显示修改过程
chown -v user file.txt
```

### chgrp 命令

修改文件所属组：

```bash
# 修改用户组
chgrp group file.txt

# 递归修改
chgrp -R group directory/
```

## 特殊权限

### SUID（Set User ID）

当执行文件时，进程具有文件所有者的权限：

```bash
# 设置 SUID
chmod u+s file

# 数字方式（4xxx）
chmod 4755 file

# 查找 SUID 文件
find / -perm -4000
```

示例：
```
-rwsr-xr-x 1 root root ... /usr/bin/passwd
```

### SGID（Set Group ID）

对于文件：执行时具有文件所属组的权限
对于目录：新创建的文件继承目录的所属组

```bash
# 设置 SGID
chmod g+s directory/

# 数字方式（2xxx）
chmod 2755 directory/

# 查找 SGID 文件
find / -perm -2000
```

### Sticky Bit

对于目录：只有文件所有者才能删除自己的文件

```bash
# 设置 Sticky Bit
chmod +t directory/

# 数字方式（1xxx）
chmod 1777 directory/

# 查找 Sticky Bit 目录
find / -perm -1000
```

示例：
```
drwxrwxrwt 10 root root 4096 /tmp
```

## 默认权限

### umask

umask 决定新建文件和目录的默认权限：

```bash
# 查看当前 umask
umask

# 设置 umask
umask 022

# 符号方式查看
umask -S
```

默认权限计算：

| 类型 | 默认权限 | umask 022 | 结果 |
|------|----------|-----------|------|
| 文件 | 666 | 022 | 644 |
| 目录 | 777 | 022 | 755 |

### 配置 umask

在 ~/.bashrc 中设置：

```bash
# 设置默认 umask
umask 022
```

## 文件属性

### lsattr 命令

查看文件属性：

```bash
# 查看文件属性
lsattr file.txt

# 查看目录属性
lsattr -d directory/

# 递归查看
lsattr -R directory/
```

### chattr 命令

修改文件属性：

```bash
# 设置不可修改属性
sudo chattr +i file.txt

# 移除不可修改属性
sudo chattr -i file.txt

# 设置只追加属性
sudo chattr +a file.txt

# 移除只追加属性
sudo chattr -a file.txt
```

常用属性：

| 属性 | 说明 |
|------|------|
| i | 不可修改（immutable） |
| a | 只能追加（append only） |
| s | 删除时安全擦除 |
| u | 删除时可恢复 |
| c | 自动压缩 |

## 访问控制列表（ACL）

### 查看 ACL

```bash
# 查看 ACL
getfacl file.txt

# 查看目录 ACL
getfacl directory/
```

### 设置 ACL

```bash
# 给用户添加权限
setfacl -m u:username:rwx file.txt

# 给用户组添加权限
setfacl -m g:groupname:rx file.txt

# 设置默认 ACL（目录）
setfacl -d -m u:username:rwx directory/

# 删除 ACL
setfacl -x u:username file.txt

# 清除所有 ACL
setfacl -b file.txt
```

### ACL 示例

```bash
# 查看文件 ACL
getfacl file.txt
# 输出：
# file: file.txt
# owner: user
# group: group
# user::rw-
# user:guest:r--
# group::r--
# mask::rw-
# other::r--
```

## 权限故障排查

### 常见问题

#### 1. 权限拒绝

```
Permission denied
```

解决方法：
```bash
# 检查文件权限
ls -l file.txt

# 检查目录权限
ls -ld directory/

# 检查所有者
ls -l file.txt

# 使用 sudo
sudo command
```

#### 2. 无法执行脚本

```
bash: ./script.sh: Permission denied
```

解决方法：
```bash
# 添加执行权限
chmod +x script.sh

# 或使用解释器执行
bash script.sh
```

#### 3. 无法访问目录

```
cd: permission denied
```

解决方法：
```bash
# 检查目录权限
ls -ld directory/

# 添加执行权限
chmod +x directory/
```

## 权限最佳实践

### 1. 最小权限原则

只授予必要的权限：

```bash
# 配置文件：644
chmod 644 config.txt

# 脚本文件：755
chmod 755 script.sh

# 私钥文件：600
chmod 600 private.key

# 敏感目录：700
chmod 700 ~/.ssh/
```

### 2. 文件权限建议

| 文件类型 | 建议权限 |
|----------|----------|
| 可执行文件 | 755 |
| 配置文件 | 644 |
| 私钥文件 | 600 |
| 日志文件 | 644 |
| Web 目录 | 755 |
| Web 文件 | 644 |

### 3. 安全检查

```bash
# 查找世界可写文件
find / -type f -perm -0002

# 查找 SUID 文件
find / -type f -perm -4000

# 查找 SGID 文件
find / -type f -perm -2000

# 查找无主文件
find / -nouser -o -nogroup
```

## 实践练习

### 练习 1：基本权限操作

```bash
# 1. 创建测试文件
touch test.txt

# 2. 查看权限
ls -l test.txt

# 3. 修改权限
chmod 755 test.txt

# 4. 查看修改后的权限
ls -l test.txt

# 5. 使用符号方式修改
chmod u-x test.txt
```

### 练习 2：所有者操作

```bash
# 1. 创建文件
touch myfile.txt

# 2. 查看所有者
ls -l myfile.txt

# 3. 修改所有者（需要 sudo）
sudo chown root myfile.txt

# 4. 修改用户组
sudo chgrp root myfile.txt
```

### 练习 3：特殊权限

```bash
# 1. 创建测试目录
mkdir testdir

# 2. 设置 Sticky Bit
chmod +t testdir

# 3. 查看权限
ls -ld testdir

# 4. 创建文件测试
touch testdir/file1.txt
```
