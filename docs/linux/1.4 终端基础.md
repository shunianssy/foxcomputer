# 终端基础

## 终端与 Shell

### 什么是终端

终端（Terminal）是一个输入输出设备，用于与计算机系统交互。在现代 Linux 系统中，终端模拟器提供了命令行界面。

### 什么是 Shell

Shell 是命令解释器，是用户与 Linux 内核之间的接口。它接收用户输入的命令，解释后传递给内核执行。

常见的 Shell 类型：
- Bash（Bourne Again Shell）：最常用的 Shell
- Zsh（Z Shell）：功能强大的 Shell
- Fish：友好的交互式 Shell
- Dash：轻量级 Shell

### 查看当前 Shell

```bash
# 查看当前使用的 Shell
echo $SHELL

# 查看系统可用的 Shell
cat /etc/shells
```

## 终端配置

### Bash 配置文件

Bash 启动时会读取以下配置文件：

#### 登录 Shell

- /etc/profile：系统级配置
- ~/.bash_profile 或 ~/.bash_login 或 ~/.profile：用户级配置

#### 非登录 Shell

- /etc/bash.bashrc：系统级配置
- ~/.bashrc：用户级配置

### 配置示例

编辑 ~/.bashrc 文件：

```bash
# 编辑配置文件
vim ~/.bashrc

# 添加自定义别名
alias ll='ls -lh'
alias la='ls -lha'
alias ..='cd ..'

# 添加环境变量
export PATH=$PATH:/usr/local/bin

# 自定义提示符
export PS1='[\u@\h \W]\$ '

# 使配置生效
source ~/.bashrc
```

### 终端外观配置

#### 修改颜色方案

```bash
# 在 ~/.bashrc 中添加
export LS_COLORS='di=34:fi=0:ln=35:pi=33:so=32:bd=34;46:cd=34;43:ex=31'
```

#### 自定义提示符

提示符变量 PS1 的特殊字符：

| 字符 | 含义 |
|------|------|
| \u | 当前用户名 |
| \h | 主机名 |
| \w | 当前工作目录 |
| \W | 当前工作目录的 basename |
| \$ | 如果是 root 显示 #，否则显示 $ |
| \t | 当前时间（24小时制） |
| \d | 当前日期 |
| \n | 换行 |

示例：
```bash
# 绿色用户名@主机名，蓝色路径
export PS1='\[\033[01;32m\]\u@\h\[\033[00m\]:\[\033[01;34m\]\w\[\033[00m\]\$ '
```

## 终端多任务

### 前台与后台

#### 后台运行命令

```bash
# 在命令后添加 & 符号
command &

# 将前台命令放到后台
Ctrl + Z
bg
```

#### 查看后台任务

```bash
# 查看后台任务
jobs

# 将后台任务调到前台
fg %1
```

### 多个终端会话

#### screen

screen 是一个全屏窗口管理器：

```bash
# 安装 screen
sudo apt install screen

# 创建新会话
screen -S session_name

# 分离会话
Ctrl + A, D

# 重新连接会话
screen -r session_name

# 列出所有会话
screen -ls

# 杀死会话
screen -X -S session_name quit
```

#### tmux

tmux 是一个现代化的终端复用器：

```bash
# 安装 tmux
sudo apt install tmux

# 创建新会话
tmux new -s session_name

# 分离会话
Ctrl + B, D

# 重新连接会话
tmux attach -t session_name

# 列出所有会话
tmux ls

# 创建新窗口
Ctrl + B, C

# 切换窗口
Ctrl + B, N（下一个）
Ctrl + B, P（上一个）

# 分割窗口
Ctrl + B, %（垂直分割）
Ctrl + B, "（水平分割）

# 切换面板
Ctrl + B, 方向键
```

## 终端安全

### 安全实践

1. 不要以 root 身份登录
2. 使用 sudo 执行需要权限的命令
3. 定期更新系统
4. 使用强密码
5. 配置防火墙
6. 限制 SSH 访问

### SSH 安全配置

```bash
# 编辑 SSH 配置
sudo vim /etc/ssh/sshd_config

# 禁用 root 登录
PermitRootLogin no

# 修改默认端口
Port 2222

# 禁用密码认证（使用密钥）
PasswordAuthentication no

# 重启 SSH 服务
sudo systemctl restart sshd
```

## 终端故障排查

### 常见问题

#### 1. 终端显示乱码

```bash
# 设置字符编码
export LANG=zh_CN.UTF-8

# 或在 ~/.bashrc 中添加
echo 'export LANG=zh_CN.UTF-8' >> ~/.bashrc
```

#### 2. 命令历史不保存

```bash
# 检查 ~/.bash_history 文件权限
ls -la ~/.bash_history

# 如果权限问题，修复权限
chmod 600 ~/.bash_history
```

#### 3. Tab 补全不工作

```bash
# 安装 bash-completion
sudo apt install bash-completion

# 重新加载配置
source ~/.bashrc
```

#### 4. 终端响应慢

```bash
# 检查系统负载
top

# 检查磁盘使用
df -h

# 检查内存使用
free -h
```

## 终端技巧

### 命令行技巧

#### 1. 快速重复命令

```bash
# 重复上一条命令
!!

# 重复上一条命令的最后一个参数
!$

# 重复上一条命令的第一个参数
!^
```

#### 2. 命令替换

```bash
# 使用命令输出作为参数
cd $(dirname $(which python3))

# 使用反引号（旧方法）
cd `dirname \`which python3\``
```

#### 3. 命令历史扩展

```bash
# 执行上一条以 ls 开头的命令
!ls

# 执行历史中第 100 条命令
!100
```

### 文本操作技巧

#### 1. 快速编辑命令

```bash
# 删除到行首
Ctrl + U

# 删除到行尾
Ctrl + K

# 交换前两个字符
Ctrl + T
```

#### 2. 命令历史搜索

```bash
# 搜索包含特定字符串的命令
Ctrl + R
# 输入搜索字符串，按 Enter 执行
```
