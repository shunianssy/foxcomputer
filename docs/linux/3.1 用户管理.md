# 用户管理

## 用户概述

Linux 是多用户操作系统，支持多个用户同时使用系统。每个用户都有独立的用户名、用户 ID（UID）和主目录。

## 用户类型

### 1. root 用户

系统管理员用户，UID 为 0，拥有系统的完全控制权。

### 2. 系统用户

用于运行系统服务，UID 通常在 1-999 之间。

### 3. 普通用户

普通登录用户，UID 通常从 1000 开始。

## 用户信息文件

### /etc/passwd

存储用户基本信息：

```
username:x:1000:1000:User Name:/home/username:/bin/bash
│        │  │   │   │         │              │
│        │  │   │   │         │              └─ 登录 Shell
│        │  │   │   │         └──────────────── 主目录
│        │  │   │   └───────────────────────── 用户描述
│        │  │   └───────────────────────────── 用户组 ID（GID）
│        │  └───────────────────────────────── 用户 ID（UID）
│        └──────────────────────────────────── 密码占位符
└───────────────────────────────────────────── 用户名
```

查看用户信息：

```bash
# 查看所有用户
cat /etc/passwd

# 查看特定用户
grep username /etc/passwd

# 查看当前用户
id
```

### /etc/shadow

存储用户密码信息（加密）：

```
username:$6$hash...:19000:0:99999:7:::
│        │         │     │  │    │ │
│        │         │     │  │    │ └─ 禁用日期
│        │         │     │  │    └── 警告天数
│        │         │     │  └─────── 密码有效期
│        │         │     └────────── 最小密码天数
│        │         └──────────────── 最后修改日期
│        └────────────────────────── 加密密码
└──────────────────────────────────── 用户名
```

查看密码信息：

```bash
# 需要 root 权限
sudo cat /etc/shadow
```

## 用户管理命令

### useradd 命令

创建新用户：

```bash
# 创建用户
sudo useradd username

# 创建用户并指定主目录
sudo useradd -m username

# 创建用户并指定 Shell
sudo useradd -s /bin/bash username

# 创建用户并指定 UID
sudo useradd -u 1001 username

# 创建用户并添加到用户组
sudo useradd -G sudo,docker username

# 创建用户并指定主目录路径
sudo useradd -d /custom/home username

# 创建用户并添加描述
sudo useradd -c "User Description" username

# 创建用户并设置密码过期
sudo useradd -e 2024-12-31 username
```

### userdel 命令

删除用户：

```bash
# 删除用户
sudo userdel username

# 删除用户及其主目录
sudo userdel -r username

# 删除用户及其主目录和邮件池
sudo userdel -r username
```

### usermod 命令

修改用户属性：

```bash
# 修改用户名
sudo usermod -l newname oldname

# 修改用户主目录
sudo usermod -d /new/home username

# 修改用户 Shell
sudo usermod -s /bin/zsh username

# 添加用户到用户组
sudo usermod -aG groupname username

# 修改用户 UID
sudo usermod -u 1001 username

# 修改用户描述
sudo usermod -c "New Description" username

# 锁定用户
sudo usermod -L username

# 解锁用户
sudo usermod -U username

# 设置密码过期
sudo usermod -e 2024-12-31 username
```

## 密码管理

### passwd 命令

设置和修改密码：

```bash
# 修改当前用户密码
passwd

# 修改指定用户密码（需要 root）
sudo passwd username

# 删除用户密码（允许无密码登录）
sudo passwd -d username

# 锁定用户密码
sudo passwd -l username

# 解锁用户密码
sudo passwd -u username

# 设置密码过期
sudo passwd -e username

# 查看密码状态
sudo passwd -S username
```

### 密码策略

#### /etc/login.defs

密码策略配置：

```bash
# 查看密码策略
cat /etc/login.defs

# 重要配置项：
# PASS_MAX_DAYS：密码最大有效期
# PASS_MIN_DAYS：密码最小有效期
# PASS_MIN_LEN：密码最小长度
# PASS_WARN_AGE：密码过期警告天数
```

#### chage 命令

管理密码过期信息：

```bash
# 查看密码过期信息
chage -l username

# 设置密码过期天数
sudo chage -M 90 username

# 设置密码最小天数
sudo chage -m 7 username

# 设置密码警告天数
sudo chage -W 7 username

# 设置账户过期日期
sudo chage -E 2024-12-31 username

# 强制下次登录修改密码
sudo chage -d 0 username
```

## 用户查询

### id 命令

查看用户信息：

```bash
# 查看当前用户信息
id

# 查看指定用户信息
id username

# 只显示 UID
id -u username

# 只显示 GID
id -g username

# 显示所有组
id -G username
```

### who 命令

查看当前登录用户：

```bash
# 查看登录用户
who

# 显示详细信息
who -a

# 显示登录时间
who -b

# 显示死进程
who -d
```

### w 命令

查看登录用户及其活动：

```bash
# 查看登录用户活动
w

# 指定用户
w username
```

### last 命令

查看登录历史：

```bash
# 查看登录历史
last

# 查看特定用户
last username

# 查看最近 n 次登录
last -n 10

# 查看失败登录
lastb
```

## 用户切换

### su 命令

切换用户：

```bash
# 切换到 root 用户
su -

# 切换到指定用户
su - username

# 切换用户但不加载环境变量
su username

# 以指定用户执行命令
su -c "command" username
```

### sudo 命令

以管理员权限执行命令：

```bash
# 以 root 权限执行命令
sudo command

# 以指定用户执行命令
sudo -u username command

# 以 root 权限打开 Shell
sudo -i

# 列出 sudo 权限
sudo -l

# 编辑 sudo 配置
sudo visudo
```

## 用户组管理

### /etc/group

存储用户组信息：

```
groupname:x:1000:user1,user2
│         │  │   │
│         │  │   └─ 组成员
│         │  └───── 用户组 ID（GID）
│         └──────── 密码占位符
└────────────────── 用户组名
```

查看用户组：

```bash
# 查看所有用户组
cat /etc/group

# 查看特定用户组
grep groupname /etc/group

# 查看用户所属组
groups username

# 查看当前用户所属组
groups
```

### groupadd 命令

创建用户组：

```bash
# 创建用户组
sudo groupadd groupname

# 创建用户组并指定 GID
sudo groupadd -g 1001 groupname

# 创建系统用户组
sudo groupadd -r groupname
```

### groupdel 命令

删除用户组：

```bash
# 删除用户组
sudo groupdel groupname
```

### groupmod 命令

修改用户组：

```bash
# 修改用户组名
sudo groupmod -n newname oldname

# 修改用户组 GID
sudo groupmod -g 1001 groupname
```

### gpasswd 命令

管理用户组成员：

```bash
# 添加用户到用户组
sudo gpasswd -a username groupname

# 从用户组移除用户
sudo gpasswd -d username groupname

# 设置用户组管理员
sudo gpasswd -A username groupname

# 删除用户组密码
sudo gpasswd -r groupname
```

## 用户环境

### 用户主目录

每个用户都有独立的主目录，通常位于 /home/username：

```bash
# 查看当前用户主目录
echo $HOME

cd ~

# 查看主目录内容
ls -la ~
```

## 安全建议

### 1. 最小权限原则

- 不要以 root 身份登录
- 使用 sudo 执行需要权限的命令
- 为每个用户分配最小必要权限

### 2. 密码安全

- 使用强密码
- 定期更换密码
- 启用密码过期策略
- 禁用空密码账户

### 3. 账户管理

- 定期审查用户账户
- 删除不需要的用户
- 锁定长期不用的账户
- 监控登录活动
