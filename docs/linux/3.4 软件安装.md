# 软件安装

## 软件包管理概述

Linux 系统使用软件包管理器来安装、更新和删除软件。不同的发行版使用不同的包管理器：

- Debian/Ubuntu：apt、dpkg
- CentOS/RHEL：yum、dnf、rpm
- Arch Linux：pacman
- Fedora：dnf

## APT（Debian/Ubuntu）

### 更新软件源

```bash
# 更新软件源列表
sudo apt update

# 升级已安装的软件包
sudo apt upgrade

# 完整升级（包括依赖关系）
sudo apt full-upgrade

# 更新并升级
sudo apt update && sudo apt upgrade -y
```

### 搜索软件包

```bash
# 搜索软件包
apt search package_name

# 查看软件包信息
apt show package_name

# 列出所有可用软件包
apt list

# 列出已安装的软件包
apt list --installed

# 列出可升级的软件包
apt list --upgradable
```

### 安装软件包

```bash
# 安装软件包
sudo apt install package_name

# 安装多个软件包
sudo apt install package1 package2 package3

# 安装特定版本
sudo apt install package_name=version

# 安装但不升级
sudo apt install package_name --no-upgrade

# 重新安装
sudo apt install --reinstall package_name

# 仅下载不安装
sudo apt install --download-only package_name
```

### 删除软件包

```bash
# 删除软件包（保留配置文件）
sudo apt remove package_name

# 删除软件包和配置文件
sudo apt purge package_name

# 删除不需要的依赖
sudo apt autoremove

# 清理下载的包文件
sudo apt clean

# 清理过期的包文件
sudo apt autoclean
```

### 软件源配置

#### /etc/apt/sources.list

主软件源配置文件：

```bash
# 查看软件源
cat /etc/apt/sources.list

# 编辑软件源
sudo vim /etc/apt/sources.list
```

#### /etc/apt/sources.list.d/

额外的软件源配置：

```bash
# 查看额外软件源
ls /etc/apt/sources.list.d/

# 添加 PPA
sudo add-apt-repository ppa:user/ppa-name

# 删除 PPA
sudo add-apt-repository --remove ppa:user/ppa-name
```

### dpkg 命令

底层软件包管理工具：

```bash
# 安装 deb 包
sudo dpkg -i package.deb

# 删除软件包
sudo dpkg -r package_name

# 删除软件包和配置文件
sudo dpkg -P package_name

# 查看已安装的软件包
dpkg -l

# 查看软件包信息
dpkg -s package_name

# 查看软件包安装的文件
dpkg -L package_name

# 查看文件属于哪个软件包
dpkg -S /path/to/file

# 修复依赖问题
sudo apt --fix-broken install
```

## YUM/DNF（CentOS/RHEL）

### 更新软件源

```bash
# 更新软件源
sudo yum makecache

# 升级所有软件包
sudo yum update

# 升级特定软件包
sudo yum update package_name
```

### 搜索软件包

```bash
# 搜索软件包
yum search package_name

# 查看软件包信息
yum info package_name

# 列出所有可用软件包
yum list

# 列出已安装的软件包
yum list installed

# 列出可升级的软件包
yum list updates
```

### 安装软件包

```bash
# 安装软件包
sudo yum install package_name

# 安装多个软件包
sudo yum install package1 package2

# 安装特定版本
sudo yum install package_name-version

# 重新安装
sudo yum reinstall package_name

# 仅下载不安装
sudo yum install --downloadonly --downloaddir=/path package_name
```

### 删除软件包

```bash
# 删除软件包
sudo yum remove package_name

# 删除软件包和依赖
sudo yum autoremove package_name

# 清理缓存
sudo yum clean all
```

### 软件源配置

#### /etc/yum.repos.d/

软件源配置目录：

```bash
# 查看软件源
ls /etc/yum.repos.d/

# 添加 EPEL 源
sudo yum install epel-release
```

### rpm 命令

底层软件包管理工具：

```bash
# 安装 rpm 包
sudo rpm -ivh package.rpm

# 升级软件包
sudo rpm -Uvh package.rpm

# 删除软件包
sudo rpm -e package_name

# 查看已安装的软件包
rpm -qa

# 查看软件包信息
rpm -qi package_name

# 查看软件包安装的文件
rpm -ql package_name

# 查看文件属于哪个软件包
rpm -qf /path/to/file
```

## Pacman（Arch Linux）

### 更新系统

```bash
# 更新软件源并升级系统
sudo pacman -Syu

# 仅更新软件源
sudo pacman -Sy

# 仅升级系统
sudo pacman -Su
```

### 搜索软件包

```bash
# 搜索软件包
pacman -Ss package_name

# 查看软件包信息
pacman -Si package_name

# 查看已安装的软件包
pacman -Q

# 搜索已安装的软件包
pacman -Qs package_name

# 查看软件包信息（已安装）
pacman -Qi package_name
```

### 安装软件包

```bash
# 安装软件包
sudo pacman -S package_name

# 安装多个软件包
sudo pacman -S package1 package2

# 安装本地包
sudo pacman -U package.pkg.tar.zst

# 从 URL 安装
sudo pacman -U http://example.com/package.pkg.tar.zst
```

### 删除软件包

```bash
# 删除软件包
sudo pacman -R package_name

# 删除软件包和依赖
sudo pacman -Rs package_name

# 删除软件包、依赖和配置文件
sudo pacman -Rns package_name

# 清理缓存
sudo pacman -Sc

# 清理所有缓存
sudo pacman -Scc
```

## Snap

Snap 是 Ubuntu 开发的通用软件包格式：

```bash
# 安装 snap
sudo apt install snapd

# 搜索软件包
snap find package_name

# 安装软件包
sudo snap install package_name

# 列出已安装的软件包
snap list

# 更新软件包
sudo snap refresh package_name

# 删除软件包
sudo snap remove package_name

# 查看软件包信息
snap info package_name
```

## Flatpak

Flatpak 是另一种通用软件包格式：

```bash
# 安装 flatpak
sudo apt install flatpak

# 添加 Flathub 仓库
flatpak remote-add --if-not-exists flathub https://flathub.org/repo/flathub.flatpakrepo

# 搜索软件包
flatpak search package_name

# 安装软件包
flatpak install flathub package_name

# 列出已安装的软件包
flatpak list

# 更新软件包
flatpak update package_name

# 删除软件包
flatpak uninstall package_name
```

## 源码编译安装

### 基本步骤

```bash
# 1. 下载源码
wget https://example.com/package.tar.gz

# 2. 解压源码
tar -xzf package.tar.gz

# 3. 进入源码目录
cd package

# 4. 配置编译选项
./configure --prefix=/usr/local

# 5. 编译
make

# 6. 安装
sudo make install

# 7. 清理
make clean
```

### CMake 编译

```bash
# 创建构建目录
mkdir build && cd build

# 配置
cmake ..

# 编译
make

# 安装
sudo make install
```

### 常见依赖

```bash
# Ubuntu/Debian 安装编译工具
sudo apt install build-essential

# 安装开发库
sudo apt install libssl-dev
sudo apt install libcurl4-openssl-dev
```

## 常见问题

### 1. 依赖问题

```bash
# APT 修复依赖
sudo apt --fix-broken install

# YUM 修复依赖
sudo yum check
```

### 2. 锁定问题

```bash
# 删除 apt 锁
sudo rm /var/lib/dpkg/lock-frontend
sudo rm /var/lib/dpkg/lock
sudo rm /var/cache/apt/archives/lock

# 重新配置 dpkg
sudo dpkg --configure -a
```

### 3. 软件源问题

```bash
# 更换软件源
sudo sed -i 's/archive.ubuntu.com/mirrors.aliyun.com/g' /etc/apt/sources.list

# 更新软件源
sudo apt update
```
