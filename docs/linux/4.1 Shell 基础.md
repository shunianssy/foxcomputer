# Shell 基础

## Shell 脚本概述

Shell 脚本是一系列命令的集合，可以自动化执行重复性任务。Shell 脚本通常以 .sh 为扩展名。

## 第一个脚本

### 创建脚本文件

```bash
# 创建脚本文件
vim hello.sh
```

脚本内容：

```bash
#!/bin/bash
# 这是一个简单的 Shell 脚本

echo "Hello, Linux!"
echo "当前用户：$USER"
echo "当前目录：$(pwd)"
```

### 执行脚本

```bash
# 添加执行权限
chmod +x hello.sh

# 执行脚本
./hello.sh

# 或使用解释器执行
bash hello.sh
```

## Shebang

脚本第一行的 #!/bin/bash 称为 Shebang，指定脚本的解释器：

```bash
#!/bin/bash       # 使用 Bash
#!/bin/sh         # 使用 sh
#!/usr/bin/env bash  # 使用 env 查找 bash
```

## 变量

### 定义变量

```bash
# 定义变量（等号两边不能有空格）
name="Linux"
version=22.04

# 使用变量
echo $name
echo ${version}

# 只读变量
readonly PI=3.14159

# 删除变量
unset name
```

### 变量类型

```bash
# 字符串
str="Hello World"

# 数字
num=100

# 数组
arr=(1 2 3 4 5)

# 关联数组
declare -A user
user[name]="Tom"
user[age]=25
```

### 特殊变量

| 变量 | 说明 |
|------|------|
| $0 | 脚本名称 |
| $1-$n | 位置参数 |
| $# | 参数个数 |
| $@ | 所有参数（作为独立字符串） |
| $* | 所有参数（作为单个字符串） |
| $? | 上一个命令的退出状态 |
| $$ | 当前进程 PID |
| $! | 后台进程 PID |
| $USER | 当前用户名 |
| $HOME | 用户主目录 |
| $PWD | 当前工作目录 |

### 环境变量

```bash
# 查看所有环境变量
env

# 查看特定环境变量
echo $PATH

# 设置环境变量
export MY_VAR="value"

# 在脚本中使用
echo $MY_VAR
```

## 字符串操作

### 字符串定义

```bash
# 单引号（原样输出）
str1='Hello $name'

# 双引号（解析变量）
str2="Hello $name"

# 反引号（命令替换）
str3=`date`
```

### 字符串操作

```bash
# 获取字符串长度
str="Hello"
echo ${#str}

# 提取子字符串
echo ${str:0:3}    # 输出 Hel

# 查找子字符串
str="Hello World"
echo ${str#Hello}   # 删除开头匹配
echo ${str%World}   # 删除结尾匹配

# 替换字符串
echo ${str/World/Linux}  # 替换第一个
echo ${str//o/O}         # 替换所有

# 字符串拼接
str1="Hello"
str2="World"
str3="${str1} ${str2}"
```

## 数组操作

### 定义数组

```bash
# 定义数组
arr=(1 2 3 4 5)

# 定义空数组
arr=()

# 添加元素
arr+=(6 7)

# 定义关联数组
declare -A user
user[name]="Tom"
user[age]=25
```

### 访问数组

```bash
# 访问元素
echo ${arr[0]}

# 访问所有元素
echo ${arr[@]}
echo ${arr[*]}

# 获取数组长度
echo ${#arr[@]}

# 获取索引
echo ${!arr[@]}

# 切片
echo ${arr[@]:1:3}
```

### 遍历数组

```bash
# 遍历数组
for item in ${arr[@]}; do
    echo $item
done

# 遍历关联数组
for key in ${!user[@]}; do
    echo "$key: ${user[$key]}"
done
```

## 运算符

### 算术运算

```bash
# 使用 $(( ))
a=10
b=3
echo $((a + b))    # 加法
echo $((a - b))    # 减法
echo $((a * b))    # 乘法
echo $((a / b))    # 除法
echo $((a % b))    # 取余
echo $((a ** b))   # 幂运算

# 使用 expr
expr $a + $b

# 使用 let
let c=a+b
```

### 比较运算

```bash
# 数字比较
-eq  # 等于
-ne  # 不等于
-gt  # 大于
-lt  # 小于
-ge  # 大于等于
-le  # 小于等于

# 示例
if [ $a -eq $b ]; then
    echo "相等"
fi
```

### 字符串比较

```bash
# 字符串比较
=   # 等于
!=  # 不等于
-z  # 长度为零
-n  # 长度不为零

# 示例
if [ "$str1" = "$str2" ]; then
    echo "字符串相等"
fi
```

### 文件测试

```bash
# 文件测试
-e  # 文件存在
-f  # 是普通文件
-d  # 是目录
-r  # 可读
-w  # 可写
-x  # 可执行
-s  # 文件不为空

# 示例
if [ -f "/etc/passwd" ]; then
    echo "文件存在"
fi
```

### 逻辑运算

```bash
# 逻辑运算
&&  # 逻辑与
||  # 逻辑或
!   # 逻辑非

# 示例
if [ $a -gt 0 ] && [ $a -lt 10 ]; then
    echo "a 在 0 到 10 之间"
fi
```

## 输入输出

### echo 命令

```bash
# 输出文本
echo "Hello World"

# 不换行
echo -n "Hello"
echo " World"

# 解析转义字符
echo -e "Hello\nWorld"

# 输出到文件
echo "content" > file.txt

# 追加到文件
echo "content" >> file.txt
```

### printf 命令

```bash
# 格式化输出
printf "Name: %s\n" "Tom"
printf "Age: %d\n" 25
printf "Price: %.2f\n" 19.99

# 格式说明符
# %s：字符串
# %d：整数
# %f：浮点数
# %x：十六进制
# %o：八进制
```

### read 命令

```bash
# 读取用户输入
echo "请输入名字："
read name
echo "你好，$name"

# 带提示的输入
read -p "请输入年龄：" age

# 静默输入（密码）
read -s -p "请输入密码：" password

# 限时输入
read -t 10 -p "请在10秒内输入：" input

# 读取多个值
read -p "输入姓名和年龄：" name age
```

## 命令替换

```bash
# 使用 $()
current_dir=$(pwd)
echo "当前目录：$current_dir"

# 使用反引号
files=`ls`
echo "文件列表：$files"

# 嵌套命令替换
result=$(echo $(date +%Y-%m-%d))
```

## 注释

```bash
# 单行注释
# 这是一个注释

: '
多行注释
可以写很多内容
'

# 函数注释
# @description: 这是一个函数
# @param: $1 - 参数1
# @return: 返回值
function my_func() {
    echo "Hello"
}
```

## 调试脚本

### 调试选项

```bash
# 显示执行的命令
bash -x script.sh

# 显示读取的命令
bash -v script.sh

# 检查语法错误
bash -n script.sh
```

### 在脚本中启用调试

```bash
#!/bin/bash

# 启用调试
set -x

# 禁用调试
set +x

# 遇到错误退出
set -e

# 使用未定义变量时报错
set -u

# 管道失败时退出
set -o pipefail
```

## 实践练习

### 练习 1：基本变量

```bash
#!/bin/bash
# 创建变量脚本

name="Linux"
version=22.04

echo "系统名称：$name"
echo "版本号：${version}"
echo "脚本名称：$0"
echo "参数个数：$#"
```

### 练习 2：字符串操作

```bash
#!/bin/bash
# 字符串操作脚本

str="Hello World"

echo "字符串长度：${#str}"
echo "提取子串：${str:0:5}"
echo "替换字符串：${str/World/Linux}"
```

### 练习 3：数组操作

```bash
#!/bin/bash
# 数组操作脚本

arr=(apple banana cherry)

echo "第一个元素：${arr[0]}"
echo "所有元素：${arr[@]}"
echo "数组长度：${#arr[@]}"

for fruit in ${arr[@]}; do
    echo "水果：$fruit"
done
```
