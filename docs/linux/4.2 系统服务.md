# 系统服务

## systemd 概述

systemd 是现代 Linux 系统的初始化系统和服务管理器，用于启动和管理系统服务。

### systemd 组件

- systemctl：服务管理命令
- journalctl：日志管理命令
- systemd-analyze：启动分析工具
- hostnamectl：主机名管理
- timedatectl：时间日期管理
- localectl：区域设置管理

## systemctl 命令

### 服务管理

```bash
# 启动服务
sudo systemctl start service_name

# 停止服务
sudo systemctl stop service_name

# 重启服务
sudo systemctl restart service_name

# 重新加载配置
sudo systemctl reload service_name

# 查看服务状态
systemctl status service_name

# 查看服务是否运行
systemctl is-active service_name

# 查看服务是否启用
systemctl is-enabled service_name
```

### 服务自启动

```bash
# 启用服务开机自启
sudo systemctl enable service_name

# 禁用服务开机自启
sudo systemctl disable service_name

# 启用并立即启动
sudo systemctl enable --now service_name

# 禁用并立即停止
sudo systemctl disable --now service_name
```

### 查看服务

```bash
# 列出所有服务
systemctl list-units --type=service

# 列出运行中的服务
systemctl list-units --type=service --state=running

# 列出所有已启用的服务
systemctl list-unit-files --type=service --state=enabled

# 列出失败的服务
systemctl list-units --type=service --state=failed

# 查看服务依赖
systemctl list-dependencies service_name
```

### 系统管理

```bash
# 重启系统
sudo systemctl reboot

# 关机
sudo systemctl poweroff

# 挂起
sudo systemctl suspend

# 休眠
sudo systemctl hibernate

# 救援模式
sudo systemctl rescue

# 紧急模式
sudo systemctl emergency
```

## 服务配置文件

### 服务文件位置

- /etc/systemd/system/：系统管理员创建的服务
- /usr/lib/systemd/system/：软件包安装的服务
- /lib/systemd/system/：系统默认服务

### 服务文件结构

```ini
[Unit]
Description=服务描述
Documentation=文档链接
After=network.target    # 在网络启动后启动
Wants=network.target    # 依赖网络服务
Requires=another.service  # 强依赖

[Service]
Type=simple             # 服务类型
ExecStart=/usr/bin/command  # 启动命令
ExecStop=/usr/bin/command   # 停止命令
ExecReload=/usr/bin/command # 重载命令
Restart=on-failure      # 重启策略
RestartSec=5s           # 重启间隔
User=username           # 运行用户
Group=groupname         # 运行用户组
WorkingDirectory=/path  # 工作目录
Environment="VAR=value" # 环境变量

[Install]
WantedBy=multi-user.target  # 安装目标
```

### 服务类型

| 类型 | 说明 |
|------|------|
| simple | 默认类型，ExecStart 启动的进程是主进程 |
| forking | ExecStart 启动的进程会 fork 子进程，父进程退出 |
| oneshot | 一次性任务，执行完毕后进程退出 |
| notify | 服务启动完成后发送通知 |
| dbus | 服务需要获取 D-Bus 名称 |

### 重启策略

| 策略 | 说明 |
|------|------|
| no | 不重启（默认） |
| on-success | 成功退出时重启 |
| on-failure | 失败退出时重启 |
| on-abnormal | 异常退出时重启 |
| on-watchdog | 看门狗超时时重启 |
| always | 总是重启 |

## 创建自定义服务

### 创建服务文件

```bash
# 创建服务文件
sudo vim /etc/systemd/system/myapp.service
```

服务文件示例：

```ini
[Unit]
Description=My Application
After=network.target

[Service]
Type=simple
User=myuser
Group=myuser
WorkingDirectory=/opt/myapp
ExecStart=/usr/bin/python3 /opt/myapp/app.py
Restart=on-failure
RestartSec=5s
Environment="PATH=/usr/local/bin:/usr/bin"

[Install]
WantedBy=multi-user.target
```

### 启用服务

```bash
# 重新加载 systemd 配置
sudo systemctl daemon-reload

# 启用服务
sudo systemctl enable myapp

# 启动服务
sudo systemctl start myapp

# 查看状态
systemctl status myapp
```

## 日志管理

### journalctl 命令

```bash
# 查看所有日志
journalctl

# 查看特定服务的日志
journalctl -u service_name

# 查看最近的日志
journalctl -n 100

# 实时查看日志
journalctl -f

# 查看今天的日志
journalctl --since today

# 查看指定时间范围的日志
journalctl --since "2024-02-01" --until "2024-02-23"

# 查看内核日志
journalctl -k

# 查看特定优先级的日志
journalctl -p err

# 查看特定用户的日志
journalctl _UID=1000

# 输出到文件
journalctl > log.txt
```

### 日志优先级

| 优先级 | 说明 |
|--------|------|
| 0 | emerg：紧急 |
| 1 | alert：警报 |
| 2 | crit：严重 |
| 3 | err：错误 |
| 4 | warning：警告 |
| 5 | notice：通知 |
| 6 | info：信息 |
| 7 | debug：调试 |

### 日志配置

编辑 /etc/systemd/journald.conf：

```ini
[Journal]
Storage=auto          # 日志存储方式
Compress=yes          # 压缩日志
Seal=yes              # 密封日志
RateLimitInterval=30s # 速率限制间隔
RateLimitBurst=1000   # 速率限制突发
SystemMaxUse=1G       # 最大使用空间
SystemMaxFileSize=100M # 单个文件最大大小
MaxRetentionSec=1month # 最大保留时间
```

重启日志服务：

```bash
sudo systemctl restart systemd-journald
```

## 定时任务

### systemd timer

创建定时器服务：

```bash
# 创建服务文件
sudo vim /etc/systemd/system/backup.service
```

服务文件：

```ini
[Unit]
Description=Backup Service

[Service]
Type=oneshot
ExecStart=/usr/local/bin/backup.sh
```

创建定时器文件：

```bash
# 创建定时器文件
sudo vim /etc/systemd/system/backup.timer
```

定时器文件：

```ini
[Unit]
Description=Backup Timer

[Timer]
OnCalendar=daily        # 每天执行
OnCalendar=*-*-* 02:00:00  # 每天凌晨2点
OnCalendar=weekly       # 每周执行
OnCalendar=monthly      # 每月执行
Persistent=true         # 错过执行时补执行

[Install]
WantedBy=timers.target
```

启用定时器：

```bash
# 重新加载配置
sudo systemctl daemon-reload

# 启用定时器
sudo systemctl enable backup.timer

# 启动定时器
sudo systemctl start backup.timer

# 查看定时器列表
systemctl list-timers
```

### cron 定时任务

```bash
# 编辑定时任务
crontab -e

# 查看定时任务
crontab -l

# 删除定时任务
crontab -r
```

cron 表达式：

```
* * * * * command
│ │ │ │ │
│ │ │ │ └─ 星期几（0-7，0和7都是周日）
│ │ │ └─── 月份（1-12）
│ │ └───── 日期（1-31）
│ └─────── 小时（0-23）
└───────── 分钟（0-59）
```

示例：

```bash
# 每天凌晨2点执行
0 2 * * * /usr/local/bin/backup.sh

# 每小时执行
0 * * * * /usr/local/bin/check.sh

# 每5分钟执行
*/5 * * * * /usr/local/bin/monitor.sh

# 每周一早上8点执行
0 8 * * 1 /usr/local/bin/weekly.sh
```

## 故障排查

### 服务启动失败

```bash
# 查看服务状态
systemctl status service_name

# 查看详细日志
journalctl -xeu service_name

# 检查服务配置
systemd-analyze verify /etc/systemd/system/service_name.service
```

### 日志问题

```bash
# 检查日志服务状态
systemctl status systemd-journald

# 检查日志存储
journalctl --disk-usage

# 清理日志
sudo journalctl --vacuum-size=100M
```
