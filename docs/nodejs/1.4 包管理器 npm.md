# 1.4 包管理器 npm

npm（Node Package Manager）是 Node.js 的默认包管理器，也是世界上最大的软件注册表。本节将详细介绍 npm 的使用方法。

## npm 简介

### 什么是 npm？

npm 包含三个主要部分：

1. **网站**：https://www.npmjs.com/ - 查找和发现包
2. **注册表**：存储 JavaScript 包的大型数据库
3. **命令行工具**：用于安装和管理包

### 查看 npm 信息

```bash
# 查看 npm 版本
npm --version
# 或简写
npm -v

# 查看 npm 配置
npm config list

# 查看详细配置
npm config list -l

# 查看 npm 安装路径
npm root -g
```

## package.json 文件

### 创建 package.json

```bash
# 交互式创建
npm init

# 快速创建（使用默认值）
npm init -y

# 使用自定义默认值
npm config set init.author.name "你的名字"
npm config set init.author.email "your@email.com"
npm config set init.license "MIT"
npm init -y
```

### package.json 结构详解

```json
{
    "name": "my-project",
    "version": "1.0.0",
    "description": "项目描述",
    "main": "index.js",
    "scripts": {
        "start": "node index.js",
        "dev": "nodemon index.js",
        "test": "jest",
        "build": "webpack --mode production"
    },
    "keywords": ["nodejs", "express"],
    "author": "Your Name <your@email.com>",
    "license": "MIT",
    "dependencies": {
        "express": "^4.18.2"
    },
    "devDependencies": {
        "nodemon": "^3.0.1",
        "jest": "^29.7.0"
    },
    "engines": {
        "node": ">=18.0.0",
        "npm": ">=9.0.0"
    },
    "repository": {
        "type": "git",
        "url": "https://github.com/user/repo.git"
    },
    "bugs": {
        "url": "https://github.com/user/repo/issues"
    },
    "homepage": "https://github.com/user/repo#readme"
}
```

### 版本号规则（语义化版本）

版本号格式：`主版本号.次版本号.修订号`

| 符号 | 含义 | 示例 |
|------|------|------|
| `^` | 兼容次版本更新 | `^1.2.3` => `>=1.2.3 <2.0.0` |
| `~` | 兼容修订版本更新 | `~1.2.3` => `>=1.2.3 <1.3.0` |
| `>` | 大于指定版本 | `>1.2.3` |
| `>=` | 大于等于 | `>=1.2.3` |
| `<` | 小于 | `<1.2.3` |
| `<=` | 小于等于 | `<=1.2.3` |
| `=` | 精确匹配 | `=1.2.3` |
| `*` | 任意版本 | `*` |
| `latest` | 最新版本 | `latest` |

## 安装包

### 本地安装

```bash
# 安装包（添加到 dependencies）
npm install express
npm i express

# 安装指定版本
npm i express@4.18.0

# 安装开发依赖（添加到 devDependencies）
npm i --save-dev nodemon
npm i -D nodemon

# 安装生产依赖（添加到 dependencies）
npm i --save express
npm i -S express

# 安装精确版本（不使用 ^ 前缀）
npm i --save-exact express
npm i -E express
```

### 全局安装

```bash
# 全局安装（命令行工具通常全局安装）
npm install -g nodemon
npm i -g nodemon

# 查看全局安装的包
npm list -g --depth=0

# 全局安装路径
npm root -g
```

### 批量安装

```bash
# 根据 package.json 安装所有依赖
npm install

# 只安装生产依赖（排除 devDependencies）
npm install --production

# 安装时忽略 package-lock.json
npm install --no-package-lock
```

## 卸载和更新包

### 卸载包

```bash
# 卸载本地包
npm uninstall express
npm un express
npm remove express
npm rm express

# 卸载开发依赖
npm un -D nodemon

# 卸载全局包
npm un -g nodemon
```

### 更新包

```bash
# 检查可更新的包
npm outdated

# 更新包到符合版本范围的最新版本
npm update
npm up

# 更新指定包
npm update express

# 更新全局包
npm update -g

# 更新到最新版本（可能超出 package.json 中的版本范围）
npm install express@latest
```

## npm scripts

### 常用脚本命令

```json
{
    "scripts": {
        "start": "node index.js",
        "dev": "nodemon index.js",
        "test": "jest",
        "build": "webpack --mode production",
        "lint": "eslint src/",
        "format": "prettier --write .",
        "clean": "rm -rf dist/",
        "prebuild": "npm run clean",
        "postbuild": "echo 构建完成"
    }
}
```

### 运行脚本

```bash
# 运行 start 脚本（可省略 run）
npm start

# 运行其他脚本（需要 run）
npm run dev
npm run build
npm run test

# 传递参数
npm run dev -- --port 8080

# 并行运行脚本
npm run dev & npm run lint

# 串行运行脚本
npm run lint && npm run test && npm run build
```

### 生命周期钩子

```json
{
    "scripts": {
        "prestart": "echo 启动前执行",
        "start": "node index.js",
        "poststart": "echo 启动后执行",
        "prebuild": "npm run clean",
        "build": "webpack",
        "postbuild": "echo 构建完成"
    }
}
```

## package-lock.json

### 作用

`package-lock.json` 文件用于锁定依赖版本：

1. 记录实际安装的每个包的精确版本
2. 确保团队成员安装相同版本的依赖
3. 加快 npm install 速度

### 示例

```json
{
    "name": "my-project",
    "version": "1.0.0",
    "lockfileVersion": 3,
    "requires": true,
    "packages": {
        "": {
            "name": "my-project",
            "version": "1.0.0",
            "dependencies": {
                "express": "^4.18.2"
            }
        },
        "node_modules/express": {
            "version": "4.18.2",
            "resolved": "https://registry.npmjs.org/express/-/express-4.18.2.tgz",
            "integrity": "sha512-...",
            "dependencies": {
                "body-parser": "1.20.1",
                "cookie": "0.5.0"
            }
        }
    }
}
```

## npx 命令

npx 是 npm 5.2+ 自带的包执行器：

```bash
# 执行本地安装的包
npx nodemon

# 执行未安装的包（临时下载执行）
npx create-react-app my-app
npx @vue/cli create my-project

# 使用特定版本
npx package@version

# 使用不同注册表
npx --registry https://registry.npmmirror.com package
```

## .npmrc 配置文件

### 配置文件位置

| 文件位置 | 作用范围 |
|----------|----------|
| `/path/to/project/.npmrc` | 项目级别 |
| `~/.npmrc` | 用户级别 |
| `$PREFIX/etc/npmrc` | 全局级别 |
| `/path/to/npm/.npmrc` | npm 内置 |

### 配置示例

```ini
# .npmrc 文件示例

# 设置注册表
registry=https://registry.npmmirror.com

# 设置代理
proxy=http://proxy.example.com:8080
https-proxy=http://proxy.example.com:8080

# 认证信息
//registry.npmjs.org/:_authToken=your-token

# 作用域包的注册表
@mycompany:registry=https://npm.mycompany.com

# 忽略 SSL 验证（不推荐生产使用）
strict-ssl=false

# 设置缓存目录
cache=/path/to/cache

# 设置全局安装目录
prefix=/path/to/global
```

## 最佳实践

### 1. 使用语义化版本

```json
{
    "dependencies": {
        "express": "^4.18.0",
        "lodash": "~4.17.21",
        "uuid": "9.0.0"
    }
}
```

### 2. 区分依赖类型

```json
{
    "dependencies": {
        "express": "^4.18.2",
        "mongoose": "^8.0.0"
    },
    "devDependencies": {
        "nodemon": "^3.0.1",
        "jest": "^29.7.0",
        "eslint": "^8.55.0"
    }
}
```

### 3. 锁定版本

```bash
# 提交 package-lock.json 到版本控制
git add package-lock.json
git commit -m "锁定依赖版本"
```

### 4. 定期更新依赖

```bash
# 检查过时的包
npm outdated

# 安全审计
npm audit

# 自动修复安全漏洞
npm audit fix

# 强制修复（可能有破坏性变更）
npm audit fix --force
```

### 5. 使用 .npmignore

```text
# .npmignore - 发布时忽略的文件
tests/
docs/
examples/
.git/
.github/
.eslintrc
.prettierrc
*.test.js
*.spec.js
```

## 小结

npm 核心知识点：

1. **package.json**：项目配置文件，定义依赖和脚本
2. **依赖管理**：区分 dependencies 和 devDependencies
3. **版本控制**：理解语义化版本和版本范围
4. **npm scripts**：自动化构建和开发流程
5. **package-lock.json**：锁定依赖版本，确保一致性

> **提示**：建议定期运行 `npm audit` 检查安全漏洞，并使用 `npm outdated` 检查可更新的包。在生产环境部署前，确保测试所有依赖更新。
