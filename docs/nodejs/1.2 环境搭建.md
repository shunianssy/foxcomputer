# 1.2 环境搭建

本节将详细介绍如何在 Windows、macOS 和 Linux 系统上安装和配置 Node.js 开发环境。

## 安装 Node.js

### Windows 系统安装

#### 方法一：官方安装包（推荐）

1. 访问 Node.js 官网：https://nodejs.org/
2. 下载 LTS（长期支持版）安装包
3. 运行安装程序，按照向导完成安装
4. 验证安装：

```powershell
# 打开 PowerShell 或命令提示符
node --version
# 输出示例: v20.10.0

npm --version
# 输出示例: 10.2.3
```

#### 方法二：使用 nvm-windows（推荐用于多版本管理）

```powershell
# 1. 下载并安装 nvm-windows
# https://github.com/coreybutler/nvm-windows/releases

# 2. 安装完成后，打开新的 PowerShell 窗口

# 查看可用的 Node.js 版本
nvm list available

# 安装指定版本
nvm install 20.10.0

# 安装最新 LTS 版本
nvm install lts

# 切换使用指定版本
nvm use 20.10.0

# 查看当前使用的版本
nvm current

# 列出已安装的所有版本
nvm list
```

### macOS 系统安装

#### 方法一：使用 Homebrew（推荐）

```bash
# 安装 Homebrew（如果尚未安装）
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 安装 Node.js
brew install node

# 验证安装
node --version
npm --version
```

#### 方法二：使用 nvm

```bash
# 安装 nvm
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash

# 重新加载终端配置
source ~/.zshrc  # 或 source ~/.bashrc

# 安装 Node.js
nvm install --lts

# 使用指定版本
nvm use --lts

# 验证安装
node --version
```

### Linux 系统安装

#### Ubuntu/Debian

```bash
# 方法一：使用 NodeSource 仓库（推荐）
# 添加 Node.js 20.x 仓库
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -

# 安装 Node.js
sudo apt-get install -y nodejs

# 验证安装
node --version
npm --version
```

#### CentOS/RHEL

```bash
# 添加 NodeSource 仓库
curl -fsSL https://rpm.nodesource.com/setup_20.x | sudo bash -

# 安装 Node.js
sudo yum install -y nodejs

# 验证安装
node --version
```

## 配置 npm

### 设置 npm 镜像源

由于网络原因，建议配置国内镜像源：

```bash
# 设置淘宝镜像源
npm config set registry https://registry.npmmirror.com

# 验证配置
npm config get registry

# 恢复官方源
npm config set registry https://registry.npmjs.org
```

### 配置 npm 全局安装路径（Windows）

```powershell
# 创建全局包安装目录
mkdir "C:\nodejs\npm_global"
mkdir "C:\nodejs\npm_cache"

# 设置全局安装路径
npm config set prefix "C:\nodejs\npm_global"
npm config set cache "C:\nodejs\npm_cache"

# 添加到系统环境变量 PATH
# 将 C:\nodejs\npm_global 添加到系统 PATH
```

### 创建 npm 配置文件

```bash
# 在用户目录下创建 .npmrc 文件
# Windows: C:\Users\你的用户名\.npmrc
# macOS/Linux: ~/.npmrc

# .npmrc 文件内容示例
registry=https://registry.npmmirror.com
prefix=C:\nodejs\npm_global
cache=C:\nodejs\npm_cache
```

## 开发工具推荐

### VS Code（推荐）

Visual Studio Code 是最流行的 Node.js 开发编辑器：

1. 下载地址：https://code.visualstudio.com/
2. 安装 Node.js 扩展：

```json
// 推荐安装的扩展
[
    "ESLint",                    // 代码检查
    "Prettier",                  // 代码格式化
    "Node.js Tools",             // Node.js 工具
    "npm Intellisense",          // npm 包自动补全
    "Path Intellisense",         // 路径自动补全
    "Thunder Client",            // API 测试工具
    "GitLens",                   // Git 增强
    "DotENV"                     // 环境变量支持
]
```

### VS Code 配置

```json
// settings.json 配置示例
{
    "editor.formatOnSave": true,
    "editor.defaultFormatter": "esbenp.prettier-vscode",

```

## 验证开发环境

### 创建测试项目

```bash
# 创建项目目录
mkdir nodejs-test
cd nodejs-test

# 初始化项目
npm init -y

# 创建测试文件
```

```javascript
// test.js - 测试 Node.js 环境
console.log('Node.js 版本:', process.version);
console.log('运行平台:', process.platform);
console.log('系统架构:', process.arch);
console.log('当前目录:', process.cwd());

// 测试 ES6+ 语法支持
const greet = (name) => `Hello, ${name}!`;
console.log(greet('Node.js'));

// 测试异步操作
Promise.resolve('异步操作正常')
    .then(msg => console.log(msg));

// 测试模块系统
const os = require('os');
console.log('系统内存:', Math.round(os.totalmem() / 1024 / 1024 / 1024), 'GB');
console.log('CPU 核心:', os.cpus().length);
```

```bash
# 运行测试
node test.js
```

### 检查环境配置

```javascript
// check-env.js - 检查开发环境
const execSync = require('child_process').execSync;

function checkCommand(cmd) {
    try {
        const version = execSync(`${cmd} --version`, { encoding: 'utf-8' }).trim();
        console.log(`${cmd}: ${version}`);
        return true;
    } catch (error) {
        console.log(`${cmd}: 未安装`);
        return false;
    }
}

console.log('=== 环境检查 ===');
checkCommand('node');
checkCommand('npm');
checkCommand('npx');
checkCommand('git');

console.log('\n=== npm 配置 ===');
console.log('registry:', execSync('npm config get registry', { encoding: 'utf-8' }).trim());
console.log('prefix:', execSync('npm config get prefix', { encoding: 'utf-8' }).trim());
```

## 常见问题解决

### 问题1：node 不是内部或外部命令

```powershell
# 检查 Node.js 是否在 PATH 中
where node

# 如果找不到，手动添加到环境变量
# 1. 右键"此电脑" -> 属性 -> 高级系统设置
# 2. 环境变量 -> 系统变量 -> Path -> 编辑
# 3. 添加 Node.js 安装路径，如: C:\Program Files\nodejs\
```

### 问题2：npm 安装包很慢

```bash
# 切换到国内镜像源
npm config set registry https://registry.npmmirror.com

# 或者使用 cnpm
npm install -g cnpm --registry=https://registry.npmmirror.com

# 使用 cnpm 代替 npm
cnpm install express
```

### 问题3：权限问题（macOS/Linux）

```bash
# 避免使用 sudo 安装全局包
# 方法：修改 npm 默认目录
mkdir ~/.npm-global
npm config set prefix '~/.npm-global'

# 添加到 PATH（在 ~/.bashrc 或 ~/.zshrc 中添加）
export PATH=~/.npm-global/bin:$PATH

# 重新加载配置
source ~/.bashrc  # 或 source ~/.zshrc
```

### 问题4：清除 npm 缓存

```bash
# 清除 npm 缓存
npm cache clean --force

# 验证缓存状态
npm cache verify
```

## 小结

环境搭建步骤总结：

1. **安装 Node.js**：推荐使用 LTS 版本
2. **配置 npm**：设置镜像源和全局路径
3. **安装开发工具**：VS Code + 必要扩展
4. **验证环境**：运行测试代码确认一切正常

> **提示**：建议使用 nvm（或 nvm-windows）来管理 Node.js 版本，这样可以在不同项目间轻松切换 Node.js 版本，避免版本冲突问题。
