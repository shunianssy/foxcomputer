# 8.3 单元测试

单元测试是保证代码质量的重要手段。本节将介绍使用 Jest 进行单元测试。

## 安装配置

### 安装 Jest

```bash
npm install -D jest
```

### 配置 package.json

```json
{
    "scripts": {
        "test": "jest",
        "test:watch": "jest --watch",
        "test:coverage": "jest --coverage"
    }
}
```

### Jest 配置文件

```javascript
// jest.config.js
module.exports = {
    testEnvironment: 'node',
    testMatch: ['**/*.test.js'],
    collectCoverageFrom: [
        'src/**/*.js',
        '!src/**/*.test.js'
    ],
    coverageDirectory: 'coverage',
    coverageReporters: ['text', 'lcov', 'html']
};
```

## 基本测试

### 简单测试

```javascript
// math.js
function add(a, b) {
    return a + b;
}

function subtract(a, b) {
    return a - b;
}

module.exports = { add, subtract };

// math.test.js
const { add, subtract } = require('./math');

describe('Math functions', () => {
    test('add should return sum of two numbers', () => {
        expect(add(1, 2)).toBe(3);
        expect(add(-1, 1)).toBe(0);
    });
    
    test('subtract should return difference', () => {
        expect(subtract(5, 3)).toBe(2);
        expect(subtract(1, 1)).toBe(0);
    });
});
```

### 匹配器

```javascript
// 相等性
expect(value).toBe(3);
expect(value).toEqual({ name: '张三' });

// 真值
expect(value).toBeTruthy();
expect(value).toBeFalsy();
expect(value).toBeNull();
expect(value).toBeUndefined();
expect(value).toBeDefined();

// 数字
expect(value).toBeGreaterThan(3);
expect(value).toBeLessThan(5);
expect(value).toBeCloseTo(0.3);

// 字符串
expect(value).toMatch(/pattern/);
expect(value).toContain('substring');

// 数组
expect(array).toContain(item);
expect(array).toHaveLength(3);

// 异常
expect(() => fn()).toThrow();
expect(() => fn()).toThrow(Error);

// 异步
await expect(promise).resolves.toBe(value);
await expect(promise).rejects.toThrow();
```

## 异步测试

```javascript
// Promise
test('async function', async () => {
    const data = await fetchData();
    expect(data).toBeDefined();
});

// 回调
test('callback function', (done) => {
    callbackFunction((result) => {
        expect(result).toBe('expected');
        done();
    });
});
```

## Mock

```javascript
// 模拟函数
const mockFn = jest.fn();
mockFn.mockReturnValue('value');
mockFn.mockResolvedValue('async value');

// 模拟模块
jest.mock('./api');
const api = require('./api');
api.getUsers.mockResolvedValue([{ id: 1 }]);

// 模拟定时器
jest.useFakeTimers();
jest.advanceTimersByTime(1000);
jest.useRealTimers();
```

## 测试覆盖率

```bash
npm run test:coverage
```

## 小结

本节学习了：

1. **Jest 配置**：安装、配置文件
2. **基本测试**：describe、test、expect
3. **匹配器**：各种断言方法
4. **异步测试**：Promise、回调
5. **Mock**：模拟函数和模块

> **提示**：单元测试应该测试代码的边界条件和异常情况。保持测试简单、独立、可重复。
